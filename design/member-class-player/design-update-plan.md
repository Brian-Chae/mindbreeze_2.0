## 0. 3안 공통 진단 (완전 일치)

회원 화면이 "썩 마음에 들지 않는" 원인은 세 가지로 수렴한다.

1. **순수 검정 `#060507` 배경** → 상담사 화면의 보라 틴트 레이어드 깊이감이 없어 평면적·건조.
2. **6지표가 평면 숫자 카드 3×2** → 선택 1개만 퍼플 하이라이트, 나머지 죽음. "살아있는 지표" 표현(다이얼·추이·증감)이 없음.
3. **상담사 화면과 디자인 언어 불일치** → 같은 제품의 회원/상담사 화면인데 이질감.

## 1. 통합 방향 (3안 일치 + Brian 보정)

**상담사 화면의 "보라 틴트 캔버스 + 아크 링 다이얼 + MIND/BODY 구분" 언어를 이식하되, 명상 몰입 맥락에 맞춰 밀도를 낮춘다.**

| 축 | 이식 | 회원 맥락 조정 |
|---|---|---|
| 캔버스 | `#12081C` 보라빛 다크 3단 서피스 | 정적 배경 (교차 페이드 제거) |
| 지표 | SVG 아크 링 + 중앙 숫자 + 단위 | **숫자·변화는 매초 실시간** (아래 §3) |
| 구분 | 마음 MIND / 몸 BODY | 본인 6지표만 (로스터·집계·순위 없음) |
| 비교 | 다이얼 틱·범위 밴드 | **그룹 평균 제거 → 본인 이전 구간 대비만** |
| 타이포 | 값 `font-weight:500` + `tabular-nums` + `letter-spacing:-1px` | 동일 (600→500 전환) |
| 간격·반경 | radius 12px, gap 8/10/12/16/20, 보더 `#ffffff1A` | 동일 |
| 모션 | 시트 `.25s ease-out` | 자동 순환·반복 점멸 제거 |

## 3. 데이터 표시 주기 — ⚠️ Brian 확정 보정 (기존 "25초 차분" 안 폐기)

3개 에이전트가 "25초 구간 평균으로 차분 표시"를 공통 제안했으나, **Brian이 아래와 같이 확정 보정했다. 25초 스로틀은 적용하지 않는다.**

| 항목 | 보정 내용 |
|---|---|
| **숫자(6지표 수치)** | **매초 실시간 갱신** — 1Hz `snapshot` 값 그대로 표시 |
| **변화량(증감)** | **매초 변화** — 직전 1초 대비 델타. "3분대비"·"25초 구간" 비교 문구 폐기 |
| **데스크톱 막대 그래프** | **지난 5분 데이터를 모두 표시** — 5분 전체 구간을 막대 그래프로 (매초 갱신 데이터 반영) |
| **모바일** | **현재 상태만 표시** — 막대 그래프(5분 추이) 없음, 현재 수치·다이얼만 |

### 3.1 지표 다이얼 처리 (여전히 분기점 — Brian 결정 필요)

| 안 | 제안 | 특징 |
|---|---|---|
| **Claude** | **히어로 1 + 서브 5** — 선택 지표만 84px 히어로 다이얼, 나머지 5개 44px 서브 다이얼 | 시선이 한 곳에 머묾. 비선택 카드 보더 제거(데스크톱). 자동 순환 없음. "나의 흐름" 패널 헤딩 |
| **Codex** | **균등 6다이얼 72px** (마음 3 + 몸 3, 각 3열) | 상담사 화면과 가장 유사. 다이얼 크기 균일, 선택은 경계·라벨만 강조 |
| **agy** | **MIND=다이얼(60px) / BODY=대형숫자+미니 스파크라인** — 지표군별 시각화 이원화 | 마음은 링, 몸은 수치+추이. 시각적 다양성 |

**취합 권고**: **Claude의 히어로 1 + 서브 5**를 기본 골격으로. 명상 중 시선 분산을 막는 "1개만 크게" 원칙이 회원 맥락(저밀도 몰입)에 가장 부합한다. (단, 값 소스는 §3 보정대로 **매초 실시간**.)

## 4. 레이아웃 (Zero-Scroll)

- **데스크톱 1280×720**: 좌(영상 ~1.5fr, 타이머 오버레이 + 진행 바) / 우(고정폭 지표 컬럼). **우측에 지난 5분 막대 그래프 포함.** 1화면 무스크롤.
- **모바일 390×844**: 탑바 → 영상 → 밴드 상태 → 마음·몸 다이얼(현재 수치) → 무음 시그널 → BGM 세로 스택. **막대 그래프 없음(현재 상태만).** 무스크롤.
- 우측 컬럼을 **반투명 검정(`#060507CC`) → 불투명 `#1D1027` 서피스**로 바꿔 영상 밝기에 따른 대비 흔들림 제거.
- 회귀 노출을 위해 `.player-right`의 `overflow-y:auto` 도피를 **`overflow:hidden`으로 전환**해 검증.

## 5. 요소별 개선 (3안 취합)

- **탑바**: 64px 고정, `← 종료` → **`← 나가기`**(Codex: 회원이 "클래스 전체 종료"로 오독할 수 있어). 2줄 헤딩(제목 + 부제). 채팅·스피커·화면끄기 우측 액션 그룹으로 이동.
- **영상+타이머**: radial 그라디언트 `#382047→#1b1025`. 타이머 = 보라 블러 글래스(`#12081CCC` + blur) + 진행 바 3px 라벤더. 아바타 호흡 4s 애니메이션 유지(명상 호흡 유도).
- **밴드 상태**: 1줄 통합 (점 + 상태문구 + 미연결 시 연결 버튼). 상태 8종 코드화(미사용/연결중/정상/원격수신/접촉불량/수신중단/AI분석중/미지원). "밴드 미사용"을 실패·경고로 표현하지 않음.
- **무음 시그널 3버튼**: pill 유지(유일한 "말 걸기" 액션), 고스트 필 `#ffffff06`. 전송 피드백 "전달했어요" 라벤더 페이드. 응답수·타인 상태·집계는 표시 안 함.
- **BGM 미니바**: 1줄 압축(아이콘+트랙명+재생중 민트점+볼륨). 상담사 음성 vs BGM 음량 구분(오프라인 기본 뮤트 보존).
- **채팅**: 탑바 아이콘+배지(안읽음 0이면 숨김), 우측 시트 `#21132b` `hcp-sheet` 동일 모션.
- **화면 끄기(몰입)**: 배경 `#12081C`, 타이머 24px/500. 끄는 중에도 오디오·수집·채팅 수신 유지.

## 6. Codex의 데이터 정합 경고 (다른 2안이 못 짚은 것)

1. **링버퍼 시간축 왜곡**: `seriesRef`는 유효 값만 저장하므로 결측이 있으면 300개 표본 ≠ 실제 5분. "최근 5분" 문구는 **연속 수신 확인 구간에서만** 사용. 결측 시 "최근 유효 데이터"로 전환.
2. **HRV 필드 불일치**: 회원은 `sdnn`, 호스트 경로는 `rmssd`. 시각 통일을 이유로 계산 정의·필드 교체 금지.
3. **BGM 미니바 실재 확인 필요**: `GuestMeditationPanel`에 BGM 미니바 직접 렌더링이 없고 `GuestAudioPanel` 사용처도 미확인 — 구현 전 실제 동기 재생 경로·노출을 확인.
4. **`%p` 표기**: 퍼센트 지표 차이는 `%p`로(상담사 화면의 "%" 혼용 방지).
5. **평가 문구 → 관찰 문구**: "천천히 낮아지는 중 · 안정" 같은 평가성 문구는 "이전보다 낮아졌어요" 식 서술로. 상승=성공/하락=실패 암시 금지.

## 7. 이식 함정 (공통)

- **데이터 계약 불변**: `useBand` / `useSessionLiveSocket` / `seriesRef`(MAX_POINTS=300) / `scoreIndices` / `averageMetricBuckets` / `METRICS` — 표현층(JSX+CSS)만 교체.
- **값 소스는 `snapshot`(1Hz) 그대로** — 숫자·변화량 모두 매초. 별도 25초 버킷 평균으로 지연시키지 않는다(Brian 확정). 단, **막대 그래프(데스크톱 5분)는 구간 평균으로 묶어** 표현한다(1초마다 300개 막대를 낱개로 그리지 않음).
- **SVG gradient id 충돌**: 다이얼 6개+막대가 같은 DOM → `useId()` 고유화(하드코딩 시 두 번째부터 아크 사라짐).
- **Tailwind 템플릿 리터럴 합성 금지**: `bg-[${token}]` 동적 합성은 JIT가 못 잡음. 신규 스타일은 전부 `member-class-player.css`로.
- **44px 터치타깃**: 서브 다이얼이 44px로 작아져도 **클릭 영역은 카드 전체**(min-height 56px 이상). 상담사 화면의 28~36px 압축 버튼은 회원 화면에 이식 금지.
- **`prefers-reduced-motion`**: `stroke-dasharray` 트랜지션·아바타 호흡·시트 슬라이드 전부 가드.
- **정본 선행**: `design/member-class-player/index.html`을 먼저 갱신 후 구현. 정본 방치 시 다음 루프에서 되돌아감.

## 8. 구현 우선순위

### P0 — 핵심 시각 개선 (이것만 해도 "마음에 든다" 도달)
- 보라 틴트 캔버스·서피스·보더·타이포 토큰 적용
- 마음/몸 6지표 다이얼 구조 (분기점 §3.1 확정 후)
- **숫자·변화량 매초 실시간 반영**
- 선택 카드 강한 퍼플 면 제거
- **데스크톱: 지난 5분 막대 그래프 전체 표시 / 모바일: 현재 상태만(그래프 제거)**
- 1280×720 / 390×844 무스크롤
- 영상·타이머·시그널·채팅·밴드 상태 위치 확정
- BGM 미니바 실제 연결·노출 확인 (§6-3)

### P1 — 지표 해석 정교화
- 데스크톱 지표별 작은 막대 추이 + 직전 1초 변화량
- 본인 표시 구간 범위 밴드
- `%p`·몸 지표 단위·"변화 없음" 문구
- 초기 수집·부분 결측·표시 축 초과 상태 표현
- 밴드·음량 팝오버 / 채팅 레이어 위치
- 평가 문구 → 관찰 문구 교체

### P2 — 마감·확장 환경
- 링 글로우·그라디언트·막대 대비 미세 조정
- 태블릿·짧은 데스크톱·가로 화면
- 긴 제목·큰 글자·고배율 확대
- 정본↔실화면 상태별 대응표 정리

## 9. 검수 완료 기준

| 항목 | 통과 기준 |
|---|---|
| 제품 일관성 | 상담사·회원 화면 나란히 봤을 때 캔버스·서피스·링·타이포·보더가 같은 체계 |
