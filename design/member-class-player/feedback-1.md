# 회원 클래스(명상) 진행 화면 — 루프 1 디자인 리뷰

- 대상: `design/member-class-player/index.html` (데스크탑 1280×720 + 모바일 390×844)
- 리뷰 기준: 정보 위계 / 간격·타이포 일관성 / 색 대비·가독성 / 막대 그래프 비율 / 모바일 반응형 / 한 화면 수렴
- 모든 지적은 실제 HTML/CSS 코드(행 번호 병기) 근거.

## P0 — 핵심 요구사항 미달 (반드시 수정)

### P0-1. "지금" 막대의 강조가 역전됨 — 그라디언트 하단 퍼플이 배경에 묻힘

- **문제**: 요구사항은 "마지막 막대 = 지금 강조(민트→퍼플 그라디언트)"인데, 현재 구현은 강조가 아니라 **오히려 흐려 보임**. 일반 막대는 `rgba(203,187,215,.60)`(61행 `.bars .bar`) — 어두운 배경 위에서 꽤 밝은 라벤더(합성 후 대비 약 4.5:1). 반면 `.bar.now`는 `linear-gradient(180deg,#01f0c8,#5F0080)`(61행)로, 상단 민트는 밝지만 **하단 절반의 #5F0080은 프레임 배경(#060507, 117행)과 대비가 약 1.7:1**이라 막대 아래쪽이 배경에 녹아 사라져 보인다. 높이 87%짜리 집중도 now 막대(217행)는 하단 40~50px이 거의 안 보이는 셈.
- **위치**: `.bars .bar.now`(61행), 프레임 배경 `.frame`(117행).
- **수정 제안**:
  - 그라디언트 하단 스톱을 가독 가능한 밝은 퍼플로: `linear-gradient(180deg, #01f0c8 0%, #a855f7 70%, #7b2a9e 100%)` 식으로 최저 밝기를 올리거나,
  - `#5F0080` 종점을 유지하려면 now 막대에 `box-shadow: 0 0 0 1px rgba(1,240,200,.45)` 또는 `outline` 형태의 민트 테두리/글로우를 더해 윤곽을 살릴 것.
  - 추가로 일반 막대를 반 톤 낮추면(예: `rgba(203,187,215,.42)`) now 막대와의 상대 강조가 복원된다.

### P0-2. 데스크탑 720px 수직 예산이 여유 ~17px — 한 화면 수렴이 사실상 경계선

- **문제**: 데스크탑 우측 컬럼 고정 요소의 합이 거의 프레임 높이를 다 쓴다. 코드 기준 계산:
  - topbar: 패딩 20×2 + 버튼 40 = **80px** (118행 `.topbar{padding:20px 24px}` + 30행 `.pillbtn{height:40px}`)
  - metrics `min-height:240px`(86행) + chartbox(패딩 24 + 차트헤드 ~18 + chart-note ~23 + bars 100(88행) + axis ~20) ≈ **190px** + hint ~17px + signals 40px + bgm ~64px + rightcol gap 12×4=48px(141행) + body 하단 패딩 24px(140행)
  - 합계 ≈ **703px / 720px**. `.frame{overflow:hidden}`(22행)이라 1~2줄만 더 길어져도(차트 캡션 줄바꿈, 폰트 렌더 차이) **BGM 바가 조용히 잘린다.**
- **위치**: `.desktop .metrics{min-height:240px}`(86행), `.desktop .bars{height:100px}`(88행), `.desktop .rightcol{gap:12px}`(85·141행).
- **수정 제안**: 안전 마진 30px 이상 확보. ① `.desktop .bars` 높이 100→84px(차트는 보조 정보이므로 비율상도 타당), ② rightcol gap 12→10px, ③ 또는 BGM 미니바를 chartbox 하단에 흡수. 셋 중 ①+②만으로 ~25px 확보 가능.

## P1 — 사용성·일관성 저해 (이번 루프에서 수정 권장)

### P1-1. 모바일 상단 pill 버튼 터치 타깃 38px — 44px 기준 미달

- **문제**: `.mobile .pillbtn{height:38px}`(96·145행). 하단 `.mobile .signals .signal`은 이미 `height:44px`(147행)로 맞춰놓고 상단 버튼(종료/음소거/화면 끄기)만 38px로 남아 기준이 갈라짐. 이 프로젝트는 직전 커밋(dd48a320)에서 44px 터치 타깃을 전면 적용한 상태라 회귀에 해당.
- **위치**: 96행, 145행.
- **수정 제안**: `.mobile .pillbtn{height:44px}`. topbar 패딩 14px(143행)을 12px로 줄이면 수직 예산 증가분(+6px)은 상쇄된다.

### P1-2. 모바일 지표 카드의 단위 누락 — 데스크탑과 정보량 불일치

- **문제**: 데스크탑 카드는 `72<span class="u">bpm</span>`, `14<span class="u">회/분</span>`, `42<span class="u">ms</span>`(199~201행)로 단위를 표기하는데, 모바일 동일 카드(348~350행)는 `<span class="v">72</span>`, `14`, `42` — 단위가 통째로 빠졌다. BPM·호흡·HRV는 %가 아니라서 숫자만으로는 축이 다름을 알 수 없고, 상단 3개(%)와 섞여 오독 소지가 있다.
- **위치**: 348~350행.
- **수정 제안**: 모바일에도 `.u` 스팬 유지(`bpm` / `회/분` / `ms`). 폭이 걱정되면 `.mobile .metric .u{font-size:9px}`로만 줄일 것. 두 프레임의 마크업은 동일하게 유지하는 것이 구현 전달 시에도 안전하다.

### P1-3. 폰트 크기 15종 난립 — 타입 스케일 부재

- **문제**: 9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 14 / 15 / 21 / 26 / 28 / 38px이 혼용된다. 특히 0.5px 단위(`12.5px` 68·73행, `11.5px` 108행, `10.5px` 147행, `9.5px` 72행)는 시각적으로 구분 불가능하면서 일관성만 해친다. 9~9.5px 텍스트(`.axis` 62행, `.bgm .t .cap` 72행)는 가독성 하한선 아래다.
- **위치**: 62, 68, 72~74, 108, 147행 등.
- **수정 제안**: 스케일을 10 / 11 / 13 / 15 / 21 / 26 / 38px 7단으로 고정하고 모든 0.5px 값과 9px대를 가장 가까운 단으로 올림. 최소 크기는 10px(캡션 전용), 본문성 텍스트는 11px 이상.

### P1-4. "동기 재생 중" 배지의 색 토큰 이탈

- **문제**: `.bgm .state`가 텍스트 `#7ef0c0` + 배경 `rgba(89,206,144,.18)`(74행), `.bgm .dot`은 기본 `#2F9E68`(75행)이었다가 아래에서 `var(--mint)`로 오버라이드(139행). 결과적으로 한 배지 안에 **민트 계열 3색(#7ef0c0, #59ce90 계열, #01f0c8)이 혼재**한다. 브랜드 민트는 #01f0c8 하나다.
- **위치**: 74~75행, 139행.
- **수정 제안**: 텍스트/배경을 토큰 기반으로 통일 — `color:var(--mint); background:rgba(1,240,200,.12)`. dot은 현재 오버라이드 유지. (참고: 76행 `@keyframes pulse`가 정의만 되고 미사용 — dot에 `animation:pulse 2.4s ease-in-out infinite`를 걸면 "재생 중" 의미가 살고, 안 쓸 거면 삭제.)

### P1-5. 배경 "보라 자연 이미지 페이드" 미반영

- **문제**: 요구사항의 배경은 "검정 풀블리드 + 보라 자연이미지 페이드 분위기"인데, 현재는 radial-gradient 2개(117행 `.frame`)만으로 처리돼 이미지 레이어가 아예 없다. 그라디언트만으로는 명상 몰입감(자연 텍스처)이 전달되지 않고, 루프 2에서 이미지가 들어오면 전체 대비 계산이 다시 틀어질 수 있어 지금 자리를 잡아두는 편이 좋다.
- **위치**: `.frame`(117행), `.video`(120행).
- **수정 제안**: `.frame` 배경에 이미지 레이어 1장 추가(목업 단계에서는 CSS로 흉내낸 placeholder라도): `linear-gradient(rgba(6,5,7,.72), rgba(6,5,7,.9)), url(nature.jpg) center/cover` 구조로, 상단은 보라 글로우·하단은 검정으로 가라앉는 페이드. 텍스트 영역(우측 컬럼) 뒤에는 반드시 어두운 스크림을 유지해 대비 확보.

## P2 — 다듬기 (여유 시 수정)

### P2-1. 죽은 코드: `.bar.low`, `.mobile .screenoff`, `@keyframes pulse`

- **문제**: `.bars .bar.low`(60행)는 HTML 어디에서도 쓰이지 않음. `.mobile .screenoff`(111행)도 대응 마크업이 없음 — 원래 모바일 하단 bottom-row에 "화면 끄기"를 두려던 흔적으로 보이며, 실제로는 topbar(333행)에 텍스트 버튼으로 남아 390px 상단을 압박한다(그 때문에 title이 12px/letter-spacing -.04em까지 축소됨, 144행). `@keyframes pulse`(76행)도 미사용.
- **수정 제안**: 미사용 셀렉터 삭제. 모바일 "화면 끄기"는 topbar에서 빼서 아이콘 버튼(🌙 등, aria-label 유지)으로 바꾸거나 bottom-row의 `.screenoff` 자리로 복귀 — title 폰트를 13~14px로 되살릴 수 있다.

### P2-2. 스타일 블록이 "기본 정의 + 루프 1 오버라이드" 2중 구조

- **문제**: 같은 셀렉터가 두 번 정의된다 — `body` 배경(12행 #0d0716 → 114행 #100d14), `.frame` 배경(22~25행 → 117행), `.topbar` 패딩(28행 → 118행), `.pillbtn` 배경(30행 → 119행), `.axis` 색(62행 → 135행), `.mobile .pillbtn`(96행 → 145행) 등. 목업 단계에서는 동작하지만 루프 2 수정 시 어느 쪽이 살아있는 값인지 혼동해 회귀를 만들기 쉽다.
- **수정 제안**: 루프 2에서 오버라이드 블록(113~155행)을 기본 정의에 병합해 셀렉터당 1회 정의로 정리.

### P2-3. 간격 체계 혼재 (5/6/8/10/12/16/24px)

- **문제**: gap 값이 5(146행), 6(143행), 8, 10, 12, 16, 24px로 흩어져 있다. 특히 모바일 signals gap 5px·padding 0 5px(146~147행)은 버튼 3개가 서로 붙어 보인다.
- **수정 제안**: 4px 그리드(4/8/12/16/24)로 정규화. 모바일 signals는 gap 6→8px로, 대신 이모지+텍스트를 `font-size:11px`로 한 단 올려 가독 유지.

### P2-4. "낮을수록 좋은" 지표의 방향 안내 부재

- **문제**: BPM·호흡 차트(254~287행)는 값이 내려가는 것이 안정 신호인데, 집중도·이완도(올라갈수록 좋음)와 동일한 시각 문법이라 막대가 낮아지는 것을 "나빠짐"으로 오독할 수 있다.
- **수정 제안**: chart-note(예: 256행 "최근 5분 · 25초 구간 평균")에 방향 코멘트 한 구절 추가 — "천천히 낮아지는 중 · 안정" 같은 상태 문구, 또는 charthead 우측 `.cur`에 ▾ 추세 아이콘. 색을 바꾸는 방식(빨강 등)은 명상 톤에 어긋나므로 금지.

### P2-5. HRV 차트의 수치-높이 매핑 불명확

- **문제**: HRV 차트(288~304행)는 aria-label 값 32→42ms인데 막대 height는 53→70%로, %지표 차트들(값=height)과 달리 임의 스케일이다. 목업으로는 무방하나 구현 전달 시 스케일 규칙(예: 0~60ms 정규화)이 명시돼야 한다.
- **수정 제안**: chart-note에 스케일 표기(예: "0–60ms 기준") 추가하거나, 구현 스펙에 지표별 min/max 정규화 테이블을 함께 전달.

## 잘된 점 (유지)

- **정보 위계**: 데스크탑에서 metrics가 `flex:1`(86행)로 주 영역을 차지하고 chartbox는 `flex:0 0 auto` + bars 100px 고정(87~88행) — "카드 주 / 그래프 보조" 요구를 구조적으로 보장. 막대도 중간 크기(20px 폭, 100px 높이)로 과하지 않음.
- **차분한 그래프**: 12구간 25초 평균 데이터(chart-note 명시), 완만한 증감 값, 은은한 그리드(133행 repeating-linear-gradient) — "1초 튀는 값 금지" 요구 충족.
- **접근성 기초**: 차트 `role="img"` + 수치 나열 aria-label(206행 등), 라디오 `aria-label`, `focus-visible` 민트 아웃라인(116행) 모두 양호.
- **모바일 한 화면 수렴**: 844px 예산 내 수렴 확인(합계 ~794px + video flex 흡수). 가로도 bars 326px ≤ 가용 338px로 스크롤 없음.

## 루프 2 브리프용 요약 (codex 전달)

"지금" 막대 그라디언트의 하단 #5F0080이 검정 배경과 1.7:1 대비로 묻혀 강조가 역전되니, 하단 스톱을 밝은 퍼플(#a855f7 계열)로 올리고 일반 막대 불투명도를 .60→.42로 낮춰 상대 강조를 복원하라. 데스크탑 720px 수직 예산이 여유 17px뿐이므로 bars 높이 100→84px, rightcol gap 12→10px로 안전 마진 30px 이상을 확보하라. 모바일에서 pillbtn 높이를 38→44px로 올리고(터치 타깃 기준), BPM/호흡/HRV 카드에 데스크탑과 동일하게 단위 스팬을 복원하라. 폰트 크기를 10/11/13/15/21/26/38px 7단 스케일로 정규화해 0.5px 단위와 9px대를 제거하고, BGM 배지 색을 브랜드 민트 #01f0c8 토큰으로 통일하라. 마지막으로 .frame 배경에 보라 자연 이미지 페이드 레이어(placeholder 가능)를 추가하되 우측 정보 컬럼 뒤 어두운 스크림을 유지해 대비를 지켜라.
