## ② 잔여 개선 포인트 (루프 3 = 마무리 다듬기)

### P0 — 없음

1차 P0는 모두 해소되었고, 한 화면 수렴·대비 모두 기준 통과. 루프 3에서 반드시 고칠 블로커는 없다. 아래 P1 3건을 마지막 루프에서 반영할 것을 권장.

### P1 — 마지막 루프에서 반영 권장

#### P1-1. 영상 영역 빈 상태(로딩/대기)가 "미완성"으로 읽힘

- **문제**: 데스크탑 영상 영역은 약 725×604px인데 콘텐츠가 64px 아바타 원(28행) + 좌상단 라벨 + 타이머뿐이라, 거대한 빈 상자가 "영상이 안 뜬 화면"처럼 보인다. 대기/로딩 상태라는 정보가 어디에도 없다.
- **위치**: `.video .avatar`(27~28행), 데스크탑 148~155행 / 모바일 298~305행.
- **수정 제안** (구조 변경 없이 2줄 추가):
  - 아바타 원 아래에 상태 문구 1줄: `<div class="wait">상담사 영상을 기다리고 있어요</div>` — `font-size:11px;color:#a996b2;margin-top:12px` (avatar flex-direction을 column으로).
  - 아바타 원에 명상 톤의 숨쉬는 글로우: `.video .circle{box-shadow:0 0 0 0 rgba(1,240,200,.14);animation:breathe 4s ease-in-out infinite}` + `@keyframes breathe{50%{box-shadow:0 0 0 22px rgba(1,240,200,0)}}` (reduced-motion 가드 포함). 빈 공간이 "조용히 기다리는 중"으로 의미화된다.

#### P1-2. ☾(화면 끄기) vs 🌙(잠시 쉴게요) — 같은 달 아이콘이 두 가지 의미로 충돌

- **문제**: 모바일 topbar의 화면 끄기 버튼이 `☾`(295행)인데, 같은 화면 하단 신호 버튼이 `🌙 잠시 쉴게요`(420행)다. 초승달이 위에서는 "화면 끄기", 아래에서는 "휴식 신호"로 쓰여 의미가 갈라지고, ☾ 단독으로는 다크모드 토글로 오독될 여지가 크다. 데스크탑은 텍스트 "화면 끄기"(145행)라 프레임 간 표현도 불일치.
- **위치**: 295행(모바일), 145행(데스크탑), 420행(신호 버튼).
- **수정 제안**: 화면 끄기 아이콘을 달이 아닌 것으로 교체 — `⏻`(전원) 또는 `✕ 화면`식 텍스트 병기. 데스크탑도 `⏻ 화면 끄기`로 아이콘을 맞추면 두 프레임의 버튼 문법(아이콘+텍스트)이 통일된다. 🌙 잠시 쉴게요는 그대로 유지(명상 톤에 적합).

#### P1-3. 모바일 신호 버튼 gap 4px — 1차 P2-3 미반영분

- **문제**: `.mobile .signals{gap:4px}` + `.signal{padding:0 4px}`(83~84행). 44px 높이 버튼 3개가 4px 간격으로 붙어 한 덩어리처럼 보이고, 터치 경계도 모호하다. 1차에서 8px를 제안했으나 오히려 5→4px로 좁아졌다.
- **수정 제안**: `gap:8px`. 폭 검증: 가용 366px(390−패딩 24) − gap 16 = 350px → 버튼당 ≈116px, 11px 폰트의 "💧 조금 어려워요"(약 90px)가 여유 있게 들어간다. 다른 수정 불필요.

### P2 — 여유 시 (한 줄짜리 수정만)

1. **차트 헤더의 수치 중복**: 선택된 카드가 "집중도 87%"를 보여주는데 바로 아래 charthead가 "집중도 · 시간 변화 / **87**% · 지금"(166행)으로 같은 값을 반복하고, axis 우측에도 "지금"(180행)이 또 있다. charthead 우측을 현재값 대신 추세로 바꾸면 중복이 정보로 바뀐다: `▲ 5분간 +32` (aria-label 데이터에서 산출 가능). 최소 수정으로는 `· 지금`만 제거.
2. **모바일 hint 10px → 11px**: `.mobile .hint{font-size:10px}`(95행)는 문장형 텍스트("지금 상태를 조용히 알려 주세요…")라 7단 스케일의 "10px=캡션 전용" 원칙과 충돌. 11px로 올려도 모바일 수직 여유(≈50px) 내.
3. **`.pillbtn.ghost`가 무의미**: ghost 변형 배경이 기본과 동일한 `rgba(255,255,255,.08)`(24~25행)이라 변형이 아무 효과 없음. 셀렉터 삭제(마크업의 class는 유지해도 무방)하거나, 종료 버튼만 미세하게 어둡게(`rgba(255,255,255,.05)`) 해 위계를 줄 것.
4. **`.mobile .bottom-row` 래퍼 잔존**: screenoff 제거 후 자식이 `.bgm` 하나뿐(422~430행)이라 래퍼가 불필요. 삭제하고 `.mobile .bgm{flex-shrink:0}`만 남기면 DOM 1단 정리.
5. **지표 단위 대비 소폭 보강**: `.metric .v .u{color:rgba(255,255,255,.5)}`(36행)는 10px 크기에서 카드 배경 대비 ≈4.4:1로 경계선. `.6`으로 올리면 안전권.

## ③ 한 화면 수렴 최종 확인

- **데스크탑 1280×720**: topbar 80 + 우측 컬럼 고정 요소 합 ≈ 366(2줄 note 기준 379) + metrics min 240 + 하단 패딩 36 ≈ 682~695px → **여유 25~38px, 수렴 ✅**. metrics가 `flex:1`이라 폰트 렌더 편차도 흡수.
- **모바일 390×844**: topbar 68 + 고정 요소(metrics 160 + chartbox ≈187 + hint 13 + signals 44 + bgm ≈58 + gap 48 + 패딩 20) ≈ 598 → **video에 246px 배분(min 180 충족), 수렴 ✅**. 가로도 bars 328px ≤ 가용 366px.
- P1-1~3, P2 항목 모두 수직 예산에 영향 없거나 ±0으로 설계했으므로 루프 3 반영 후에도 수렴 유지된다.

## 루프 3 브리프용 요약 (codex 전달)

1차 피드백 P0·P1 7건은 전부 정확히 반영됐고 오반영은 없으므로, 루프 3은 구조 변경 없는 마무리 다듬기만 수행하라. 첫째, 영상 영역 빈 상태를 의미화하라 — 아바타 원 아래 "상담사 영상을 기다리고 있어요" 상태 문구 1줄과 민트 숨쉬는 글로우 애니메이션(4s, reduced-motion 가드)을 추가할 것. 둘째, 모바일 화면 끄기 버튼 ☾(295행)이 하단 "🌙 잠시 쉴게요"와 의미 충돌하니 ⏻ 등 달이 아닌 아이콘으로 바꾸고 데스크탑 버튼과 아이콘+텍스트 문법을 통일하라. 셋째, 모바일 신호 버튼 gap을 4→8px로 벌려라(폭 검증 완료, 다른 수정 불필요). 여유가 되면 charthead의 "87% · 지금" 현재값 중복을 추세 표기(▲ 5분간 +32)로 교체하고, 모바일 hint 10→11px, 무의미한 `.pillbtn.ghost` 배경 정의와 `.bottom-row` 래퍼를 정리하라.
