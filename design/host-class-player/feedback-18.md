# 피드백 18 — Body 막대 그래프 + 셀프뷰 중앙 정렬 + 상세 사전 설문

`design/host-class-player/index.html` 을 아래 3가지를 수정하라. (구현 금지, 목업 HTML만)

## 1. Body 그래프 → 막대 그래프
- 몸 BODY 지표(BPM·호흡수·HRV)의 스파크라인(라인)을 **세로 막대 그래프**로 변경
  - 개인 상세 슬라이드의 BODY 3줄
  - 그룹 흐름의 BODY 3개
- 막대 위에 정상범위 밴드·그룹 평균 점선은 오버레이로 유지

## 2. 셀프뷰 중앙 정렬
- "나의 화면 · 호스트" + "셀프뷰 미리보기" 텍스트와 아이콘을 **셀프뷰 패널 가운데(수평·수직 중앙)** 로 정렬

## 3. 상세 슬라이드 사전 설문 기록
- 개인 카드(또는 테이블 행) 클릭 시 상세 슬라이드에 해당 참가자의 **사전 설문(survey) 기록** 표시
- 데이터: 각 참가자 `survey` 필드(예: "수면 부족 · 스트레스 7/10", "업무 스트레스")
- 헤더 아래 또는 마음 MIND 위에 소형 라벨("사전 설문") + 내용으로 표시

## 제약 (유지)
- 2칼럼 레이아웃, 조용한 신호 카드, 미확인 pill, chip 단일 선택+모두, 10초 순환, 정렬, 상세 슬라이드(링+막대) 유지
- 다크테마 #12081C·보라 #5F0080·크림 #F7F4F0
- 데스크탑 1280×720 / 모바일 390×844
