# 피드백 1 — 모바일 레이아웃 수정

## 지시
`design/host-class-player/index.html` 을 읽고 아래 사항을 반영해 수정하라.

## 반영 사항 (확정)
**모바일(390×844)만**:
1. 상단 1화면(844px 높이 이내, 스크롤 없음)에 다음만 배치:
   - 헤더(제목 + 진행 중 + 일시정지)
   - 상담사 셀프뷰 + 타이머
   - 진행 큐시트(현재 단계 + 진행바 + 다음 단계)
   - 가이드 · BGM
2. **참가자 모니터(그룹 게이지 + 카드/표 + 발언권)는 그 아래 별도 섹션으로** — 자연스럽게 스크롤로 내려서 보는 구조. 모니터 섹션 시작 부분이 접혀 보이지 않게 하지 말고, 스크롤로 이어지게.

**데스크탑(1280×720)은 현재 1화면 유지** (변경 금지).

## 검증
- 모바일 390×844: 상단 4개 블록(헤더/셀프뷰/큐시트/가이드BGM)이 844px 안에, 스크롤 없이 수렴
- 참가자 모니터는 그 아래로 자연스럽게 스크롤
- 데스크탑은 그대로 1화면
