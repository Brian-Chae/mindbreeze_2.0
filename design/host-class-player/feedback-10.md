# 피드백 10 — 상세 뷰를 슬라이드 시트(오버레이)로 변경

## 지시
`design/host-class-player/index.html` 의 상세 뷰 표시 방식을 수정하라. (구현 금지, 목업 HTML만)

## 현재 문제
개인 카드 선택 시 상세 뷰가 **우측 고정 패널**(카드 그리드와 나란히 좌우 2분할)로 표시됨.

## 원하는 것
- 기본 레이아웃은 그대로: **좌측(셀프뷰·미디어·조용한 신호) + 우측(그룹 흐름 + 참가자 카드)**
- 개인 카드 선택 시: **오른쪽에서 왼쪽으로 슬라이드되어 들어오는 임시 시트**가 기존 참가자 카드 영역을 **절반 정도 덮는** 형태
- 모바일 바텀시트가 아래에서 올라오듯, 데스크탑에서는 **우측 슬라이드 시트**(약 화면 절반 폭)
- 닫으면 카드 그리드가 다시 전체 노출

## 상세 요구
- 슬라이드 시트 폭: 대략 화면 절반(50% 내외), 우측 정렬
- 뒤에 깔린 카드 그리드는 어둡게(dim) 처리
- 열림/닫힘 슬라이드 애니메이션(transform translateX 등)
- 시트 내용은 기존 상세(몸3+마음3: 현재값·5분 라인·3분 델타·그룹 점선·정상범위 밴드) 유지
- 닫기 버튼·바깥 클릭·Esc 로 닫힘

## 제약 (유지)
- 기본 좌(셀프뷰)+우(그룹+카드) 레이아웃
- 그룹 흐름 스파크라인 타일 4분할, 개인 카드 심플(숫자 초대형+화살표 델타), 테이블 단순화
- 지표 10초 순환, 칩 필터, 정렬 유지
- 데스크탑 1280×720 / 모바일 390×844 1화면
