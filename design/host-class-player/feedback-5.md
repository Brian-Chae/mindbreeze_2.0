# 피드백 5 — 지표를 "지난 3분 평균 대비" 변화로 표시

## 지시
`design/host-class-player/index.html` 을 수정해 지표 표시 방식을 아래와 같이 바꿔라.

## 1. 그룹 흐름에 평균 HRV 추가 (총 4개 지표)
- **평균 HRV / 평균 집중도 / 평균 이완도 / 정서안정도**
- 각 지표는 **"지난 3분 평균 대비" 얼마나 높은지/낮은지** 표시
  - 예: 집중도 68 (+7 ↑) · 이완도 72 (+12 ↑) · HRV 38 (+2 ↑) · 정서안정도 74 (+9 ↑)
- 상승=↑(민트 계열) / 하락=↓(오렌지·코랄 계열) 색+화살표로 즉시 구분

## 2. 개인별 6대 지표도 "지난 3분 대비" 표현
- BPM·호흡수·HRV·집중도·이완도·정서안정도 각각에 **지난 3분 평균 대비 상승/하락** 표시
- 예: BPM 72 (+3 ↑) · 호흡 16 (−1 ↓) · HRV 38 (+2 ↑) · 집중 72 (+5 ↑) ...
- 상승/하락을 색+화살표로 즉시 구분, 변화량 숫자 병기

## 3. 3분 이전(데이터 부족) 처리 — 검토해서 적용
- 세션 시작 후 3분 미만이면 "지난 3분 평균"이 없음
- 아래 두 방식 중 더 이해하기 쉬운 쪽을 **검토해서 선택·적용**하고, 선택 이유를 로그에 남겨라:
  a. `···` (측정 중 placeholder)
  b. 아예 변화 표시 안 함 (현재 값만 표시)
- 그룹·개인 모두 동일 규칙 적용. 목업에 3분 이전 상태를 시각적으로 보여주는 예시 1개 포함(예: 특정 참가자 또는 그룹 일부 지표가 `···` 또는 값만 표시)

## 4. 기존 "기준선(첫 2분) 대비" 표기 교체
- "변화는 기준선 대비" → "지난 3분 평균 대비"
- "2분 보정 완료" → 관련 문구 정리(예: "유효 표본 3명"만 남기거나 재문구)
