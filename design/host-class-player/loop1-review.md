## 우선 과제: 조용한 신호 재레이아웃
- 현재: 가로 띠(높이 44px, flex 가로, 라벨+배지 가로 나열)
- Brian 요구: **좌측 칼럼 최상단 카드**로 재배치
  - 세로 나열: `잘 따라가요 [2]` / `조금 어려워요 [1]` / `잠시 쉴게요 [1]`
  - 각 항목 **보라 원 숫자 뱃지**
  - 부제 "익명 · 최근 10초"
  - "미확인 새 신호 있음"은 **우측 칼럼 상단**(그룹 흐름 위) + 빨간 점
- 구체적 배치/크기/간격 설계 제시 (최상위 앱 수준)
