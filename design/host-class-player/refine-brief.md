# 호스트 클래스 화면 — 1안 확정 + 세부 다듬기

## 미션
`design/host-class-player/index.html` 을 **1안(그룹 요약 띠 + 참가자 작업판)** 기반으로 재설계하라. 아래 Brian 확정 요구사항을 세심하게 반영. (구현 금지, self-contained 목업 HTML만)

## 1안 기본 구조 (유지)
- 상단 헤더 → **전체너비 조용한 신호 띠(독립)** → 본문 → 하단 제어(일시정지/종료/채팅)
- 본문 좌측: 셀프뷰+타이머 / 우측: 그룹 요약(가로) + 참가자 작업판(카드/테이블 전환)

## 신규 요구사항 (이번에 반영)

### 1. 셀프뷰 위 미디어 제어 오버레이
- 좌측 셀프뷰 영역 위에 제어 버튼 그룹: **녹음 / 녹화 / 영상(카메라) / 음성(마이크) / BGM**
- 각 버튼 on/off 상태 시각화(녹음 중=빨간 점, 카메라 off=사선 아이콘 등)
- BGM: 트랙명("빗소리 명상") + 재생/일시정지. 플레이어 느낌으로 직관적 아이콘

### 2. 그룹 요약 — 평균 3지표
- 우측 그룹 요약에 **평균 집중도 / 평균 이완도 / 정서안정도** 3개 표시
- 각 지표: 현재 평균값 + 기준선 대비 변화(+/-). (예: 집중도 68(+7) · 이완도 72(+12) · 정서안정도 74(+9))
- 유효 표본 3명 · 2분 보정 완료 유지

### 3. 참가자 6대 지표 한눈에
- 개별 참가자 카드에 **6대 지표**를 컴팩트하게 표시(숫자 + 미니 게이지):
  1. 집중도 2. 이완도 3. 스트레스 4. 정서안정도 5. 인지부하 6. 좌우뇌 균형
- 밴드 미사용·수신 끊김 참가자는 지표 대신 `—` + 사유 표시

### 4. 지표 chip 필터
- 카드/테이블 전환 스위치 **바로 옆**에 6개 지표 chip (작은 pill)
- 각 chip 클릭 → 해당 지표 선택/해제(토글). 선택된 chip은 보라 강조
- 해제된 지표는 참가자 카드·테이블 열에서 즉시 숨김

## 6대 지표 정의 (시스템 정본)
| 한글명 | 영문키 |
|---|---|
| 집중도 | focus |
| 이완도 | relaxation |
| 스트레스 | stress |
| 정서안정도 | emotionalStability |
| 인지부하 | cognitiveLoad |
| 좌우뇌 균형 | hemisphericBalance |
