# 루프1 구현 — 조용한 신호 재레이아웃 + 전체 완성도 Top-5

`design/host-class-player/index.html` 을 아래 Claude 리뷰 설계대로 수정하라. (구현 금지, 목업 HTML만)

## 1. 조용한 신호 재레이아웃 (좌측 최상단 카드)
- 컨테이너: `justify-content:flex-start`(데드스페이스 제거), 배경 #231531, border 1px #ffffff1F, radius 14px, padding 16px, 높이 ~200px
- 헤더 블록: 좌 "조용한 신호" 13px/600 + 우 "응답 4·6명" 10px muted(baseline 정렬)
- 부제 "익명 · 최근 10초" 10px
- 신호 행 3개(각 min-height 40px): 단색 Lucide 글리프(#c4a0d5) `check-circle`(잘 따라가요)·`help-circle`(조금 어려워요)·`pause-circle`(잠시 쉴게요) + 라벨 13px + **보라 원 뱃지 28px**
- **0상태 중공 뱃지**: background transparent + border 1px #ffffff26 + 숫자 #6b5a78
- 행 사이 헤어라인 1px #ffffff0D(마지막 없음)

## 2. "미확인 새 신호" → pill (우측 칼럼 상단)
- pill: height 26px, padding 0 10px 0 8px, radius 999px, bg #2A1030, border 1px #ED647959
- 7px 빨간 점 #ED6479 + "미확인 새 신호 2건" 11px/500 + chevron 12px
- 0건이면 완전히 숨김

## 3. 전체 완성도 Top-5
1. **칼럼 밀도/정렬**: 좌측 세로 리듬 재배분(셀프뷰 축소, 조용한 신호 ~200px), 조용한 신호 카드 top ↔ 그룹 흐름 top 베이스라인 정렬
2. **카드 반복 크롬 제거**: "10초 순환"+6점 순환 도트를 정렬 바 1곳으로 승격, 카드 하단 여백 회수. 비측정 카드(밴드 미사용/수신 끊김)는 dim 처리 + 아이콘·사유 중앙 정렬
3. **소형 타이포**: 본문 보조 최소 10px, muted 전부 #bcaec5 이상 통일, 8px 제거
4. **델타 표기 통일**: `숫자+화살표` 1규칙(tabular-nums), 부호·화살표 순서 통일(그룹·카드·상세 모두)
5. **그룹 흐름 타일 구분**: 4타일 간 1px 헤어라인 또는 4등분 그리드, "평균" 접두어 규칙 통일
