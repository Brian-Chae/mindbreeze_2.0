# 피드백 9 — 카드 정보 정제 (애플워치식 심플 + 미니 차트)

## 지시
`design/host-class-player/index.html` 의 **참가자 카드 내부**를 재구성하라. 애플워치 인터페이스처럼 최대한 심플하되 정보 전달은 더 쉽게. (구현 금지, 목업 HTML만)

## 카드 구성 (위→아래, 간결하게)
1. **이름 + 성별·나이** (유지)
2. **밴드 연결 상태** (유지)
3. **현재 지표 값** (큰 숫자, 유지 — 이 크기는 좋음)
4. **미니 차트** (신규)

## 사전 설문 제거
- 카드에서 사전 설문 내용(고민 등)을 **제거**하라.

## 미니 차트 (기존 "3분 +N / 그룹 +N" 숫자 표시를 대체)
- 현재 지표 숫자 오른쪽(또는 아래)에 미니 차트 배치:
  - **지난 3분의 값 3개를 세로 막대**로 (트렌드, 시간순)
  - **그룹 평균값을 가로 점선 라인**으로
  - **현재 값을 강조된 막대(또는 점)** 로 함께
- 한눈에 "최근 3분 변화 추세 + 그룹 평균 대비 위치"를 파악하게
- 애플워치 심박·활동 그래프처럼 미니멀한 비주얼(불필요한 축·라벨 없이)

## 제약 (유지)
- 카드 크기 174×152 고정, 한 행 5명(5열)
- 지표 10초 순환, 칩 필터(0~1개 카드/2개+ 테이블), 성별·나이, 밴드 상태 유지
- 정렬(카드 뷰 자동·기본 이완도 / 테이블 수동) 유지
- 그룹 흐름(평균 HRV·집중·이완·정서안정, 3분 대비)·미디어 제어·조용한 신호 띠 유지
- 다크 테마 #12081C·보라 #5F0080·크림 #F7F4F0·Pretendard
- 데스크탑 1280×720 / 모바일 390×844 1화면 수렴
- self-contained(외부 CDN/이미지 없음), 구현 금지
