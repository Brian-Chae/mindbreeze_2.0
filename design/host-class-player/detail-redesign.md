# 참가자 개별 상세 슬라이드 — 재디자인 기획

당신은 UI 디자이너 겸 리뷰어입니다. 호스트(상담사) 클래스 화면의 **참가자 개별 상세 슬라이드**를 재디자인할 설계안을 제시하세요. (구현 금지, 설계만)

## 현재 상태
우측 슬라이드 시트(폭 ~50%, 참가자 카드 리스트 영역에 오버레이)에 열림.
몸3(BPM·호흡수·HRV) + 마음3(집중도·이완도·정서안정도) 각 지표마다:
- 현재값 크게 + 단위
- 실시간 라인(최근 5분)
- 3분 델타
- 그룹 평균 점선
- 정상범위 반투명 밴드

## 재디자인 목표
호스트가 개별 참가자 상태를 **한눈에 빠르게 판단**할 수 있도록.
애플워치식 심플함 + 정보 전달 용이 + 몸3/마음3 구분 명확.

## 요구 산출물
1. **내용 구성**: 섹션/순서(헤더 포함). 어떤 정보를 어떤 순서로
2. **그래프 스타일**: 라인/막대/게이지/링 중 몸·마음 지표별 최적 제안
3. **시각 요소 배치**: 헤더·요약·그래프·추가정보의 시각적 배치
4. 구체적 스케치(텍스트로 박스/영역 설명)

## 제약
- 다크테마 #12081C·보라 #5F0080·크림 #F7F4F0
- 우측 슬라이드 시트(폭 ~50%, 세로는 카드 리스트 영역)
- 6대 지표: 몸=BPM(bpm)·호흡수(회/분)·HRV(ms), 마음=집중도·이완도·정서안정도(%)
- "3분 대비"는 증감 숫자로, 그룹 평균 대비 맥락 필요
- 가치판단 색(초록=좋음/빨강=나쁨) 금지, 방향은 화살표/증감만
