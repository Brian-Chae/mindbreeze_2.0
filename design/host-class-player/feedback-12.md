# 피드백 12 — 슬라이드 시트 범위 + "3분 대비" 표기 + chip 단일 선택

## 지시
`design/host-class-player/index.html` 을 아래 3가지를 수정하라. (구현 금지, 목업 HTML만)

## 1. 슬라이드 시트 = 참가자 카드 리스트(roster) 컴포넌트 기준
- 현재: `position:fixed`로 페이지 전체(뷰포트) 기준 우측 슬라이드
- 원함: **참가자 카드 리스트(roster) 컴포넌트에 대한 슬라이드**로 수정
  - 헤더·그룹 흐름·푸터는 그대로 보이고, **카드 리스트 영역만** 시트가 덮음
  - `position:absolute`(roster 기준) 또는 roster 내부 배치
  - backdrop도 roster 영역만 어둡게

## 2. "3분 대비" 표기 수정
- 현재: `3분 대비 ▲+2` (라벨+화살표+숫자)
- 원함: **메인 숫자 오른쪽에 +2 / -1(증감 숫자)**, 그 오른쪽에 **작게 "3분대비" 라벨**
- 배치 예: `60%  +2  3분대비` (상승 +/하강 -, 라벨 소형 저대비)
- 카드·상세 모두 동일 규칙

## 3. chip 단일 선택 + "모두" chip
- chip 목록: **[모두] [BPM] [호흡수] [HRV] [집중도] [이완도] [정서안정도]**
- **"모두" 선택** → 테이블 뷰(6개 지표 전체 컬럼)
- **개별 지표는 1개만 선택(단일 선택, radio)** → 카드 뷰(해당 지표)
- "모두"와 개별 지표는 상호 배타적(하나를 누르면 다른 쪽 해제)
- 기본값: **이완도 1개 선택(카드, 10초 순환 유지)**

## 제약 (유지)
- 기본 좌(셀프뷰·미디어·조용한 신호) + 우(그룹 흐름 + 참가자 카드) 레이아웃
- 그룹 스파크라인 타일 4분할, 개인 카드 심플, 상세 시트 내용(몸3+마음3) 유지
- 닫기(버튼·바깥 클릭·Esc), 10초 순환, 정렬(카드 자동·기본 이완도 / 테이블 수동) 유지
