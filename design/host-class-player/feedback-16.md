# 피드백 16 — 그룹 흐름 Mind/Body 6지표 + 테이블 행 클릭 상세

`design/host-class-player/index.html` 을 아래 2가지를 수정하라. (구현 금지, 목업 HTML만)

## 1. 그룹 흐름 → Mind & Body 6지표 차별화
- 현재: 4지표(평균 HRV·집중도·이완도·정서안정도)를 숫자+증감으로 표시
- 변경: **개인 상세 슬라이드와 동일한 시각 언어**로 6지표를 Mind/Body로 나눠 차별화
  - **마음 MIND**: 집중도·이완도·정서안정도(%) → **링 게이지(컴팩트)** + 중앙 숫자 + 3분 증감
  - **몸 BODY**: BPM(bpm)·호흡수(회/분)·HRV(ms) → **스파크라인(컴팩트)** + 값+단위 + 3분 증감
- "지난 3분 평균 대비" 증감 표기 유지
- "유효 표본 N명" 유지, 0명이면 "표본 없음"
- 그룹 흐름 영역 높이 제약 내에서 컴팩트하게(링 지름·라인 높이 축소)

## 2. 테이블 행 클릭 → 상세 슬라이드
- 테이블 뷰("모두" 선택)에서 참가자 행 클릭 시 **개인 상세 슬라이드**가 열리도록
- 카드 클릭과 동일한 상세 슬라이드(링+스파크라인) 오픈
