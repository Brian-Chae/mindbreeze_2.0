# 피드백 6 — 지표 순환 카드 + 참가자 인구·사전설문 표시

## 지시
`design/host-class-player/index.html` 을 아래 요구에 맞게 수정하라. (구현 금지, self-contained 목업 HTML만)

## 1. 카드 뷰 — 지표 1개씩 10초 순환 + 크게
- 카드에서 6대 지표를 동시에 나열하지 말고, **지표 1개만 크게** 표시
- **10초마다 다음 지표로 순환**: BPM → 호흡수 → HRV → 집중도 → 이완도 → 정서안정도 → 반복
- 현재 지표명 + 값 + 지난 3분 대비 변화(↑/↓)를 크게 표시
- 순환 상태를 알 수 있게 현재 지표 인디케이터(점 6개 등) 표시

## 2. 카드 고정 크기 + 한 행 5명
- 카드 크기를 화면에 맞춰 늘리지 말고 **고정 크기**(예쁜 크기)
- 데스크탑 **한 행 5명**(5열). 6명이면 5명 + 2행에 1명
- 남는 공간은 여백 유지(카드 확대 금지)

## 3. chip 선택 수에 따른 뷰 자동 전환
- 지표 chip **0~1개 선택** → 카드 뷰(지표 순환)
- 지표 chip **2개 이상 선택** → 테이블 뷰(선택 지표를 컬럼으로)
- 카드/테이블 수동 스위치와 chip 선택을 연동

## 4. 참가자 성별·나이 표시
- 카드·테이블에 **성별(남/여) + 나이** 표시. 예: "여 · 28세"

## 5. 사전 설문 표시
- 카드에 **사전 설문 응답** 요약 표시(주요 고민 1줄 등)
