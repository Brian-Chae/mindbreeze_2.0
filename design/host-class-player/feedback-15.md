# 피드백 15 — 그룹 흐름 숫자 복원 + 조용한 신호 이미지 일치 + 레이아웃

## 지시
`design/host-class-player/index.html` 을 아래 3가지를 수정하라. (구현 금지, 목업 HTML만)

## 1. 그룹 흐름: 막대 그래프 제거 → "지난 3분 평균 대비" 숫자 표시
- 현재 4개 타일의 **세로 막대 차트를 제거**
- **현재값 크게 + 단위** + 오른쪽/아래에 **지난 3분 평균 대비 증감 숫자**(예: `38 ms (+2 ↑)`)
- 부제 "지난 3분 평균 대비" 유지
- 4지표: 평균 HRV·평균 집중도·평균 이완도·정서안정도

## 2. 조용한 신호: 첨부 이미지와 동일하게
- 좌측 칼럼 **최상단 카드**, 세로 나열: `잘 따라가요 [2]` / `조금 어려워요 [1]` / `잠시 쉴게요 [1]`
- 각 항목 **보라 원 숫자 뱃지**
- 부제 "익명 · 최근 10초"
- "미확인 새 신호 있음"은 **우측 칼럼 상단**(그룹 흐름 위) + 빨간 점

## 3. 레이아웃: 첨부 이미지 레이아웃 유지
- 좌측 칼럼(위→아래): 조용한 신호 → 미디어 제어 → 셀프뷰 → 함께한 시간
- 우측 칼럼: 그룹 흐름 → 참가자(카드/테이블)

## 제약 (유지)
- 참가자 카드 심플, "3분 대비" 증감 표기, chip 단일 선택+모두, 상세 시트(roster 오버레이) 유지
- 데스크탑 1280×720 / 모바일 390×844 1화면
