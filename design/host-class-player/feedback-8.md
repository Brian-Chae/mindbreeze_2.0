# 피드백 8 — 정렬 단순화 + 개인 지표에 "그룹 대비" 추가

## 지시
`design/host-class-player/index.html` 을 아래와 같이 수정하라. (구현 금지, 목업 HTML만)

## 1. 정렬 규칙 단순화
- **자동 정렬은 카드 뷰(지표 0~1개 선택)에서만** 동작
- **기본 정렬 = 이완도** (지표 0개 선택 시 이완도 기준)
  - 3분 이내: 이완도 현재값 낮은(안좋은) 순
  - 3분 이후: 이완도 3분 대비 악화 순
- 지표 1개 선택 시 → **선택한 지표 기준**으로 정렬(같은 안좋은 방향 규칙)
- 지표 2개 이상 선택(테이블) → **자동 정렬 없음**

## 2. 테이블 정렬 = 사용자 수동
- 테이블 뷰에서 사용자가 정렬 기준을 **직접 선택**(컬럼 헤더 클릭 등)하면 적용
- 기본 상태는 자동 정렬 없이 입장순(또는 이완도). 정렬 기준 라벨로 현재 기준 표시

## 3. 개인 지표 — "3분 대비" + "그룹 대비" 이중 표시
- 각 개인 지표에 두 가지 비교를 함께 표시:
  1. **3분 대비**: 개인 자신의 지난 3분 평균 대비 변화(기존 ↑/↓)
  2. **그룹 대비**: 그룹 평균과의 차이(내 값이 그룹 평균보다 높음/낮음)
- 표기 예: `집중도 72 (3분 +5↑ · 그룹 +7)`
- 그룹 평균은 상단 "그룹 흐름"의 평균값(HRV 38 · 집중 65 · 이완 65 · 정서안정 71) 기준
- 3분 미만 참가자는 "3분 대비"는 변화 대기, "그룹 대비"는 표시 가능하면 표시

## 참가자 데이터 (그룹 대비 계산용)
- 그룹 평균: HRV 38 · 집중 65 · 이완 65 · 정서안정 71
- 예: 김민지 집중 72 → 그룹 +7 / 이준호 집중 58 → 그룹 −7 / 이준호 이완 71 → 그룹 +6
