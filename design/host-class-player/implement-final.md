# 호스트 클래스 화면 — 최종 재설계 (그룹 스파크라인 + 개인 심플 + 상세 패널 + 테이블 단순화)

## 지시
`design/host-class-player/index.html` 을 아래 설계(Claude 리뷰 확정)에 맞게 재설계하라. (구현 금지, self-contained 목업 HTML만)

## 1. 그룹 흐름 — 스파크라인 타일 4분할
- "익명 집계" 글자 제거
- 상단 가로 바를 4등분 타일: `[지표명 소형] [현재 평균값 크게 + 단위]` + 하단 **스파크라인**(세션 시작~현재 추이)
- 4지표: 평균 HRV(ms) · 평균 집중도(%) · 평균 이완도(%) · 정서안정도(%)
- 유효 표본은 미세 라벨로만

## 2. 개인 카드 심플 (174×152 고정, 한 행 5명)
- 위→아래: 이름·성별·나이(1줄) → 밴드 도트(우상단) → **현재 지표 숫자 초대형(≈40px) + 단위 소형** → "3분 대비" **화살표 델타**(▲+6 / ▼-4 / ≈) → 6점 순환 인디케이터
- "관찰값" 글자 제거, 단위(%·bpm·ms·회/분)만 숫자 옆 소형
- **밴드 미사용 / 수신 끊김 / 추이 대기(3분 미만) 구별을 미니차트로**:
  - 밴드 미사용: 차트 없음 + "밴드 없이 참여"
  - 수신 끊김: 차트 없음 + "새 신호 대기"
  - 추이 대기(값 있음·3분 미만): 값 표시 + 차트는 "대기" 상태 시각화
- 가치판단 색(초록=좋음/빨강=나쁨) 금지. 방향은 화살표·기호로만

## 3. 상세 보기 — 데스크탑 좌우 분할 + 모바일 바텀시트
- **데스크탑**: 참가자 카드 그리드(좌) + **상세 패널(우)** 로 좌우 분할. 카드 선택 시 우측 패널에 상세.
- **모바일**: 바텀시트
- 상세 내용 — 몸 3대(BPM·호흡수·HRV) + 마음 3대(집중도·이완도·정서안정도), 각 지표:
  - 현재값 크게 + 단위
  - 실시간 라인(최근 5분, 스트리밍 유입 느낌)
  - 3분 대비 델타(▲/▼)
  - **그룹 평균 점선**(HRV 38·집중 65·이완 65·정서안정 71)
  - 정상 범위 반투명 밴드
- 상세에서 **밴드 연결/미사용 상태는 표시 안 함**(아래 카드에 이미 보이므로)

## 4. 테이블 단순화
- 테이블 형태를 단순화·보기 좋게
- 열: 참가자(이름·성별·나이) + 선택 지표 컬럼(숫자+단위+델타)
- 과도한 장식·중복 라벨 제거
