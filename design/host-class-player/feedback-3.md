# 피드백 3 — BGM 오버레이 + 우측 패널 탭 전환

## 지시
`design/host-class-player/index.html` 을 읽고 아래 2가지를 반영해 수정하라.

## 반영 사항

### 1. BGM → 셀프뷰(상담사 영상) 위 오버레이 아이콘
- "이것도 일종의 플레이어" — 영상 영역 상단(좌상단 또는 우상단)에 재생 아이콘(▶/⏸) + 트랙명 미니 라벨을 오버레이로.
- 클릭 → 재생/일시정지. 트랙 선택은 아이콘 클릭 → 작은 드롭다운 메뉴.
- 우측의 별도 "가이드 · BGM" 섹션은 제거.

### 2. 우측 = 고정 패널 + 탭 전환 (팝업 모달이 아니라 패널 내용 전환)
- 우측 패널 상단에 탭 3개: **[그룹 상태] [참가자] [조용한 신호]**
- 탭 클릭 → 우측 패널 내용만 전환(모달 팝업 금지).
- 기본 탭 = 참가자.
- 그룹 상태 탭: 게이지 + 이완/집중 집계 + 페이스 안내
- 참가자 탭: 참가자 카드 6명 + 발언권 버튼
- 조용한 신호 탭: 신호 집계(잘 따라가요/조금 어려워요/잠시 쉴게요) + 시간순 목록

## 유지(변경 금지)
- 데스크탑 1280×720 / 모바일 390×844 **1화면 수렴**
- 다크 토큰(#12081C·보라 #5F0080·Pretendard), 익명 집계, 개인 점수·순위 없음
- 하단 상태 전이 버튼(일시정지/종료) + 채팅 배지
- 참가자 개별 "상세"는 카드 클릭 시 모달 허용(탭 전환과 별개)
- 진행 큐시트는 기본 화면에 없음(더보기 모달만)

## 제약
- 구현 금지 — 디자인 정본 HTML만. self-contained(외부 의존성 없음)
