# 호스트 클래스 화면 — 구조 재편 리뷰 (그룹 미니차트 + 개인 심플 + 상세 보기)

당신은 UI 리뷰어입니다. 아래 Brian의 최종 방향을 읽고 **설계 제안**을 하세요. 구현하지 말고, 텍스트 설계 제안만.

## Brian 최종 방향 (확정)
1. **상단 그룹 흐름**: "익명 집계" 같은 글자 제거 → **시간에 따른 지표 흐름 미니차트(스파크라인)** 로 구성
2. **개인 카드는 심플**: 이름·성별·나이 + 밴드 연결 상태 + **현재 지표 숫자(크게)** + **"지난 3분 평균 대비 어떤지"** 만 표시. 복잡한 미니차트는 카드에서 제거.
3. **개인 카드 선택 → 상세 보기**: 몸 3대(BPM·호흡수·HRV) + 마음 3대(집중도·이완도·정서안정도)의 **상세한 실시간 분석 자료** 표시
4. 카드 숫자 옆 "관찰값" 글자 제거 → **단위(%, bpm, ms)** 로

## 현재 상황
- 카드 174×152px 고정, 한 행 5명, 다크테마(#12081C · 보라 #5F0080 · 크림 #F7F4F0)
- 6대 지표: 몸(BPM bpm·호흡수 회/분·HRV ms) + 마음(집중도·이완도·정서안정도 0~100)
- 지표 10초 순환, 정렬(카드 자동·기본 이완도 / 테이블 수동)
- 그룹 평균: HRV 38 · 집중 65 · 이완 65 · 정서안정 71

## 요청 — 다음을 제안하라
1. **그룹 흐름 미니차트 스타일** — 4개 지표(HRV·집중·이완·정서안정)의 시간 흐름을 스파크라인/미니차트로. 글자 최소화. 스타일 2~3개 제안(각각 비주얼·크기·장단점).
2. **개인 카드 심플 구성** — 현재 숫자 + "3분 대비 어떤지"를 최소 요소로 표현하는 방식 제안.
3. **상세 보기 구성** — 카드 선택 시 열리는 상세(모달/패널)에서 몸3+마음3 지표의 실시간 분석을 어떻게 보여줄지. 실시간 그래프(최근 N분 라인), 현재값, 3분 대비, 그룹 대비, 기준선 등.
4. **단위 표기** — 숫자 옆 단위(%·bpm·ms) 표시 방식.

## 제약
- 카드 174×152px 고정, 한 행 5명 유지
- 애플워치식 미니멀(불필요한 글자·축 제거)
- 익명 집계, 개인 점수·순위 없음, 진단 아님
- 데스크탑 1280×720 / 모바일 390×844 1화면
