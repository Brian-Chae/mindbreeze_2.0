## 1안 — 그룹 요약 띠 + 참가자 작업판
- 상단 헤더 → **전체너비 조용한 신호 띠(고정)** → 그룹 요약(가로 배치) → 참가자 작업판
- 좌측: 셀프뷰+타이머(392px) / 우측: 그룹 요약 + 참가자 카드 그리드(카드/테이블 전환 버튼)
- 신호는 헤더 아래 독립 띠로 항상 노출

## 2안 — 좌측 그룹 요약 + 우측 전체 명단
- 좌측 256px: 셀프뷰(상단)+그룹 요약(중앙)+페이스 안내(하단)
- 우측 960px: 참가자 전체 명단(카드 6명 or 테이블 전환)
- **조용한 신호는 하단 제어 위 고정 배지 바** (세 범주 배지)
