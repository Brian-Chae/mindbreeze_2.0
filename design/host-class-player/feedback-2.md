# 피드백 2 — 호스트 화면 재기획 (요약 대시보드 + 상세 모달)

## 확정 변경 (Brian 지시)
1. **진행 큐시트 제거** — 기본 화면에서 큐시트를 완전히 뺀다(호스트가 안 본다). 필요하면 모달로만.
2. **전체 컴팩트화** — `design/member-class-player/index.html`(게스트 정본)처럼 한 화면 안에 정리.
3. **기본 화면 = 전체 상태를 한눈에** — 그룹 상태 + 참가자 요약 + 핵심 컨트롤을 요약/대시보드식으로.
4. **상세는 모달(팝업)** — 필요할 때 눌러서 상세 조정·데이터 확인.

## 설계 방향
**기본 화면(1화면, 컴팩트, 스크롤 없음)**:
- 좌측: 상담사 셀프뷰(영상) + 타이머 오버레이 + 핵심 상태 칩(녹음/AI분석/마이크/카메라)
- 우측: 그룹 상태 게이지(익명 집계) + 참가자 요약(컴팩트 그리드) + 조용한 신호 집계 + 상태 전이 버튼(일시정지/종료) + 채팅 배지

**상세 모달(팝업 — 기본 화면에서 카드/버튼 클릭 시 열림)**:
- 참가자 개별 상세(참가자 카드 클릭 → 지표·발언권·상태·신호)
- 녹음 · 화상 · 마커(별도 모달)
- 큐시트(필요 시 모달, 기본 화면엔 없음)

## 참고·제약
- 게스트 정본 `design/member-class-player/index.html` 의 다크 토큰·타이포·밀도를 그대로 따른다
- 데스크탑 1280×720 / 모바일 390×844 **둘 다 1화면 수렴**(모바일도 스크롤 최소화)
- 개인 점수·순위 미노출, 익명 그룹 게이지 유지
- `design/host-class-player/index.html` 을 **재설계(전체 교체)**하라. 기존 큐시트 레이아웃 유지하지 말 것.
- 구현 금지 — 디자인 정본 HTML만
