# 루프2 구현 — 정밀 완성도 개선 (Claude 리뷰 P1~P5)

`design/host-class-player/index.html` 을 아래 결함 개선안대로 수정하라. (구현 금지, 목업 HTML만)

## P1 · 상세 BODY 스파크라인 진폭/종횡비
- y 매핑을 고정 임상범위가 아니라 **최근 5분 min–max 오토스케일**로 (진폭이 보이게)
- 차트 높이 48→**64px**, 가로 상한 **~240px**, `preserveAspectRatio="none"` 제거
- 정상범위 밴드·평균 점선은 유지하되 오토스케일 범위 안에서 표시

## P2 · 참가자 카드 높이/리듬 통일
- 카드 높이 152→**120px** (모바일 110→**96px**)
- 성숙 카드 하단 ~33% 공백 제거, 3종(성숙/<180s/비측정) 수직 리듬 통일
- 비측정 카드는 dim + 아이콘·사유 중앙 정렬 유지

## P3 · MIND 링 평균 인코딩 정리
- 그룹 평균을 **틱 + "평균 N" 텍스트 2중 표기하지 말고 1개로** (틱 유지 시 틱 옆 "평균" 마이크로 라벨, 또는 틱 제거 후 텍스트만)
- 링 호 종료부(그라디언트 암부) 대비 보정

## P4 · 모바일 노출/터치 타깃
- 모바일 카드 96px + sort-bar/toolbar 압축으로 **6명(3행) 수렴** 또는 비측정 카드 상단 고정
- 보조 버튼(sort-actions·metric-chip) min-height **≥36px**

## P5 · 상세 범례 정합
- 글리프(`▨ ┈ ----`) 대신 **실제 스타일과 동일한 미니 스와치**(점선/연한 fill)로 교체
- "평균" 표기는 **지표당 1회**로 (차트 점선+meta 텍스트 중복 제거)
- 범례를 **몸 BODY 섹션 하단**으로 스코프 이동

## 추가 (P6)
- 그룹 흐름 4타일 값 좌측 기준선 통일(첫 타일 padding-left 보정)
- 상세 전체 밀도 재배분(6지표 가시성 향상)
