# 호스트 클래스 화면 — 그룹 상태·참가자 표시 방식 브레인스토밍

## 미션
상담사 호스트 클래스 화면(`design/host-class-player/index.html` 참고)의 **"그룹 상태 + 참가자 상태 표시 방식"** 을 브레인스토밍해서 **3가지 설계안**을 제안하라. (구현 아님 — 설계안 텍스트만)

## Brian 확정 요구사항
1. 그룹 상태 + 참가자까지 한 화면에 보여주되, **참가자 상태 정보를 더 자세히** 보여줘야 함(현재 카드가 이름+상태 2줄뿐)
2. **카드 비율이 위아래로 너무 큼** → **카드 뷰 + 테이블 뷰 둘 다 제공**
   - 테이블 뷰: 참가자 많을 때 — 한 행에 이름·지표(bpm/호흡)·상태·발언권
   - 카드 뷰: **사용자 수에 따라 카드에 표시할 정보 수를 제한**(2명/5명/20명 등 인원별 밀도)해 인식 가능하게 나열
3. **조용한 신호는 독립적으로** — 사용자 신호를 바로바로 봐야 하므로 그룹 상태/참가자 탭과 분리. 별도 영역(상단 스트림·고정 배지 등)으로 항상 노출. 이전처럼 독립 표시.
4. BGM 플레이어는 이번 범위 아님(별도 재작업 예정)

## 3가지 안에 담을 내용 (각 안 공통)
- 레이아웃 구조(좌/우/상단 배치 — 텍스트로 명확히)
- 그룹 상태 + 참가자 표시 방식(자세한 참가자 정보 어떻게)
- 카드 뷰 ↔ 테이블 뷰 전환 방식 + **사용자 수별 정보 밀도 제한 규칙**(구체적: N명이면 카드당 항목 몇 개)
- 조용한 신호의 독립 표시 방식(위치·형태)
- 장단점(수업 진행 중 상담사가 한눈에 보기 좋은지, 모바일에서 어떨지)
