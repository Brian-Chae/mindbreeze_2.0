# 호스트 클래스 화면 — 루프2 리뷰 (정밀 완성도)

당신은 시니어 UI 리뷰어입니다. `design/host-class-player/index.html` 을 다시 리뷰하세요. (구현 금지, 리뷰만)

루프1에서 반영됨: 조용한 신호 세로 3행(글리프+28px 뱃지+헤어라인), "미확인 새 신호 2건" pill, "10초 순환" 정렬 바 통합, 카드 크롬 제거, 소형 타이포 10px, 델타 표기 통일, 그룹 타일 구분.

## 이번 루프 초점
1. **상세 슬라이드 정밀 리뷰** — 마음 MIND 링 게이지 3개 + 몸 BODY 스파크라인 3줄 + 범례. 시각 정합·정렬·밀도·가독성 결함 도출.
2. **그룹 흐름 타일** — 4타일 간격/구분/라벨 대칭 정밀 점검.
3. **참가자 카드** — 카드 내 여백·정보 계층·비측정 카드(dim) 처리 정밀 점검.
4. **모바일(390×844)** — 1화면 수렴·터치 타깃·스택 순서.

## 산출
우선순위 1~5 개선점 (구체 수치 포함). 루프1에서 다룬 항목은 제외하고 **새 결함** 위주로.
