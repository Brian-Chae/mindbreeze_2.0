# 상세 슬라이드 재디자인 구현 (Claude 설계 기반)

## 지시
`design/host-class-player/index.html` 의 상세 시트(#detail-panel) 내부를 아래 설계대로 재디자인하라. (구현 금지, 목업 HTML만)

## 설계 (Claude 리뷰 확정)

### 지표군별 시각 언어 분리
- **마음3(집중도·이완도·정서안정도, %) → 링 게이지 3개 가로 1행 (히어로 영역)**
  - 보라 그라데이션(#5F0080→라벤더) 아크로 현재 % 채움, 미채움 트랙 #ffffff14
  - 중앙 큰 숫자 + 아래 작은 `↑+4`(3분 대비, 화살표+숫자만)
  - 링 트랙 위 노치(tick) = 그룹 평균 위치, 하단 캡션 `평균 65`
- **몸3(BPM·호흡수·HRV) → 스파크라인 로우 3줄 (근거 영역)**
  - 좌: 라벨 + 큰 현재값+단위 + `+3↑`(3분 대비)
  - 우: 최근 5분 라인 + 정상범위 반투명 밴드 + 그룹 평균 점선 + 캡션 `정상 60-90 · 평균 72`

### 섹션 순서
① **헤더(sticky)**: 이름(24px) · 성별·나이 · 밴드 dot · 경과시간 · [닫기]
② **마음 MIND**: 링 3개 1행
③ **몸 BODY**: 라인 로우 3줄
④ **범례/고지(sticky 하단)**: `최근 5분 · 평균 ┈ · 정상범위 ▨ · 진단 아님` 1줄 통합

### 원칙
- 단일 보라 계열만 사용, 좋음/나쁨 색 금지, 방향은 `↑ ↓ →` 화살표+숫자로만
- 숫자 tabular-nums, 단위는 값의 1/3 크기로 종속 표기
- 지표별 축(5분전/현재) 제거, 범례·고지 통합 → 애플워치식 단순화

### 모바일
- 링 3개 1행 유지(공간 부족 시 2+1 래핑), 몸 로우 세로 스택, 헤더·범례 sticky 유지

## 제약 (유지)
- 우측 슬라이드 시트(roster 영역 오버레이, position:absolute) 유지
- 닫기(버튼·바깥 클릭·Esc) 유지
- 다크테마 #12081C·보라 #5F0080·크림 #F7F4F0·Pretendard
