# 피드백 7 — 참가자 정렬 (주의도 순)

## 지시
`design/host-class-player/index.html` 에 참가자 정렬 방식을 추가하라. (구현 금지, 목업 HTML만)

## 정렬 규칙
### 3분 이내 (세션 시작 후 3분 미만)
- **현재 값 기준 "안좋은 방향"**(주의가 필요한) 사람이 위로
- 안좋은 방향 정의:
  - 집중도 / 이완도 / 정서안정도 / HRV → **낮을수록** 안좋음
  - BPM → 정상(60~80)에서 **벗어날수록** 안좋음(너무 높거나 낮음)
  - 호흡수 → 정상(12~20)에서 **벗어날수록** 안좋음
- 각 지표의 안좋음 정도를 종합해 "주의도" 높은 순으로 정렬

### 3분 이후
- **3분 평균 대비 변화가 안좋은 방향인 지표 수**가 가장 많은 사람이 위로
- 예: 집중↓ + 이완↓ + HRV↓ = 악화 3개 → 최상단. 악화 0개 → 최하단
- 안좋은 방향: 집중/이완/정서안정/HRV ↓, BPM·호흡수가 정상범위 밖으로 ↑/↓

## 반영 사항
- 참가자 순서를 정렬 기준에 맞게 재배치 (목업에서 실제로 보여주기)
- 정렬 기준 라벨 표시. 예: "주의도순 · 현재값" / "악화 지표순 · 3분 대비"
- 3분 미만(변화 대기) 참가자와 3분 이상 참가자 구분 표시
- 정렬 기준이 바뀌는 시점(3분 경계)이 이해되도록 툴팁/설명

## 참가자 데이터로 정렬 예시 산출
- 3분 이후 기준 악화 지표 수(예시):
  - 이준호: 집중 -2↓ · 호흡 -2↓ · BPM -3↓ = 악화 3개 → 최상단
  - 김민지: 호흡 -1↓ = 악화 1개
  - 최유나: 호흡 -1↓ = 악화 1개
  - 강도현: 3분 미만(변화 대기) → 별도 구분
- 목업에서 이 순서로 정렬된 것을 보여주되, 정확한 계산은 codex가 결정
