# 호스트 클래스 화면 — 루프4 리뷰 (최종 폴리시)

당신은 시니어 UI 리뷰어입니다. `design/host-class-player/index.html` 을 리뷰하세요. (구현 금지, 리뷰만)

루프1~3 반영됨: 조용한 신호 카드·미확인 pill·카드 컴팩트 120px·스파크라인 축 보정·링 틱·선택 통일·범례 스와치 등.

## 이번 루프 초점 (최종 폴리시, 수렴 단계)
1. **전체 톤/피니시** — 여백·쉐도우·라운드·보더 일관성. 최상위 앱의 "완성감".
2. **엣지 케이스** — 0명/1명 참가자, 모든 신호 0건, 밴드 전원 미사용, 화면 최소 폭.
3. **접근성 잔여** — 포커스 링, aria, 대비.
4. **잔여 시각 결함** — 루프1~3에서 놓친 것.

## 산출
우선순위 1~5 (미세 조정). **더 이상 없으면 "수렴 완료"로 명시**하고 잔여 폴리시만.
