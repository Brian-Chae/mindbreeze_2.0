# 루프3 구현 — 정밀 조정 (Claude 리뷰 P1~P5)

`design/host-class-player/index.html` 을 아래대로 수정하라. (구현 금지, 목업 HTML만)

## P1 · 스파크라인 밴드/평균 축 보정 (중요)
- 축을 개인 데이터 min/max가 아니라 **정상범위 경계 + 그룹 평균을 항상 포함**하도록:
  `low = min(dataMin, 정상하한) - padding`, `high = max(dataMax, 정상상한) + padding`
- 결과: 정상범위 밴드가 위아래 여백 있는 "띠"로, 평균 점선이 플롯 중간에 떠서 의미 회복

## P2 · 측정 <3분 차트 공백 표식
- x≈156(측정 시작)에 1px 세로 구분선 + 공백부에 뮤트 "측정 시작" 라벨

## P3 · 카드 선택 전환 애니메이션
- 선택 카드에 `transition:background .2s ease, border-color .2s ease` 추가 (패널 이징과 통일)

## P4 · 링 평균 틱 + 중앙 대시 정리
- 링 트랙 위 평균 각도에 2px 틱 1개 추가
- 링 중앙 "—" 와 BODY 값 뒤 "—"를 **부호 있는 3분 델타**(예 +4↑ / −2↓)로 치환

## P5 · 활성/선택 시각 통일 + 비측정 글리프 강화
- 선택 가능한 크롬(칩·카드·탭·버튼)의 aria-pressed=true 시각을 **bg 시프트 + 1px 테두리 토큰 1종**으로 통일
- 비측정 카드: 점 대신 중앙 글리프(circle-slash/wifi-off)를 키우고 상태 라벨 무게 강화

## 제약 (유지)
- 2칼럼 레이아웃, 조용한 신호 카드, 상세 시트(링+스파크라인), chip 단일 선택+모두, 10초 순환 유지
- 다크테마 #12081C·보라 #5F0080·크림 #F7F4F0
