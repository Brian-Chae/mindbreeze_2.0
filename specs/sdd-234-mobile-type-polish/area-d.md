## 변경 요약

- 목록(ChatPage·ClientChatPage): 이름 16/26, 미리보기 15/24, 시간 13/20, 배지 13(22px), 아바타 글자 14, 빈 상태/오류 15.
- 정렬 토글: 라벨 13, 터치 높이 44(체크박스 20px, label 전체가 터치 영역).
- 방 헤더: 방 이름 16/26, 보조 13. 메뉴(⋯) 44×44.
- 입력 16/26, 높이 48, 전송 높이 48·너비 44↑. 메시지 본문 16/26, 간격 8/12/16(행간 4, 묶음 16), URL `overflow-wrap:anywhere`.
- 신고(상대방/메시지) 44×44 터치, 글자 13. 알림/오류 띠 15.
- 모달(방 생성·초대·설정·신고)·ClassChatPanel·GuestChatNotice: 글자 토큰, 입력 48, 버튼/라벨/닫기 44↑.
