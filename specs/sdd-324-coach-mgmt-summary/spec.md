# SDD-324 — 코치 홈·회원·리포트 관리 요약 — 화면 개선과 서버 집계

- 상태: Stage ① Spec
- 브랜치: `sdd/324-coach-mgmt-summary`
- 작성일: 2026-11-09
- 대표 승인(11/9): "시안 반영 + 서버 새 집계도 함께 진행"

## 목적
코치·기관관리자가 회원/리포트 관리 화면 상단에서 "지금 챙길 일"을 한눈에 보도록 서버 집계를 추가한다.
근거 문서: 분석 `analysis.md` §상단 요약 통계 (시안 제외됐던 항목을 이번에 서버로 정의).

## 범위 (BE)
1. 회원 요약 `GET /clients/summary` + `/clients?filter=` 목록 필터
2. 리포트 요약 `GET /reports/summary` + hierarchy `tab` 확장 + hierarchy summary 보정
3. 리포트 상세 GET 읽음 처리 오염 여부 점검·수정
FE는 별도 워커(별도 워크트리). 이 spec의 BE 계약은 `plan.md` §API 계약이 정본.

## 원칙
- 점수·등급·종합 없음. 비율 단정 대신 건수. 밴드 미착용을 문제로 표기하지 않음.
- 오류를 0으로 숨기지 않음(조회 실패는 HTTP 오류).
- 권한은 기존 `/clients`, `/reports/hierarchy`와 동일(코치=본인 범위, 기관관리자=관리 기관 범위).
- 하위호환: 기존 응답 필드·쿼리는 그대로, 필드만 추가.

## 비범위
배포, 마이그레이션 데이터 백필, 프론트 변경.
