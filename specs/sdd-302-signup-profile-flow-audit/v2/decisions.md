# SDD-302 — v2 결정 및 시안 변경

## 이번 대화에서 확정된 결정
- 선택 프로필을 입력하지 않아도 회원 홈을 이용한다.
- ‘나중에 하기’를 누르면 자동 재안내하지 않는다. 30일 재안내 및 별도 다시 보지 않기 체크박스를 제거한다. 재입력은 설정에서 사용자가 직접 시작한다.
- 행사 전 최소안/행사 후 확장으로 나누지 않는다. 전체 가입 과정 개선 후 배포하려는 사용자 의향으로 변경한다.
- 현재 요청은 디자인 시안 재작성이다. 이번 산출물은 제품 구현/배포가 아니다. 실제 배포 환경·범위는 구현 준비 단계에서 구체화한다.
- 이전 spec.md/plan.md의 크림 배경과 30일 후 재안내, 행사 전후 분리안은 이 결정으로 대체한다. 이전 문서 및 시안 원본은 보존한다.

## 디자인 해석
‘이전 클래스 화면’을 designs/class-player-redesign/member.html의 자연 배경+다크 반투명 패널로 해석했다. source의 background8.webp, sheet rgba(24,12,36,.58/.78), text #F7F4F0/#CFC6D6, pale #D2AEFC, pill/24px sheet를 재사용한다. 실제 클래스에는 A/B 안이 있으므로 이 해석과 다른 기존 화면을 뜻했다면 기준을 교체할 수 있다.

## 산출물
- 302-v2-board.html: 가입 시작/소셜/이메일 인증/가입 정보/선택 프로필/보류 후 홈 6화면 비교.
- 302-v2.html: ?screen=으로 화면 이동하는 정적 인터랙티브 시안. 로그인·설정·오류 상태도 포함.
- 302-v2.css / 배경 webp / 브랜드 svg: 기존 제품 자산 기반.
- 기존 밝은 시안과 제품 코드 변경 없음.

## 동작과 검증 범위
이메일 인증번호 받기 → 시안용 OTP 입력 → 정보 입력 → 홈을 연결한다. 소셜은 외부 인증을 호출하지 않고 정보 확인 예시로 이동한다. 폼 기본 required 검증만 제공하며 실제 인증/동의/프로필 데이터를 전송하거나 저장하지 않는다. 프로필 저장과 나중에 하기 이후의 상태도 서버 저장을 시연하는 정적 상태다.
비밀번호 정책·생년월일·코치 코드 검증 등 서버 동작은 미구현이다. 필수 동의는 체크박스 required로 구분하되 전문은 설명용이다.

내장 브라우저는 사용 불가, Paseo 브라우저도 시간 초과였다. 로컬 자동 캡처 대신 사용자가 ‘HTML 시안만 먼저 보기’를 선택했다. 따라서 v2 PNG 생성·390/768 렌더 검증·실제 UI 상호작용 검증은 수행하지 않았다. v1의 캡처 검증 결과를 v2에 적용하지 않는다. HTML/CSS 파일 정적 확인 및 공유 HTTP 응답만 검증한다.
