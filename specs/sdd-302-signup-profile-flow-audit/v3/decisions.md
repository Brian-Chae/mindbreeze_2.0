# SDD-302 — v3 필수·선택 항목 정정

- 사용자 결정: 성별 필수, 전화번호 선택. 회원 주소 DB 필드가 없으면 주소 제외.
- 이메일/소셜 가입 정보 화면에 성별 required select 추가. 빈 선택값으로 제출 불가. 선택 프로필 화면에서는 성별 제거, 전화번호만 유지.
- 나중에 하기 후 자동 재안내 없음은 선택 전화번호에 적용하며 성별 필수 입력을 우회하지 않는다.
- 현재 회원 DB 모델 User(user.py:122 전화)와 ClientProfile(client_profile.py:13–27)을 확인했다. ClientProfile.gender(:18)는 존재하지만 두 모델에 회원 주소 필드는 없다. 코치 주소(counselor_profile.py:27–29)·기관 주소는 회원 주소와 별개이므로 이번 가입 시안에서 주소 제외.
- 운영 DB에 접속하지 않았다. 위 판단은 저장소의 ORM 모델/요청 스키마 기준이다. 현행 서버 gender는 nullable/선택이므로 실제 구현 때 필수 검증과 기존 성별 누락 회원의 최소 보완 동선을 함께 반영해야 한다. 저장된 성별이 있으면 재질문하지 않는다.
- v1/v2 보존, v3만 신규 작성. 제품 코드·DB 변경 없음.
- 사용자의 HTML 우선 검토 선택 유지. 브라우저 렌더·실제 제출 동작은 미검증. JS 구문과 정적 폼 구조 및 HTTP 응답만 확인.
