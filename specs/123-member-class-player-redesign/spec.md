# [SDD-123] 회원용 클래스 화면 디자인 개선

## Goal
회원용(내담자용) 클래스 진행 화면(`GuestMeditationPanel` + `member-class-player.css`)을, 완성된 상담사용 화면(`host-class-player.css` + `HostClassWorkspace`)의 디자인 언어로 개선한다. 데이터 계약은 유지하고 표현층만 교체한다.

## Context
- **기획**: `design/member-class-player/design-update-plan.md` (Claude·Codex·agy 3안 취합 + Brian 확정 보정). 3안이 진단·방향에서 완전 수렴.
- **현재 문제**: ① 순수 검정 `#060507` 배경(보라 틴트 레이어드 없음) ② 6지표가 평면 숫자 카드 3×2("살아있는 지표" 표현 없음) ③ 상담사 화면과 디자인 언어 불일치.
- **Brian 확정 보정(2026-10-04)**: 25초 구간 평균 스로틀 안은 폐기. **숫자·변화량은 매초 실시간(1Hz)**, **데스크톱은 지난 5분 막대 그래프 전체 표시**, **모바일은 현재 상태만(그래프 없음)**.
- **다이얼 처리 확정**: Claude안 채택 — **히어로 1(84px) + 서브 5(44px)**, 선택 지표만 크게. 자동 순환 없음.

## Scope

### ✅ In-scope
1. **토큰 체계 이전**: `#060507` → `#12081C` 캔버스, 서피스 3단(`#1D1027`/`#231531`/`#21132B`), 선택 `#2B1637`+`#B78CCA`, 라벤더 `#DCB5EE` 도입, 민트 `#01F0C8` 의미 한정(연결·재생 점 전용). 난립 보조 텍스트 색 7종 → `--muted` 단일 토큰. radius 12px 통일, 600→500 타이포.
2. **6지표 다이얼 재설계**: 마음(MIND: 집중도·이완도·정서안정도) / 몸(BODY: BPM·호흡·HRV) 2섹션. SVG 아크 링(퍼플→라벤더 그라디언트, round cap) + 중앙 숫자 + 단위. 히어로 1(선택) + 서브 5. `useId()` 그라디언트 고유화.
3. **매초 실시간**: 숫자·변화량(직전 1초 대비)을 `snapshot`(1Hz) 값 그대로 표시. 25초 스로틀 없음.
4. **데스크톱/모바일 분기**: 데스크톱 = 지난 5분 막대 그래프 전체 표시(구간 평균 묶음). 모바일 = 현재 상태만, 그래프 제거.
5. **Zero-scroll**: 1280×720 / 390×844 무스크롤. `.player-right` `overflow-y:auto` → `overflow:hidden` 전환해 회귀 노출.
6. **요소 개선**: 탑바(`종료`→`나가기`, 채팅 우측 액션 그룹), 타이머 블러 글래스 + 진행바, 밴드 상태 1줄(8종 코드), 무음 시그널·BGM·채팅·몰입 오버레이 토큰 적용.

### ❌ Out-of-scope
- 데이터 수집·분석·통신 계약 변경 (`useBand`/`useSessionLiveSocket`/`seriesRef`/`scoreIndices`/`METRICS` 불변).
- BGM 동기 재생 경로·노출 구조 변경 (단, 실재 여부 확인 후 미노출이면 노출까지 — §함정 참조).
- 개인 점수·순위·그룹 평균·집계 노출 (계속 금지).
