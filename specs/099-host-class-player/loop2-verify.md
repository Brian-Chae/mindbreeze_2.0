# 루프2 — 수정 전 대조·검증 계획

2026-10-03. 사용자 요청 「루프2 — 목업 일치성 검증 + 개선」이 수정 및 빌드 실행을 명시적으로 승인했다. 기존 루프1 파일과 목업을 보존한다.

## 원인과 수정 범위

- 카드에 성별·나이 자리가 없고 136px 높이·증감 세로 배치로 정본과 다르다. 공통 프로필 표시 함수를 통해 카드/테이블/상세에 `—`를 제공한다.
- 신호 카드 42px 행·모바일 제목 줄바꿈, 그룹의 모바일 지표 간격이 정본 최종 cascade와 다르다.
- 상세가 목록 높이만 사용하고 배경·링/몸 지표 간격이 다르다. roster 내부에 높이를 확보하고 닫기 3종과 포커스 복귀를 유지한다.
- 선택 칩이 정본의 둥근 pill·선택 토큰과 다르다.
- 사용자 174×152px·5열 요구는 목업 후속 CSS의 120px(모바일 96px)보다 우선한다. 모바일은 2열 유지.
