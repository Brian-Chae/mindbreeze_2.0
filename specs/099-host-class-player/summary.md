## 명시적으로 남긴 정본과의 차이

- 목업 CSS의 후속 override는 데스크톱 카드 높이 120px이지만, 사용자 명시값 174×152px·5열을 우선했다. 모바일은 정본의 최종 96px 높이를 사용한다.
- 성별·나이·사전 설문은 계약에 없으므로 모두 `—`. `hostParticipantProfile(row)`에 `// TODO: 백엔드 계약 확장(gender/birth_date/concerns)`를 추가했다. SessionLiveMetric 확장 후 이 함수만 연결하면 카드·테이블·상세가 함께 반영된다.
- 목업의 임의 정상범위·그룹평균 마커·고정 시연 추이/증감은 이식하지 않았다. 범례는 실제 표시 중인 현재값·최근 수신값·3분 대비를 설명한다. 이력이 부족하면 추이 대기다.
- 기존 실서비스 헤더·미디어/BGM/녹음·상태 전이 컨트롤은 유지한다. 목업 전체 화면과 픽셀 단위 동일성을 주장하지 않는다.

## 검증

- `npx vitest run tests/host-class-workspace.test.tsx tests/quiet-signal.test.ts tests/group-aggregate.test.ts tests/class-chat-panel.test.ts` — 4파일, **40개 통과**.
- 신규 컴포넌트 테스트 6개: 프로필 placeholder, 칩/순환/자동 정렬, 테이블 수동 정렬·행 상세, 상세 닫기 3종·포커스, 선택 참가자 퇴장 후 순환 복구, 179초/180초 변화량 정렬.
- 수정 전 placeholder 누락·퇴장 후 순환 정지 테스트 실패를 확인한 후 수정했다.
- `npm run build` — **tsc + Vite 성공, 종료 코드 0**. 기존 tokens.css import 해석 경고와 500kB 초과 청크 경고는 남아 있다.
- `git diff --check` 통과.
- 독립 읽기 전용 코드 리뷰: 이번 범위에서 중대한 회귀 없음.
