# 루프4 수정 전 검증 계획

사용자 요청(2026-10-03): “구현 금지 아님 — 수정 + 검증”. 기존 SDD-099의 잔여 수정 수행 승인으로 적용한다. 신규 기능 기획이 아니다.

- 최종 CSS cascade: 상세 578/690px와 내부 스크롤, 그룹 링 68/30px, 카드 정렬, 푸터 컨트롤 대조.
- 기존 명시 규격인 데스크톱 174×152px 카드와 모바일 148px 좌측 칼럼 유지.
- 빈 참가자 목록은 상태 안내만 표시. 전원 밴드 미사용은 표본 없음, 미확인 0건은 pill 없음.
- 상세 aria-modal, Tab/Shift+Tab, 닫기/Esc/백드롭 및 테이블 셀 클릭 후 포커스 복귀.
- 1280×720 / 390×844: 문서 넘침, 0/1/6명, 상세 끝까지 스크롤, 테이블 내부 스크롤.
- 관련 Vitest 회귀 + npm run build 종료 코드 0. 모의 화면과 실기기 미검증 범위를 결과에 구분.

수정 전 증거: 신규 회귀 3건 실패(빈 테이블, 표본 없음, 테이블 포커스 복귀). 기존 8건 통과. loop4-before-layout.json 및 캡처 확보.
