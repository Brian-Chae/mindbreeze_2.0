## 실제 데이터와 시간

- [ ] 기존 훅 및 applyEegFeatureToMetricsDetailed·scoreIndices·signal-status 의미 유지.
- [ ] EEG feature 추가 3지표가 실제 수신값으로 표시되고, 폴링 후 임의 소실·오래된 값 복원이 없음.
- [ ] 미수신·NaN·무한대는 대기, 0은 유효값. 정서안정도를 스트레스 역수로 추정하지 않음.
- [ ] 밴드 미사용/끊김/stale/리드오프 시 현재값·평균·증감에서 부적절한 값을 제외.
- [ ] 179초는 추이 대기, 충분한 180초 이력 이후 3분 대비 표시. 늦은 입장과 재연결도 같은 조건.
- [ ] 현재값·과거 평균이 같은 지표와 단위를 사용하며 그룹 비교는 동일한 유효 표본 사용.
- [ ] 서버 aggregate의 baseline_relative·sample_status·min_wearers 의미 보존.
- [ ] 성별·나이·사전 설문에 목업의 고정 데이터를 사용하지 않음. 자료 없으면 정보 없음.
- [ ] 다른 세션/run/참가자 이력이 섞이지 않음. 퇴장 시 선택된 상세와 시계열을 적절히 정리.
