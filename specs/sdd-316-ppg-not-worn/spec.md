# SDD-316 — 밴드 미착용 시 심박·HRV·호흡수를 값 대신 "착용 필요"로 처리

- 상태: Stage ① Spec (대표 승인 2026-11-06: 착용 판정 = PPG 직류 레벨, 설계 A = 코어 처리)
- 브랜치: `sdd/316-ppg-not-worn`

## 1. 문제
밴드를 벗어도 PPG 센서는 공기/외부 광 값을 계속 보낸다. 코어 PPG 경로(`dsp/ppg.rs`, `dsp/hrv.rs`, `engine.rs run_ppg`)에는 착용 가드가 없어
BPM 이 한 값으로 고정(오늘 109, 어제 96·101·121)되고 SDNN·RMSSD·호흡수도 공기값으로 계산돼 화면에 숫자로 나간다.
`guard.rs`(포화·계단·lead-off·갭)는 EEG 지표 전용이다.

## 2. 착용 판정 신호 조사 결과
| 후보 | 결과 |
|---|---|
| PPG 패킷 자체의 접촉 정보 | 없음. 샘플 = red/ir BE uint24 뿐 (`parser.rs`, `linkband-docs/sdk/data-spec.mdx`) |
| EEG lead-off 비트 | 있음(bit0=ch1, bit2=ch2). 단 문서·SDK 모두 "EEG 전극 접촉"으로만 정의, PPG 착용 판정에 쓰라는 근거 없음. EEG 미사용 세션에서는 판정 불가 |
| SDK 문서/코드 | PPG 착용 판정 로직 없음 |
| **결정** | PPG IR 직류 레벨(히스테리시스). 정식 신호가 아니라 실측 근거에 의존함을 명시 |

## 3. 실측 분포 (dev 회차, 원시 PPG 패킷, 50Hz)
| 회차 | 미착용 IR(<100k) | 착용 IR(>1M) | 중간(100k~1M) |
|---|---|---|---|
| 83a39b18 | 72,068샘플, 2,641~41,248 | 20,662샘플, 최소 1,134,896 | 3,702샘플(착탈 전환 약 74초) |
| 1df2153e | 21,314샘플, 3,870~32,704 | 14,969샘플, 최소 1,139,987 | 5샘플 |
- 미착용 최대(41k)와 착용 최소(1.13M) 사이 약 27배 간격. 중간값은 전환 과도기에서만 나타난다.

## 4. 판정 규칙
- 샘플 단위 상태기계(전달 단위·cadence 무관, 결정적):
  - 진입(worn→not_worn): IR < **100,000** 이 연속 **150샘플(3초)**.
  - 복귀(not_worn→worn): IR ≥ **500,000** 이 연속 **150샘플(3초)**.
  - 그 외(진입 조건 미충족, 중간 구간 포함)는 직전 상태 유지, 연속 카운터는 해당 조건을 벗어나면 0 으로 리셋.
- 초기 상태 = worn(알 수 없을 때 숨기지 않는다). 시작부터 벗은 경우 3초 후 not_worn.
- 임계 선택 이유: 100k 는 미착용 최대(41k)의 2.4배 여유, 500k 는 착용 최소(1.13M)의 절반 이하이고 과도기 잡음(100k~500k)에서 복귀 오판을 막는다. 3초는 ppg 분석 주기(1초) 3회 — 접촉 순간 끊김의 깜빡임 방지.
- 값 클램프·null→0·임의 보정 없음.

## 5. 동작
- not_worn 진입 시: HR 평활·bpm 버퍼·RR 버퍼·호흡 이력·LF/HF 상태·SDNN/RMSSD 모두 비움, PPG 링도 비움(공기값 오염 방지). motion(ACC)은 유지.
- not_worn 중: PPG 분석 건너뜀. 1초마다 `LatestPpg{not_worn:true}` 기록 → 프레임 BPM·SDNN·RMSSD·LF/HF·호흡 = value null, validity `invalid`, reason `not_worn`.
- 복귀 시 PPG 링을 한 번 더 비워 전환 과도기 값이 섞이지 않게 한다. 이후 정상 warming_up → valid.
- EEG 지표·motion 은 영향 없음.

## 6. 설계 비교

| A (채택) | 코어에서 null+사유 | Android/iOS/웹 WASM 이 동일 코어 → 저장값·화면·리포트 일관 |
| B | 표시층에서만 숨김 | 서버 저장값·리포트 평균에 공기값 남음, 플랫폼별 불일치 |

## 7. 계약·ABI·하위호환
- C ABI: **불변**. 사유는 프레임 `reason` 문자열(`^[a-z][a-z0-9_]{0,63}$`)만 추가. `PpgEmission`(Rust 진단용, serde 제외)과 내부 상태 필드만 추가.
- 체크포인트: `LatestPpg.not_worn`·`HrvState` 신규 필드는 `#[serde(default)]` → 구 체크포인트 복원 가능(단 fingerprint 정책은 기존대로).
- 구 서버/구 클라이언트: validity `invalid` + 새 reason 문자열을 그대로 null 로 취급. 구 APK 는 계속 숫자를 내므로 **앱 재빌드 필요**(웹은 WASM 재생성 필요).
- 서버 `eeg_feature_windows`: null 로 저장, 마이그레이션 없음(구현 단계에서 리포트 집계의 null 처리 확인해 summary 에 기록).

## 7-1. 범위 추가 (대표 승인 11/6): RR 중앙값 ±25% 게이트 락인 수정 (후보 B)
- 결함: 가짜 박동이 RR 버퍼를 선점하면 기준 중앙값이 굳어 진짜 박동이 전부 탈락 → SDNN·호흡 영구 null (웹 `AnalysisMetricsService.ts` 와 코어 `hrv.rs` 동일 결함).
- 수정: 새 박동이 **연속 12창** 전부 게이트 탈락하면 버퍼·호흡이력·파생 플래그를 비우고, 탈락 풀의 자체 중앙값 ±25% 박동으로 재시드. 상수 `RR_GATE_RESEED_STREAK=12` 를 코어·웹이 공유.
- 후보 A(기준 20개 한정)는 오염 초기값이 20개 안이면 못 풀고, C(not_worn 진입 시 리셋)는 이미 §5 에 포함 → B+C 최소 조합.
- 웹 TS 도 동일 적용(대표가 '웹 무수정 원칙' 해제).

## 8. 화면 (최소)
- 코어 프레임 reason=`not_worn` → 라이브 어댑터(`liveNotWorn`)가 사유를 읽어 회원 화면 BPM·HRV·호흡 칸(상태 시트·히어로 링 보조 문구)에 표시. 호흡·HRV·BPM 칸이 null 이고 사유가 `not_worn` 이면 "측정 중" 대신 "밴드를 착용해 주세요". 새 화면 없음, 금지 표현(점수·좋음·나쁨·완료·보증·100%) 사용 안 함.
