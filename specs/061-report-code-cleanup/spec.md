# SDD-061 — 리포트 코드 품질 정리

> 리포트 관련 프론트/백엔드 코드의 미사용 import·죽은 코드·중복을 정리한다.

## 1. 배경
- 여러 SDD를 거치며 미사용 import/함수/타입이 남아 있을 수 있다.
- score 표시 제거 등으로 쓰지 않게 된 코드 정리.

## 2. 구현 범위 (codex)
- 프론트 리포트 관련 파일: 미사용 import/변수/함수 정리 (build 경고·TS6133 등)
- 백엔드 리포트 관련 파일: 미사용 import/함수 정리
- 죽은 코드(주석 처리된 레거시 등) 정리
- 단, 동작 변경 없음 (순수 정리)

## 3. 완료 기준
- 정리 후 BE pytest 통과, FE build 0 error
- 동작 회귀 없음
