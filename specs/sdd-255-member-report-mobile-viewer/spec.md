## 승인 기록
- 대표 발언(2026-10-29): "응 좋아. 기획안대로 구현하자" — 기획안·시안·추천 결정 4개 승인.

## 1. 문제
회원 리포트는 모바일 기준 설계이나, 화면이 넓어지면 추이선·막대 그래프가 가로로 늘어나고 지표 카드가 2열로 퍼진다. 상담사 검토 패널도 같은 본문을 써서 폭에 따라 모양이 흔들린다.

## 2. 목표
1. 회원용 리포트는 어떤 화면에서든 최대 430px 한 컬럼 뷰어로 보인다. 뷰포트 ≤560px는 전체 폭.
2. 뷰포트 ≥561px에서만 '데스크톱 보기' 버튼을 노출하고, 클릭 시 현재의 넓은 레이아웃을 모달로 연다.
3. 회원 앱 리포트 상세·상담사 검토 패널(회원용)·메일 토큰 열람 페이지가 같은 뷰어를 쓴다.

## 3. 확정 결정
| # | 결정 |
|---|---|
| 1 | 상담사 검토 패널도 모바일 뷰어 고정 = 예 |
| 2 | 데스크톱 보기 선택 기억 = 아니오 (항상 모바일 뷰어로 시작) |
| 3 | 메일 토큰 열람 페이지 적용 = 예 |
| 4 | PDF 변경 없음 · 상담사용(type counselor) 리포트 변경 없음 |

## 4. 요구사항
- R1 뷰어 프레임 `max-width:430px`, 가운데 정렬, ≥561px에서 카드형(둥근 모서리·옅은 그림자·보라 크림 배경). ≤560px 전체 폭·장식 없음.
- R2 프레임 안은 **프레임 폭 기준**(CSS container query)으로 모바일 레이아웃: 지표 1열, 그래프 `max-height:210px`, 사이드 목차 숨김, 모바일 타이포 토큰.
- R3 '데스크톱 보기' 버튼: 뷰어 상단 우측, ≥561px에서만 표시, 터치 타깃 44px, 라벨 "데스크톱 보기".
- R4 모달: native `dialog`, 최대 1240px, ESC·바깥 클릭·닫기 버튼으로 닫기, "모바일로 보기" 보조 버튼, 닫으면 호출 버튼으로 포커스 복귀. 모달 안은 프레임 제한 없는 기존 뷰포트 기준 스타일.
- R5 선택은 저장하지 않는다.
- R6 파급 금지: 상담사용 리포트·PDF 렌더·전역 토큰·다른 화면 불변. 변경은 `.member-report-frame` 범위로 한정.

## 5. 범위 밖
PDF 레이아웃, 상담사용 리포트, 모바일 앱(Capacitor) 전용 변경, 서버 API.
