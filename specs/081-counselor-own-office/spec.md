# SDD-081 — 상담사 개인 상담소 자동 개설 (가입 시 기본 소속)

> 상담사가 가입하면 "개인 상담소(kind=individual)"를 자동 개설해 기본 소속으로 배정한다.
> 기관에서 해제돼도 개인 상담소가 남아 무소속 상태가 원천적으로 사라진다. **claude(fable) 위주로 개발**.

## 1. 정책 확정 (Brian)
- 상담사 가입(초대 수락·개인 신청 승인) 시 개인 상담소 자동 개설 + 주 소속 배정
- 개인 상담소 이름: `{상담사 이름} 개인 상담소` (중복 시 코드 접미)
- 개인 상담소 재사용 (owner_user_id 기준, 중복 생성 금지)
- 기관 해제 → 개인 상담소 복귀 + 안내 메일 + 로그인 팝업
- 개인 상담소는 기관 관리자 화면(기관 목록·구성원)에서 숨김 (소유자 본인만 접근)

## 2. 구현 범위 (claude fable)

### T1. 개인 상담소 자동 개설
- 상담사 가입 시점(초대 수락 `consume_invite`, 개인 신청 승인 `signup_application_service`)에
  개인 상담소를 생성(없으면)하고 membership(active, is_primary=True)으로 배정
- 개인 상담소: `kind='individual'`, `owner_user_id=상담사`, `name='{이름} 개인 상담소'`, `verified=True`
- 기존 개인 상담소가 있으면 재사용 (owner_user_id로 조회)

### T2. 기관 해제 → 개인 상담소 복귀
- 소속 해제(membership status='left') 시 남은 active 소속이 개인 상담소뿐이면 그대로 유지 (무소속 아님)
- 안내 메일: "기관에서 해제되어 개인 상담소로 등록되었습니다" (기관명 + 개인 상담소 안내)
- 로그인 시 안내 팝업 (해제·전환 사실 최초 1회 안내)

### T3. 개인 상담소 숨김
- 기관 관리자 화면(org 목록, 구성원 목록, org 검색)에서 kind='individual'인 개인 상담소 제외
- 단, 소유자 본인의 대시보드에서는 "내 개인 상담소"로 노출

### T4. 안내 메일 + 로그인 팝업
- 기관 해제 시 안내 메일 발송 (email worker)
- 로그인 시 안내 팝업 (해제 사실 1회 안내, 확인 후 재노출 안 함)

## 3. 주의
- 개인 상담소는 상담사 개인 자산 — 기관 관리자가 접근/수정/삭제 불가
- 개인 상담소 중복 생성 금지 (owner_user_id unique-ish)
- 이메일 = 아이디 유지, counselor_code = 계정당 1개 유지
- 기존 개인 상담사 신청(SDD-073) 로직과 정합 — 이미 개인 기관을 만드는 경로가 있으면 재사용

## 4. 완료 기준
- 상담사 가입 시 개인 상담소 자동 개설 + 주 소속 배정
- 기관 해제 시 개인 상담소로 복귀 (무소속 상태 없음)
- 안내 메일 + 로그인 팝업
- 개인 상담소가 기관 관리자 화면에서 숨김
- BE pytest 통과, FE build 0 error
