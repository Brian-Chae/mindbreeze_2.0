# SDD-318 — 내담자 앱 화면 D안 적용 (기능 플래그, dev 한정)

- 상태: Stage ① Spec 완료 → ② Plan → ③ Verify
- 브랜치: `sdd/318-client-ui-v2-flagged`
- 작성일: 2026-11-06
- 승인: 대표 승인(11/6) — 단계 ③~⑥ 연속 진행

## 1. 무엇을, 왜
내담자(client) 모바일 화면을 시안 D(클래스 플레이어 구조 + 밝은 색)로 교체한다. 시안 정본: `~/.hermes/share/design-1106/D/`.
**기능 플래그 `UI_V2`(`VITE_UI_V2`, 기본 false) 뒤에서만** 바뀐다. dev 빌드는 켜고 운영 빌드는 끈다.
11/11 행사 직전이므로 **플래그 off 상태의 운영 화면은 한 픽셀도 바뀌면 안 된다**(최우선 불변 조건).

## 2. 범위
| 포함 | 제외 |
|---|---|
| 플래그 `UI_V2` | 상담사·기관·관리자 쉘 |
| `.ui-v2` 스코프 토큰 CSS(신규 파일) | 채팅·알림·설정·가입·온보딩 |
| 내담자 쉘(접히는 큰 제목 헤더 + 플로팅 하단 내비) | 클래스 플레이어·대기실 |
| 화면 5개: 홈 / 클래스 목록 / 클래스 상세 / 리포트 목록 / 리포트 상세 | 백엔드·코어·앱 빌드 |
| 라이트 아크 링 공용 컴포넌트 1개 | 전역·프리셋 토큰 수정 |

## 3. 화면별 현행 → 시안 변경표
| 화면 | 현행 | 시안 D | 시안에 없어 유지할 기존 기능(D 언어로 배치) |
|---|---|---|---|
| 홈 | 히어로(다크 배경 이미지)·요약 타일·내 클래스 스트립·상담·`CounselorSection` | 다음 클래스 히어로(46px 시각+아크) → 이번 주 클래스 → 최근 리포트 → 새 알림 → 최근 대화 | 초대 카드, 코드로 입장 버튼, 담당 코치 섹션, 상담 섹션(상담 플래그 on일 때), 이어서 예정 일정 |
| 클래스 목록 | 2열 카드, 그룹(참여 중/완료/대기/이탈/기타) | 참여 상태별 카드 스택 + 전체 회차 숫자 | 클래스 신청하기, 코드 입력, 클래스 코드 가입 폼, 대기·이탈 그룹, 로딩/오류/빈 상태 |
| 클래스 상세 | 개요 카드·진행바·탭(개요/회차)·회차 카드 | 아크 커버 + 세로 회차 타임라인 | 멤버 작업(나가기/대기 등 `MemberOperations`), 개요 탭, 입장하기 링크, `sessionId` 선택 강조 |
| 리포트 목록 | 모바일 카드·검색·정렬·코치별 그룹·전체 읽음 | 제목·서사 중심 카드 | 검색·정렬·그룹·전체 읽음, 검토 중 내용 비노출, 페이지네이션 |
| 리포트 상세 | 다이얼로그 + 툴바 + `ClientReportViewer` + 과거 비교 | 큰 제목 + 전체 폭 흰 시트 | dialog 동작(ESC·포커스 복원·배경 차단), 닫기 버튼, 검토 중 안내, 과거 리포트 비교 |

## 4. 제약
- 금지 표현(화면 문구): 점수·종합점수·좋음·나쁨·완료율 단정·보증·100% 단정. 리포트는 서사·변화량만. 원시→"측정 기록 파일", feature→"분석 데이터".
- 밴드 미착용 사용자도 성립(EEG 없이). `bandConnected` 가드 유지.
- 접근성: 본문 대비 4.5:1, 터치 44px, `prefers-reduced-motion` 존중, 하단 예약 `140px + env(safe-area-inset-bottom)`, 390~393px 제목 잘림 금지.
- 코딩: kebab-case 파일, PascalCase 컴포넌트, `any` 금지, 불변성. 기존 테스트 불변.
- 금지: 푸시·PR·배포·메일·삭제·dev/운영 DB 접근·앱 빌드. 커밋은 로컬 브랜치만.
