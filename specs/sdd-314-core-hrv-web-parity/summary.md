## 6. HR/HRV 두 경로 피크 비교 (iOS 호흡이 아니라 신호 품질 분석)
| 항목 | 62c5fe4b | 8d857524 |
|---|---|---|
| 창당 피크: HR 경로(적응 임계) / HRV 경로(불응기) 중앙값 | 9 / 11 | 7 / 10 |
| 간격 중앙값 → bpm: HR 경로 | 580ms → 103 | 680ms → 88 |
| 간격 중앙값 → bpm: HRV 경로 | 520ms → 115 | 560ms → 107 |
| HRV 경로 RR 중 450ms 미만 비율 | 39% | 42% |
| 유일 박동 수 / 분 (HRV 경로) | 113.8 | 114.9 |
| 국소 중앙값(±15박) 대비 ±25% 정상 / 짧음 / 긴 RR | 57% / 18% / 25% | 55% / 16% / 28% |
| 이중 피크 쌍(둘 다 <0.75×기준, 합≈기준) | 28쌍 | 9쌍 |
| SDNN: 전체 RR / ±25% 통과분 | 259 / 228 ms | 246 / 164 ms |

해석:
- **이중 피크는 주원인이 아니다**(9~28쌍 / 약 3600박). 불응기 300ms 가 거의 처리한다.
- 박동의 43~45% 가 국소 기준에서 ±25% 이상 어긋난다: 짧은 RR(16~18%) = 가짜 피크 추가, 긴 RR(25~28%) = 박동 누락. 즉 **피크 추가와 누락이 동시에** 생긴다. 사용자 PPG 자기상관 0.18~0.26(정상>0.5)과 일치.
- 두 경로의 피크 집합이 다르다: HRV 경로가 HR 경로보다 박동을 15~25% 더 잡는다(→ 표시 HR 은 85~96, RR 역수는 107~115). HR 은 적응 임계로 약한 피크를 덜 잡아 상대적으로 현실적이다.
- iOS SDNN 117 은 웹 TS 와 같은 값이며 신호 품질 문제다. 중앙값 필터 통과분만으로도 164ms 로 정상 범위(<~100)를 넘는다.
