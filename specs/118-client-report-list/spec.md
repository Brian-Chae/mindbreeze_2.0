# SDD-118 회원 리포트 목록

회원 리포트를 상담사용 목록 패턴에 맞춰 개편한다.
- md 이상: 제목/세션유형/날짜/상태/액션 테이블. 모바일: 기존 카드.
- 제목·세션 검색, 최신순/오래된순/제목순, 세션 그룹핑 기본 ON.
- listReports({page, limit:20}), total 기반 페이지 수와 표시 건수. 검색·정렬 변경 시 1페이지.
- 기존 상담사 화면과 동일하게 검색·정렬·그룹핑은 현재 조회 페이지에 적용한다.
- sent_at 기준 확인 가능/대기, 기존 상세 모달 및 헤더/빈 상태/재시도 유지.
- 상담사용 필터·관리 기능·개인정보 열은 추가하지 않는다.

사용자가 승인 게이트 없이 즉시 구현을 명시했으므로 별도 승인 대기 없이 진행한다.
