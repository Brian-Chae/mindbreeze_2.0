# 구현 전 검증 항목

구현 전에 작성. 사용자 지시로 승인 대기는 생략한다.

- [x] 데스크톱 테이블과 모바일 카드가 md 기준으로 분기된다.
- [x] 제목과 세션 제목을 공백/대소문자 무관하게 검색한다.
- [x] 세 정렬 모드가 예상 순서로 표시된다.
- [x] 세션 그룹핑은 기본 ON이며 OFF 시 평면 목록이다.
- [x] 페이지당 20건 요청, total 기반 페이지 경계 및 필터 변경 시 1페이지 초기화.
- [x] 검색 결과가 없는 페이지에서도 페이지 이동이 가능하다.
- [x] 상태는 확인 가능/대기, ID 없는 리포트는 열리지 않는다.
- [x] 행/보기/카드에서 모달을 열고 닫기·포커스 복원이 유지된다.
- [x] 빈 목록/오류/재시도와 늦은 응답 취소를 확인한다.
- [x] 관련 vitest 및 프로덕션 빌드를 통과한다.

검증 방식: DOM 기반 vitest. 실제 브라우저의 시각적 QA는 수행하지 않았다.
