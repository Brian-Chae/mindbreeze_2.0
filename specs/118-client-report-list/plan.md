# 구현 계획

1. 회원 목록 DOM 테스트를 추가하고 미구현 기능의 실패를 확인한다.
2. ClientReportListPage에 검색/정렬/그룹핑 함수를 상담사용 패턴에 맞춰 적용한다. 상담사용 파일의 기존 변경은 보존한다.
3. 페이지/전체 건수 상태와 API 요청, 반응형 테이블/카드, 상태 및 페이지네이션을 구현한다.
4. 새 테스트와 기존 모달 회귀 테스트, 리포트 관련 vitest 및 npm run build를 실행한다.

검토 중점: 제목 없이 headline만 있는 항목, 같은 세션의 여러 리포트, 날짜 없는 항목, 검색 결과 없음, 페이지 요청 실패/늦은 응답, ID 없는 항목, 키보드와 모달 포커스 복원.
