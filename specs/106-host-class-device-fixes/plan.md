# SDD-106 호스트 클래스 실기기 버그 수정 [Fix]

사용자가 승인 게이트 없이 즉시 구현하도록 명시했다. 실제 기기 연결·배포 대신 정적 경로 분석 및 회귀 테스트로 검증한다.

## 원인 분석 및 작업
- 셀프뷰는 라이트 색상 고정: dark 선택 속성을 추가하고 호스트 클래스에서만 사용한다.
- EEG WS/REST 인증·저장·호스트 전파를 추적한다. REST 저장 뒤 브로드캐스트가 없는 경로를 수정한다.
- 신호 버튼 disabled, 화면 가림, 소켓 수명, 참가자 식별 및 서버 전파를 추적하고 재현된 결함만 수정한다.
- 기존 payload 및 인증/동의 검증은 유지한다.
- 회귀 테스트 실패 확인 → 최소 수정 → 관련 테스트 및 프런트 빌드.
