# SDD-106 구현 전 검증 시나리오

- [ ] dark 프리뷰의 카드·제목·설명·권한 오류·마이크 경고·확인 창이 다크 테마로 표시된다.
- [ ] 기본 프리뷰는 기존 라이트 테마를 유지한다.
- [ ] 비로그인 참가자와 로그인 회원의 EEG 업로드가 기존 소유권/동의 검증을 유지한다.
- [ ] WS 업로드와 REST 폴백 모두 호스트 EEG/집계 갱신으로 이어진다. 중복/오래된 데이터는 최신값을 회귀시키지 않는다.
- [ ] 신호 버튼 클릭 성공/실패, 미연결/미식별 상태 및 호스트 수신 경로를 검증한다.
- [ ] 프런트 관련 회귀 테스트, 전체 vitest, npm run build 및 관련 백엔드 테스트를 실행한다.

실기기·dev 배포는 이번 검증 범위 밖이다. 사용자 지시에 따라 별도 승인 대기 없이 구현한다.
