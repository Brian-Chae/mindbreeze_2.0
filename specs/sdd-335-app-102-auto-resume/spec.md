## 배경 (11/25 운영 조사)
- 몸돌봄 4회차: 진*진(iOS 1.0.0) `user_left` 후 재진입했지만 밴드 데이터 0 / 박*선(Android 1.0.0) `user_stop` 후 재시작 없음 / 이*은 입장 동의 화면에서 뇌파 '거절' → 측정 미시작 → 재동의 후에도 데이터 0.
- 마음돌봄 3회차: 앱 1.0.1 회원이 14:31 밴드 연결 → 14:37 수업 시작 시 앱이 백그라운드라 끝까지 측정 0.
- 1.0.1 기기의 RMSSD·SDNN은 수정 후 값(엔진 수정 4c46bca8·84cd80cf 포함). 기록 없는(=1.0.0) 기기는 과대값 → 1.0.0 사용자 차단이 해결책.
- 미뤄 둔 버그: `raw-capture.ts:17` PPG 헤더 바이트 순서(근거 `docs/ppg-clock-reset-1123/report.md`).

## 범위
1. 측정 자동 재시작 — 앱이 포그라운드로 돌아올 때 측정 엔진이 멈췄거나(BLOCKED/CLOSED/IDLE/stream 없음) 시작 실패 상태면 정지→새 요청으로 재시작. 수업 대기·측정 중 화면 꺼짐 방지는 기존 `useWakeLock(wait|live)` 유지.
2. 수업 화면 재진입 재연결 — 이탈로 native stop(`user_left`) 된 뒤 같은 회차에 다시 들어오면 **새 requestId**(세대 번호 증가)로 시작해 capture_stream 이 새 generation 으로 열린다. 측정 중 뒤로가기(SPA 이동·하드웨어 뒤로)는 확인 창.
3. 동의 화면 안내 — 뇌파 수집 미선택/거절 시 "이번 수업의 측정과 리포트 지표가 없어요" 안내, 다시 선택 가능. 동의 정책 불변.
4. 구버전 차단 — 기존 `latest.json`(download.mindbreeze…) 매니페스트에 선택 필드 `minAppVersion`(예 "1.0.1") 추가. 네이티브 앱이 수업 입장 화면 진입 시 확인해 미만이면 스토어 업데이트 화면으로 유도(웹 제외, 조회 실패 시 통과). 서버 입장 API 차단 검토 결과는 `plan.md §4`.
5. PPG 헤더 `getUint32(0, true)` + 테스트.
