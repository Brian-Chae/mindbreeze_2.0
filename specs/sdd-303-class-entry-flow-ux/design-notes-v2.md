전체 개선 대상은 기존 plan.md의 A안 전체이며 행사 전 1탭 축소에 한정하지 않는다. 동의 보존, 신규 가입 의사 확인, 밴드 opt-in, OS 제스처, SDD-293 인계 조건은 유지한다. 실제 앱 구현과 배포 검증은 아직 수행하지 않았다.
