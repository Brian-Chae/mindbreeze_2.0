# SDD-303 — 시안 설계와 확인 기록

## 시안 범위
`303-preview.html`은 단일 HTML 합성 시안이다. 현재 화면은 코드에서 확인한 순서·문구를 재구성한 흐름 지도이며 실제 제품 캡처가 아니다. After는 행사 후 A안이며 제품 구현이 아니다. 상단 링크로 현재/코드/첫 입장/밴드/재입장/밴드 없음 상태를 비교한다.

390px·768px에서 동일한 단일 주 행동을 유지한다. 주 버튼은 보라색, 밴드 미사용은 별도 보조 행동이다. 동의는 기본 미선택이고 필수 체크와 리포트 명시 선택 후 진행한다. EEG 거절은 밴드 없음으로 바로 이동한다. 기존 선택 확인은 서버 조회 성공을 가정한 합성 상태다.

## 시각·상호작용 원칙
- 현장 용어는 클래스·코치·밴드·대기실. 수업 내용/날짜는 예시이며 실제 일정으로 사용하지 않는다.
- 권한 설명을 연결 화면에 둬 ‘연결하기 → 설명 확인’을 한 동작으로 줄인다. 실제 OS 창은 구현하지 않는다.
- 접촉 확인 수신, 수업 시작 수신은 검토용 버튼으로만 가정한다. 타이머로 성공을 꾸미지 않는다.
- 첫 입장 동의 원문은 실제 정책을 연결해야 한다. 여러 항목을 한 화면에 두는 시각적 제안이며 동의 범위/법적 적정성 검증이 아니다.
- 화면 수는 논리 화면 기준. 밴드 미연결/연결중/접촉 변화는 한 화면, 권한 시트는 별도이다. 상태 화면 기준으로 밴드 연결됨을 별도 세면 현재 화면 수가 +1임을 독립 검토에서 확인했다.
- 기획 수치 9→3탭은 이미 가입했고 개인정보·EEG 동의가 유효하지만 회차 리포트 선택이 필요한 오프라인 회원 기준이다. 첫 입장은 미결 동의 항목 수만큼 추가 탭이 있다.

## 검증 범위
HTML 로컬 렌더·상태 전환·가로 넘침·버튼 크기·금지 문구 검사와 PNG 시각 확인을 수행한다. 검사 결과는 `303-check.json`에 기록한다. 제품 앱 빌드, 운영 API, BLE, OS 권한, 네이티브 인계, 푸시 수신, 40명 동시 입장은 실행하지 않는다.

## 기존 자료 보존
기존 spec 초안의 제목·브랜치·작성일을 확장했다. 기존 공유 폴더의 299-* 파일은 변경하지 않고 신규 303-* 파일만 복사한다. 제품 파일은 수정하지 않는다.

## 독립 검토 반영
현행 논리 화면 8/9개, 탭 9/10회 산식은 독립 검토에서 코드와 부합함을 확인했다. 설정 왕복 시 밴드 미사용 상태 유지, EEG 동의/거절 명시 선택, 네이티브 인계 순서 문구를 수정했다. 리포트는 드롭다운 대신 라디오로 바꾸어 한 번의 선택 행동과 물리 탭을 맞췄다. Before에 단계 지도와 별도로 `?state=before-screen` 입장 확인 화면 재구성을 추가했다.

## 최종 확인 결과
390px·768px 11상태씩 PNG 22개 생성. 가로 넘침 0건, 금지 문구 0건, 44px 미만 버튼/탐색 링크 0건, 스크립트 오류 0건. 상태 전환 7개 검사 통과. 연락 시트와 첫 입장·현재 화면 재구성 PNG를 시각 확인했다. 공유 디렉터리·HTML HTTP 200, 기존 공유 파일 185개 해시 불변. git 상태는 본 산출물 디렉터리만 untracked이며 추적 제품 파일 diff 없음. 세부 결과는 303-check.json과 303-delivery-check.json 참조.
