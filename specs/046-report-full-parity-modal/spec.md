# SDD-046 — 리포트 정본 완전 정합 + 샘플 팝업 모달

> 정본(design/report-redesign/index.html)과 완전히 동일한 디자인으로 맞추고,
> 샘플 보기를 별도 페이지가 아니라 **팝업 모달**로 띄운다.

## 1. 배경·원인

- 정본(index.html)에는 ① 커버(표지 "나에게 돌아온 20분") ② 왼쪽 사이드바 내비게이션(01~05)이 있다.
- 현재 NarrativeSections는 02 종합 여정부터 시작해 **커버와 사이드바가 빠져 있다.**
- 샘플 보기는 별도 라우트(`/reports/sample`)인데, 사용자는 **팝업 모달**을 원한다.

## 2. 구현 범위

### T1. 커버(표지) + 사이드바 추가 (정본 완전 정합)
- 정본 index.html의 구조를 그대로 React로 옮긴다:
  - **사이드바**: "오늘의 명상 기록" + 01 나의 명상 / 02 종합 여정 / 03 몸의 변화 / 04 마음의 변화 / 05 마무리 (앵커 내비게이션) + side-note
  - **커버(01 나의 명상)**: "나에게 돌아온 20분, 몸과 마음의 이야기" + 세션 정보 카드(클래스/진행시간/기록신호/비교구간/데이터품질) + 원형 그래픽
  - 02 종합 여정 → 03 몸의 변화 → 04 마음의 변화 → 05 마무리 (기존 NarrativeSections 유지)

### T2. 샘플 보기 → 팝업 모달
- `/reports/sample` 별도 라우트 제거(또는 유지하되) → 리포트 목록(ReportListPage)에서 "샘플 보기" 클릭 시 **모달**로 리포트 표시
- 모달은 전체 화면(오버레이) 또는 큰 모달로, 정본 디자인을 그대로 표시
- 모달 내부에 사이드바 + 커버 + 섹션 포함

## 3. 주의
- 정본 index.html의 CSS·색상·타이포·SVG를 그대로 사용 (narrative-sections.css 확장)
- 점수(0~100) 없음, 방향성 + 변화량만
- 실제 데이터(timeline) 그래프 유지

## 4. 완료 기준
- 샘플 보기 → 팝업 모달로 정본과 동일한 디자인(커버+사이드바+5섹션) 표시
- `npm run build` 0 error
