# SDD-046 구현 전 검증 체크리스트

구현 전 작성. 사용자가 전달한 재구현 브리프의 구현 지시 범위에 따라 진행한다.

- [ ] 커버·5개 앵커·사이드바·푸터가 정본 구조로 렌더링된다.
- [ ] 샘플 이름·날짜·품질 안내는 샘플에만 전달되고 일반 호출자는 미확인 메타데이터를 만들지 않는다.
- [ ] 기존 실제 timeline 그래프와 결측 구간 처리가 유지된다.
- [ ] 목록의 상단·빈 상태 버튼 모두 라우트 이동 없이 동일 모달을 연다.
- [ ] 닫기·Escape·키보드 포커스 복귀와 모달 내 앵커 탐색이 동작한다.
- [ ] 데스크톱 2단·모바일 1단이며 가로 넘침이 없다.
- [ ] 기존 node 테스트 및 npm run build 통과.
