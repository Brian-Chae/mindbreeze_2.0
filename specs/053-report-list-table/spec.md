# SDD-053 — 리포트 목록 테이블화 + 검색/필터/클래스 그룹핑

> 리포트 목록을 카드 그리드 → 데이터 테이블로 개편하고, 검색·필터·정렬·클래스별 그룹핑을 추가한다.

## 1. 배경
- 현재 ReportListPage는 카드 그리드. 리포트가 늘면 검색/조회/비교가 어렵다.
- 사용자 니즈: 검색, 클래스별 모아보기, 조회/비교.

## 2. 구현 범위 (FE cursor)
- ReportListPage를 테이블로 개편:
  - 컬럼: 제목/타입/세션유형/날짜/상태/액션(보기)
  - 검색 입력 (제목/세션명 필터)
  - 상태 필터 (전체/검토중/승인됨)
  - 정렬 (날짜/제목)
  - 클래스(세션)별 그룹핑 또는 필터
- 자동 승인 토글 + 샘플 보기 버튼 유지
- 점수(score) 표시 제거 (루프 2에서 일괄 처리하거나 여기서 제거)

## 3. 완료 기준
- 테이블 + 검색/필터/정렬 동작
- FE build 0 error
