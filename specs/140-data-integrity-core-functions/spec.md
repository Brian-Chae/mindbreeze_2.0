# SDD-140 — 데이터 무결성·핵심 기능 (중 7건)

## 배경

전체 코드 리뷰 중 26건 추림 중 **데이터 무결성·핵심 기능 7건**.
기준: AI 기록·EEG 정확성·가입 무결성·권한 게이트 — 기능 신뢰에 직결되는 항목.

## 대상 (7건)

| # | ID | 이슈 | 리스크 |
|---|---|---|---|
| 1 | STT-01 | 청크 하나 누락 시 전체 전사 실패 + 타임스탬프 드리프트 | 세션 전체 STT 실패 → 리포트 partial |
| 2 | EEG-01 | 60초 롤업 버킷이 일시정지/재개 세그먼트를 합산 | EEG 추이·커버리지 왜곡 |
| 3 | DATA-01 | 리포트 유일 제약 없음 → 중복 생성 | 목록 중복·승인 이중 처리·progress 왜곡 |
| 4 | STATE-01 | state_version 전이당 +2 점프 | 계약(SDD-026 '+1') 불일치·버전 비교 혼선 |
| 5 | DATA-03 | 가입 트랜잭션 비원자성 | 중간 실패 시 불완전 가입(부분 상태) |
| 6 | AUTHZ-01 | 온보딩 게이트 우회 | 미완료여도 완료 플래그 → 접근 제어 무력화 |
| 7 | AUTHZ-03 | 마지막 org_admin 강등 락아웃 | 기관 관리 기능 완전 잠김 + 감사 누락 |

## 목표

- 핵심 기능(STT·EEG) 정확성과 가입·리포트 무결성을 회복한다.
- 기존 기능 회귀 없이 백엔드 1009 테스트 통과.
