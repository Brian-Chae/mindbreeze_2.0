# verify (구현 전)
- [ ] 뇌파 필터: 10Hz 사인 진폭 ≥0.9 통과, 2Hz·50Hz 진폭 ≤0.15
- [ ] 맥파 필터: DC 오프셋(예 50000) 제거 후 평균≈0, 1.2Hz 맥박 성분 통과, 0.1Hz 드리프트 감쇠, 15Hz 노이즈 감쇠
- [ ] 빈/1점/짧은 배열/NaN 입력 예외 없이 안전
- [ ] 창 앞·뒤 가장자리 진폭이 중앙 대비 ≥0.8(과도응답 억제)
- [ ] min/max decimation: 길이 ≤ count, 큰 스파이크 보존
- [ ] 자동 스케일: 정규화 |v|≤1, 급상승 즉시, 감소는 0.85 감쇠
- [ ] 웹/네이티브 두 경로 모두 필터 적용, 라벨 확인
- [ ] vitest 기준선(17 fail/8파일) 외 새 실패 0, tsc -b 통과, gradle testDevDebugUnitTest 통과
- [ ] 실기기: 파형 가독성(8–30Hz 뇌파, 맥박 모양)
