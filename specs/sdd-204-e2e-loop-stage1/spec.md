# SDD-204 — E2E 테스트 루프 1단계 (배포 후 스모크 자동 실행)

## 목적
dev 배포가 성공할 때마다 핵심 시나리오(스모크)를 자동 실행하고, 실패 시에만 텔레그램으로 알린다.

## 확정 결정 (Brian, 2026-10-15)
| # | 항목 | 확정 |
|---|---|---|
| 1 | 수정본 dev 반영 | C. dev 전부 자동. 운영 main은 승인 유지. 스모크 실패 시 자동 반영 중단 + 텔레그램 알림 |
| 2 | E2E 전용 기관·계정 | A. 허용. 'E2E-' 접두어 + 정리 방법 마련 |
| 3 | 실제 메일 발송 시나리오 | A. 1단계 제외 (2단계 이후 본인 주소 한정) |

## 범위 (1단계)
- 스모크 약 7개: 4개 역할 로그인, 주요 페이지 로딩, 콘솔/네트워크 오류 0
- 대상: https://dev.mindbreeze.looxidlabs.com
- 트리거: Deploy Dev 성공 직후
- 알림: 실패 시에만
## 비범위
- 역할별 여정(2단계), 버그 자동 수정 연결(3단계), 야간 탐색(4단계), 메일 발송 시나리오, 운영 서버 자동 반영
