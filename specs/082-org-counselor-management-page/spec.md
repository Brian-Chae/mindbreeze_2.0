# SDD-082 — 기관 관리자 상담사 관리 페이지

> 기관 관리자(org_admin)가 소속 상담사를 조회·상태 관리·활성화/비활성화·이력 조회하는 전용 기능.
> 왼쪽 사이드바에 "상담사" 메뉴 추가. **claude(fable) 위주로 개발**.

## 1. 요구
- 기관 관리자 사이드바에 "상담사" 메뉴 추가
- 상담사 조회(검색/필터) + 상태(활성/대기/정지) + 정보 관리 + 최근 이력 관리 + 활성화/비활성화

## 2. 현재 상태 (재사용/신설 구분)
- ✅ 이미 있음: `GET /org/{org_id}/counselors`(목록, SDD-079 membership 기반), `PUT .../role`(역할 변경), `GET/PATCH .../profile`(정보 수정, SDD-077)
- ❌ 신설: 기관 관리자용 상담사 **활성화/비활성화(suspend/unsuspend)** — 현재 `/admin/users/{id}/suspend`는 플랫폼 관리자 전용
- ❌ 신설: 상담사별 **최근 이력**(세션/리포트 활동) 조회
- ❌ 신설: 기관 관리자 사이드바 "상담사" 메뉴 + 전용 페이지

## 3. 구현 범위 (claude fable)

### T1. BE — 기관 관리자용 상담사 상태 관리
- `POST /org/{org_id}/counselors/{user_id}/suspend` + `unsuspend` (org_admin, 소속 상담사만)
- 사유 필수 + 감사 기록 + 대상자 안내
- 자기 자신/주 담당자/기관 관리자 본인 정지 금지 (소속 상담사 counselor만 대상)

### T2. BE — 상담사 최근 이력 조회
- `GET /org/{org_id}/counselors/{user_id}/activity` — 최근 세션 목록(상태/일시/참여자 수) + 최근 리포트 목록
- org_admin 전용, 소속 상담사만

### T3. FE — 사이드바 "상담사" 메뉴 + 전용 페이지
- ORG_ADMIN_NAV_ITEMS에 "상담사" 메뉴 추가 (`/org/counselors` 또는 `/counselors`)
- 상담사 관리 페이지: 목록(검색 이름/이메일/코드 + 필터 역할/상태) + 상태 배지
- 행 메뉴: 정보 수정(SDD-077 재사용) + 활성화/비활성화 + 이력 보기
- 상세 패널: 정보 + 최근 이력(세션/리포트)

## 4. 주의
- 활성화/비활성화는 계정 상태 변경일 뿐 데이터 삭제 아님 (자산 원칙)
- 정지된 상담사는 로그인 차단(기존 suspended 로직), 해제 시 복구
- 주 담당자(org_admin)/자기 자신은 정지 불가
- 개인 상담소(kind=individual) 소속 상담사도 목록에 포함 (기관 상담사와 구분)
- 감사 기록, 사유 필수

## 5. 완료 기준
- 기관 관리자 사이드바에 "상담사" 메뉴 + 관리 페이지
- 상담사 목록(검색/필터/상태) + 정보 수정 + 최근 이력 + 활성화/비활성화
- BE pytest 통과, FE build 0 error
