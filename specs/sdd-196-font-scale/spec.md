# [SDD-196] 글씨 크기 전면 조정 (모바일 가독성)

> 근거: `docs/프론트_디자인_조사_글씨크기.md`

## Goal
채팅 본문을 15px로 키우고, 서비스 전체의 글씨 크기를 "최소 12px · 본문 15px · 입력 16px(모바일)" 기준으로 정렬한다.

## Context
- 조사 결과: 12px 이하 37%, 9~11px 376건, 단계에 없는 임의 값 다수, 입력칸 18곳 16px 미만(iOS 자동 확대), 시간 글씨 대비 2.6:1.
- Brian 결정: 채팅 본문 15px, 전체 조정 진행.

## Scope
### ✅ In-scope
1. 채팅(`MessageBubble`·`agent-bubble`): 본문 15 / 시간 12(색 #6F6F6F) / 이름 13 / 라벨 12 / 행간 1.5 / 말풍선 폭 80%. 루시 안내 문구 13.
2. Tailwind 전역: `text-sm` 14→15px(행간 22px). `text-xs`는 12 유지.
3. 임의 값 정렬(`text-[Npx]`·인라인 `fontSize`): 9~11→12(숫자 배지 제외), 12.5→13, 13.5→13, 14·14.5→15, 17·19→18, 21→20, 23·26→24.
4. 모바일(≤767px) 입력칸(input/select/textarea, 체크·라디오 제외) 16px 강제 — iOS 포커스 확대 방지.
5. 제외: `pages/design`(목업), `components/playground`(개발도구), 테스트, 다른 작업자의 미커밋 변경 파일.

### ❌ Out-of-scope
사용자 글씨 크기 설정(rem 전환), 작은 터치 영역(h-6~8) 확장, 상담사 화면 레이아웃 재설계, 색 대비 전수 수정(채팅 시간만).

## Acceptance Criteria
- [ ] 채팅 말풍선 15px·시간 12px·이름 13px
- [ ] 대상 범위에 9~11px 잔존 없음(배지 숫자 예외 목록 명시)
- [ ] 모바일 입력칸 computed font-size ≥16px
- [ ] 390px 폭에서 주요 화면 가로 넘침 증가 없음(전/후 비교)
- [ ] `tsc -b`, `npm run build`, 기존 vitest 회귀 없음

## Risks
| 리스크 | 대응 |
|---|---|
| 글씨 커져 레이아웃 넘침 | 390px 가로 넘침 전/후 자동 스캔, 필요 시 개별 보정 |
| 배지 숫자(16~18px 원) 깨짐 | 배지 라인 예외 처리 |
| 다른 작업자 변경과 충돌 | 미커밋 파일 제외 |
