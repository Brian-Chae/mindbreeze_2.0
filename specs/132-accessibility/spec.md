# [SDD-132] 접근성(a11y) 일괄

## Goal
스크린리더 낭독 절제·키보드 조작·색대비·표기 정합을 일괄 보강한다.

## Issues
- ①-15 미터값 초당 스크린리더 통보 → 시각 막대 aria-hidden + 상태 전이만 안내
- ①-16 상태 배지 대비 낮음 → in_progress 전경색 어둡게(#1F8A5B→#1F7A4D)
- ②-5 접촉불량 모달 키보드 → Escape + 초기 포커스
- ②-6 디바이스 상태 초당 낭독 → role=status 제거, 경과 시간 aria-hidden
- ②-7 패널 폭 키보드 → 핸들 tabIndex + 방향키/Home/End
- ②-10 다이얼 값 접근성 → aria-hidden을 SVG로 이동 + role=meter
- ②-12 배터리 "—%" 어색 → null 분기 단위 분리
- ②-14 온보딩 모달 키보드 → Tab 포커스 트랩
- ②-19 추이 지표 키보드 → roving tabindex + 방향키

## Acceptance Criteria
- [ ] 미터/디바이스가 초당 낭독되지 않는다(상태 전이만).
- [ ] 배지 대비 4.5:1 이상.
- [ ] 모달·패널·탭이 키보드로 조작된다.
- [ ] 다이얼 값이 스크린리더에 노출된다.
- [ ] 빌드 0 errors, 관련 테스트 통과.
