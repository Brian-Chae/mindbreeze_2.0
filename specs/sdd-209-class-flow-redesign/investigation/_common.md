## 확정 결정 요약 (2026-10-17, 뒤집지 말 것)
1. 클래스 입장 코드·게스트·인증 코드(OTP) **전면 제거**. 사용자는 이메일 인증된 가입 회원, 클래스는 초대 방식. 리포트 신청도 코드 없이 계정 이메일 1탭. 클래스 링크 = 로그인 필요한 상세 딥링크.
2. LINK BAND는 이마에만 착용. 기존 `SensorTracker`(L·기준·R 전극 LED, 색만)를 접촉 불량일 때만 띄워 어느 전극이 안 닿는지 보여준다.
3. 카메라 영상이 있으면 영상+음성을 하나의 "내 영상·소리" 컴포넌트로. 마이크 레벨은 아이콘 미터(마이크 토글 둘레 5단계 링 + 아이콘 밝기, 칩 `정상`/`조용해요`). 카메라 없이 마이크만이면 가로 막대.
4. 소요 시간 5분 단위(최소 5분 스텝퍼), 예약 시작 시각도 5분 단위.
5. 상담사는 준비 안 된 회원이 있어도, 대기실이 비어 있어도(초대 0명 포함) 시작 가능. 시작 확인 시트에 준비 중 회원 표시. 시작 후에도 초대 회원이 입장해 준비를 이어서 한다. 준비 단계 중 시작되면 `지금 입장하기`/`준비 이어서 하기` 시트.
6. 몰입형(입장 확인·사전 확인 마법사·시작 대기·종료·생성 마법사·세팅·로비·시작/종료 확인·닫힘·오류)은 앱 셸 없이. 셸형(회원 홈·목록·상세, 상담사 목록·상세)은 기존 앱 셸 유지 + 클래스 카드·칩·버튼·시트를 진행 화면 언어로.
7. 용어: 클래스(세션·수업 금지) / 회원 `입장하기` / 상담사 `클래스 열기`→`시작하기` / `나가기` vs `클래스 닫기` / 해요체 / 영문 대문자 아이브로우 금지.
8. 입장 전 동의 단계(FM06a) 신설, 상담사 시작 전 확인 시트(FH07)에서 녹음 동의를 시작 전에 확인.
- 비범위: 진행 중 화면(SDD-208), 지표 산출, LiveKit 연결 방식, 푸시 콘텐츠, 상담사 코드(상담사–회원 연결 코드, S-M00)는 유지. **기존 데이터(과거 세션 access_code, 게스트 참가자)는 삭제하지 않는다(읽기 호환 유지).**
