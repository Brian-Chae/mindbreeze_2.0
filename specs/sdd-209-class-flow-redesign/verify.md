## 2A. R4 정책 계약 (RV1~RV7) — 구현 전 합의된 합격 조건

> 아래는 R4 의 "구현 전 검증 계약"을 실행 가능한 항목으로 풀어 쓴 것이다. 하나라도 미통과면 해당 Task 는 완료가 아니다. 보관 정책(RV1)은 백엔드·설정·스토리지까지 검증하기 전에는 **완료로 보고하지 않는다.**

### RV1 기본 DB 기간 삭제·삭제 권한 (P1 R5 · D-2) — B
- [ ] RV1-1 기간 **미경과** 음성/영상/EEG raw 픽스처는 삭제 스위프를 **실제 실행한 뒤에도** 파일 바이트(해시)·DB 행·참조가 모두 유지된다. 기간 **경과**분(종료 후 N+1일)은 행과 S3/로컬 파일이 모두 삭제되고 객체 부재가 확인된다.
