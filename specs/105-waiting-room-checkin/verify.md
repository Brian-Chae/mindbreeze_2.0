# SDD-105 구현 전 검증안

작성 시점: 제품 코드 변경 전. 상태: Brian 승인 완료(본 세션 구현 요청). 아래는 승인된 구현 전 체크리스트이며 실행 결과는 summary.md에 기록한다.

## 승인 대상

- 제공된 목업에 따른 React 표현층 개편과 기존 기능 보존.
- 준비 상태를 실제 상담사 화면에 전달하기 위한 기존 WS 이벤트의 선택적 readiness 확장 및 최소 서버 중계.
- 목업에만 있는 리마인드 시연을 실제 세션 내 WS 안내로 구현. 외부 메시지 발송은 없음.

## 회원 시나리오

- [ ] 최초 hero, 설문 활성 탭, 0/3, 이름 게이트와 자동 입장 안내가 보인다.
- [ ] 설문 저장 성공은 1/3 및 밴드 탭 이동. 실패는 오류 표시와 미완 유지. 건너뛰기도 완료로 센다.
- [ ] 탭 왕복 시 SAM·전달 말·스킵 상태가 보존된다.
- [ ] 밴드 실제 이미지와 01/02/03 안내 표시. 연결 성공/미사용으로 완료 처리한다.
- [ ] BLE 미지원·권한 거부·연결 오류에서도 밴드 없이 진행할 수 있다.
- [ ] 탭 이동 및 meditation 전환에서 singleton 연결과 EEG 전달이 보존된다.
- [ ] 마이크 자동 확인·미터, 카메라 미리보기·끄기, 스피커 테스트음이 동작한다.
- [ ] 기기 확인/건너뛰기는 완료, 오류만 발생한 경우에는 자동 완료하지 않는다.
- [ ] 모든 단계 스킵 가능. 이름만 유효하면 0/3에서도 입장 가능, 빈 이름은 입장 불가.
- [ ] 상담사 시작 시 준비 중이어도 이름이 유효하면 자동 입장한다. 완료/취소는 기존 경로로 처리한다.
- [ ] 대기 BGM·Wake Lock 유지, 퇴장/라이브 전환 시 프리뷰 트랙·RAF·AudioContext 정리.

## 상담사 및 통신 시나리오

- [ ] 0명 빈 상태, 일부/전원 완료의 인원·진행률·3뱃지·n/3이 일치한다.
- [ ] 건너뛰기·밴드 미사용도 완료. 미완 행 배경과 좌측 점, 완료 행 일반 표시.
- [ ] 기존 체크인 요약과 전달 말 및 세션 중 보존 기능 유지.
- [ ] 상태 변경 즉시 갱신, heartbeat/재연결 복구, leave/TTL 제거.
- [ ] readiness 없는 기존 클라이언트와 호환, 잘못된 데이터·신원 사칭 차단.
- [ ] 리마인드는 호스트만 요청 가능하며 해당 세션 대상자 본인에게만 전달.
- [ ] 리마인드 실패는 성공으로 표시하지 않음. 0명·연결 끊김·전송 중 버튼 비활성.
- [ ] 녹음·타이머·밴드·카메라 등 상담사 기존 제어 핸들러 유지.
