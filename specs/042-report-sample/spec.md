# SDD-042 — 리포트 샘플 보기 (상담사 페이지)

> 상담사 리포트 목록 페이지에 "샘플 보기" 기능을 추가해, 실제 데이터가 없어도
> 몸·마음 서사형 리포트의 샘플을 미리 확인할 수 있게 한다.
> 섹션 순서: 종합 여정 → 몸의 변화 → 마음의 변화 (docs/MIND_BREEZE_2.0_몸마음리포트_기획.md 참조)

## 1. 배경

몸·마음 서사형 리포트를 기획했지만 아직 실제 리포트에 반영 전이다.
상담사가 "이런 리포트가 나온다"를 미리 볼 수 있도록, 리포트 목록에 샘플 보기를 추가한다.
샘플은 mock 데이터 기반으로, 종합 여정 → 몸의 변화 → 마음의 변화 순서로 렌더링한다.

## 2. 구현 범위

### T1. 샘플 보기 진입점
- `ReportListPage.tsx`: 빈 상태("아직 생성된 리포트가 없습니다")에 "샘플 리포트 보기" 버튼 추가
- 일반 목록 상단에도 "샘플 보기" 링크/버튼 추가

### T2. 샘플 리포트 페이지
- 신규 `ReportSamplePage.tsx` (라우트 `/reports/sample`)
- mock 데이터 기반 서사형 렌더링:
  - **종합 여정**: 한 문단 서사 (몸·마음이 어떻게 흘렀는지)
  - **몸의 변화**: BPM·HRV·호흡수 — 방향성(↑/↓) + 변화량(±bpm/±ms/±회) + 추이 그래프
  - **마음의 변화**: 집중·이완·감정안정도 — 방향성 + 변화율(%) + 추이 그래프
- 1.0 디자인 스킴 (보라 크림/그린 크림 배경, #5F0080 액센트)

### T3. 라우팅
- App 라우팅에 `/reports/sample` 추가

## 3. 샘플 데이터 (mock, 대표값)

- 종합: "몸은 점차 안정으로, 마음은 산만함에서 차분한 집중으로 흘렀습니다."
- 몸: 호흡수 ↓ 2.4회/분, 심박수 ↓ 5bpm, HRV ↑ 8ms
- 마음: 집중도 ↑ 18%, 이완도 ↑ 12%, 감정안정도 ↑ 9%

## 4. 주의
- 점수(종합 0~100) 없음 — 서사 + 개별 변화량만
- 그래프는 Recharts (기존 mindbreeze 사용), 점수 축 대신 추세 흐름
- mindbreeze 디자인 토큰 (#5F0080, bg-white, #F5EDFC) — haru 다크 테마 금지

## 5. 완료 기준
- `npm run build` 0 error
- 상담사 리포트 목록에서 샘플 보기 → 서사형 샘플 리포트 표시
- 섹션 순서: 종합 → 몸 → 마음
