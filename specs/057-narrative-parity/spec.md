# SDD-057 — 서사 규칙 문장/임계값 정합성 정렬

> 프론트(narrative.ts)와 백엔드(report_narrative.py)의 규칙 기반 서사 로직(방향 판단 임계값·문장 템플릿)이
> 서로 달라 일관성이 떨어진다. 백엔드 규칙 폴백 문장을 프론트와 동일한 수준으로 정렬한다.

## 1. 배경
- 백엔드 fallback_narrative: "높아졌어요/낮아졌어요/비슷하게 유지됐어요" (단순)
- 프론트 narrative.ts: "호흡이 깊고 느려졌어요" 등 지표별 구체 문장
- 두 규칙 폴백이 다른 문장을 생성 → 일관성 부족

## 2. 구현 범위 (BE codex)
- `report_narrative.py`의 `fallback_narrative` 문장을 지표별 구체 문장으로 개선 (프론트 narrative.ts와 동일 수준)
- 방향 판단 임계값이 프론트와 일치하는지 확인·정렬
- LLM 서사(프롬프트/파싱)는 변경하지 않음

## 3. 완료 기준
- 백엔드 규칙 폴백 문장이 프론트와 일관성 확보
- BE pytest 통과
