- 미리보기: http://100.105.138.107:8001/design-1105/307-host-flow-v3.html

- 모든 화면은 합성 시안이다. 현재 구조 화면은 코드 구조를 바탕으로 재구성했고 실제 앱 캡처가 아니다. 금지 어휘를 피하기 위해 현재 문구 일부를 축약했으며 정확한 버튼명은 plan.md에 기록했다.

## 화면과 상호작용
상단 검토 도구에서 현재 구조/개선안, 열기 전/대기실, 온라인/오프라인, 인원 상태를 전환한다. 이 검토 도구는 제품 UI 제안에 포함하지 않는다. URL은 `?v=before`, `?stage=setup&place=online&mic=off`, `?place=online`, `?people=ready`, `?people=empty`를 지원한다.

A안은 열기 전 장비 점검을 유지한다. 온라인 마이크가 꺼져 있으면 결과를 인라인으로 설명하고 `음성 없이 클래스 열기` 한 번으로 대기실로 간다. 실제 권한 요청이나 미디어 스트림은 없다.

대기실의 코드 영역은 스크롤 중 상단에 붙는다. 1280px은 코드/시작 2열, 768px도 2열, 390px은 코드→녹음→시작→인원 순으로 쌓는다. 명부는 별도 스크롤이다. 전체 화면 코드 확대는 클릭으로 열고 Escape/닫기로 복귀한다. 실제 브라우저 Fullscreen API를 호출하는 기능은 아니며 뷰포트를 채우는 dialog이다.

코드는 1280px 80px, 768px 64px, 390px 60px. 확대창은 뷰포트에 따라 70~270px, 명암 대비를 높이고 회원 이름·동의 정보를 제거했다. 40명 행사장에서 실제 3m·5m 거리, 프로젝터·조명 조건 가독성은 미검증이다. 화면 크기만으로 현장 가독성을 보장하지 않는다.

## 데이터 의미
예시 코드는 4729이며 실제 참여용이 아니다. 회원 이름은 회원 01~40의 합성 값이다. 준비 중 상태는 입장 32명/준비 24명, 준비됨 상태는 40/40, 빈 상태는 0/0이다. `밴드 준비`는 기획 검토용 예시이며 연결 수와 다름을 표기했다. `녹음 동의 미집계`는 현재 대기실 모델의 데이터 부재를 나타낸다. 행사 후 신뢰할 수 있는 연결/동의 집계를 확보하기 전에는 실제 수로 바꾸지 않는다.

초대 링크 공유·복사는 검토 안내창만 띄운다. 클립보드 쓰기·실제 공유·초대 발송은 하지 않는다. 도구 버튼도 구성 확인 안내만 제공한다. 시작/취소는 로컬 타이머만 바꾸고 네트워크 API를 호출하지 않는다. 이는 실제 기능 동작 검증이 아니다.

## SDD-299와 정합
이번 시안의 대기실 도구는 기존 BGM·내 밴드·발언권·채팅 조건을 유지한다. 라이브 독의 분석·채팅·미디어/녹음·설정을 대기실에 그대로 복제하지 않는다. 시작 뒤 라이브 화면을 다시 설계하지 않는다. 정원 늘리기는 SDD-296 수정과 SDD-299 설정 배치를 유지하며, 이번 시안에서는 경로 안내만 제공한다.

## 검증 범위
정적 HTML을 브라우저로 렌더하고 각 화면의 가로 넘침·버튼 높이·표시 문구를 측정한다. PNG를 시각 확인한다. API·회원 입장·마이크 권한·메일·실장비 연결·제품 E2E·앱 빌드는 실행하지 않는다. 후속 구현 시험 관점은 plan.md에 별도로 기록했다.

- v1은 보존했다. 시각 확인에서 검토용 선택 상자의 글자가 배경과 구분되지 않는 문제가 보여 v2에서 글자색을 명시했다.

- 독립 검토 후 v3: 음성/영상 안내 분리, 마이크 off에서도 보관·접근 고지 유지, 리포트 미반영 2명·연구 활용 동의 5명 익명 예시 추가. v1·v2 파일은 보존했다.

## 최종 측정과 검토 결과 (v3)
- 390×844, 768×1000, 1280×1000: 현재 구조/오프라인/온라인/40명/0명/마이크 off 열기 전 총 18개 렌더 HTTP 200.
- 위 18개에서 가로 넘침 0, 높이 44px 미만 표시 버튼 0, 지정 금지 어휘 0. 확대창 3개 포함 PNG 21장 생성.
- 확대창 Escape 닫기 3/3, 시작 요청 전 로컬 취소 3/3 확인. 측정은 `307-measurements-v3.json` 참조.
- 21장 전체를 폭별 갤러리로 시각 확인했다. 390px는 상단 검토 도구 때문에 첫 화면 높이를 더 사용한다. 실제 제품에는 검토 도구가 없다. 폰 글자 확대·낮은 가로 화면·실제 행사장 원거리 가독성은 미검증이다.
- 독립 검토자 4건 지적을 반영한 뒤 문서·HTML 재검토로 반영을 확인했다. 감독은 직접 코드 근거·브라우저 측정·캡처를 대조했다.
- 작업 트리의 추적 파일 변경은 없으며 산출물은 지정 specs 폴더와 공유 폴더의 307 접두 파일뿐이다. 기존 v1/v2·다른 시안은 보존했다.
