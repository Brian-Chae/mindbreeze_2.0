# SDD-307 — 승인 v6 대기실 구현 결과

## 결과
- 기존 클래스 디자인으로 입장 코드·카메라·회원 초대·준비 집계를 한 화면에 배치했다.
- 700px 이상에서는 회원 표만 내부 스크롤한다. 모바일은 페이지 스크롤·8명 더 보기·하단 플로팅 시작을 유지한다.
- 온라인 setup→lobby 미리보기 스트림을 유지하고 직접 재입장·live 정리·늦은 권한/AudioContext 응답을 처리한다. 대기 중 방송·녹화는 시작하지 않는다.
- 녹음 선택과 고지를 인라인으로 옮겼다. 시작 2초 전 취소, 다른 메뉴 진입 취소, 중복 클릭 방지, 서버 상태 재조회, 실패 후 재시도를 지원한다.
- 서버 409 일정 충돌 지문 확인·진행 중 재녹음 동의·기존 초대 권한을 보존했다. 준비 상태와 녹음 동의를 구분하고 익명 집계 조회 실패는 미확인으로 표시한다.
- 클래스 생성·backend·배포 설정·운영 배포 변경 없음.
