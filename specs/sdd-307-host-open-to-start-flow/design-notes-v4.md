# SDD-307 — 시안 v4 디자인 기록

현재 시안: http://100.105.138.107:8001/design-1105/307-host-flow-v4.html

대표 정정 4개를 반영했다: 온라인 카메라 미리보기, 바로 접근하는 회원 초대, 한눈에 보는 준비 집계/명부, 기존 클래스 디자인 사용.

## 디자인 근거
- 현재 `player-tokens.css`를 `307-player-tokens.css`로 복사해 사용했다. 제품 소스는 수정하지 않았다.
- 현재 자연 배경 `frontend/public/images/background8.webp`를 `307-background8.webp`로 복사했다. 기존 배경·어두운 스크림·반투명 보라 패널·민트/코랄 상태·보라 주 버튼을 사용한다.
- `HostHeadSlot.tsx` 셀프뷰의 실루엣 표현과 SDD-299 실제 캡처를 참조했다. 영상 위치·표시 상태를 보여 주는 합성 예시이며 카메라 권한을 요청하거나 촬영하지 않는다.
- 레이아웃은 신규 요구에 맞춘 대기실 제안이다. 기존 클래스의 디자인 언어를 적용했으며 기존 화면과 픽셀 단위로 동일하다는 의미는 아니다.

## 핵심 배치
- 코드: 상단 바에 항상 표시. 복사·크게 보기 유지.
- 온라인: 카메라 미리보기 상시 표시, 바로 옆/아래 회원 초대. 오프라인은 카메라 영역 제거.
- 초대: 모든 폭에서 첫 화면의 `＋ 회원 초대` 1탭 → 기존 회원 선택/초대 링크 공유/코드 크게 보기. 실제 초대·링크 발송은 하지 않는다.
- 현황: 입장 32/40, 준비됨 24, 준비 중 8, 미입장 8의 예시. 준비 중 회원 우선, 설문/밴드/기기 열과 상태 표시. 전체·준비 중·미입장 필터 제공. 밴드 미사용 상태를 준비됨에서 허용한다.
- 녹음·기록 고지와 시작은 고정 하단. 미집계 녹음 동의는 준비 집계와 섞지 않는다. 기존 리포트·연구 익명 수는 기록 안내에 유지한다.
- `?place=offline`, `?people=ready`, `?people=empty`로 상태 전환. 아래 보기 전환은 시안 검토 도구이며 제품 UI에 포함하지 않는다.

## 후속 구현 검증
실제 온라인 미리보기의 장비 스트림을 세팅→대기실→라이브로 넘기는 수명 관리가 필요하다. 카메라 off·권한 거절·네트워크 단절·재입장·오프라인에서 실기기 확인 필요. 현재 작업은 합성 시안으로 제품 코드·API·장비·메일에 접근하지 않았다.

## v4 검증 결과
- 390×844·768×900·1280×900에서 온라인/오프라인/입장 0명/40명 12개 상태 렌더. 초대 시트 포함 PNG 15장 생성.
- 12개 상태 가로 넘침 0, 지정 금지 문구 0. 회원 초대·시작 버튼은 전 상태 첫 화면에 표시. 온라인 셀프뷰 표시/오프라인 숨김 확인.
- 준비 중 필터는 세 폭 모두 8행 표시. 390px 온라인 명부 영역은 185px이며 내부 스크롤을 사용한다.
- 온라인 세 폭 및 모바일 초대·오프라인 태블릿 캡처 직접 확인. HTTP 200. 제품 frontend/backend 추적 파일 diff 0.
- 독립 검토 반영: 오프라인 준비 중은 설문/밴드 미준비만 사용, 모든 폭에서 상단 도구 버튼으로 기존 BGM·내 밴드·발언권·채팅 접근(오프라인 내 밴드·채팅), 초대 시트에 기존 이메일 초대 경로 추가.
