## 5. 코드와 인원 정보
- 현재 대기실: 다시 알림 → 초대 시트(1탭) → 코드 확인, 복사(+1탭). `away=0`이면 다시 알림이 비활성이라 이 경로로 코드를 열지 못한다. 초대 추가가 허용된 경우 다른 초대 시트에서 코드 확인 가능하나 권한에 따라 막힌다(E5/E6).
- 라이브: 상단 코드 → 크게 보기(1탭) → 복사(+1탭). QR·직접 링크 공유는 이 컴포넌트에 없다(E10).
- 제안: 대기실 상단 코드 항상 표시(0탭), 복사(1탭), 크게 보기(1탭), 링크 공유(1탭). 공유는 자동 발송하지 않고 운영체제 공유창 또는 복사만 사용한다. HTTP 비보안 컨텍스트·API 미지원이면 선택 가능한 URL과 수동 복사 안내를 표시한다.
- 링크는 검증된 기존 회차 참여 경로를 사용하고, 클래스 공개 코드와 회차 access_code가 다른 경우 표시 기준을 확정해야 한다. 이 검증을 통과하지 못하면 행사 전에는 링크 버튼을 숨기고 코드만 제공한다. 새 라우트·새 QR는 행사 후.
- 현재 준비 모델: 입장 인원·준비 인원·설문/밴드/기기 셀. 밴드 준비는 연결 텔레메트리가 아니다. 밴드 연결 M명은 신선한 실제 연결 데이터·분모가 확보될 때만 표시한다.
- 녹음 동의 K명은 현재 로비 모델에 없다. 행사 전 `녹음 동의 · 미집계`와 `회원 입장 단계에서 확인해요`로 표현한다. 연구 동의 수로 대체 금지. 행사 후에만 입장 N명 중 유효 고지 버전 동의 K명·미확인 U명, 집계 시각·조회 실패 상태를 설계한다.
- BAND none: `밴드 사용 안 함`. optional에서 건너뛴 회원은 별도 수이며 연결 인원에 포함하지 않는다.

## 6. 안전장치와 예외
- 시작 버튼은 코드 복사/초대 추가와 공간을 분리한다. 시안은 2초 취소 구간 후 요청. 취소하면 서버 호출 0회. 대기 중 Enter 연타·더블 탭은 한 번만 처리하도록 후속 구현에서 검증한다. 2초 지연은 FE 상호작용 제안이며 상태 머신 변경이 아니다.
- 요청 후에는 취소 버튼을 제거한다. 응답 유실은 상태 재조회, 이미 진행 중이면 라이브로 이동. 단순 재전송으로 중복 시작하지 않는다. start 성공 후 audio 실패면 `수업 진행 중 · 녹음 연결 확인 필요`로 분리한다.
- 온라인 마이크 권한 없음: 인라인 설명, 권한 안내는 보조 행동, 수동 기록으로 열기 가능. 오프라인 녹음 실패는 수업을 되돌리지 않으며 수동 기록/녹음 재시도 경로 안내.
- 네트워크 끊김: 최신 인원 수처럼 표시하지 않고 `연결 확인 중 · 마지막 수신` 표기. 전이 요청은 재연결/서버 상태 확인 전 잠근다. 이 처리는 구현 전 현재 연결 플래그와 검증 필요.
- 정원 마감: 입장 N과 정원 C를 분리. 설정 → 정원 늘리기 기존 CapacityIncreaseForm 재사용(SDD-296의 stale 입력 수정 보존). SDD-299의 설정 첫 구역 배치를 유지. 서버 상한·권한 초과 시 증원을 약속하지 않는다. 대기실에 없던 증원 연결은 후속 승인 범위에서 검토.
- 코드 재발급: 대기실의 주 행동으로 추가하지 않는다. 기존 명부 관리 경로(E15)를 사용한다. 재발급 뒤 코드·확대창·공유 링크의 최신값을 재조회하고 실패 시 기존 코드를 새 코드처럼 보이지 않게 한다. 이번 시안은 재발급을 호출하지 않는다.
- 라이브의 녹음 중지는 가능하나 전체 수업 시작을 취소하는 것과 다르다. 서버 전이 후 open 복귀는 행사 후 상태 계약 검토 사항.

## 8. 후속 구현 시험 관점
- 온/오프라인 × 마이크 on/off/denied × 녹음 선택/해제 × BAND none/optional/required × 인원 0/1/40 × 준비중/준비됨을 조합해 E11-E13 계약을 유지한다.
- 첫 시작·open 재입장·in_progress 재입장·녹음 재개를 별도로 시험한다. 종료 뒤 재시작을 지원한다고 오인하지 않는다.
- 지문 충돌·403·400·409·응답 유실·start 성공 후 audio 실패·오프라인 브라우저 권한 거절에서 실제 응답을 확인한다.
- 390/768/1280에서 40행 스크롤, 확대창 Escape/포커스 복귀, 키보드 조작, 44px 터치 영역, 확대 글자 잘림, 가로 넘침을 검사한다.
- 통계는 준비/연결/동의를 구분하고 조회 실패를 0으로 처리하지 않는다. 익명 집계를 회원별 동의 명부로 확대하지 않는다.
- 이 목록은 기획 단계의 시험 관점이며 Stage ③ Verify를 사후 작성한 문서가 아니다.

## 9. 독립 검토 반영
- 목록 바로 입장은 이미 열린 회차 조건임을 재검증하고 첫 시작 탭 수에 목록→클래스 상세→회차 상세의 2탭을 추가했다.
- audio=manual은 영상 녹화를 끄는 신호가 아니다(E2:999-1002). 온라인 카메라 on + record_video 설정이면 영상 녹화가 남는다. 인라인 안내는 음성/영상을 분리하고, 기록 보관·접근 고지는 수동 음성 모드에서도 유지한다. 시험 행렬에 audio record/manual × video on/off × camera on/off를 추가한다.
- 기존 리포트 제외·연구 활용 익명 수는 녹음 선택 아래 별도 두 줄로 이동한다. 0일 때 숨기며 조회 실패는 0 대신 미확인이다. 시안 예시는 리포트 미반영 2명·연구 활용 동의 5명이며 준비/녹음 동의 수에 합산하지 않는다.
- 4건 모두 기획·시안 정합 수정으로 반영했고 추가 사업 결정은 만들지 않았다.
