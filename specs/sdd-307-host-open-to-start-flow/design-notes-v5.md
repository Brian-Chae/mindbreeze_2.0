# SDD-307 — 시안 v5 디자인 기록

최신 시안: http://100.105.138.107:8001/design-1105/307-host-flow-v5.html

사용자 지정에 따라 Astra가 v5 HTML을 작성했고, 주 에이전트가 별도로 브라우저 측정과 캡처를 확인했다. 제품 구현이 아닌 합성 시안이다.

## 변경
- 모바일의 고정 높이 화면과 명부 내부 스크롤을 없앴다. 전체 페이지가 자연스럽게 스크롤된다.
- 클래스 시작 버튼은 하단 플로팅 영역에 고정했다. 준비 인원 요약과 주 행동 하나를 표시하고, 시작 직후 2초 취소 구간에만 취소 버튼이 나타난다.
- 녹음 선택·보관 기간·접근 대상·영상 녹화 안내·리포트/연구 익명 수는 본문 `녹음과 기록` 영역에 배치했다.
- 명부는 8명부터 보여 주고 `8명 더 보기`로 최대 40명까지 펼친다. 준비 중/미입장 필터를 바꾸면 첫 8명으로 되돌아간다.
- 태블릿·데스크톱은 카메라/초대와 집계/명부를 2열로 배치하되 전체 페이지 스크롤·하단 플로팅 CTA 원칙은 동일하다.
- 검토용 보기 전환은 본문 상단 접이식 영역으로 옮겨 제품 버튼과 겹치지 않는다. 온라인/오프라인과 인원 조건을 조합해 전환할 수 있다.

## 기존 디자인과 요구 보존
기존 `307-player-tokens.css`의 보라색 브랜드·반투명 패널·민트/코랄 상태 및 `307-background8.webp` 자연 배경을 유지했다. 온라인 카메라 미리보기는 실제 촬영 대신 명시된 합성 일러스트다. 오프라인은 카메라/기기 열을 숨기고 설문·밴드만으로 준비 상태를 표현한다.

회원 초대는 기존 회원 선택·이메일·링크·코드의 네 경로를 유지한다. 도구 메뉴도 모든 화면 폭에서 접근한다. 코드 확대는 별도 전면 dialog이며 실제 공유·발송·카메라 권한 요청·시작 API 호출은 없다.

v4의 첫 화면에 모든 정보를 압축하는 기준은 이번 사용자 지시에 따라 페이지 스크롤 기준으로 대체했다. 상단 코드·미리보기는 스크롤에 따라 이동하며, 시작 버튼과 준비 인원 요약만 계속 보인다.

## 실제 측정
- 크기: 390×844, 390×667, 768×1024, 1280×720, 1280×900.
- 각 크기에서 온라인/오프라인/40명 준비됨/입장 0명 총 20개 상태 확인.
- HTTP 200, 가로 넘침 0, JS 오류 0, 지정 금지 어휘 0, 본문 내부 세로 스크롤 0.
- 20개 모두 시작 버튼이 viewport 안에 표시되고, 페이지 상단과 하단에서 버튼의 Y 좌표가 같았다.
- 390×667 온라인: 문서 높이 2063px, 실제 scrollY 1396px. 버튼 Y=590px로 유지.
- 마지막 기록 영역과 플로팅 영역 사이 간격: 모바일 약 42px, 태블릿/데스크톱 약 62px. 마지막 고지가 가려지지 않음을 캡처로 확인했다.
- 5개 크기에서 명부 8→16행, 준비 중 필터 8행 확인.

## 검증 한계
safe-area inset은 CSS에 반영했으나 실제 iPhone 홈 인디케이터와 브라우저 주소창 변화는 미검증이다. 카메라·초대·회원 준비 현황은 합성 예시이며 실제 API/장비/메일 동작을 증명하지 않는다. 제품 코드·빌드·푸시·PR·배포 작업은 수행하지 않았다.

추가 검증: 390×667·768×1024·1280×720에서 40행 전체 펼치기/더 보기 숨김, 시작 전 취소 후 버튼 재활성, 코드 확대 Escape 닫기 각각 3/3 확인. 40행을 펼친 뒤에도 본문 끝 간격 42/62/62px 유지. 모바일·낮은 데스크톱 전체 명부 하단 캡처를 직접 확인했다.
