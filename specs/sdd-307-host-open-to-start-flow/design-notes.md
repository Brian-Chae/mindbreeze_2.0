# SDD-307 — 시안 v6 디자인 기록

최신 화면별 미리보기: http://100.105.138.107:8001/design-1105/307-preview-v6.html
원본: http://100.105.138.107:8001/design-1105/307-host-flow-v6.html

## 사용자 정정 반영
- 모바일 699px 이하: v5 그대로, 전체 페이지 스크롤·8명씩 더 보기·하단 플로팅 시작 버튼.
- 태블릿·데스크톱 700px 이상: 페이지 전체는 한 화면에 고정. 40명 전체 명부를 표시하고 회원 목록만 내부 세로 스크롤.
- 코드·카메라·초대·집계·기록 설정·시작 버튼은 목록 스크롤에 따라 움직이지 않는다. 명부 제목·필터·열 제목은 읽을 수 있도록 고정한다.
- 낮은 화면에서는 상단·기록 영역 여백을 줄이고 기록 고지를 이어서 배치한다. 전체 내용은 기록 안내에서도 확인할 수 있다.
- 태블릿 카메라가 과하게 세로로 늘어나지 않도록 미리보기 높이 상한을 적용했다.
- 보기 전환은 큰 화면에서 오버레이로 열려 본문 높이를 밀지 않는다. 700px 경계 변경 시 명부 8/40행 정책도 전환한다.

## 검증
Astra가 v6를 작성했고 주 에이전트가 읽기·브라우저 측정·캡처로 독립 확인했다. 카메라 높이 상한 보완 후 전체 측정을 다시 실행했다.
- 390×667/844, 768×1024, 1024×768, 1280×720/900의 6크기 × 온라인/오프라인/준비됨/입장 0명 = 24상태.
- 큰 화면 16상태 모두 pageScrollY=0, 문서 높이=viewport. 회원 목록 scrollTop>0으로 실제 내부 스크롤 확인.
- 큰 화면 명부 높이: 768×1024 369px, 1024×768 227px, 1280×720 179px, 1280×900 299px.
- 모바일은 페이지 스크롤 유지, 명부 내부 scrollTop=0. 390×667·390×844의 v5/v6 PNG 바이트 비교가 동일했다.
- 24상태에서 가로 넘침·JS 오류·지정 금지 문구 0. 모든 시작 버튼이 화면 내 표시. 큰 화면 기록 영역과 CTA 간격 14px.
- 데스크톱 낮은 화면·태블릿 가로/세로 캡처를 직접 확인했다.
