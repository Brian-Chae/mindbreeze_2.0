# SDD-216 — 프론트 운영 트랙

- 구현 전 계획·기대값. 사용자 개발 계속·하위 에이전트 지시 적용.
- 원본 verify 변경 없음. 전체 BE/FE 회귀 금지. 직접 변경 테스트만 실행, 최종 빌드는 루트 통합 후 1회.
- 소유: host-class-detail-page, host-class-views, 신규 class-operations API/컴포넌트, SessionDetailPage, NoticeStepView, member-prep, useEntryPrep, EntryPage, class-flow의 고지 유형 전달, 운영 전용 테스트 및 이 문서.
- 공용 API/DTO는 adfacb71 의존. 검증용 읽기 복사하며 본인 커밋 제외.

| Task | 구현 | 구현 전 기대값·검증 |
|---|---|---|
| O1 | 최소 멤버 초대·이메일 결과 | 회원 검색 초대 후 새로고침, failed만 재시도, sent를 수신 완료라 부르지 않음 |
| O2 | 설정·강사·수명 전이 | 조회 설정 보존, revision 전달, 마지막 주강사/재배정 오류 표시, 명시 확인 후 취소/보관 |
| O3 | 회차 진행자 요청·CH30·참관 | 요청 목록 및 후보 수락, 현재 진행자만 진행 CTA, 참관 송출·EEG·제어 없음 |
| O4 | D05/D28 | 명상 class-team-v1 표시·확인 저장, 상담 r5-1 유지, 관리자 진행 CTA 숨김 |

## 실행 결과

- O4 명상 고지 저장·표시 RED 2건 확인 후 GREEN. 신규 4 + 기존 준비 화면 13 = 17개 통과(1.28초).
- 실제 LiveKit·서버·시안 브라우저 검증 미확인.

- O1/O2 멤버 탭·이메일 상태·실패 재시도, 설정 전체 값 보존, 강사 추가·제거·주강사 지정, 마무리·취소·보관·복원 구현. 관리자 사유 입력과 operation_key 재시도 유지, 중복 클릭 차단. 신규 8개 통과. 기존 클래스 화면 포함 직전 실행 21개 통과.

- O2 검토 보완: 정기형 planned_session_count=null 허용(요청 스키마 필수값 8은 정기형 총횟수가 아님), 실제 BE stale_class/stale_session 오류 문구, active 보관 CTA 제거, 고정형 미완료 회차 마무리 안내. 정기형 테스트 RED→GREEN.
- O3 CH30 새 회차 상세, 재배정 경고, 현재 진행자만 플레이어·기록 CTA, 관리자는 편성만. 진행자 요청 조회·후보 수락·거절·관리자 승인·취소, 충돌 명시 확인, requestId 알림 행 강조, 해당 회차 대강 등록.
- 참관 LiveKit audio/video/screen=false, 송출·제어·개인 EEG 없는 수신 화면. 팀 사후 기록은 별도 읽기 패널로 요약·메모만 표시(전사 요청·원본·편집·저장 없음).
- CH20 의존 1741a45b class-schedule-editor를 capabilities.schedule=true 상세 회차 탭에 연결. 검증용 의존 파일은 본인 커밋 제외.
- 직접 영향 9개 파일 46개 통과(4.12초). 타입 검사 1회 통과(편집기 연결·팀 기록 추가 전). 최종 통합 타입/빌드는 루트 담당.
- 실제 LiveKit 연결·권한 회수, 실제 서버 초대/메일·브라우저 시각 비교는 미확인. 시안 색·곡면·행 구분·모바일 배치를 코드에 적용했으나 시각 완료 판정은 하지 않음.
