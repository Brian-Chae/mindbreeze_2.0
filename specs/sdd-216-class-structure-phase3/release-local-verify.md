- 기준 HEAD: `36d42741`. 작업 시작 시 미커밋 변경 없음. 이전 구현 `fb0347b6` 이후 들어온 회원 화면 수정은 유지한다.
- RL-01~06 기대값은 이번 출시 준비 코드 수정 전에 작성했다. RL-07~08은 추가 결함의 실패 테스트로 먼저 고정한 뒤 이 표에 기록했다. 원래 구현 전 게이트는 `verify.md`이며 이 문서로 대체하지 않는다.
