# SDD-216 — 프론트엔드 후속 구현

- 담당: FE 전담 워커. 전용 브랜치 `sdd/216-fe-followup`.
- 변경 소유: `frontend/`, 이 문서. BE·배포·원본 verify 변경 없음.
- BE 실제 배포 미확인. 로컬 구현과 모의 API 테스트는 배포 검증과 구분한다.
- 전체 BE/FE 회귀를 실행하지 않는다. 변경별 focused Vitest와 최종 타입·빌드 1회.

| 작업 | 내용 | 구현 전 기대값 |

| F02 | 새 마법사 기본·일정·배정·초대 4단계 | 명상 생성은 `/classes`; 상담 생성 유지. 요일/정원/주소/날짜 검증, server preview만 사용 |
| F03 | 초안·재개·복제·충돌·완료 | 미정 공개 차단/초안 허용, 입력 변경 시 preview·충돌 동의 폐기, 저장 중 중복 호출 차단 |

- F01~F03 진행 중. F04~F07 대기.
- V-54~65 및 CH10~15·CH20·CH04/06/30 기준. 원본 verify는 구현 전 게이트를 유지한다.
