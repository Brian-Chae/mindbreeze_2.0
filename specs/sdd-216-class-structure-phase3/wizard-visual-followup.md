## 구현·검증 결과

- WV01~05 구현: 시작 카드·실제 완료 클래스 복제 선택·기본/일정/강사/초대·공개/초안 완료·이탈/강사/일정/충돌 시트.
- 원본 배경4/5·색·치수·중앙640px·카드·단계점·하단 버튼 선언을 `.cs-wizard`에 한정. 임의 라이트 2열과 우측 설명을 제거.
- 원본과 정책 차이: 정원10 유지, LINK BAND none/optional, 템플릿 저장 미노출. 초안 저장은 상단 별도 버튼으로 유지.
- CH14 회원은 별도 워커의 클래스 후보 picker 사용. 선택 변경 시 기존 preview 폐기, 재검사 전 공개 차단.
- RED: 시작 화면·승인 구조 없는 기존 코드에서 7개 실패. GREEN: 마법사 선택 테스트 9개 통과(1.50초). 추가 4개는 시작/시안 구조/회원 변경 재검사/초안 완료.
- 시각 증거: 상위 트랙이 확보한 CH11-reference-1280.png를 직접 확인. 실제 구현 1280×720 및 모바일 비교는 상위 통합 후 수행 예정; 픽셀 오차는 미측정.
- 전체 BE/FE 회귀·전체 빌드·push·배포 실행 없음.
- 의존 파일 `class-member-picker.tsx`, `class-member-candidates.ts`는 다른 워커 소유로 검증용 복사했고 본 커밋에서 제외. 상위가 해당 워커 커밋과 결합.

## 화면 비교 후 보완

- 상위 브라우저에서 CH10~12 제목이 전역 h1 색상으로 어둡게 보임을 확인. 마법사 h1/h2 텍스트 토큰 명시.
- 고급설정 행 좌정렬·연보라 아이콘·선택 칩 연보라 테두리·정원 접두 표시 보완.
- CH14 회원 수/CSV 행을 검색 뒤·후보 목록 앞에 배치. 후보 검색의 정확 이메일 안내는 실제 권한 정책에 따라 유지.
- CH15 공개 완료는 서버 session_ids의 첫 회차 경로로 연결. 회차 없으면 클래스 상세, 초안이면 편성 이어서 하기.
- 완료 경로 RED 1개 확인 후 전체 마법사 선택 테스트 10개 통과. 전체 회귀 실행 없음.
- 시안 고정 샘플과 차이: 회원 이름/가린 이메일은 실제 API, 정원10, 건너뛸 날짜·반복간격 설정 진입, 관리자 사유, 상단 초안 저장을 유지.

- 상위 실제 API 브라우저: 시작 날짜 +14회로 11/2~12/21 8회 미리보기 정상 확인(상위 전달). CH13 모든 회차/회차 목록으로 용어 정리, 배정 설명 행 원본 레이아웃과 어두운 스크롤 보완. 표시 CSS·용어 변경은 전체 테스트 반복 없이 화면 재확인 대상으로 인계.

## WV06 초안 재저장 후 재개 — 구현 전 기대값

- 기존 `/classes/new?draft=D`에서 초안 저장→완료→편성 이어서 하기 시 같은 주소라도 입력 화면을 새로 연다.
- 초안 상세를 다시 조회하고 최신 `draft_schedule`·`revision`을 사용한다. 이전 완료 상태·멱등키·저장 체크포인트를 재사용하지 않는다.
- 재개 후 다시 저장하면 재조회 revision이 PATCH expected_revision에 들어간다. 실제 라우터 이동으로 RED→GREEN 검증한다.

- WV06 결과: 동일 초안 링크 재개 테스트 RED 1개 확인→마법사 11개 GREEN(1.19초).
- 라우터 location.key를 마법사 진입 키에 포함. 동일 주소 재개 시 재마운트하여 완료 상태·요청 키·체크포인트 초기화, 상세 GET 재실행.
- 테스트는 revision3 초안 저장→같은 주소 재개→서버 revision5/title 재조회→expected_revision5로 재저장과 서로 다른 operation_key까지 확인.
