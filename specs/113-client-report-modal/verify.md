# 구현 전 검증 시나리오

- 목록 카드 클릭 시 URL과 목록이 유지되며 내담자 리포트 dialog가 표시된다.
- 완료 세션 리포트 버튼은 동일 모달을 연다.
- 닫기 버튼, ESC(cancel), 오버레이는 모달을 닫고 트리거에 포커스를 복원한다.
- 본문 클릭은 닫히지 않는다. 열린 동안 body 스크롤이 잠기고 닫으면 이전 값으로 복원된다.
- 요청 진행 상태와 실패 메시지를 표시하고 닫기 동작이 가능하다.
- 상담사 코멘트·주관 체크인이 유지되고 not_measured EEG 및 종합점수 대형 노출이 없다.
- 직접 URL 상세 페이지와 PDF 액션을 유지한다.
- 관련 vitest 및 npm run build 성공.

승인 게이트는 이번 사용자의 명시적 요청에 따라 생략한다. 구현 전에 작성함.
