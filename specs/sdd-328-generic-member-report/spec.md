# SDD-328 — 범용 회원 명상 리포트 — 단계 없는 실측 기반 구조·쉬운 말

- 기준 원본: `ref/sample.pdf` (18쪽, 현 v11 구현물 = SDD-327)

## 1. 배경·문제

- SDD-327(v11)은 몸돌봄 수업 한 종류의 구성(준비·호흡 / 몸 움직임 / 명상 전반 / 명상 후반 4구간)을 코드에 고정(`_REF_SEGMENTS`, 64분 기준 비례 환산)했다.
- 마음돌봄 등 다른 수업은 같은 구간 이름이 맞지 않는다 → 범용 불가.
- 본문에 RMSSD·SDNN·LF/HF·심박수 같은 전문 용어가 큰 글씨로 노출되어 회원이 읽기 어렵다.
- 요약·종합 의견 일부를 AI(`ai_text`)로 쓸 수 있는 경로가 있어 호출 비용·편차가 있다.

## 2. 목표 (대표 결정 11/17)

1. **구간 폐기**: 수업 종류별 고정 구간(4구간 템플릿) 제거. 실측 기반 비교로 대체.
2. **범용 비교 규칙**: 몸돌봄·마음돌봄·그 밖의 명상 수업에 동일 규칙 적용.
3. **쉬운 말**: 전문 용어는 제목·본문에서 제거, 원어는 각주에만 남긴다.
4. **AI 호출 0**: 모든 문장은 규칙·문장 틀로 생성(비용 0, 결정적 출력).
5. 기존 그래프·쪽 구성(18쪽 책, 웹 화면)은 유지하되 **구간 정보만 제거**.

## 3. 범위

### 3.1 실측 기반 규칙 (시안 `build.py`가 정본)

| 규칙 | 내용 |
|---|---|
| 안착 제외 | 수업 시작 후 첫 2분(분 인덱스 0·1)은 밴드 안착 시간 — 비교·요약에서 제외, 그래프에는 회색 배경 |
| 처음 5분 | 인덱스 2~6(화면 표기 3~7분)의 분별 **중앙값** |
| 마지막 5분 | 인덱스 n-5~n-1(표기 n-4~n분)의 분별 중앙값. 유효 측정 길이 n |
| 전후 비교 | 처음 5분 → 마지막 5분 (지표별). 빈 분은 보간하지 않는다 |
| 전체 흐름 | 안착 이후 전 구간 분 단위 시계열(결측은 선 끊김) |
| 가장 편안했던 5분 | 인덱스 2 이후 연속 5분 중 심박·움직임이 모두 있는 창에서 ① 움직임 평균 최소 → ② 심박 중앙값 최소 → ③ 이른 시각 순. 문구는 "찾았어요/후보"이며 편안함을 확정하지 않는다. 시기 표현: n×0.3 미만 "수업 초반에", n×0.7 이상 "수업이 끝나갈 무렵", 그 사이 "수업 중간에" |
| 그룹 비교 | 회원 본인 제외 그룹. 분별 **평균 ±1 표준편차(모집단 SD, ddof=0)** 띠 + 평균 점선. 해당 분 유효 인원 **10명 이상**인 분만 표시(미만이면 그 분의 평균·띠 생략, 선 끊김). 현재 중앙+50/80% 띠는 폐기 |
| 분포 | 개인 분 값 히스토그램 + 그룹 분 값 가우시안 KDE 곡선 + 평균선(나 실선/그룹 점선) + ±1SD 음영 |
| 상대 변화 | RMSSD·SDNN은 본인의 처음 5분을 0%로 둔 상대 변화(%)로 표시. 그룹 곡선·띠도 **같은 기준값(회원 처음 5분 중앙값)** 으로 변환 후 계산. LF/HF는 `log1p` 흐름 방향만, 세로축 숫자·그룹 비교 생략 |
| 마음 지표 | 집중도·이완도·감정 균형도(정규화 후 값). 뇌파 1/f 기울기는 원자료(원시 EEG) 있고 기준 통과 시에만 쪽 유지(현행 규칙), 없으면 쪽 생략(현행) |

### 3.2 쉬운 말 대응

| 원어(각주에만) | 제목·본문 |
|---|---|
| RMSSD / HRV | 심장 리듬의 여유 |
| SDNN | 심장 리듬의 여유 · 전체 흐름 |
| LF/HF | 긴장과 휴식의 균형 (표기 "흐름"만, 단독 판정 금지) |
| 심박수 | 1분 동안 뛴 횟수 |
| 움직임 / 가속도 | 몸이 움직인 정도 |
| (유지) 집중도·이완도·감정 균형도 | 그대로 |

- "불규칙" 표현 금지(심장 이상 오해). 대안: "박동 사이 간격이 조금 더 다양해졌어요. 몸이 쉬는 흐름과 함께 나타날 수 있어요."
- 큰 글씨(제목·히어로·요약 카드·쪽 제목)에는 전문 용어 0. 각주(7.5~11pt)에만 RMSSD·SDNN·LF/HF·PRV 허용.
