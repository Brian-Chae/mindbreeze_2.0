# [SDD-133] 반응형·디자인 토큰·게이트 정합

## Goal
대기 화면 UX·색상 일관성·불필요 서버 호출·반응형 잘림·게이트 정책을 정비한다.

## Issues
- ①-3 시작 대기 중 BGM 조절 불가 → WaitingForStart에 BGM 바 추가
- ①-5 이름 입력마다 서버 신호 → presence effect에서 nickname 의존성 제거
- ①-7 자동 참여 중복 호출 → joinStartedRef 가드 + participantToken 의존성
- ①-9 모바일 입장 버튼 순서 → order 유틸로 이름→입장 순서
- ①-11 대기 화면 색상 불일치 → 토큰(#1D1027 등) + 보라 스크림 통일
- ①-12 밴드 탭 자동 연결 → 탭 활성일 때만 마운트
- ①-13 밴드 연결 자동 완료 → 명시적 버튼 확정으로 변경
- ①-19 게이트 정책 문서-구현 불일치 → 3단계 강제로 주석 통일
- ②-8 노트북 폭(1024~1124px) 잘림 → 브레이크포인트 1164px

## Acceptance Criteria
- [ ] 시작 대기 중 BGM 조절 가능.
- [ ] 이름 타이핑 시 서버 신호 없음.
- [ ] 자동 참여 중복 호출 없음.
- [ ] 모바일에서 이름이 입장보다 먼저.
- [ ] 대기/진행 화면 색상 일관.
- [ ] 밴드 탭 열 때만 연결.
- [ ] 연결 자동 완료 제거(버튼 확정).
- [ ] 1024~1124px에서 잘림 없음.
- [ ] 빌드 0 errors, 관련 테스트 통과.
