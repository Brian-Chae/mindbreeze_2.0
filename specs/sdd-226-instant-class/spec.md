# SDD-226 — 즉시 클래스 — 지금 바로 시작

- 상태: Stage ① Spec — Brian 승인(2026-10-21 "좋아 시작해")
- 브랜치: `sdd/226-instant-class` · 작성일: 2026-10-21
- 기획: [docs/즉시-클래스-기획.md](../../docs/즉시-클래스-기획.md) · 시안: [designs/instant-class/index.html](../../designs/instant-class/index.html)

## 1. 문제
준비 없이 지금 명상 수업을 열어야 할 때(갑작스러운 요청·예약 누락), 기존 '바로 지금'(SDD-216)은 4단계 마법사 2단계 안에 있어 7~8번 클릭과 이름 입력이 필요하다.

## 2. 목표
버튼 2번(진입 → 지금 열기)으로 대기실이 열리고 코드를 회원에게 알려 줄 수 있다.

## 3. 범위 (확정 결정)
| # | 내용 | 결정 |
|---|---|---|
| D1 | 기본 소요 시간 | 30분 (칩 20/30/45/60 + 직접 입력 5~480분, 5분 단위) |
| D2 | 연 뒤 동선 | 공유 화면(IC-04) → [대기실로 들어가기] 1클릭. 자동 이동 없음 |
| D3 | 끝난 즉석 클래스 '다시 열기' | 포함 — 같은 설정으로 새 즉석 클래스 화면(IC-03) 진입 |
| D4 | 공유 수단 | 회원(앱 알림)·이메일만. 문자·카카오톡 제외(유료). 코드·링크 복사 제공 |

### 포함
1. 새 라우트 `/classes/now` — 즉석 클래스 한 화면(IC-03). 필수 입력 없음.
   - 이름 자동 `즉석 명상 · {M월 D일} {오전/오후 h:mm}`(KST), 비우면 자동 이름 사용.
   - 소요 시간 칩, 진행 방식(온라인/오프라인+주소 필수), 더보기(정원·LINK BAND·녹음·영상 녹화(온라인)·채팅), 회원 초대(선택, 회원 선택+이메일).
   - 관리자: 진행 지도사 1명 필수. 상담사: 본인.
   - 지난 즉석 설정 기억: localStorage 키 `mb:instant-class:last:{userId}` (시간·방식·주소·정원·LINK BAND·녹음·영상·채팅·관리자의 지도사). 이름·초대 대상은 저장 안 함.
   - [지금 열기] = 기존 `schedulingApi.preview` → `create(status:'active', start_now:true)` 계약 재사용. 충돌 시 경고 시트 1번 → '그대로 열기'(기존 force+fingerprint).
2. 공유 화면(IC-04): 대기실 열림 배지, 클래스 코드 크게, QR(입장 경로 `/join` URL; 코드 미포함), 코드 복사·입장 링크 복사·회원 초대, 초대 상태 목록(이메일 발송 상태 `ClassInstantInviteStatus` 재사용 + 회원 초대 결과), 상담사 [대기실로 들어가기] → `/sessions/{id}/player`, 관리자 [회차 확인] → `/classes/{cid}/sessions/{sid}`.
3. 회원 초대 시트(IC-06): 탭 2개(회원/이메일). 회원=`classOperationsApi.inviteMembers`, 이메일=`schedulingApi.inviteEmails`. 정원 초과 선택 차단. 보낸 뒤 시트 닫고 토스트+상태.
4. 진입점: 클래스 목록 헤더 '지금 바로 시작'(주)+'새 클래스 만들기', 목록 상단 안내 카드, 홈 대시보드 '클래스 바로 열기' → `/classes/now`, 마법사 시작 화면 맨 위 강조 카드(IC-02).
5. 목록: 즉석 클래스 '즉석' 칩·필터, 완료된 즉석 클래스에 '다시 열기'(→ `/classes/now?from={id}`, 상세의 설정으로 초기값).
6. BE: `ClassSummary.is_instant: bool`(= `recurrence_rule.start_now is True`) 가산. 기존 필드 변경 없음.

### 제외
- 문자·카카오톡 발송, '최근 함께한 회원' 서버 집계(1차는 기존 회원 검색 picker 사용), 기기 간 설정 동기화, 즉석→정기 전환.
- 기존 마법사 '바로 지금' 옵션은 유지(호환).

## 4. 제약
- LINK BAND 없이 동일 동작. 수업 시작·녹음 자동 시작 없음(기존 start_now 계약).
- URL·QR에 코드·이메일 넣지 않음. 실제 메일 발송 테스트 금지(대역).
- 모바일 390px 넘침 0, 하단 CTA 고정.
