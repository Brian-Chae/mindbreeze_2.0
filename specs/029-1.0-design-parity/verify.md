# SDD-029 — Verify (구현 전 QA 게이트)

## 1. 명상 화면
- [ ] 검정 풀블리드 (그라데이션 카드 제거)
- [ ] 자연 이미지 페이드: 20초 간격 + 1초 교차 (webp 10장)
- [ ] 두뇌휴식도 clamp(64~130px) 흰색
- [ ] "AI 분석중" 깜빡임 (LeadOff 해소 후 15초)
- [ ] 바차트 (회색 둥근 막대, threshold 40)

## 2. 호스트 화면
- [ ] 흰 배경 + 세션코드 배너
- [ ] DashboardBox 4종 수평 카드, 경고 빨강
- [ ] 평평한 8컬럼 테이블 (교차행 + 빨강 행 강조)
- [ ] 시작 진보라 / 종료 연보라

## 3. 결정 반영
- [ ] 배터리 `<=25%` 경고 통일
- [ ] 리포트 = 메일 발송 경로

## 4. 회귀
- [ ] 프론트 tsc 0 error + build
- [ ] 백엔드 pytest
- [ ] 상태 머신/WS/BLE 동작 유지
