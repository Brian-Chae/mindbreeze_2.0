# SDD-074 구현 전 Verify

작성 시점: 애플리케이션 코드 변경 전. 구현 권한: 코디네이터가 전달한 SDD-074 구현 브리프.

- [ ] 두 신규 API: 플랫폼 관리자 성공, 비로그인 거절, 다른 역할 403.
- [ ] 없는 기관 404, 잘못된 UUID 422.
- [ ] 상세 주소/인증시각/유형/생성시각 및 최소 담당자·소유자 요약.
- [ ] 담당자/소유자 부재는 null, version은 DB 미도입으로 null.
- [ ] 상담사 코드 원본 및 프로필 부재 null, 타 기관/내담자 제외.
- [ ] 상담사 created_at ASC, 동률 id ASC 및 표시 플래그.
- [ ] 기존 org 관리자 경로 권한 유지, 기존 목록 배열/등록/재초대 회귀.
- [ ] 모달 두 탭, 독립 로딩/오류/재시도, 오류를 0명으로 표시하지 않음.
- [ ] 기관명 버튼 및 행 클릭, 복사·재초대 전파 차단.
- [ ] Enter/Space 열기, Escape 닫기, 포커스 복귀/내부 격리.
- [ ] 목록 검색/필터/그룹핑 및 상담사 검색/역할/상태 필터.
- [ ] 개인 기관 소유자, 담당자 미지정, 누락 코드, 미확인 상태 표시.
- [ ] backend venv/bin/pytest 및 frontend npm run build.

실행 결과는 사후 변경 대신 summary.md에 기록한다.
