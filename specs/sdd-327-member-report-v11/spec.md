## 2. 책 순서 (page-map.json 정본)

1 표지 → 2 목차 → 3 요약 카드·지금 나의 상태 → 4 종합 의견 → 5 몸의 변화·수업 여정 → 6 몸의 움직임 → 7 안정된 5분 → 8 심박수 → 9 RMSSD → 10 LF/HF 흐름 → 11 마음의 변화·집중도 → 12 이완도 → 13 감정 균형도 → 14 뇌파 1/f 기울기 → 15 다음 걸음 → 16 손글씨 메모 → 17 방법·참고문헌·문의 → 18 뒷표지.
- 지표 9개(6~14쪽) 각 **정확히 1쪽**. 넘치면 글자 하한(본문 9.5pt·라벨 8.5pt·각주 7.5pt)을 낮추지 않고 패딩·그래프 높이(시간 170px·분포 145px, LF/HF 245px)로 조정.
- 화면은 같은 순서의 한 컬럼 스크롤(데스크톱은 좌측 목차 고정).
- 뒷표지 머리말·꼬리말: **결정 필요(기본값)** — 표지처럼 제거. 뒷표지 제목은 가운데 정렬(`#back-center`).

## 3. 결론·해석 문장 생성 규칙 (코드화 대상)

| 입력 | 규칙 |
|---|---|
| 지표별 전·후반 변화량(후반−전반) | 방향 임계(기존 `report_narrative.direction_for_change` 재사용: 심박 3bpm·HRV 5ms·마음 3지표 5%)를 넘으면 "올랐어요/내려갔어요", 미만은 "비슷했어요" |
| 반대 방향 | 기대와 반대여도 숨기지 않고 같은 형식으로 정직하게 표기 |
| 인과 | "명상 때문에" 단정 금지. "이 수업 동안 ~했어요"처럼 관찰형 |
| 결측(밴드 미착용·신호 부족) | 값을 0으로 채우지 않음. 해당 지표 문구 "이번에는 비교할 만큼 측정되지 않았어요" 고정 |
| 점수화 | 종합점수·등급·좋음/나쁨 판정 금지(서사+변화량만) |
| LF/HF | 범위 판정 금지, 시간 흐름만 표시 |
| 종합 의견 | 규칙 문장이 확정, Gemini(2.5-flash) 초안은 검증 통과분만 보강(기존 `class_report_narrative` 검증 체계 재사용). AI 실패 시 규칙 문장 |

문장 틀은 시안 `wording.json`·v8~v11 README 대조표를 `report_member_wording.py` 상수로 옮기고, 시안 값(`v11-numeric.json`)으로 골든 테스트한다.

## 4. 고정 규칙 (테스트 대상)

1. 점수·등급·좋음/나쁨 표현 0.
2. 금지어 0: `B5`, `건강 수준`, `점수`, `등급`, `스트레스`, `우울`, `진단합니다`, `위험` (화면 텍스트·PDF 텍스트 모두). ※ 내부 필드명 `stress_index`는 화면에 노출하지 않음.
3. 문의처 문구 "담당 클래스 코치".
4. LF/HF에 정상·높음·낮음 범위 판정 없음.
5. 실명 미표시 — 회원 식별은 표시 규칙(시안: 회원 식별 코드 `B2-18` 형식)으로. **결정 필요(기본값)**: 코드 = 클래스 내 순번 기반 `B{클래스}-{순번}`, 본인 PDF에도 실명 미기재.
6. "의료 진단이 아닙니다" 안내를 방법·참고문헌 쪽(17)과 화면 하단에 유지.
7. 시안 수치·SVG 도형 불변(이식 시 시안 샘플값으로 렌더해 시안 `v11-numeric.json`과 일치 확인).

## 6. LINK BAND 미착용 회원 (알려진 이슈 1)

- 생체·뇌파 장(몸의 변화 6~10, 마음의 변화 11~14)을 생략한 **축약판**: 표지·목차·요약·종합 의견(수업 참여 서사)·다음 걸음·손글씨 메모·방법/문의·뒷표지. 쪽수는 목차가 자동 재계산.
- 일부 지표만 결측이면 해당 쪽은 "측정되지 않았어요" 한 줄 쪽으로 대체하지 않고 **그 지표 쪽 자체를 생략**(지표 1쪽 원칙 유지), 요약 카드는 가용 지표만.
- 화면도 동일하게 장 단위로 숨김. `bandConnected`/지표 가용성 가드 필수.

## 7. 그룹 비교 개인정보

- 그룹 분포는 **집계(분포 구간·평균)만** 전달. 타 회원 개인 값·ID는 응답에 포함 금지.
- 최소 인원: 시안 29명(유효 10분 이상) 기준. **결정 필요(기본값)**: 해당 지표 유효 인원 ≥ 10명일 때만 그룹 비교(분포·점선 평균) 표시, 미만이면 그룹 비교 숨기고 "나의 기록"만(숨김은 숫자도 미전송).
- 유효 기준: 개인 유효 시간 ≥ 10분(시안 기준; 기존 `MIN_VALID_SEC=60`과 별개의 신규 상수).

## 9. 공유 메일 보내기 (추가 범위, 2026-11-13 대표 지시)

> 지시: "이 PDF나 리포트를 자기 메일 말고 다른 메일로도 보낼 수 있는 기능."
> 현재: 상담사·기관관리자만 `POST /reports/{id}/resend-email`로 다른 주소 재발송 가능. **회원(내담자·클래스 회원)은 불가** — 이번 추가의 핵심. 기존 재발송 토큰은 *등록된 본인 이메일*에 묶여(RESEND-006) 다른 주소 수신자가 열면 403이 되는 구조라, 공유용 토큰을 별도로 둔다.

### 9.1 사용자 흐름
**회원**: 리포트 화면 "리포트 보내기"(모바일 상단/하단 고정, 데스크톱 상단 우측) → 보내기 시트(모바일 바텀시트/데스크톱 모달) → 받는 주소 입력(칩, 최대 3) · 책 PDF 첨부 토글(기본 켬) · 짧은 메시지(선택, 200자) · 민감정보 확인 체크 → 보내기 → 성공("N곳에 보냈어요")/실패 안내 → 리포트 상세 하단 "보낸 기록" 카드.
**상담사·기관관리자**: 기존 재발송 UI(`ReportDetailView.tsx`)를 같은 시트로 대체(주소 1개 입력 → 칩 입력 통일). 권한·본인 리포트 범위만 다름.
**받는 사람(로그인 불필요)**: 메일 수신 → "리포트 열기"(7일 유효, 받는 주소 전용) 또는 첨부 PDF 열람.
**앱(Capacitor)**: 같은 시트에 "다른 앱으로 공유" 보조 버튼(Capacitor Share로 책 PDF 파일 공유).

### 9.2 기본값 (결정 필요(기본값) — 대표 확인 전까지 이 값으로 구현)
1. 보내는 사람: 회원 본인(자기 리포트만) + 상담사·기관관리자 기존 경로 유지, UI는 같은 시트.
2. 받는 사람: 1회 최대 3개 주소(중복 제거), 회원 하루 10통 상한(통 = 수신 주소 1건), 같은 주소 연속 발송 1분 간격.
3. 형태: 본문 = 요약 카드(효과 결론·전후 4쌍) + "리포트 열기" 링크(토큰 7일, 받는 주소 전용) + 명상 기록 책 PDF 첨부 선택(기본 켬). PDF > 8MB면 링크만(첨부 토글은 자동 해제하고 안내).
4. 민감정보: 발송 전 확인 문구 "심박·뇌파 등 개인 기록이 담겨 있어요. 받는 분이 열어볼 수 있어요." + 체크 필수. 수신 메일 하단: "보낸 사람: {회원 표시명}님이 공유", "의료 진단이 아닙니다".
5. 기록: 발송 이력(시각·받는 주소 마스킹·형태)을 리포트 상세에서 회원 본인이 열람, 서버 감사 로그. 링크 회수 버튼은 **후속(비범위)**.
6. 앱 기기 공유는 기본 포함, 구현 난도 높으면 후속으로 표시(plan T15에 분리).
7. 금지어·문의: 리포트와 동일(점수·등급 등 0, 문의 "담당 클래스 코치").

### 9.3 권한
- 회원: 본인 `participant`에 속한 `completed`(승인 완료) 리포트만. 타인 리포트 403, 미승인 409, `report_included=false`·`pii_scrubbed_at` 존재 시 409(기존 재발송과 동일 검사).
- 상담사·기관관리자: 기존 `require_report_host`(호스트 세션) 범위.
- 받는 사람: 토큰 소지자 + 주소 일치만 열람. 로그인 정보 불필요, 계정 생성 없음.

### 9.4 개인정보·남용 방지
- 받는 주소 전용 토큰(주소 해시 바인딩) → 링크가 전달·유출돼도 다른 주소 컨텍스트로는 같은 토큰 재사용 불가(본문 열람 시 토큰 내 수신자 해시 검증). *한계*: 받는 사람이 메일 자체를 재전달하면 열람 가능 — 확인 문구로 고지, 회수는 후속.
- 하루 10통·주소별 1분 간격·1회 3주소(서버 강제, 클라 검증은 보조). 상한 초과 429 + 남은 횟수/재시도 시간 안내.
- 주소는 로그·감사에 마스킹 저장(`a***@d***.com`), 메시지 본문(200자)은 HTML 이스케이프, 링크·URL 패턴 제거(스팸·피싱 악용 방지). 발신 이름은 회원 표시명(이메일 주소 아님).
- 본인 이메일 주소로의 공유는 허용(제한 없음, 일일 상한엔 포함).
- 개인정보 보관 만료(`pii_scrubbed_at`)·리포트 제외 시 열람 차단(기존 SDD-209 B3 규칙 승계).

### 9.5 메일 템플릿 요구

- 제목: "{회원 표시명}님이 명상 기록을 공유했어요".
