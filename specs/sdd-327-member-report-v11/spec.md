## 2. 책 순서 (page-map.json 정본)

## 3. 결론·해석 문장 생성 규칙 (코드화 대상)

| 입력 | 규칙 |
|---|---|
| 지표별 전·후반 변화량(후반−전반) | 방향 임계(기존 `report_narrative.direction_for_change` 재사용: 심박 3bpm·HRV 5ms·마음 3지표 5%)를 넘으면 "올랐어요/내려갔어요", 미만은 "비슷했어요" |
| 반대 방향 | 기대와 반대여도 숨기지 않고 같은 형식으로 정직하게 표기 |
| 인과 | "명상 때문에" 단정 금지. "이 수업 동안 ~했어요"처럼 관찰형 |
| 결측(밴드 미착용·신호 부족) | 값을 0으로 채우지 않음. 해당 지표 문구 "이번에는 비교할 만큼 측정되지 않았어요" 고정 |
| 점수화 | 종합점수·등급·좋음/나쁨 판정 금지(서사+변화량만) |
| LF/HF | 범위 판정 금지, 시간 흐름만 표시 |
| 종합 의견 | 규칙 문장이 확정, Gemini(2.5-flash) 초안은 검증 통과분만 보강(기존 `class_report_narrative` 검증 체계 재사용). AI 실패 시 규칙 문장 |

문장 틀은 시안 `wording.json`·v8~v11 README 대조표를 `report_member_wording.py` 상수로 옮기고, 시안 값(`v11-numeric.json`)으로 골든 테스트한다.

## 4. 고정 규칙 (테스트 대상)

1. 점수·등급·좋음/나쁨 표현 0.
2. 금지어 0: `B5`, `건강 수준`, `점수`, `등급`, `스트레스`, `우울`, `진단합니다`, `위험` (화면 텍스트·PDF 텍스트 모두). ※ 내부 필드명 `stress_index`는 화면에 노출하지 않음.
3. 문의처 문구 "담당 클래스 코치".
4. LF/HF에 정상·높음·낮음 범위 판정 없음.
5. 실명 미표시 — 회원 식별은 표시 규칙(시안: 회원 식별 코드 `B2-18` 형식)으로. **결정 필요(기본값)**: 코드 = 클래스 내 순번 기반 `B{클래스}-{순번}`, 본인 PDF에도 실명 미기재.
6. "의료 진단이 아닙니다" 안내를 방법·참고문헌 쪽(17)과 화면 하단에 유지.
7. 시안 수치·SVG 도형 불변(이식 시 시안 샘플값으로 렌더해 시안 `v11-numeric.json`과 일치 확인).

## 6. LINK BAND 미착용 회원 (알려진 이슈 1)

- 생체·뇌파 장(몸의 변화 6~10, 마음의 변화 11~14)을 생략한 **축약판**: 표지·목차·요약·종합 의견(수업 참여 서사)·다음 걸음·손글씨 메모·방법/문의·뒷표지. 쪽수는 목차가 자동 재계산.
- 일부 지표만 결측이면 해당 쪽은 "측정되지 않았어요" 한 줄 쪽으로 대체하지 않고 **그 지표 쪽 자체를 생략**(지표 1쪽 원칙 유지), 요약 카드는 가용 지표만.
- 화면도 동일하게 장 단위로 숨김. `bandConnected`/지표 가용성 가드 필수.

## 7. 그룹 비교 개인정보

- 그룹 분포는 **집계(분포 구간·평균)만** 전달. 타 회원 개인 값·ID는 응답에 포함 금지.
- 최소 인원: 시안 29명(유효 10분 이상) 기준. **결정 필요(기본값)**: 해당 지표 유효 인원 ≥ 10명일 때만 그룹 비교(분포·점선 평균) 표시, 미만이면 그룹 비교 숨기고 "나의 기록"만(숨김은 숫자도 미전송).
- 유효 기준: 개인 유효 시간 ≥ 10분(시안 기준; 기존 `MIN_VALID_SEC=60`과 별개의 신규 상수).
