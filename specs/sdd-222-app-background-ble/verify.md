# SDD-222 Verify — 구현 전 QA 체크리스트

- 상태: Stage ③ Verify — **Brian 승인 대기 (구현 전 게이트)**
- 이 문서는 구현 **전**에만 작성한다(AGENTS.md: 사후 작성 금지). 구현 중 항목 추가·변경이 필요하면 별도 개정 이력으로 남기고 승인을 다시 받는다.
- 표기: **V** = 자동(vitest, 사람이 개입하지 않음) / **M** = 실기기 수동 / **차단** = 하나라도 실패하면 출시 불가.
- 실기기 기준: Android 14 이상 1대 이상(가능하면 삼성 + 타 제조사), iOS 17 이상 1대, LINK BAND 2.0. 에뮬레이터·시뮬레이터 결과는 인정하지 않는다.
- 범위: 회원 앱 + **상담사(호스트) 앱 화면 포함**(D3, 2026-10-20 개정).
- 공통 전제: 앱 빌드는 dev 환경, 수업은 테스트 클래스(밴드 연결 회원 1명 + 호스트 1명), 서버에서 해당 세션의 raw 청크 수신 시각을 확인할 수 있어야 한다.

## C. 판정 기준

- **출시 가능**: 차단 ✅ 항목 전부 통과. 단 M5·M8(iOS 백그라운드)이 플랫폼 제약으로 미달이면 **원인·재현 조건·대안**을 summary 에 적고 Brian 판단을 받는다(spec R1·R2).
- **자동 테스트 변경 금지**: 구현 중 V 항목을 완화·삭제하지 않는다. 필요 시 개정 요청.
- **데이터 정합**: M1·M3·M5·M9 는 서버 raw 수신 시각과 클라이언트 갭 로그를 대조해 **공백 구간 = BLE 끊김 구간**임을 확인한다(그 외 공백이 있으면 시스템 결함으로 판정).
