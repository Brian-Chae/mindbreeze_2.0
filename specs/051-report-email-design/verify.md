# SDD-051 구현 전 Verify

작성 시점: 구현 전. 코디네이터 승인 완료 (구현 시작 전 CLI ask 응답: 승인합니다. 진행하세요).

- [ ] 메일 HTML의 table 레이아웃, 브랜드 4색, 리포트 보기 CTA, 7일 안내 및 텍스트 폴백 확인
- [ ] CTA 링크의 특수문자 escape 및 기존 JWT 링크 목적지 유지
- [ ] 열람 페이지 커버/인사이트/7지표/푸터와 viewport, 모바일 줄바꿈 확인
- [ ] 점수는 접힌 상세에서만 노출, 0은 유효값, null은 미측정으로 구분
- [ ] 제목/요약/인사이트/지표의 HTML 삽입 차단, 허용 필드만 출력
- [ ] CSP 인라인 스타일 허용 및 스크립트/프레임 차단, no-store/no-referrer 유지
- [ ] 기존 인증/만료/권한 테스트와 전체 backend venv/bin/pytest -q 통과
- [ ] 데스크톱/모바일 샘플 렌더 확인 (실제 Gmail/Outlook 전송 검증과 구분)
