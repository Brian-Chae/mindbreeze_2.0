# SDD-227 — 로그인 화면에서 코드로 바로 입장

- 상태: Stage ③ Verify 완료 → 구현
- 브랜치: `sdd/227-login-code-entry`

## 문제
앱은 랜딩 없이 로그인 화면부터 열린다. 로그인 화면에 코드 입장 진입점이 없어 계정 없는 참여자가 클래스에 들어갈 길이 없다.

## 요구사항
1. 회원 탭에서만 화면 하단에 코드 입장 카드를 고정(플로팅) 표시 → `/join`. 상담사·기관 탭, 플랫폼 관리자 로그인에는 없음.
2. 카드가 폼을 가리지 않도록 회원 탭 아래 여백(카드 높이 + 하단 안전영역 + 여유)을 둔다.
3. 회원 탭 순서: 이메일·비밀번호 → [이메일로 회원 로그인] → 비밀번호 찾기·회원가입 → "간편 로그인" 구분선 → Google·Apple(→ 신규 가입 동의).
4. 이메일·비밀번호 입력 중에는 카드를 숨긴다.
5. 코드 입장 흐름(`/join`)과 서버는 변경하지 않는다. 코드는 URL에 싣지 않는다.
