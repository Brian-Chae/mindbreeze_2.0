## A8-0. 범위
- 코어(`packages/measurement-core/src`)·frontend·backend 무수정. 홀드아웃(MARSH 14명, CapnoBase) 미접근 — `run-holdout` 거부 유지, 접근 로그 holdout 0건이어야 한다.
- 대상: 개발 세트 중 호흡 참값이 있는 BIDMC 53 + MARSH dev 15 = 68 기록. 창 L=60, 채점 hop 10s(기준선과 동일). MIMIC·DaLiA 는 호흡 참값 없음 → 제외.
- 호흡수가 틀렸다는 전제는 철회 상태다. 목적은 기준선 오차(BIDMC MAE 5.4 / MARSH 3.1)가 알고리즘 때문인지 참값·데이터(손가락 PPG) 때문인지 가르는 단서를 얻는 것이다. **결과는 관찰로 서술하고 인과를 단정하지 않는다.**
- 값을 10회/분에 맞추는 상수 보정, 참값에 접근해 튜닝하는 것은 금지. 변형의 모든 파라미터는 아래에 고정되어 있고, 결과를 본 뒤 조정하지 않는다.

## A8-1. 방법: 거울 구현
- 변형 실험은 코어를 고칠 수 없으므로 **파이썬 거울**(`ppg_eval/variants.py`)에서 한다. 코어(`replay_eval`)는 기록당 1회 돌려 프레임별 후보 RR·박동 종료시각·코어 호흡값을 얻고, 기존 `Shadow`(RR 버퍼 거울, 98,174프레임 0건 불일치로 검증됨)가 매 호흡 계산 시점의 RR 버퍼를 만든다. 호흡 계산(재표본 4Hz → Welch → 피크 → 5중앙값)과 코어의 초기화 시점(시계 역행 리셋·재시드) 처리를 거울에 새로 구현한다.
- 기존 모듈(`shadow.py` 등)은 수정하지 않는다. 기준선 `run-dev` 산출물은 바이트 동일이어야 한다.
- 변형 간 비교의 공정성: 모든 변형이 **같은 RR 버퍼 스냅샷**(변형 0 의 것)을 입력으로 쓴다. 변형은 RR 정제·버퍼 규칙은 바꾸지 않고 호흡 계산 단계만 바꾼다.

## A8-2. 거울 동치 게이트 (변형 실험 전 필수)
변형 없는 거울(V0)의 프레임별 호흡값을 코어 C0 의 해당 프레임 `resp` 와 비교한다. 대상은 개발 세트 호흡 기록 68건 전체(일부가 아니라 전체; 비용이 작음).
- 프레임 일치 = (둘 다 null) 또는 (둘 다 값이 있고 |Δ| ≤ 1e-6 회/분).
- 통과 기준: 전체 불일치 프레임 ≤ 0.1%, 어느 기록도 불일치 프레임 ≤ 1%.
- **통과하지 못하면 원인을 해결하기 전에는 변형 실험을 하지 않는다**(변형 결과를 만들거나 보고하지 않는다). 원인 분석은 코어 읽기·거울 수정만 허용.

## A8-3. 변형 정의 (한 번에 하나만 바꾼다; 나머지는 V0 와 동일)
V0 기준 동작(코어 `hrv.rs` 의 `respiratory`): 호흡 가능 게이트(RR 합 ≥60s, 박동 시각차 ≥60s) → 누적 RR 시간축에 RR(초)값을 4Hz 선형 보간(`interpolate_linear`, 마지막 구간 y2=NaN) → Welch(Hamming, 창 max(64,min(256,N/2)), 50% 중첩, NaN 구간은 PSD 0, 평균·추세 제거 없음) → 대역 [0.15, 0.4]Hz 최대 PSD 빈 → rate=f·60, [6, 40] 밖이면 실패 → 직전 5개 중앙값. 실패하면 호흡값 null·이력 비움.

| ID | 변경점 (이 외는 V0 와 동일) | 판정 대상 |
|---|---|---|
| V1 | 보간 끝단 NaN 처리: 마지막 구간의 y2 가 없으면 y1 을 유지(끝단 값 유지 외삽). NaN 점이 사라진다 | 예(주) |
| V1b | 보간 끝단 NaN 구간 제외: 마지막 RR 시작 시각(t[n-1]) 이후의 4Hz 점을 버린다(재표본 길이가 줄어 Welch 창도 함께 정해짐) | 아니오(관찰) |
| V2 | 탐색 대역 하한 0.15 → 0.10Hz | 예(주) |
| V2a | 하한 0.12Hz | 아니오(관찰) |
| V2b | 하한 0.08Hz (rate<6 실패 게이트는 불변이므로 0.1Hz 미만 피크는 null 이 된다) | 아니오(관찰) |
| V3 | 시간축: 누적 RR 대신 실제 박동 시각. i 번째 값의 시각 = (ts[i]−rr[i]) − (ts[0]−rr[0]) (그 박동의 시작=직전 피크 시각), 끝점 = ts[n−1] − (ts[0]−rr[0]). 값·보간 방식(마지막 구간 NaN 포함)은 V0 와 같다. 시각이 단조 증가가 아닌 프레임은 V0 의 누적 시간축으로 되돌리고 그 프레임 수를 보고한다 | 예(주) |
| V4 | Welch 전에 4Hz 재표본(유한 점)의 평균과 선형 추세를 최소제곱으로 제거(NaN 점은 NaN 유지) | 예(주) |
| V5 | 탐색 대역 상한 0.4 → 0.5Hz (rate>40 실패 게이트 불변) | 예(주) |
| V6 | 피크 선택에 연속성 한 가지: 직전 성공 계산의 지배 주파수 f_prev 가 있으면, 대역 안에서 |f−f_prev| ≤ 0.04Hz 인 빈 중 최대 PSD 빈을 후보로 하고, 그 PSD ≥ 0.5×(대역 전체 최대 PSD) 이면 채택, 아니면 대역 전체 최대. f_prev 는 실패·리셋 시 비운다 | 예(주) |

- 조합 변형은 이 단계에 없다(별도 단계).
- V1·V1b·V3 은 같은 방향(끝단·시간축)의 문헌 가설이다. 서로 독립 가설로 다중성 보정은 하지 않는다. 판정 대상 6개이므로 **우연히 개선 1개가 나올 확률을 감안해** 요약에 "판정 6건 중 개선 n건" 으로 병기한다.

## A8-4. 판정 규칙 (판정 대상 변형 6개에만 적용; 관찰용은 수치만 보고하고 판정 라벨을 붙이지 않는다)
비교 대상은 V0(거울 기준선; 동치 게이트 통과가 전제). 통계는 verify.md V6 과 같이 기록 단위 cluster bootstrap, B=2000, 시드 317.
- (a) **MAE**: 68기록 풀링 MAE 의 쌍체 차이(변형−V0)를 같은 부트스트랩 재표본으로 계산한 95% CI(percentile)의 상한이 0 미만이거나, 변형 MAE 의 독립 95% CI 와 V0 의 95% CI 가 겹치지 않으면서 변형이 낮을 것. (쌍체 CI 가 0 을 제외하는 경우만으로도 통과로 본다.)
- (b) **coverage**: 풀링 coverage 의 감소 ≤ 5%p (분모=참값이 정의된 창, null 창 유지). 또한 BIDMC·MARSH 각각에서도 감소 ≤ 5%p.
- (c) **층 비악화**: 참값 층 <6, 6–12, 12–20, >20 각각을 데이터셋별로 평가. 기록 수 n_rec < 10 인 (데이터셋, 층) 칸은 **해석불가**로 표기하고 이 조건에서 제외(다른 데이터셋의 같은 층으로 판단). n_rec ≥ 10 인 칸은 MAE 점추정 Δ(변형−V0) ≤ 0 이어야 한다(> 0 이면 악화). 판정에 쓸 수 있는 칸이 하나도 없는 층은 "층 판정 불가"로 표기하되 다른 층 조건은 그대로 적용한다.
- (d) 보조(통과 조건 아님, 항상 병기): MAE_pen(null 창 12회/분 패널티)의 쌍체 차이 CI. (a)·(b)·(c) 를 모두 만족해도 MAE_pen 쌍체 CI 의 하한이 0 초과(= 패널티 포함 시 유의하게 악화)이면 **"개선 아님 (MAE_pen 악화)"** 로 기록한다.
- 라벨: 모두 만족 → **개선**, 하나라도 미달 → **개선 아님**(미달 항목 병기). 개선이라도 홀드아웃 확인 전 "코어 반영 후보"일 뿐이다.
- null 을 빼서 MAE 만 낮추는 것 방지: (b)·(d) 가 이를 막는다.

## A8-5. 보고 지표 (기준선 baseline-c0.md 와 동일)
변형 × 데이터셋(BIDMC/MARSH) × 층(전체,<6,6–12,12–20,>20): 기록 n·창 n, coverage, MAE, 중앙AE, bias, LoA, p95, MAE_pen (+CI), 첫 유효값 지연(중앙/최소/최대), 1초 점프>4회/분 비율. 변형 vs V0 쌍체 차이 CI(MAE, MAE_pen, coverage). 층별 n 경고 규칙은 verify.md V6 과 같다(n_rec<3 표본 부족, <10 CI 넓음).
