# [SDD-199] 루시 감정·상황 인식 강화 — 감정 톤·강도 분류 → 맞춤 공감

## Goal
루시가 내담자 메시지의 감정 톤(슬픔·불안·분노·피로·외로움·기쁨)과 강도(약·중·강)를 감지해 프롬프트에 전달, 공감 정확도를 높인다(투표 2위 A4).

## Context
- 현재 루시는 LLM이 자연어로 감정을 이해하지만, 명시적 감정 신호가 없어 공감이 들쭉날쭉함
- 위험 신호(자해 등)는 agent_guard 로 감지하지만, 일상적 감정 톤(피곤함·외로움 등)은 별도 분류 없음
- SDD-198 기억(emotion_trend)과 시너지 — 감정 추이를 구조화 기억에 축적

## Scope

### ✅ In-scope
- `agent_emotion.py` — 키워드 기반 감정 분류(6종 + 중립) + 강도(약·중·강)
- 루시 응답 시 최근 내담자 메시지의 감정 신호를 프롬프트에 전달
- 감정 신호를 프롬프트 "■ 현재 감정" 형태로 직렬화

### ❌ Out-of-scope
- 별도 감정 분류 LLM 호출(비용·지연 증가)
- 감정 기반 자동 개입(위험 신호 판정은 기존 agent_guard 유지)
- 감정 다이어리 UI

## Acceptance Criteria
- [ ] 감정 6종 + 강도가 키워드로 감지됨
- [ ] 매칭 없으면 neutral(강도 없음)
- [ ] 루시 응답 프롬프트에 감정 신호가 포함됨
- [ ] 감정 신호는 [허용 자료] 원칙 안에서만 사용(진단·점수 금지 유지)
- [ ] `pytest` 관련 테스트 통과

## Dependencies
- SDD-188/191(체크인), SDD-193(감정 대화), SDD-198(구조화 기억)

## Risks
- 키워드 매칭 오탐(예: "화"가 "화요일"에 매칭) → 단어 경계·구문 주의
- 감정 신호가 과도한 지시가 되어 대화를 막지 않게 — 가이드 수준으로만
