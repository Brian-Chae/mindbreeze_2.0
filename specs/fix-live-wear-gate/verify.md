# verify — 실기기 체크리스트 (구현 전 불변식 + 실기기)

## A. 착용하지 않은 밴드(책상 위)로 확인 — 불변식
- [ ] BLE 연결이 유지되고 끊겨도 자동 재연결된다 (착용 여부와 무관)
- [ ] 세션 참여 상태가 유지되고 상담사/호스트 화면에 밴드 "연결됨"으로 표시된다
- [ ] 원시 EEG/PPG/ACC 청크가 계속 업로드된다 (업로드 현황 카운트가 시간에 따라 증가)
- [ ] live metric 배치가 1초 창 단위로 계속 전송된다 (서버에 창이 쌓임; PPG 지표만 null, 사유 `no_pulse` 또는 `not_worn`)
- [ ] BLE 끊김 시 gap 이벤트가 기록된다
- [ ] 시리얼 번호가 정상 표시된다
- [ ] 책상 잡음(DC 높음·맥박 없음)에서 BPM·RMSSD·SDNN·호흡이 값 대신 비어 보인다 (예전엔 65~70 근방 값이 나옴)

## B. 착용 1개로 확인
- [ ] 착용 후 약 10~15초 뒤 BPM·HRV·호흡 정상 출력
- [ ] 벗기 → 3초 뒤 지표 비움(not_worn) → 다시 착용 → 약 10~15초 뒤 회복
- [ ] 약한 맥박(이마 접촉이 느슨할 때) 간헐 비움이 과하지 않은지 (교류 SD 임계 6 근처)

## C. 앱 재빌드 필요
- 코어(measurement-core) 변경 → 웹 WASM 재생성(`scripts/build-all.sh`), iOS xcframework, Android .so 재빌드·재배포 필요. 이번 작업에서 빌드하지 않음.
- 서버 변경 없음.
