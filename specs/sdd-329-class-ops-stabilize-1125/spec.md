## 범위 (4건, 서버만 수정 — 스토어 앱 구버전 하위호환)

- B. 승인 상태 역행 차단(P0): 리포트 생성 저장 시 DB 최신 승인 상태 재확인(행 잠금), 같은 리포트 동시 생성 방지, 상태 변경 로그. 운영 기존 1건 복구는 범위 밖.
