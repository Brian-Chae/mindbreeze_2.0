# SDD-268 — 회원 업로드 안내를 연결 아이콘 토글로 전환

- 상태: Stage ① Spec
- 브랜치: `sdd/268-upload-notice-toggle`
- 작성일: 2026-11-01

## 배경·결정 (대표 11/1)
회원 클래스 화면 상단에 상시 노출되던 "데이터 업로드 중 · …" 안내(`UploadProgressNotice`)는 필요 없다.
기본값은 **숨김**. 오른쪽 위 초록 연결 상태 아이콘(`mp-conn`)을 누르면 나타나고 다시 누르면 사라진다.
**이상이 있으면 자동으로 나타난다.**

## 요구
1. 기본: 안내 숨김(측정 중·종료 후·업로드 중 모두).
2. 연결 아이콘 탭 → 안내 표시, 다시 탭 → 숨김(토글). 아이콘은 버튼(키보드 접근, `aria-expanded`).
3. 이상 = 업로드 현황 `kind === 'needs_review'`(거절·격리 건 있음). 이때는 토글과 무관하게 표시한다.
4. 안내 문구는 내부 용어를 쓰지 않는다: feature→"분석 데이터", 원시→"측정 기록 파일"(코치 화면과 동일 기준). '완료' 단어 금지 규칙은 이 회원 안내에 한해 기존 문구 "업로드 완료"를 "모두 도착했어요"로 바꾼다.
5. 서버·네이티브 변경 없음. 웹(앱 번들) 변경만.

## 비범위
연결 아이콘 자체의 연결 상태 판정, 코치 화면.
