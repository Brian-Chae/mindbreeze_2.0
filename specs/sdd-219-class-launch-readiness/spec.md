## 3. 범위

### 3.1 상담 비공개 (P8-01)

원칙: **프론트 진입점만 닫고, 서버·API·DB·상담 기능 코드는 그대로 둔다**(삭제·마이그레이션·서버 차단 없음). 출시 후 Phase 6·7 개발에서 재활용한다.
플래그는 **환경변수** `VITE_COUNSELING_ENABLED`(기본 false, 빌드 시 주입)로 일괄 제어한다. 재공개 = 값 변경 후 재배포.

| 진입점 | 현재 위치 | 처리 |
|---|---|---|
| 상담사/기관관리자 사이드바 `상담` | `SidebarNav.tsx:95,106` | 플래그 off 시 항목 제거 |
| 회원 사이드바 `내 상담` | `SidebarNav.tsx:118` | 제거 |
| 모바일 하단 탭 | `BottomTabBar.tsx:38` | 제거(탭 개수·레이아웃 재조정) |
| 직접 URL | `App.tsx:182-183,221-224` `/counseling*`, `/app/counseling*` | 클래스 홈으로 리다이렉트 |
| 세션 생성 유형 | 편성/즉시 마법사의 임상·최면 유형 | 선택지에서 제외(프론트만. 서버 거부는 하지 않음) |
| 알림·딥링크 | `dashboard-navigation.ts`(상담 세션 경로) 등 | 상담 경로 진입 시 안전한 대체 이동 |
| 회원 홈 `내 상담` 영역 | `member-structure-home-page.tsx:40-41` | 영역 전체 비노출(조회 호출도 생략) |
| 레거시 세션 경로 해석 | `legacy-session-path.ts:11` | 상담 세션이면 클래스 홈으로 대체 이동 |
| 경로 계산 보조 | `navigation.ts:5`, `notifications.ts:168`, `read-state.tsx:23` | 상담 경로 반환 시 대체 이동 |
| 홈 통계·목록 | `area=counseling` 행 | 클래스 화면에 상담 행이 섞이지 않도록 확인 |
| 문구 | 사이드바 "상담사 전용" 등 | 클래스 출시 관점으로 점검 |

**건드리지 않는 것**: 상담 테이블, 읽기·쓰기 API, 기존 상담 세션 데이터, 입장 코드 경로(이미 있는 세션의 입장은 막지 않음).
**잔존 경로(허용)**: API 직접 호출은 서버가 막지 않는다. 일반 사용자 화면에서는 진입 경로가 없으므로 출시 위험으로 보지 않으며, 점검 문서에 명시한다.
