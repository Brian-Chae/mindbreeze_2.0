# SDD-258 — 기관관리자 추가(초대) 기능

- 상태: Stage ① Spec
- 브랜치: `sdd/258-org-admin-invite`
- 작성일: 2026-10-30

## 1. 배경·목적
- 구성원 화면에는 코치(상담사) 초대만 있어, 기관관리자를 추가하려면 플랫폼 관리자에게 의존해야 한다.
- 기관관리자가 같은 기관의 다른 기관관리자를 직접 초대할 수 있게 한다.

## 2. 범위
1. 구성원(상담사 관리) 화면에 **기관관리자 초대** 버튼·팝업 추가 (이름+이메일).
2. 이메일로 초대 → 수락 시 해당 기관 `org_admin` 멤버십 부여.
   - 신규 이메일: pending 계정(role=org_admin) + 비밀번호 설정 링크 → 설정 시 계정 활성 + 멤버십 active.
   - 기존 계정(상담사/기관관리자): 해당 기관 `org_admin` 멤버십(invited) 추가 + 소속 초대 수락 링크 → 수락 시 active.
3. 초대 재발송: 기관관리자 초대도 기존 재발송 경로 사용.
4. 권한: 해당 기관의 active org_admin 만 초대 가능. 타 기관 대상 불가(403).
5. 기관관리자 비활성화(정지): 자기 자신 불가, 기관에 다른 활성 기관관리자가 남아 있어야 한다(최소 1명 가드, 409).
6. 목록 역할 필터(기존)에 초대 대기 기관관리자도 표시되도록 응답 `role` 을 멤버십 역할 기준으로 반환.

## 3. 비범위
- 메일 실제 발송(코드상 템플릿만, 테스트는 목), 코치 용어 치환(SDD-257), 기관관리자 역할 변경 UI.

## 4. 결정
- 신규 엔드포인트 없이 `POST /org/{org_id}/counselors/invite` 에 `role`(`counselor`|`org_admin`, 기본 `counselor`) 추가 — 하위호환.
- 토큰: 신규 계정=기존 `org_admin_invite`, 기존 계정=기존 `membership_invite` 재사용. 수락 화면 변경 없음.
- 소속 초대 메일은 `role=org_admin` 일 때만 문구 분기(기존 호출 시그니처 유지).
