# SDD-224 — 클래스 실시간 지연·지표 표시 수정

- 상태: Stage ③ Verify 작성 완료 → 구현

- 작성일: 2026-10-20
- 승인: Brian 2026-10-20 (진행 방식 승인, 표준 모델은 하루밴드 데이터로 복구)

## 배경 (테스터 피드백 7건, 2026-10-20 클래스 진행)

1. 손들기가 상담사에게 늦게 전달됨
2. 상담사 본인 영상이 거의 안 보이고 간헐적으로 나타남(회원 쪽 상담사 영상은 양호)
3. 상담사 화면에서 회원 상세를 열면 데이터가 안 보임(회원 본인 화면은 6지표 정상)
4. 회원 '내 상태' 선택이 상담사에게 매우 늦게 전달됨
5. 지표 값이 전반적으로 부정확함(표준 데이터 적용 여부)
6. 상담사 화면의 일부 지표 숫자가 소수점 여러 자리로 크게 카드 밖으로 넘침
7. 클래스 만들기의 참여자(회원) 목록 영역이 작아서 추가 초대가 어려움

## 원인 (진단 확정)

- **A. raw EEG 업로드 422 폭주**: FE stream_id `eeg:{session}:{participant}`(콜론)를 BE `_STREAM_ID_RE`(`[A-Za-z0-9._-]`, 009f6bee·10/6)가 거부함. 실패 청크가 4초마다 재시도되어 20분에 10,807건이 쌓였고, 단일 uvicorn(2코어)을 점유함. 10/6 이후 raw EEG 저장 0건.
- **B. 브로드캐스트마다 전원 권한 재검사**: `_refresh_instructor_rooms` 가 eeg_feature·집계·신호 등 모든 방송 직전에 세션 접속 소켓 전원을 DB로 재검증함. 참가자가 N명이면 초당 O(N²) 조회.
- A+B로 WS 이벤트(손들기 speaking_changed, class:signal, eeg_feature)가 지연되어 1·3·4번이 발생. 상세 시트는 10초 신선도 기준이라 지연되면 값이 사라짐(3번).
- **C. 표준 모델 부재(5번)**: dev DB `normalization_models` 0건이라 코호트 상수로만 점수화됨. **운영 조치로 하루밴드 데이터(기준측정 6·모델 11, 활성 v7) 복구 완료(2026-10-20)**. 코드 변경 없음.
- **D. 숫자 미반올림(6번)**: BPM·호흡·HRV 서버 float 가 그대로 링에 표시됨.
- **E. 목록 높이 고정(7번)**: `class-scheduling.css` 의 `max-height:640px` 미디어쿼리가 회원 목록을 220px 로 고정함.
- **F. 상담사 셀프뷰(2번)**: 과부하 영향에 더해, 로컬 트랙 attach/detach 반복 또는 녹화용 getUserMedia 와 LiveKit 카메라 경합이 의심됨(구현 중 재현해 확정).

## 범위

- BE: stream_id 허용 문자에 `:` 추가(경로 이탈 문자 `/`·`..` 차단 유지), 권한 재검사 주기 제한(세션별 throttle. 세션 상태·참여자 변경 방송은 즉시).
- FE: 재시도해도 성공할 수 없는 4xx(400/403/404/409/413/422)는 즉시 dead-letter, 상담사 지표 반올림·넘침 방지, 회원 목록 높이, 셀프뷰 안정화.

## 비범위

- 표준 모델 산출 로직 변경, LiveKit 서버 설정, EC2 사이징.

## 완료 기준

- dev 로그에서 `eeg-raw/presign` 422 가 0건이고, 정상 200과 ack 200이 발생.
- 손들기·내 상태가 상담사 화면에 1~2초 안에 반영됨(수동 확인).
- 상담사 지표 숫자는 정수로만 표시되고 카드 밖으로 넘치지 않음.
- 클래스 만들기 회원 목록이 낮은 창에서도 충분히 보이고 스크롤 가능.
