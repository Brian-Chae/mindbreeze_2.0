# SDD-066 구현 계획

- 모달 스크롤 영역 밖에 safe-area를 반영한 하단 액션 호스트를 두고 공용 뷰의 기존 승인/PDF 액션을 portal로 배치한다.
- 모달의 목록/닫기 액션 전달을 제거한다. 독립 상세 페이지의 목록 이동은 유지한다.
- 본문 DOM과 현재 스타일을 동일 출처 인쇄 iframe에 복제하고 UI 액션/오류/재발송 영역은 제외한다. 폰트와 이미지 준비 후 브라우저 인쇄를 열어 PDF 저장을 지원한다.
- 기존 서사 인쇄 스타일을 재사용하고 Tailwind print 유틸리티로 긴 본문 분할 및 overflow를 보정한다.
- 브라우저 회귀 검증과 프로덕션 빌드 후 summary.md에 결과를 기록한다.

## 수정 구현
기존 플로팅/PDF 변경을 보존한다. 승인 메일 큐 제거 회귀 테스트를 먼저 실패시키고 approve_report에서 큐 부작용만 제거한다. completed 상태에서만 발송 폼을 표시하고 승인/발송 문구를 분리한다. 자동 승인은 기존 approve_report 재사용을 유지한다.
