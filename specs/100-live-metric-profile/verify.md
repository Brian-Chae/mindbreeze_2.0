# 구현 전 검증 항목

2026-10-03 구현 전 작성. 사용자의 구체적인 필드·우선순위·화면·검증 명세 및 구현 요청을 실행 기준으로 삼는다.

- 회원 프로필의 성별·생년월일·설문이 API로 전달된다.
- 참가자 성별·생년월일이 프로필보다 우선하며, 프로필 없는 회원은 null/null/[]이다.
- 게스트는 입력한 성별·생년월일만 전달하고 concerns는 항상 []이다.
- 회원 프로필 조회는 참가자별 쿼리가 아닌 일괄 조회다.
- 생년월일은 ISO 날짜로 직렬화된다.
- 카드·테이블·상세에서 성별과 만 나이를 표시하고, 생일 전날/당일을 구분한다.
- 누락·잘못된 날짜·미래 날짜를 나이로 표시하지 않는다. 없는 항목의 구분점도 생략한다.
- 게스트 및 빈 설문의 섹션은 표시하지 않는다.
- 관련 백엔드/프론트 테스트 및 npm run build가 성공한다.
