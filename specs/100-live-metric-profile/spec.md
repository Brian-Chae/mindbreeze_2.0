# SDD-100 — 라이브 참가자 프로필 계약 확장

사용자가 지정한 계약과 구현·검증 요청을 기준으로 기존 호스트 화면에 실제 프로필을 연결한다.
SessionLiveMetric에 gender, birth_date, concerns를 추가한다. 성별·생년월일은 참가자 값을 우선하고 회원 프로필을 보완값으로 쓴다. 설문은 회원 프로필에서만 제공한다.
카드·테이블·상세에 한국어 성별과 오늘 기준 만 나이를 표시한다. 없는 정보와 빈 설문 섹션은 생략한다.

범위: 기존 미커밋 호스트 화면 작업을 보존하며 계약·표시·회귀 테스트만 확장한다.
