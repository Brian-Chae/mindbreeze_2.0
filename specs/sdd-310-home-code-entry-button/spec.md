# SDD-310 — 홈 코드 입장 버튼 상단 고정 제거 및 높이 균형 개선

- 상태: Stage ① Spec
- 브랜치: `sdd/310-home-code-entry-button`
- 작성일: 2026-11-05

## 배경 (대표 지시 11/5)
홈 최상단 '코드로 바로 입장' 버튼이 다른 버튼보다 위아래가 좁아 보이고(44px vs 히어로 입장하기 48px), 작은 폰에서는 헤더 한 줄(전체 폭)을 차지해 화면을 많이 쓴다.

## 요구
1. 모바일(≤767px)에서 헤더 슬롯이 아니라 본문 흐름(히어로 카드 아래)에 둔다. sticky/fixed 금지.
2. 본문 버튼 높이 48px, 카드와 같은 폭·radius(pill)·간격(24px).
3. 위계: 히어로 `입장하기`=주(채움), `코드로 바로 입장`=보조(외곽선). 숨기지 않는다.
4. 데스크톱(≥768px) 헤더 우측 배치 유지(회귀 금지). 홈 구조/레거시/내 클래스 3곳 일관.
5. 문구 '코드로 바로 입장' 유지, 금지 문구 0건.
