# SDD-207 — E2E 루프 4단계 (야간 탐색 + 회귀 시나리오 자동 생성)
## 목적
정해진 시나리오 밖의 문제를 밤새 찾고, 발견한 문제를 영구 회귀 시나리오로 남겨 같은 문제가 다시 생기면 즉시 잡는다.
## 흐름
야간 탐색(역할별 화면 순회, 읽기 전용) → 문제 분류·중복 제거 → 상위 3건을 회귀 시나리오로 등록 → 다음 배포 검증에서 실패 → 3단계 자동 수정 → 통과하면 영구 회귀 목록에 남음
## 탐색 점검 항목
화면 오류(JS 오류), 서버 오류 응답(4xx/5xx), 깨진 이미지, 'undefined/null/NaN' 노출, 카드 제목 중복, 모바일 가로 넘침
## 안전
읽기 전용(링크 이동만, 버튼 클릭·제출 없음), E2E 계정만 사용, 하룻밤 신규 등록 최대 3건, 일시정지 중에는 등록 안 함, 운영 불가침
## 비범위
데이터 생성 탐색, 메일 시나리오, 운영 서버 탐색
