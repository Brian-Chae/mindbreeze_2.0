## 현재 단계에서 확인 가능한 것

정적 코드 근거는 spec.md에 기록. 디자인은 가상 이름·기관·날짜와 로컬 상태만 사용한다. mockup.png는 3보드 시안이며 실제 회원 데이터나 서버 연결을 사용하지 않는다. 시안 측정 결과는 `designs/member-counselor-management/qa.json`에 저장한다.

시안 검증: Chrome headless에서 A/B/C 각각 390×844, 가로 넘침 0, 버튼 높이 최소 44/44/48px, JS 오류 0. 로컬 추가 시뮬레이션 1행 반영 확인. 합성 화면 육안 확인 완료. 시스템 한글 폰트 사용, 앱 번들 폰트 로딩 검증은 아님.
