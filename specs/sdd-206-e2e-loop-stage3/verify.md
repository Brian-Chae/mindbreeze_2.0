# Verify (구현 전 QA 체크리스트)
- [ ] 코드 원인 실패 → 자동 수정·반영·재검증 통과, 보고 수신
- [ ] 환경 의심 실패(서버 5xx/로그인 API) → 수정 시도 없이 알림만
- [ ] 허용 범위 밖 파일 변경 시 push 차단
- [ ] 수정 후 새 실패 → revert push + 일시정지 + 🔴 알림 (모의 검증)
- [ ] 일시정지 파일 존재 시 수정 시도 없음
- [ ] 같은 실패 3번째는 시도하지 않음
- [ ] 운영(main) 브랜치 변경 0, 비밀값 출력 0
- [ ] 이미 보고된 실행은 중복 처리 안 함(멱등)
