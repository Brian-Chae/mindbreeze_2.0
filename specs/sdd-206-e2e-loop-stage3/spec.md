# SDD-206 — E2E 루프 3단계 (실패 → 자동 수정 → 재검증 → 반영/되돌림)
## 목적
스모크·여정이 실패하면 사람 개입 없이 원인 수정 → dev 반영 → 재검증까지 돌리고, 결과를 텔레그램으로 보고한다.
## 결정 승계
dev 전부 자동 반영(운영 main 제외). 스모크 실패 시 자동 반영 중단 + 알림.
## 범위
- 실패 분류: 코드 원인(자동 수정 대상) / 환경·데이터 의심(알림만: 서버 5xx, 서버 상태, 로그인 API 오류)
- 수정 범위 제한: 화면·서버 코드와 E2E 시나리오만. DB 마이그레이션·배포 설정·비밀값 변경 금지
- 같은 실패 최대 2회 시도. 수정 후 새 실패가 생기면 자동 되돌림 + 자동 반영 중단(일시정지 파일)
- 일시정지 중에는 수정·반영을 하지 않고 알림만
## 비범위
운영 반영, 4단계(야간 탐색, 회귀 시나리오 자동 생성)
