# SDD-064 — 리포트 목록 팝업 모달 + 재발송 섹션 표시

> 리포트 목록에서 아이템/보기 버튼 클릭 시 팝업 모달로 리포트를 확인하게 한다.
> 재발송 섹션은 client 리포트에서만 표시되는 현재 설계를 그대로 유지한다(정상 동작).

## 1. 현황
- 리포트 목록(ReportListPage)에서 아이템/보기 버튼이 `/reports/{id}`로 페이지 이동.
- 사용자 요구: 클릭 시 팝업 모달로 리포트 확인 (페이지 이동 대신).

## 2. 구현 범위 (FE cursor)
- ReportListPage에서 아이템 행/보기 버튼 클릭 → 팝업 모달 열기
- 모달 안에 리포트 상세 본문 렌더링 (ReportDetailPage의 내용 — 커버/서사/EEG/재발송)
- 리포트 데이터 로드(getReport) 후 모달에 표시
- 모달 닫기/닫기 버튼, ESC, 오버레이 클릭

## 3. 주의
- ReportDetailPage 본문을 모달로 재사용 (컴포넌트 추출 또는 공용화)
- 재발송 섹션은 client 리포트에서만 표시 (기존 설계 유지)
- 반응형 (모바일/태블릿/웹)
- 기존 "/reports/{id}" 라우트는 유지 (직접 URL 접근 대비)

## 4. 완료 기준
- 아이템/보기 버튼 클릭 → 팝업 모달로 리포트 표시
- FE build 0 error
