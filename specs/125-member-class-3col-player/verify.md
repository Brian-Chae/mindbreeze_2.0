# [SDD-125] — Verification (Pre-Implementation)

## Test Scenarios

### TS1: 3열 레이아웃 + 리사이즈
1. 데스크톱(≥1024)에서 회원 클래스 뷰 진입.
2. 좌(460px)·중(flex)·우(420px) 3열 확인. 좌우 핸들 드래그 시 폭 변경, min/max clamp(좌 250~460, 우 220~420).
- **Expected:** 3열 렌더, 기본 폭 = 최대폭, 드래그로 좁힘 가능(더 넓힘 불가), 가로 오버플로 없음.

### TS2: 지표 카드 6종 정본 스타일
1. "나의 상태" 영역에서 MIND 3(집중·이완·감정안정) + BODY 3(BPM·호흡·HRV) 확인.
- **Expected:** 링 게이지(62px) 안 숫자(13px)+단위, 라벤더 틱 마커(그룹 평균), 캡션 "그룹 평균 N"+"추이 대기", 범례 3항목. 델타("±N") 문구 없음.

### TS3: raw — ACC 제거 + CHIP + PPG IR/RED
1. 밴드 연결(또는 mock) 후 우측 raw 확인.
- **Expected:** EEG 2ch(Fp1/Fp2) + PPG(IR·RED 두 색 overlap)만 표시. ACC 없음. EEG 위 CHIP(집중·이완·감정안정), PPG 위 CHIP(BPM·HRV·호흡).

### TS4: 캔버스 자동 리사이즈
1. 우측 패널 폭을 드래그로 변경.
- **Expected:** EEG/PPG 캔버스가 새 폭에 맞춰 재할당(ResizeObserver), 잘림·늘어짐 없음.

### TS5: 중앙 MAIN(영상+채팅)
1. 중앙 컬럼에 상담사 라이브 + 함께한 시간 + 채팅 배치 확인.
- **Expected:** 영상 위, 채팅 아래. 채팅 topbar 잔재 없음(중앙으로 이동).

### TS6: 클래스 정보·프로필 카드
1. 좌측 상단 클래스 정보(상담사·참여자·밴드착용·그룹집중) + 프로필(이름·성별나이·밴드상태) 확인.
- **Expected:** 데이터 있으면 표기, 없으면 "—"/최소 표기(크래시 없음).

### TS7: 모바일 단일 스택
1. 뷰포트 ≤1024.
- **Expected:** 3열 → 단일 스택(영상→채팅→클래스정보→프로필→지표→디바이스). 핸들 숨김. 스크롤 정상.

### TS8: 회귀 없음
1. `npm run build` + `npx tsc --noEmit` + 기존 회원 뷰 테스트 실행.
- **Expected:** 0 errors, 테스트 통과.

## Edge Cases
- [ ] 밴드 미연결 → CHIP "—", raw 빈 캔버스(크래시 없음), 디바이스 스트립 "미연결".
- [ ] LeadOff(접촉 불량) → 지표·CHIP null 처리, 스트립 접촉 경고.
- [ ] 그룹 평균 표본 부족 → 틱 마커 숨김, 캡션 "표본 부족".
- [ ] 게스트(비로그인) → 프로필은 이름만, 클래스 정보는 by-code(host_name·participant_count) 폴백.
- [ ] 몸 지표 null(BPM/호흡/HRV) → "—" 유지(0 치환 금지).
- [ ] 몰입(화면 끄기) 오버레이가 3열 전체를 덮음.

## Security Review
- [ ] 그룹 평균·CHIP은 본인값 + 익명 그룹 평균만 노출(타 참가자 개인 raw 미노출).
- [ ] 클래스 정보(상담사명·참여자수)는 본인이 접근 가능한 세션 스코프 내에서만 조회.
- [ ] 프로필(gender/birth_date)은 `/auth/clients/me/profile` 본인 조회만 사용(타인 프로필 미호출).
