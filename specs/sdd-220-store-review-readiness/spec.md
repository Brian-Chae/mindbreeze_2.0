### 3.2 AI 기능 첫 출시 제외 (D9)

원칙: **SDD-219 상담 비공개와 같은 방식** — 코드·DB·테이블은 유지하고 플래그로 닫는다. 재공개 = 값 변경 후 재배포. 단 비용은 서버에서 발생하므로 **프론트 숨김만으로 끝내지 않고 서버에서도 호출 자체를 막는다**.

플래그
- 프론트 `VITE_AI_ENABLED`(기본 false) — `lib/feature-flags.ts` 에 `isAiEnabled()` 추가
- 백엔드 `AI_FEATURES_ENABLED`(기본 false) — `config.py`

### 3.3 Sign in with Apple (D1)

- 프론트: 로그인·가입 화면에 Apple 버튼(iOS 앱·웹 모두). 기존 `@capgo/capacitor-social-login` 의 Apple 공급자 사용 여부를 plan 에서 확정.
- 백엔드: `POST /auth/apple` — id_token 서명(Apple JWKS)·`iss`·`aud`(번들 ID / 서비스 ID)·`exp`·`nonce` 검증. 신규 사용자는 Google 가입과 같은 약관 3종 + 연령(§3.5) 동의 경로.
- '이메일 가리기'(privaterelay) 이메일 그대로 계정 생성. Apple 은 이름을 최초 1회만 주므로 첫 응답에서 저장.
- 계정 작업(사용자/Aside): App ID 에 Sign in with Apple capability, 웹용 Services ID·Return URL, 키(.p8).

### 3.4 채팅 신고 → 즉시 차단 (D3)

- 메시지 메뉴와 상대 프로필에 "신고" 버튼 1개. 사유 선택(선택 입력).
- 신고 즉시: 신고자 ↔ 대상자 **상호 차단** 기록 → 이후 신고자에게 대상자 메시지 비노출, 1:1 방은 메시지 전송 불가, 대상자를 초대 검색에서 제외.
- 신고 건은 `chat_reports` 에 적재하고 운영 메일(D6 이메일)로 알림. 관리자 처리 화면은 범위 밖(DB 조회로 대응).
- 이용약관에 금지행위·제재 조항(§3.7).
- 차단 해제 UI는 첫 출시 범위 밖(설정 > 차단 목록은 후속).

### 3.10 심사관용 체험(mock-up) 모드 (D11, Apple 2.1)

심사관은 LINK BAND 가 없으므로 밴드 의존 기능을 **기기 없이 끝까지** 볼 수 있어야 한다.

- 현재: `/playground`(`pages/playground/PlaygroundPage.tsx`)에 개발용 `useMock`·`forceMock` 토글이 있고, 진행자·관리자 내비게이션(`SidebarNav.tsx:104,136`, `BottomTabBar.tsx:55`)에만 노출. 보정·정규화·디버그 패널(`DebugPanel`·`CalibrationPanel`·`NormalizationPanel`)이 그대로 보인다.
- 처리
  - "체험 모드(예시 데이터)"를 사용자 기능으로 승격: 밴드 미연결 상태에서 버튼 하나로 시작 → 시뮬레이션 신호로 파형·스펙트럼·지표·명상 시뮬레이터가 실시간으로 움직인다.
  - 화면 상단에 **"예시 데이터입니다 · 실제 측정값이 아닙니다"** 띠 상시 표시(1.4.1 오인 방지 겸용).
  - prod 빌드에서는 디버그·보정·정규화 등 개발자 패널 숨김(사용자용 비주얼라이저만).
  - 회원(client) 데모 계정으로도 볼 수 있게 회원 쪽 밴드 연결 화면(또는 프로필)에 "체험 모드" 진입점 추가.
  - 클래스·리포트 화면은 심사 데모 시드(§3.9)의 저장된 뇌파 데이터로 확인 가능하게 한다.

### 3.13 탈퇴하기 — 앱 내 계정 삭제 (D2·D14, Apple 5.1.1(v)·Play 계정 삭제 정책)

- 위치: 설정 > 계정 > **탈퇴하기**(진행자·회원·기관 관리자 모든 역할, iOS·Android·웹 공통). 찾기 쉬운 위치(설정 첫 화면에서 2탭 이내).
- 흐름: 안내(삭제되는 데이터·되돌릴 수 없음·법정 보관 항목) → 본인 재확인(비밀번호, 소셜 계정은 재로그인) → 최종 확인 → 즉시 로그아웃.
- 서버 `DELETE /users/me`
  - 즉시: 로그인 차단(`users.status` 비활성), 모든 토큰·푸시 토큰 폐기, 채팅·클래스 명단에서 "탈퇴한 사용자"로 표시.
  - 데이터: **전체 삭제**(D2) — 프로필, 뇌파 원본(S3)·지표, 리포트, 녹음·녹화 원본, 채팅 메시지, 동의 기록(법정 보관분 제외). 보관기간 스위프(§3.7, D7)로 **탈퇴 30일 후 영구 삭제**(E5, 처리방침·탈퇴 안내 화면에 명시. 유예 중 복구 기능은 두지 않음). 법령상 보관 의무 항목은 분리 보관 후 만료 시 삭제.
  - **Sign in with Apple 사용자는 Apple REST API 로 토큰 폐기(revoke)** — Apple 요구사항.
  - Google 로그인 사용자는 연결 해제 처리.
  - 연구 동의 데이터: 기존 `research_withdrawal_requests` 철회 흐름에 함께 등록(Spark 측 삭제 확인).
- 예외 규칙
  - 기관의 유일한 관리자: 다른 관리자 지정 또는 기관 정리 안내 후 진행(한 사람 탈퇴로 기관 전체 데이터를 지우지 않음).
  - 예정 회차가 있는 진행자: 회차 정리 안내 후 진행.
- 기관이 발급한 계정도 본인이 직접 탈퇴할 수 있다(기관 관리자 승인 불필요).
- Play 요구: 앱 밖 **웹 삭제 요청 페이지**(`/account-deletion`, 로그인 없이 이메일로 요청 접수 → 운영 메일 알림)와 그 URL 을 Play Console 데이터 보안에 등록.
