# SDD-220 스토어 메타데이터 — 검토용 초안

현재 상태: 제출 준비 미완료. 콘솔·운영·실기기 항목은 실행하지 않았으며 아래 미체크 항목은 완료 증거가 필요하다. 비밀번호·토큰·개인 연락처를 이 문서에 쓰지 않는다.

## 공개 설명 초안

- 이름: MIND BREEZE
- 부제: 기관과 함께하는 명상과 활동 기록
- 설명: 여러 기관의 진행자와 회원이 명상 클래스에 참여하고 활동 기록을 확인하는 서비스입니다. LINK BAND 연결은 선택 사항이며, 밴드 없이도 클래스와 기록을 이용할 수 있습니다. 체험 모드에서는 실제 측정값과 구분된 예시 데이터를 살펴볼 수 있습니다. 집중도·이완도·스트레스는 추정 참고 지표입니다.
- 배포 모델(심사 설명): 앱은 무료로 배포됩니다. 기관 도입은 앱 밖 기관 계약으로 진행됩니다. 앱 안에는 판매·외부 결제 링크가 없습니다. 특정 기관 전용 앱이 아닌 다기관 B2B 서비스입니다.
- 카테고리 제안: 건강 및 피트니스. 명상·활동 기록 중심이라는 이유이며, 실제 콘솔 카테고리와 건강 앱 신고는 담당자가 최종 확인해야 합니다.
- 연령: 만 14세 미만 가입 제한. 스토어 연령 등급은 콘솔 설문으로 별도 확정하며 가입 제한과 동일하다고 가정하지 않습니다.

## 심사 메모 초안

진행자 로그인: [보안 채널에서 전달할 심사 이메일]
회원 로그인: [보안 채널에서 전달할 심사 이메일]
로그인 비밀번호: 보안 채널로 별도 전달(문서·로그 기록 금지).

밴드 없는 경로: 로그인 → 체험 및 밴드 신호 → ‘체험 모드(예시 데이터)’ → 움직이는 파형·스펙트럼·추정 참고 지표·명상 → 체험 종료. 화면에는 ‘예시 데이터입니다 · 실제 측정값이 아닙니다’가 계속 표시되며 이 데이터는 기록으로 저장되지 않습니다.
저장된 예시 리포트: 회원 로그인 → 기록/리포트 목록 → ‘예시 데이터 · 명상 기록’. 클래스와 리포트는 합성 자료입니다. 체험 화면에서 생성된 기록이 아닙니다.

- [ ] 감독자 통합 후 회원 메뉴·체험 경로와 저장된 리포트 열람 확인
- [ ] 진행자·회원 실제 로그인 접근 확인 및 안전한 자격증명 전달
- [ ] 심사 기간 계정·샘플 자료 동결 담당자와 기간 지정
- [ ] 계정이 탈퇴되면 복구하지 않고 새 이메일 계정으로 대체하고 심사 메모 자격증명 갱신
- [ ] LINK BAND 실측 1~2분 영상의 비공개 심사 접근 링크 준비 및 재생 확인
- [ ] 밴드 선택·권한 거부·앱 내 계정 탈퇴 위치 설명을 최종 빌드와 대조

시드 스크립트는 기본 dry-run(접속 0)입니다. `--apply`는 SQLite 메모리 또는 `test_store_review_` 접두 파일의 격리 테스트 DB에만 허용합니다. 운영 실행 방법은 제공하지 않습니다. 운영 자료 준비는 별도 승인·안전성 검토가 필요합니다. 합성 자료 생성은 동의 수집의 증거가 아닙니다.

## 수집 신고 대응 초안

App Privacy / Play Data safety 입력 전 각 항목을 실제 출시 빌드·보관정책·위탁 계약과 대조해야 합니다. 아래는 신고 초안이며 콘솔 입력 완료를 의미하지 않습니다.

- 계정 이메일·이름·사용자 ID·생년월일: 계정 관리·연령 확인·기관 소속 서비스 제공. 계정과 연결됨. 필수/선택 구분·보관 기간은 최종 방침과 대조.
- 음성: 클래스 녹음 선택 시 수집·저장. 진행자/참여자 고지·동의 및 접근 권한 필요. Apple 오디오 데이터 / Google 음성·오디오 파일 항목과 대조.
- 영상·이미지: 클래스 영상·프로필·첨부 선택 시 수집. Apple 사진 또는 비디오 / Google 사진·동영상 항목과 대조.
- EEG·집중도·이완도·스트레스·심박: 밴드 선택 시 수집하는 민감한 생체·건강 관련 데이터로 보수적으로 검토. Apple 건강 / Google 건강 정보 신고 및 건강 앱 선언 대상 여부 확인. 추정 참고 지표 고지 유지.
- 채팅·클래스 기록·리포트: 사용자 콘텐츠 및 서비스 활동 정보. 계정과 연결됨. 차단·탈퇴·30일 삭제 및 혼합 원본 보존 범위와 대조.
- 기기 푸시 토큰: 알림 전달 목적 기기 식별자. 알림 선택·철회·탈퇴 차단과 대조.
- 카메라·마이크·블루투스·알림 권한: 실제 권한 요청 시점·목적 문구·거부 후 대체 동작을 영상·화면으로 확인. 권한 자체와 서버 전송 항목을 구별.
- AWS S3·Resend·FCM·LiveKit: 저장·메일·푸시·실시간 통신의 위탁/공유 분류를 실제 계약·국가·처리 항목으로 확인. 서비스 제공자 예외 적용 여부는 콘솔 정의와 법무 검토로 확정.
- AI 기능 비공개 빌드: 외부 AI 전송 없음은 b 트랙의 네트워크 0건 검증과 운영 설정 확인이 필요. 이 문서만으로 완료 판정 금지.
- 광고·마케팅·데이터 브로커 제공·앱 간 추적: 사용하지 않는 정책을 최종 SDK·네트워크 목록으로 검증 후 ‘해당 없음’ 신고. 근거 없이 ‘수집 안 함’ 일괄 선택 금지.
