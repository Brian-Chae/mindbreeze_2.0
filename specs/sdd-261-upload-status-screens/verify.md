## 구현 착수 시 첫 확인 항목(현재 코드로 확정 불가)

1. 앱 하단 내비/드로어에서 `/settings` 진입 경로와 역할별 노출(`BottomTabBar.tsx`, `MobileDrawer.tsx`).
2. platform_admin 이 현 `RoleGuard`(counselor/org_admin 한정) 라우트를 통과하는지 → 별도 `/admin/upload-status` 라우트 필요 여부.
3. 실DB feature 시작 sequence 분포(0/1)와 legacy NULL 비율.
4. nginx/서버 워커 수 → 프로세스별 1초 TTL 캐시 효과, 2~3초 폴링 로그 볼륨.
5. 읽기 전용 REPEATABLE READ 와 `get_db` 세션 충돌 여부.
6. index.html 캐시 헤더로 현장 브라우저가 신규 번들을 받는지.
7. 앱 번들 포함 확인 방법(동결 11/2 12:00 이전 develop 머지 + 앱 빌드 담당 확인).
