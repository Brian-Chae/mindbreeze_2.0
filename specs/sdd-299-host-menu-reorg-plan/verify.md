# SDD-299 — Verify (구현 전 QA 체크리스트)

> Stage ③. 구현 전에 작성한다. 범위는 "배치만 이동"이며 기능 추가·삭제, 서버·API 변경은 없다.
> 내부 시트 키(`metric`/`chat`/`media`/`tools`)는 유지하고 라벨·제목·시트 내용만 재배치한다.

## V1. 독 라벨
- [ ] 온라인 독 4개 순서·라벨 = 분석 · 채팅 · 미디어 · 설정
- [ ] 오프라인 독 4개 순서·라벨 = 분석 · 채팅 · 녹음 · 설정
- [ ] 화면 어디에도 구 라벨 "지표 기준"(독·시트 제목), "도구"(독·시트 제목) 0건
- [ ] 채팅 안 읽음 뱃지 유지(채팅 시트가 열려 있으면 0)
- [ ] 라벨은 `host-player-case.ts` 한 곳(온라인/오프라인 분기)에서 정의

## V2. 분석 시트 (구 지표 기준 + 구 도구의 표시 방식)
- [ ] 제목 "분석", 부제 "실시간 표시 방식"
- [ ] 보는 지표 6개 선택 + 10초 순환 토글 유지
- [ ] 회원 정렬(입장순·낮은 순·높은 순) 이동 후 동일 동작
- [ ] 손든 회원 우선은 온라인 그룹에서만 표시, 오프라인·1:1 숨김
- [ ] 표로 보기 스위치 이동 후 동일 동작(켜면 표, 타일 사라짐)

## V3. 미디어 / 녹음 시트 (구 설정의 미디어 구역)
- [ ] 온라인: 카메라·마이크 토글, 권한 안내, 녹음 제어, 영상 상태·전후면·무음 영상, 마커
- [ ] 오프라인(제목 "녹음"): 카메라·송출 마이크 토글·전후면 전환 DOM 없음, 녹음 조작·마커 유지
- [ ] 이 시트에는 정원 늘리기가 없다

## V4. 설정 시트 (구 도구 + 정원)
- [ ] 제목 "설정", 첫 구역 = "정원 늘리기"(정원 정보가 있을 때), 제목 옆 온라인 "최대 50명"/오프라인 "최대 100명"
- [ ] 정원 현황(정원·입장·대기)과 CapacityIncreaseForm 로직은 그대로(위치만 이동)
- [ ] 이어서 참여 안내(입장 코드 표시·복사), 회원 초대, 내 밴드, 화면 이동(클래스 화면 나가기)
- [ ] 모든 구역 제목이 같은 형식
- [ ] 상단 status 카드에 정원 늘리기 버튼 없음(HostTopBar)

## V5. 보존
- [ ] 수업 상태·체크인·신호·발언권·필터·대기·회원 상세 진입 유지
- [ ] 녹음 칩 → 미디어/녹음 시트로 직접 연결(`media` 키)
- [ ] 허용 방법 시트(permcam/permmic) 유지
- [ ] 금지 표현(점수·종합점수·좋음·나쁨·완료 단정·보증·100%) 신규 0건
- [ ] 서버·API·props 삭제 없음

- [ ] 갱신: host-settings-dock, class-player-host-view/sheets/container, host-tools-exit, class-flow-host-member-invite (삭제 금지, 이동 후 동일 동작 단언)
- [ ] 신규: 독 라벨 4개(온/오프), 각 시트 계약 기능, 정원 첫 구역·상한 표기, 오프라인 카메라류 숨김, 구 "도구" 라벨 0건
- [ ] `tsc -b` 0 오류
- [ ] 전체 vitest = 기준선(23건/13파일 실패)과 동일, 신규 실패 0
- [ ] 390px/768px 하니스 스크린샷(온라인·오프라인 독 + 설정 시트), 가로 넘침 0
