# SDD-299 재편성 제안

## 확정 구성
대표 결정에 따라 A안을 확정했다. 정렬·표 보기는 분석으로 모으고, 정원 늘리기는 새 설정에 둔다. 온라인 독은 분석·채팅·미디어·설정, 오프라인 독은 분석·채팅·녹음·설정이다. B안과 오프라인 미디어 라벨 대안은 검토 대상에서 제외한다. 과거 파일은 삭제하지 않고 이력으로 보존한다.

분석은 실시간 표시 방식을 뜻하며 신규 분석 결과·리포트 생성 기능을 추가하지 않는다.

## 온라인·오프라인
네 메뉴 순서는 동일하되 세 번째 라벨과 시트 제목은 온라인 ‘미디어’, 오프라인 ‘녹음’으로 확정한다. 오프라인에서는 카메라·송출 마이크 토글·전후면 전환은 표시하지 않는다. 녹음 조작·마커와 채팅은 유지한다. 온라인 그룹의 손 우선 옵션은 오프라인/1:1에서 숨긴다. 오프라인 상한 100, 온라인 상한 50은 현행 계약이다. 밴드 미착용이어도 기록·채팅·정원 조작은 유지한다. 신규 종합 지수나 평가 기능을 만들지 않는다.

## 정원 흐름
설정 첫 카드 제목은 ‘정원 늘리기’다. 제목 옆에 온라인 ‘최대 50명’, 오프라인 ‘최대 100명’을 표시해 입력 전에 상한을 알 수 있게 한다. 같은 카드에서 현재 정원·입장·대기와 새 정원 입력을 이어서 보여 준다. 모든 설정 카드 제목은 같은 15px/600/22px 형식이다. 참여 안내 (입장 코드), 회원 초대, 내 밴드, 화면 이동은 각각 별도 카드로 둔다. 필드가 길어지면 시트 내부 스크롤이며 상단 상태 카드에는 변경 버튼을 추가하지 않는다. 입력은 정수·증원만·입장 인원 이상·방식별 상한을 검사한다. 기관관리자 사유 필수, 상담사에게는 현행처럼 사유 입력을 표시하지 않는다. revision 미확보 시 잠금, 처리 중 중복 제출 차단, 오류는 입력 가까이에 유지한다.

결과는 응답의 정원과 입장 처리 수를 보여 주고 실제 접속 인원을 임의로 올리지 않는다. v3 가정값은 현재 정원 40/입장 40/대기 10, 변경 후 정원 50이다. 화면 안에는 제작 단계 문구를 넣지 않되 이 문서에서 가정값임을 명시한다. 입장 처리 수는 현재 시안에서 임의로 표시하지 않는다. 새 정원만으로 입장 처리 수를 예측해 보장하지 않는다. 최신 값 충돌/권한 없음/통신 실패는 오류별 설명과 재시도 경로를 유지한다. 시트 제목은 고정하고 본문만 스크롤한다. 정원 카드가 화면에서 벗어나면 고정 정원 제출 버튼을 숨겨 참여 안내·내 밴드 조작과 혼동하지 않게 한다.

## 용어와 접근성
- ‘분석 데이터’, ‘측정 기록 파일’, ‘서버에 도착’처럼 대상과 상태를 분리한다. 수치의 가치 판단이나 전송·입장 보장 표현은 쓰지 않는다.
- 기존 코드 복사의 결과 문구는 ‘복사했어요’로 제안. 금지 어휘 목록 자체는 산출물에 재기재하지 않고 검사 결과만 남긴다.
- 독은 실제 앱 토큰을 따른다. 390px 화면 좌우 16px, 독 높이 60px·반경 24px, 항목 반경 18px. 아이콘 24px·2px 스트로크, 라벨 12px, 터치 높이 44px 이상이다. 모바일 안전영역은 하단 추가 여백으로 처리한다.
- 버튼/입력 최소 높이 44px. 선택 상태는 색+테두리+aria-pressed. 시트 제목·닫기 이름·입력 label·오류 aria-describedby·role=alert/status를 제공한다.
- 제품 구현 시 PlayerSheet의 포커스 이동·트랩·Esc·닫은 뒤 복귀를 보존한다. 키보드 표시 시 채팅 입력/제출, 긴 설정 내부 스크롤, 확대 글꼴을 확인한다. 390px PNG는 네이티브 안전영역·키보드 실측이 아니다.

## 확정 사항과 남은 확인
- 확정: A안으로 정렬·표 보기를 분석에 모은다.
- 확정: 오프라인 독·시트 제목은 녹음이다. 라벨 대안 비교는 종료한다.
- 확정: 정원 상한은 제목 옆, 모든 설정 섹션은 같은 제목 형식으로 표시한다.
- 남은 메뉴 구성 결정은 없다. 분석을 신규 분석 결과로 오해하지 않도록 부제 ‘실시간 표시 방식’을 유지한다.

### 남은 기술 검증
인원 통계가 연결된 사람 수인지 참가 목록 길이인지 HostLiveView/Container 계약을 후속 검증에서 확인한다. 이번 UI 재편성으로 집계 의미를 변경하지 않는다. 실제 장치·대기 승격·전송 상태는 이 기획에서 검증하지 않았다.
