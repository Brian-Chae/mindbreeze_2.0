## 문제
지표 선택은 ‘지표 기준’, 표시 방식은 ‘도구’로 나뉘고, ‘설정’에는 미디어와 정원 변경이 함께 있다. 미디어 조절과 클래스 운영을 구분하기 어렵다. 이는 코드 구조에 대한 진단이며 사용성 조사 결과는 아니다.

## 목표
1. 온라인 독은 분석 · 채팅 · 미디어 · 설정, 오프라인 독은 분석 · 채팅 · 녹음 · 설정으로 확정한다.
2. 정원 늘리기는 새 설정(구 도구)에 배치하고, 상단 인원 카드는 읽기 전용으로 유지한다.
3. A안 확정: 지표 선택·정렬·손 우선·표 보기를 분석에 모은다. 기존 조건부 노출·진입 경로는 보존한다.
4. 390px 온라인·오프라인 각 네 시트와 정원 입력·처리·결과·오류를 HTML/PNG로 제시한다.
5. 기존 보라 토큰과 자연 배경을 유지한다. 수치·이름·메시지는 합성 예시다.

## 산출물

- `plan.md`: 확정 A안, 이동 표, 영향·남은 검증 사항
- `design-notes.md`: 시안 경로, 표현·접근성·확인 결과
- `~/.hermes/share/design-1105/299-v3-index.html`, `299-v3-preview.html` 및 PNG. v1/v2는 보관 기록이며 검토 정본은 v3다.

## 비범위
제품 코드, API·DB·권한 계약, 실제 녹음·채팅·장치 제어, 운영 데이터 조회, 신규 분석 기능, 배포를 포함하지 않는다. 이번 단계에서는 verify.md와 summary.md를 작성하지 않는다. 기존 SDD-284/289 문서와 11/4 시안을 보존한다. 커밋·푸시·PR·메일·삭제를 수행하지 않는다.

## 검토 기준
네 메뉴가 온라인·오프라인에 모두 보이고, 정원 동작은 새 설정에서만 찾을 수 있어야 한다. 입력·오류·결과를 시안에서 비교할 수 있어야 한다. 코드 근거와 제안, 합성 동작과 실제 동작을 구분한다.

## 대표 확정 결정과 v3 표현 규칙
- A안: 정렬·표 보기는 분석에 배치한다. 정원 늘리기는 설정 첫 구역이다.
- 오프라인의 세 번째 독과 시트 제목은 녹음으로 확정한다. 미디어/녹음 대안 비교는 검토 대상에서 제외하고 과거 파일만 보존한다.
- 정원 입력 전 상한을 알 수 있도록 정원 늘리기 제목 옆에 온라인 최대 50명 / 오프라인 최대 100명을 표시한다.
- 설정 섹션 제목은 정원 늘리기 / 참여 안내 (입장 코드) / 회원 초대 / 내 밴드 / 화면 이동으로 통일한다. 각 카드에 같은 제목 크기·굵기를 적용한다.
- 화면 안 제작 단계 문구는 현장 용어로 교체한다. 데이터가 가정값이며 실제 서비스와 연결되지 않았다는 사실은 이 문서와 전달 보고에서 명시한다.
- 온라인은 단순한 Video 아이콘, 오프라인은 Mic 아이콘. 같은 Lucide 세트·24px·2px 스트로크를 유지한다.
- 메뉴 구성의 추가 결정 사항은 없다. 구현 승인과 실제 장치/키보드/접속 인원 계약 확인은 별도다.
