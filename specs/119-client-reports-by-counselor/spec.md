# SDD-119 회원 리포트 상담사별 목록

회원 리포트를 counselor_name 기준으로 그룹핑한다. 누락된 이름은 상담사로 표시한다.
제목과 scheduled_at의 날짜·시간을 강조하고 content.summary를 두 줄까지 표시한다. 요약이 없으면 headline을 사용한다.
검색은 제목·headline·요약을 대상으로 하며 기존 현재 페이지 검색·정렬·페이지네이션, 모달, 빈 상태, 재시도를 유지한다.
API 실제·합성 리포트에 nullable counselor_name을 제공하고 목록에서는 상담사 이름을 배치 조회한다.
사용자가 승인 게이트 없이 즉시 구현하도록 명시했다.
