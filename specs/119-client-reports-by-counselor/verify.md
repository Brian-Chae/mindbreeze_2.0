# SDD-119 구현 전 검증 시나리오

구현 전에 작성. 사용자 지시에 따라 승인 대기 생략.

- 같은 상담사의 다른 세션은 동일 테이블에 속한다. 다른 상담사와 null 이름은 별도 그룹이다.
- 데스크톱·모바일 모두 제목, 예약 날짜·시간, 요약을 표시한다. 모바일에는 상담사명도 표시한다.
- 요약 누락 시 headline, 이름 누락 시 상담사, 잘못된 날짜는 -로 표시한다.
- 제목·요약 검색, 최신/오래된/제목 정렬, 페이지네이션과 비동기 응답 취소를 유지한다.
- 상세 모달·빈 상태·재시도를 유지한다.
- API 실제·합성 항목의 counselor_name 일관성, 목록에서 상담사별 N+1 없음.
- 관련 vitest, npm run build, report 관련 pytest 성공 여부 기록.
