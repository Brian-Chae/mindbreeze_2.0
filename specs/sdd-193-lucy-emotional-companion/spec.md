# [SDD-193] 루시 감정 대화 기본 ON — 친근한 친구 톤

## Goal
내담자가 루시에게 말을 걸면 항상 감정 대화(공감 + 열린 질문)로 응답해 라포를 형성하고, 대화 내용이 내담자 프로파일로 자연스럽게 축적되게 한다(감정 일기 대체).

## Context
- 루시 응답 경로 3단계: ① 위험 감지 → ② 안부 대화(checkin) → ③ 리포트 대화
- 현재 ② 안부 대화는 **상담사가 내담자별로 "안부 켜기"를 한 경우에만** 동작(`AgentCheckinEnablement.enabled`)
- 대부분 내담자는 상담사가 안부를 켜지 않아서 ③으로 떨어져, "기분이 안좋아" 같은 감정 얘기를 해도 리포트/명상 수업 얘기로만 끌고 감
- **Brian 결정 1**: 감정 대화를 모든 내담자에게 기본 ON (상담사 스위치 제한 제거)

## Scope

### ✅ In-scope
- **반응형** 감정 대화 기본 ON — 담당 상담사(active 링크)가 있으면 상담사 스위치와 무관하게 안부 대화로 응답
- 담당 상담사가 없는 내담자도 감정 대화 가능(프로파일 축적 대상 없음 → 대화만)
- 친근한 친구 톤 말투 개선 (SYSTEM_RULES · REPLY_FALLBACKS · 폴백 문구)
- 감정 대화 종료 시 프로파일 추출 (기존 `agent_profile.extract_and_store` 재사용)

### ❌ Out-of-scope
- **아웃리치(AI 선발화) 기본 ON** — 기존 상담사 스위치 정책 유지 (이번 범위 밖)
- 진단·처방·점수 차단 완화 — 법적/윤리 문제로 `agent_guard` 유지
- 담당 상담사 없는 내담자의 프로파일 축적 (전달 대상 없음)

## Acceptance Criteria
- [ ] 담당 상담사가 있는 내담자는 상담사가 안부를 켜지 않아도 감정 대화가 열린다
- [ ] "기분이 별로 안좋아" → 공감 + 열린 질문 응답 (리포트/일정 얘기로 끌고 가지 않음)
- [ ] 감정 대화 종료(6턴) 시 체크인 요약 + 프로파일 추출
- [ ] 담당 상담사가 없는 내담자도 감정 대화 응답을 받는다
- [ ] 위험 표현 감지·진단/점수/조언 차단은 그대로 동작
- [ ] `pytest` 관련 테스트 통과

## Dependencies
- SDD-188 (루시 채널), SDD-191 (안부 대화·프로파일) — 기존 코드 확장

## Risks
- 아웃리치 정책과의 혼선 → 반응형/아웃리치를 명확히 분리(`active_counselor_ids` vs `enabled_counselor_ids`)
- 담당 상담사 없는 내담자 처리 → `_build_reply`에 감정 대화 폴백 경로 추가(스키마 변경 없음)
