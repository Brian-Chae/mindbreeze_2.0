# [SDD-193] — Verification (Pre-Implementation)

## Test Scenarios

### TS1: 담당 상담사가 있으면 안부 스위치 없이도 감정 대화가 열린다
1. 내담자 + 담당 상담사(active 링크) 구성, 상담사는 안부 **끔**
2. 내담자가 "기분이 별로 안좋아" 전송
3. 루시가 공감 + 열린 질문으로 응답 (checkin kind)
- **Expected:** 응답 kind = `checkin` (리포트 `report_chat` 아님), 체크인 행 생성

### TS2: 담당 상담사가 없어도 감정 대화 응답
1. 담당 상담사 없는 내담자 구성
2. "요즘 힘들어" 전송
3. 루시가 공감 + 열린 질문 응답
- **Expected:** `NO_CONTEXT_REPLY`("아직 함께 볼 수 있는...") 가 아닌 감정 공감 응답

### TS3: 리포트/일정이 있으면 기존 리포트 대화 유지
1. 리포트 있는 내담자가 리포트 질문
2. 루시가 리포트 범위 응답
- **Expected:** kind = `report_chat` (회귀 없음)

### TS4: 감정 대화 종료 시 프로파일 추출
1. 체크인 6턴 진행
2. 마무리 메시지 + 프로파일 추출
- **Expected:** 체크인 `closed_at` 설정, `summary`·`mood_direction` 채워짐, 프로파일 아이템 생성

### TS5: 위험 표현·진단·조언 차단 유지
1. "죽고 싶어" → 위험 감지 (상담사에게만 신호, 내담자에겐 안전 응답)
2. "우울증인가요?" → `OUT_OF_SCOPE_REPLY`
- **Expected:** 기존 보호 로직 그대로 동작

### TS6: 아웃리치는 기존 정책 유지
1. 상담사가 안부를 끈 내담자에게 스윕 실행
2. 아웃리치 미발송
- **Expected:** `start_outreach` 는 `enabled_counselor_ids` 기준 → 미발송

## Edge Cases
- [ ] 담당 상담사 여러 명 → 가장 최근 매칭 1명 기준으로 체크인
- [ ] 열린 체크인 이미 존재 → 새로 열지 않음 (기존 유지)
- [ ] 리포트/일정도 없고 담당도 없음 → 감정 대화 폴백 (빈 응답 아님)

## Security Review
- [ ] 진단·처방·점수·조언 차단(`agent_guard`)은 완화하지 않음
- [ ] 감정 대화 내용은 요약으로만 상담사 전달(원문 아님) — 기존 D1 유지
- [ ] 담당 상담사 없는 내담자 대화는 어디에도 프로파일로 남지 않음(전달 대상 없음)
