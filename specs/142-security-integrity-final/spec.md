# SDD-142 — 보안·무결성 3차 (11건)

## 배경

전체 코드 리뷰 89건 중 상·중 상위 처리를 마치고, 잔여 중 11건 + 하 보안 항목에서
**실제 리스크가 있는 것**만 11건을 추렸다. 기관 권한·업로드·계정 잠금·리마인더 등
보안·데이터 무결성 경계를 마감한다.

## 대상 (11건)

| # | ID | 이슈 | 리스크 |
|---|---|---|---|
| 1 | AUTHZ-02 | 기관 관리자 판정이 membership 아닌 org_id 미러 의존 | 다중기관 상담사가 비주소속 기관 관리 불가·오판 |
| 2 | CONC-01 | 오디오/비디오 청크 동시 중복 삽입 IntegrityError 미처리 | 멱등 업로드 500 |
| 3 | AUTHZ-04 | 계정 잠금이 이메일 키만 → 임의 피해자 DoS | 계정 15분 잠금 공격 |
| 4 | SEC-12 | 증빙 업로드 매직바이트 미검증 | 악성 파일 업로드 |
| 5 | CFG-01 | 초대 URL dev 도메인 하드코딩 + 토큰 평문 | 배포 환경 링크 오동작 + 토큰 유출 재사용 |
| 6 | TXN-01 | notify_event 조기 커밋 | 부분 커밋·미확정 변경 조기 반영 |
| 7 | REM-01 | 리마인더 발송 로그 순서 → 중복 발송 레이스 | 중복 알림 |
| 8 | SEC-03(FE) | VerifiedTier 타입 상충 + requireFullyVerified 오작동 | 검증 게이트 무력화 |
| 9 | SEC-05(FE) | devAuth 프로덕션 번들 포함 | 프로덕션에 dev 로그인 노출 |
| 10 | SEC-06(FE) | 증빙 업로드 apiClient 우회 | 토큰/재시도/에러 처리 누락 |
| 11 | SEC-07(FE) | 내담자 프로필 상세 역할 미검증 | 비공개 메모 노출 |

## 목표

- 기관 권한·업로드·계정 잠금·알림 경계의 보안·무결성을 마감한다.
- 백엔드 1009 / 프론트 318 테스트 통과.
