## 1. 목적
사용자에게 보이는 "상담사" 표기를 전부 "코치"로 바꾼다. **표기만** 변경 — 코드 식별자(`counselor_*`, `role='counselor'`, 라우트 경로, DB 컬럼·enum 값, API 필드명)는 바꾸지 않는다.

## 4. 결정 필요 (비즈니스)
1. **"상담" 단어**(상담 세션·상담 기록·상담소·상담센터)도 "코칭"으로 바꾸나, 상담사→코치만 바꾸나? (권한: 후자면 약 1/3 작업, 용어 혼재)
2. **조직 유형별 분기**: 임상·최면 상담 기관도 "코치"인가, 명상 기관은 이미 "지도사"인데 유지인가?
3. **법적 문서(개인정보처리방침·약관·동의서)**: 문구 변경 시 동의 버전 상향·재동의가 필요한가? (표기만이면 버전 유지 가능)
4. **이메일·푸시·PDF 리포트·AI 출력**: 이미 발송된 것은 그대로 두고 신규분부터 적용하면 되나?
5. **기관관리자·플랫폼 관리자 화면**까지 포함인가, 회원·코치 화면만인가?

## 5. 조사 보정
"상담사" 끝 받침 없음(사) → 코치 역시 받침 없음 → **가/를/와/는/로/의 등 대부분 그대로 유효**(상담사가→코치가, 를→를, 와→와, 는→는, 로→로). 받침 차이 문제는 거의 없고, 위험은 **"상담사님"→"코치님" 어감, "상담사용"→"코치용"** 정도다. 단 "상담" 단독을 "코칭" 등으로 바꾸면(결정 1) 받침(담→칭 ㅇ)으로 조사 보정 필요: 이/가, 은/는, 을/를, 과/와, 으로/로.
