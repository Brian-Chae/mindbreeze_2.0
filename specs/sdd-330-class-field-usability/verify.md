# SDD-330 — Verify (구현 전 체크리스트)

## A
- [ ] Android 앱: 연결 불가 안내에서 "권한 허용하기"가 OS 권한 창을 띄운다
- [ ] "설정 열기"가 앱 정보 화면(Android)/설정 앱 이 앱 화면(iOS)을 연다
- [ ] "배터리 제한 풀기"는 Android 에서만, 이미 제외된 경우 숨김
- [ ] 웹 브라우저·플러그인 없는 구버전 앱에서는 버튼 없이 기존 문구, 예외 없음
## B
- [ ] 클래스 입장 후 코치마크가 뜨지 않는다
- [ ] 입장 API 호출이 팝업 확인과 무관함을 코드로 확인
- [ ] 동의 화면 변경 없음
## C
- [ ] 기본: 한 번이라도 입장한 회원만 보임(미입장 제외)
- [ ] "입장 N명 · 이상 M명" 표시, 이상 정의 명시
- [ ] 전체 보기 토글로 미입장 포함, 이상 숫자 탭 시 이상 회원만
- [ ] 1:1(solo) 화면 영향 없음, 점수·등급 표시 없음
