# SDD-330 — 수업 현장 사용성 개선 — 첫 안내 팝업 제거·코치 라이브 입장자 기본 보기·권한 설정 바로가기

- 상태: 구현 완료(Stage ⑥), 대표 리뷰 대기
- 브랜치: `sdd/330-class-field-usability`
- 작성일: 2026-11-21 (대표 지시 11/21, 승인됨)

## 배경(대표 원문 요지)
1. 안드로이드·iOS 에서 블루투스·성능 최적화 권한을 "메뉴로 가서 설정하라"고만 안내해 사용자가 메뉴를 못 찾는다 → 설정 바로가기 버튼 또는 앱 안 직접 변경.
2. 클래스 시작 시 첫 사용자에게 안내 팝업(다시 보지 않기 체크박스)이 뜬다. 확인을 안 누르면 입장 처리가 안 되는 것 같다. 의미 없으니 제거.
3. 코치 진행 화면에 입장한 회원과 안 한 회원이 모두 보여 보기 나쁘다. 기본값은 한 번이라도 입장한 회원만. 총 입장 수와 이상 수를 한눈에.

## 범위
- A. 권한 설정 바로가기(앱 빌드 필요 — 스토어 앱은 다음 빌드부터)
- B. 첫 안내 팝업(코치마크) 제거
- C. 코치 라이브 화면 입장자 기본 보기 + "입장 N명 · 이상 M명" 요약

## 비범위
- 동의 화면(리포트·데이터 수집 동의)은 건드리지 않는다. 라이브 소켓·명령 흐름 무수정. 백엔드 변경 없음.
