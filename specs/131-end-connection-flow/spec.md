# [SDD-131] 종료·연결 플로우 정합

## Goal
종료 화면·상담사 영상 연결의 누락된 안내와 안전장치를 보강한다.

## Issues
- ②-4 접촉불량 시 복구 방법 안내 없음 → LeadOffModal에 복구 절차 3단계 추가
- ②-15 종료 화면 인증코드 재발송 불편 → OTP 단계 재발송 버튼(30초 쿨다운)
- ②-16 종료 화면 단계 전환 안내 없음 → 3단계 스텝퍼 추가
- ②-17 상담사 영상 무한 재시도 → 지수 백오프(최대 5회) + 수동 재시도
- ②-18 스피커 기본 상태 시점 문제 → locationType 확정 시 동기화
- ②-20 종료 버튼 확인 없이 즉시 이탈 → LeaveConfirmModal 신규 + 적용

## Acceptance Criteria
- [ ] 접촉불량 복구 절차가 안내된다.
- [ ] 인증코드를 재발송할 수 있다.
- [ ] 종료 단계가 표시된다.
- [ ] 영상 재시도가 유한(최대 5회)이며 수동 재시도가 가능하다.
- [ ] 스피커 기본값이 locationType 계약대로 적용된다.
- [ ] 종료/이탈 시 확인 모달이 뜬다.
- [ ] 빌드 0 errors, 관련 테스트 통과.
