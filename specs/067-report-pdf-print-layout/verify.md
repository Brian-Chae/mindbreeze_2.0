# SDD-067 재구현 구현 전 검증 계획

작성 시점: 재구현 CSS 수정 전. 최신 브리프가 구현 승인을 제공한다.

- 커버/여정/몸/마음/마무리, 그래프, 서사, 상담 요약이 출력되는지 확인.
- 긴 여정과 마무리 끝 표식을 PDF에서 추출하여 생략 여부 확인.
- EEG 상세는 인쇄 DOM에서 제외하고 화면 열린 상태는 유지.
- A4 다중 페이지, 좌우 넘침 없음, 페이지별 렌더링으로 빈 공간 확인.
- 미측정 상담 요약 전체 출력 및 화면 1280/390/320px 회귀 확인.
- 개선·빌드·PDF 시각 확인 3회 이상과 최종 회귀 테스트 성공.
