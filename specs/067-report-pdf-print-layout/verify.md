# SDD-067 구현 전 검증 — 4페이지

최신 브리프 구현 승인에 따라 CSS 수정 전에 작성.

- 기본 리포트 PDF 정확히 4쪽 및 섹션별 페이지 배치.
- ReportCoverSection 참여자/상태/브랜딩 헤더 인쇄 숨김과 화면 보존.
- 모든 본문과 그래프, 상담 요약 텍스트 보존.
- EEG 상세와 details 인쇄 제외.
- 최소 3루프 빌드와 PDF 이미지 검토.
- 긴 내용은 자르지 않고 추가 페이지로 이어지는지 별도 확인.
- 미측정 요약과 모바일 액션 회귀 확인.

## 몸 1페이지 및 머리글 재수정 — 구현 전 검증

최신 디스패치의 재구현 승인을 적용한다.
- 몸·마음 서사 문단이 있는 6지표 fixture에서 4페이지 및 각 지표/주석이 해당 페이지 안에 보존되는지 검증한다.
- 모든 페이지의 상단 브랜드와 하단 현재/전체 페이지 번호를 PDF 텍스트로 확인한다.
- 카드 3mm, 태그 pill, 그래프 사각 모양과 원문 보존을 시각 검토한다.
- 개선 → 빌드 → PDF 미리보기 3회, 긴 원문 및 미측정 회귀를 수행한다.

## 1페이지 콘텐츠 압축 재구현 — 구현 전 검증

이번 디스패치의 구현 지시에 따라 기존 승인 범위 안에서 진행한다.
- 여러 문단 분량의 여정(약 900자)을 포함한 fixture로 현재 첫 페이지 넘침을 재현한다.
- cover/journey 제목·여백·카드 패딩을 압축하고 두 섹션의 전체 텍스트가 PDF 1쪽에 포함되는지 확인한다.
- 3회 CSS 조정 → 빌드 → Chrome PDF 생성 → 페이지 이미지 검토를 수행한다.
- A4 실제 내용 높이 273mm(297 - 12 × 2), 4쪽 순서, 몸·마음 전체 원문 및 머리글/페이지 번호 보존을 확인한다.
- 초장문은 잘림 없이 이어지며, 웹/모바일 화면과 미측정 요약 회귀를 확인한다.
