# SDD-067 4페이지 재구현 계획

최신 디스패치가 재구현을 승인했다.

1. 기존 인쇄 회귀를 헤더 숨김 및 4쪽 섹션 경계 기준으로 변경.
2. 1루프: 헤더 숨김과 명시적 페이지 분리.
3. 2루프: 페이지별 높이와 카드 여백 확대.
4. 3루프: 전체 페이지 시각 검토 후 간격 보정.
5. 빌드, PDF 텍스트 보존, 긴 문장과 미측정 회귀를 기록.

## 최신 재수정 실행 계획

1. 몸·마음 서사 문단 fixture로 기존 넘침을 재현한다.
2. 머리글/꼬리글 여백 확보 및 카드/그래프 압축을 적용한다.
3. 카드·태그 모서리와 작은 주석의 가독성을 보정한다.
4. 각 루프에서 빌드와 PDF 전체 페이지 시각 검증을 수행한다.
5. 페이지별 원문·머리글·페이지 번호와 긴 원문·미측정 회귀를 확인한다.
