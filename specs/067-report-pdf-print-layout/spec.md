# SDD-067 — 전체 서사형 A4 리포트 인쇄

2026-09-16 재구현 브리프 승인: 기존 한 장 요약 요구를 대체한다.

- 웹 커버, 종합 여정, 몸, 마음, 마무리, 서사 문장과 그래프를 생략 없이 출력한다.
- EEG 상세(data-print-exclude, details)는 제외한다.
- A4 세로 다중 페이지, 작은 여백, 자연스러운 흐름으로 빈 공간을 줄인다.
- 보라/그린/크림과 화면 디자인을 유지하고 인쇄 CSS만 변경한다.
- 스타일 개선 → 빌드 → Chromium PDF 시각 확인을 최소 3회 수행한다.
