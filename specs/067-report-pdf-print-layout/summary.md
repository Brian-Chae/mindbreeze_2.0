# SDD-067 최신 재수정 — 몸 1페이지와 머리글/꼬리글

2026-09-16 최신 디스패치 요청에 따라 완료했다. 아래 이전 결과보다 이 절이 우선한다.

## 원인과 변경

기존 회귀 fixture에는 몸·마음 설명 문단이 없었다. body/mind 문단을 넣자 몸 섹션이 다음 장으로 이어져 3쪽 마음 제목 검증이 실패했다(RED 0/2).

- 제품 변경은 `frontend/src/lib/report/report-print.css`에 한정했다.
- A4 좌우 6mm·상하 12mm 여백, @top-center 브랜드 머리글 및 @bottom-center 현재/전체 페이지 번호를 추가했다.
- 지표 카드 최소 높이 66→56mm, 간격 5→3mm, 패딩 5→4mm, 그래프 최대 높이 44→38mm로 조정했다.
- 본문 영역 273mm에 맞춰 몸·마음 최소 높이를 272mm로 보정했다. 커버/여정/마무리 높이도 새 여백에 맞췄다.
- 카드 모서리 3mm, 요약 칩 2mm, 상태 태그 pill, 그래프 사각형을 적용했다. 주석·그래프 캡션·페이지 번호는 9pt이다.
- 원문 축약이나 잘라내기는 없다. 별도 관리 커버 헤더와 EEG 상세 제외를 유지했다.

## 3회 개선 및 검증

OS 대화상자 대신 Chrome 인쇄 엔진의 PDF와 전체 페이지 PNG를 확인했다. 각 루프에서 npm run build exit 0 및 브라우저 회귀 2/2 통과했다.

1. compact-loop1: 카드 53mm·그래프 35mm로 압축하고 머리글/꼬리글 추가, 정확히 4쪽.
2. compact-loop2: 남는 공간을 활용해 카드 56mm·그래프 38mm로 확대하고 모서리 형태 정리, 정확히 4쪽.
3. compact-loop3: 주석·머리글·페이지 번호 9pt, 제목 태그 줄바꿈과 그래프 최소 폭 보정, 정확히 4쪽.

최종 PDF는 `evidence/compact-loop3.pdf`이다. 루프별 PDF/PNG/build/test 로그를 evidence에 보존했다.

- 1쪽 명상/종합 여정, 2쪽 몸, 3쪽 마음, 4쪽 마무리/AI 요약.
- 몸·마음 각각 설명 문단+3개 지표+전체 주석이 해당 페이지에서 완전히 추출된다.
- 모든 페이지에 브랜드 머리글과 1 / 4 ~ 4 / 4 페이지 번호가 추출된다.
- 모든 본문 제목/문단을 DOM과 PDF 텍스트로 대조하여 보존 확인.
- 브라우저 회귀 2/2: 이메일 유/무, 1280/390/320px 액션, 인쇄 iframe, EEG 제외, 승인/메일 발송을 mock API로 검증.
- 서사 컴포넌트 회귀 6/6 통과.
- 긴 원문 8쪽 및 미측정 1쪽, 종료 표식 보존. 세 PDF 모두 텍스트 좌표가 페이지 밖으로 나가지 않았다.
- 최종 4쪽 전체와 몸 페이지 확대 이미지에서 겹침/잘림 없이 카드와 머리글/꼬리글을 확인했다.
- 빌드 오류 0. 기존 CSS import 순서와 번들 크기 경고는 남아 있다.

설명 문단이 포함된 테스트 데이터에서 4페이지를 확인했다. 임의 길이의 원문은 축약하지 않고 추가 페이지로 이어진다. 실제 프린터, 운영 데이터 전체 및 다른 브라우저의 margin box 지원은 검증하지 않았다. 커밋/배포는 수행하지 않았다.

# 이전 재구현 결과 — 섹션별 4페이지 PDF

2026-09-16 최신 디스패치의 4페이지 구성과 상단 헤더 제거를 반영했다.

## 변경

- 제품 변경은 `frontend/src/lib/report/report-print.css`에만 한정했다. 화면 스타일, React 컴포넌트, iframe 인쇄 로직은 변경하지 않았다.
- 별도 `ReportCoverSection`의 브랜딩 태그, 참여자 정보, 승인 상태와 장식 전체를 인쇄에서 숨겼다. `NarrativeSections`의 명상 여정 제목/부제목과 세션 정보는 보존했다.
- 몸·마음·마무리 앞에 `break-before: page`와 `page-break-before: always`를 적용했다.
- A4 6mm 여백, 페이지별 최소 높이와 여백, 29pt 커버 제목, 23pt 섹션 제목, 66mm 지표 카드, 44mm 그래프를 적용했다.
- 본문과 상담 요약을 생략하지 않으며 EEG 상세와 details 제외, 서사형 팔레트와 exact 색상 출력은 유지했다.

## 3회 개선 및 검증

각 루프 CSS 수정 → npm run build(exit 0) → Chromium 인쇄 PDF 생성 → 4페이지 PNG 시각 검토를 수행했다. OS 인쇄 대화상자가 아닌 Chrome PDF 인쇄 엔진 결과를 확인했다.

1. `four-page-loop1`: 헤더 숨김과 페이지 분리, 4쪽 확인. 하단 여백이 커 추가 개선. 테스트의 PDF 제목 비교가 글자 간 공백 때문에 실패하여 공백 정규화로 수정했다.
2. `four-page-loop2`: 글자/그래프/카드 확대, 4쪽 및 브라우저 회귀 2/2 통과.
3. `four-page-loop3`: 커버와 여정 간격 및 지표/제안 카드 높이 개선, 최종 4쪽 및 브라우저 회귀 2/2 통과.

최종 PDF: `evidence/four-page-loop3.pdf`. 각 루프의 PDF, 전체 페이지 PNG, 빌드/테스트 로그를 evidence에 보존했다.

## 최종 결과

- 1쪽 명상 여정 + 02 종합 여정, 2쪽 03 몸, 3쪽 04 마음, 4쪽 05 마무리 + 기존 AI 요약을 PDF 텍스트로 검증했다.
- 하단 마지막 텍스트 위치는 A4 높이 842pt 중 페이지별 742/763/777/782pt로, 1차의 555/532/532/503pt보다 공간 활용이 개선됐다.
