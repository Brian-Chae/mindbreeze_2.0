## 배경 (대표 실기기 테스트: Android 1대 + iOS 1대, dev 서버)
1. 클래스 종료 후 데이터 현황에서 iOS 는 "측정 기록 파일 모두 도착"인데 데이터 크기가 0KB. Android 는 정상.
2. 클래스 코드 입장 후 동의 화면에서 전체 선택 → 다음으로 가면 같은 동의 화면이 한 번 더 뜬다(양 플랫폼).
3. iOS: 뒤로 갔다 동의 화면에 다시 오면 "전체 동의"는 눌려 있는데 선택 항목은 비어 있다.

## 범위
- 2번: 자격을 새로 받는 제출(녹음 게이트)에서 같은 화면을 두 번 보이지 않게 한다. 새 화면 추가 없음.
- 3번: 전체 동의 체크를 화면에 보이는 항목 전부에서 파생한다(잠긴 뇌파 항목 포함).
- 1번: 원인 확정 시도. 서버 집계 입력과 결과를 읽기 전용으로 검증한다. 확정 못 하면 가설로 남기고 수정하지 않는다.

## 비범위
DB 마이그레이션, 서버 API 변경, 새 화면.
