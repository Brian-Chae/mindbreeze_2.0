## 실행 증거 규칙

PG는 마이그레이션 적용 임시 DB·별도 연결 2개를 사용한다. SQLite/대역 통과로 경합을 대체하지 않는다. 합성 브라우저와 실제 BE 연결, 카메라 대역과 실카메라 결과를 나눈다. 외부 메일/푸시를 실제 수신하지 않았다면 미확인이다. 사용자 중지나 실행 시간 초과는 실패/중단으로 기록하며 전체 통과로 합산하지 않는다.

실행 후 결과는 별도 summary에 ID·명령·환경·SHA·결과·증거·미확인을 기록한다. 이 문서에 사후 기대값을 만들어 테스트에 맞추지 않는다.
