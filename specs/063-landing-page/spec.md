# SDD-063 — 메인 랜딩 페이지 개선 (반응형 + 전환 최적화)

> 메인 랜딩 페이지(#/)를 기관·상담사·명상가가 "사고 싶게" 만드는 고완성 반응형 랜딩으로 개편한다.
> codex(gpt-6-astra)로 5회 루프를 돌며 완성도를 끌어올린다.

## 1. 현황 문제
- 상단 버튼 4개(클래스 참여/상담사 로그인/회원 로그인/기관로그인) → 복잡
- 메뉴가 '서비스/AI 리포트/상담사/고객센터'로 되어 있고, LINK BAND/리포트 메뉴 구조가 요구와 다름
- 페이지 로딩이 길고 반응형 적용 미흡 (모바일에서 버튼 4개가 붙음)

## 2. 개선 목표
### T1. 상단 버튼 3개로 단순화
- "클래스 바로 참여" (→ /join)
- "로그인" (→ /login)
- "회원가입" (→ 회원가입 라우트 확인 후 연결)

### T2. 메뉴 4개
- 서비스 / LINK BAND / 리포트 / 고객센터

### T3. 콘텐츠 (기관·상담사·명상가 전환 목적)
- LINK BAND 소개 섹션 (linkband.looxidlabs.com 참고 — 브라우저로 확인)
- 리포트 미리보기 섹션 (기존 NarrativeSections/샘플 리포트 활용)
- 서사형 리포트의 강점(점수 아닌 몸·마음 변화) 강조

### T4. 반응형 + 로딩 최적화
- 모바일/태블릿/웹 반응형 (모바일 햄버거 메뉴, 버튼 정리)
- hero 이미지 최적화(lazy/크기), 불필요 리소스 지연 로딩

## 3. 진행 (codex gpt-6-astra 5회 루프)
각 루프에서 개선 → 브라우저 확인 → 다음 루프. 최종 고완성 랜딩.

## 4. 완료 기준
- 버튼 3개 + 메뉴 4개 + 콘텐츠(LINK BAND/리포트) + 반응형/로딩 개선
- FE build 0 error
