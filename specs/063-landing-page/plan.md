# SDD-063 구현 계획

- 기존 랜딩 내부 개편으로 한정하고 로그인·가입·참여 및 실제 리포트 계약은 유지한다.
- 보라색 #5F0080 + 따뜻한 화이트, 큰 타이포, 제품 이미지와 서사형 리포트로 상담센터·상담사·명상가에게 가치를 전달한다.
- 메뉴: 서비스 / LINK BAND / 리포트 / 고객센터. 상단 행동: 클래스 바로 참여 / 로그인 / 회원가입.
- 모바일은 햄버거 메뉴와 세로 행동 버튼, 웹은 수평 내비게이션을 제공한다.
- 기존 NarrativeSections 기반 샘플을 지연 로딩해 미리보기 제공. 예시 데이터임을 명시한다.
- 이미지 WebP·반응형 크기·lazy loading 적용. 새 스타일은 Tailwind 유틸리티만 사용한다.

## 5회 개선 루프
1. 내비게이션·히어로·반응형 골격 → build + 브라우저 데스크톱/모바일 확인.
2. 대상별 문제와 해결·서비스 프로세스 → build + 브라우저 확인.
3. 공식 제품 페이지 확인 기반 LINK BAND 섹션 → build + 브라우저 확인.
4. 서사형 리포트 미리보기·고객센터 → build + 브라우저 상호작용 확인.
5. 접근성·성능·전체 화면 시각 보정 → build + 브라우저 다중 너비 최종 확인.
