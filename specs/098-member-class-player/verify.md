# 구현 전 검증 계획

작성 시점: 구현 전. 사용자의 확정 디자인 이식·끝까지 구현 지시를 승인 근거로 진행한다.

- [ ] 1280×720 / 390×844: 문서와 패널의 scrollWidth/Height가 clientWidth/Height 이내. 내부 요소 잘림 없음.
- [ ] 카드 6개 유지, 카드 탭 시 해당 단위와 chartMax로 12구간 평균 표시.
- [ ] 최대 300포인트, 25포인트 단위, 부분 구간 오른쪽 정렬, 입력 데이터 변경 없음.
- [ ] 막대는 25초마다 갱신하며 마지막 구간만 민트→퍼플 강조.
- [ ] 밴드 미연결 안내·연결 버튼, 연결 시 상태 아이콘, 접촉불량·AI 분석중 유지.
- [ ] 스피커 기본값(온라인 ON/오프라인 OFF), 강당형 영상 제외 및 타이머 유지.
- [ ] BGM 볼륨 팝업/차단 해제, 몰입 시에도 오디오 엔진 마운트 유지.
- [ ] 기존 클래스 채팅 게이트/안읽음·게스트 안내·온보딩·무음 시그널 유지.
- [ ] 모든 주요 버튼 44px 이상, reduced-motion 대응.
- [ ] npm run build 및 npx vitest run.
