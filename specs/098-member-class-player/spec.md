# SDD-098 회원 클래스 진행 화면

사용자의 확정 구현 브리프 및 `design/member-class-player/index.html`을 정본으로 한다.
기존 세로 스크롤 화면을 1280×720 및 390×844에서 스크롤 없는 화면으로 이식한다.
6지표 카드, 25초 평균 12구간 막대, 영상 타이머, 무음 시그널, BGM 미니바·볼륨 팝업,
보라 스크림과 영상 대기 글로우를 포함한다.
밴드/WS/오디오/채팅 계약, 1Hz 300포인트 링버퍼, 강당형 영상 숨김, 몰입·접촉불량·온보딩 기능 유지.
사용자가 방향을 확정하고 추가 질문 없이 구현·검증까지 수행하도록 명시적으로 승인했다.
