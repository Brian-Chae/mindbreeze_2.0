# SDD-202 — 루시 대화 맥락 상실 수정

> 사후 작성: 구현 완료 후 기록 정리 목적. 구현 전 승인 게이트 아님.

- 근거: `summary.md`, 커밋 `8f00a21b`~`a1bb36ee`(2026-10-10~12)

## 1. 목적

루시(내담자 채널 AI 동반자)가 짧은 말에 맥락 없는 응답을 하거나, 인사·감탄사에 감정 위로로 동문서답하는 문제를 고친다.
함께 드러난 LLM 실패 시 고정 폴백 문구, 상담사 연결 제안 문구·버튼, 체크인 6턴 고정 마무리 문제도 이 SDD 에서 정리했다.

## 2. 증상

| # | 증상 | 확인된 원인 |
|---|---|---|
| 1 | "고마워 친구" 같은 짧은 말에 "그 일을 떠올리면 어떤 생각이 드나요?" 식 응답 | 체크인 진행 중 직전 대화 원문이 프롬프트에 없음(`memories` 는 마무리 후 요약), few-shot 5개가 모두 "공감 → 질문"으로 끝나 과적합 |
| 2 | "안녕??"에 "그런 마음이 들었군요", "아야야"에 "편안한 순간은 언제인가요" | 감정 위로 프롬프트가 모든 입력을 감정 표현으로 해석 |
| 3 | LLM 지연 시 문맥과 무관한 고정 문구(`REPLY_FALLBACKS`) | dev 모델 첫 토큰 7~10초, 스트리밍 read 타임아웃 15초 초과 |
| 4 | 상담사 연결 제안이 모호하고 버튼 없음, 거절해도 되풀이 | 제안 문구·버튼 부착 패턴이 넓고 거절 기억 없음 |
| 5 | 체크인 6번째 턴에 LLM 없이 고정 마무리 | `CLOSING_TEMPLATE` 고정 종료 |

## 3. 범위

- 내담자 채널 루시의 프롬프트 구성(`agent_policy.py`, `agent_llm.py`), 스트리밍·타임아웃, 체크인 종료 규칙, 상담사 연결 CTA(`agent_service.py`), 프론트 재시도 UI.
- 범위 밖: 상담사 채널 루시, 브리핑·리마인더 템플릿, 비스트리밍 `POST /agent/messages`(프론트 미사용).
