### 1.2 지표 카드 한 장의 구조 (`MetricChangeCard`)

제목 + 방향 배지(증가/감소/유지) → **명상 전체 평균 큰 숫자+단위** → 전반 {a} → 후반 {b} + 변화량 pill(+/−) → 방향 해석 한 줄(기호+문구) → 지표 문장 1개(`metric.sentence`) → 지표 정의(쉬운 말) → ‘어느 방향이 무엇에 가까운지’ 안내 → 캡션(‘명상 시작 평균 대비 마무리 평균’). 오른쪽(모바일은 아래)에 2종 차트.

### 1.3 문장 생성 규칙

| 항목 | 규칙 | 근거 |
|---|---|---|
| 비교 기준 | 시간 범위를 **전반/후반**으로 나눈 평균 비교. 실행 세그먼트(`play_group_id`)별로 중간점을 따로 구해 세그먼트 평균을 동일 가중 | `report_narrative.py` `build_metrics_summary` |
| 방향 임계 | 호흡수 1회/분, 심박 3bpm, HRV(SDNN) 5ms 미만 변화는 ‘유지’. 마음 3지표는 변화율 5% 미만 ‘유지’ | `METRICS`, `build_metrics_summary` |
| 마음 지표 가드 | 세션 상태 valid/degraded 이고 윈도우 품질 valid/degraded 일 때만 사용. 몸 지표는 EEG 품질과 독립 | 같은 함수 `_half_mean` |
| 다인 혼합 | 여러 참여자를 한 사람의 전후 변화로 해석하지 않도록 **혼합 집계는 방향을 내지 않음** | 같은 함수 `mixed` |
| 지표 문장 | 지표×방향(3) 고정 템플릿. 예: 호흡 ↓ ‘호흡이 깊고 느려졌어요’, 집중 ↑ ‘집중이 깊어졌어요’, 이완 stable ‘이완이 유지됐어요’ | `SENTENCE_TEMPLATES` |
| 종합 여정 | 몸 추세(relax/arouse/stable) × 마음 추세(calm/scatter/stable) 3×3 템플릿 또는 LLM 서사. 6지표 방향 시그니처(↓↓↑↑↑↑ 등)로 캐시 | `narrative.ts` `JOURNEY_TEMPLATES`, `build_narrative_signature`, `narrative_cache` |
| 규칙 폴백 | 방향 없는 지표는 문장에서 생략. 둘 다 없으면 ‘측정 자료가 부족해 {몸/마음}의 전후 변화를 확인하기 어려워요.’ | `fallback_narrative` |
| LLM 문장 검수 | 금지 용어(SDNN·RMSSD·PPG·정규화·점수·스코어·원천 등), 60자 초과, 하락 지표에 ‘회복/개선’ 표현이면 규칙 문장으로 폴백 | `validate_metric_sentence` |
| 쉬운 말 치환 | HRV→‘심박변이’, SDNN→‘심박변이(심장 박동 간격의 변화)’, ‘정서 안정’→‘감정안정도’ | `simplifyReportTerms` |

### 1.4 클래스 요약에 가져올 것 / 바꿀 것

| 구분 | 내용 |
|---|---|
| **가져온다** | ① 섹션 흐름(한 줄 → 흐름 → 몸 → 마음 → 다음) ② 전반/후반 비교 + 변화량 pill ③ 시간 추이 선(이동평균, 결측 비연결) ④ 방향 임계값·문장 템플릿·금지어 검수·결측 생략 규칙 ⑤ 쉬운 말 용어 ⑥ 면책 고지 |
| **바꾼다** | ① 주어: ‘나’ → ‘오늘 수업·함께한 사람들’ (2인칭 위로 문구 제거, 관찰 어조) ② 판정형 해석 제거: 현행 `metricChangeInterpretation`은 ‘좋아졌어요/주의가 필요해요’를 쓰지만 **명상 클래스 요약에는 쓰지 않는다**(P1). 방향 안내(`metricDirectionGuide`)는 ‘읽는 법’ 접이식으로만 둔다 ③ 마음 지표 ‘점’ 단위 → **%** (진행 화면과 동일, §5.E.1) ④ 회원 리포트의 ‘권장(정상) 범위 띠’는 쓰지 않는다(정상/비정상 판정으로 읽힘) ⑤ 5구간 분포·표정 범례 제외 ⑥ 마무리의 ‘다음 제안’ → 상담사 업무(S6) |

## 2. 회차 요약 서사 구조 (명상 클래스, 상담사용)

한 화면 세로 스크롤. 섹션 7개. 번호·제목은 회원 리포트처럼 eyebrow(`01 · …`)를 붙인다. 모든 섹션은 데스크톱 1열 풀폭 카드(§5.E 결정 6과 동일), 모바일도 같은 순서.

```
S0 헤더 ─ 클래스 종료 확인
S1 오늘 수업 한 줄
S2 함께한 사람들
S3 수업 흐름 (시간축 그래프)
S4 몸과 마음의 변화 (지표 6장, 몸→마음)
S5 참여자별로 이어보기
S6 상담사가 할 일
```

### S0. 헤더 (서사 밖 고정 영역)

- 와이어: 클래스명 / 회차 / 완료 일시 / 진행 시간 + ‘클래스가 종료되었습니다’ 배지. 오른쪽 위 ‘목록으로’.
- 문구: `{클래스명} {n}회차 · {M/D HH:mm} 종료 · {N}분 진행`
- 데이터: 현재 있음(세션·클래스·종료 시각). 진행 시간은 실제 시작~종료.

### S1. 오늘 수업 한 줄 (회원 리포트 ‘종합 여정’ 대응)

- 와이어: 큰 인용문 1단락(2~3줄) + 요약 칩 2개(몸·마음, 칩은 지표 방향 나열). 칩 옆 작은 라벨 ‘측정 {n}명 기준’. 점수·아이콘 평가 없음.
- 문장 템플릿 (측정 ≥2명, 몸·마음 방향 모두 있음):
  - `{N}분 수업 동안 함께한 {n}명의 {몸 추세 문구}, {마음 추세 문구}.`
  - 몸 추세 문구: relax ‘호흡과 심박이 차분해지는 쪽으로 움직였고’ / stable ‘호흡과 심박이 비슷한 리듬을 유지했고’ / arouse ‘호흡과 심박이 조금 빨라졌고’
  - 마음 추세 문구: calm ‘집중과 이완 신호는 후반으로 갈수록 높아졌어요’ / stable ‘집중과 이완 신호는 비슷하게 유지됐어요’ / scatter ‘집중 신호는 후반에 낮아졌어요’
  - 예시: ‘45분 수업 동안 측정된 4명의 호흡과 심박이 차분해지는 쪽으로 움직였고, 집중과 이완 신호는 후반으로 갈수록 높아졌어요.’
- 규칙: 몸/마음 추세는 회원 리포트의 `BodyTrend`·`MindTrend`와 같은 산식을 **클래스 평균 전후 방향**에 적용(신규 집계, §4). 한 그룹의 방향이 없으면 그 문장 절만 생략. 둘 다 없으면 상태 문구(§3) 사용.
- 칩 예시: `몸 호흡수 ↓ 느려졌어요 · 심박수 ↓ · 심박변이 →` / `마음 집중도 ↑ · 이완도 ↑ · 감정안정도 →` (해석 어휘는 §4.2 사전).

### S2. 함께한 사람들

- 와이어: 숫자 3개 가로 배치 — **참석 {a}명 · 측정 {b}명 · 리포트 대상 {c}명**. 아래 한 줄 보조 설명. 참석/측정/대상은 서로 다른 분모임을 라벨로 구분. 측정 인원이 지표마다 다르면 ‘지표별 측정 인원은 아래 각 카드에 표시돼요’ 안내.
- 문장 템플릿:
  - 일반: `참석한 {a}명 중 {b}명이 LINK BAND로 측정했어요. 측정하지 않은 {a-b}명은 기록·리포트만 이어져요.`
  - 전원 측정: `참석한 {a}명 모두 측정했어요.`
- 그래프: 없음. 선택 — 얇은 가로 막대 ‘참석 → 측정 → 유효 분석’ 3단(분모 확정 시에만. 확정 전에는 숫자만, 비율 금지. 정책: 분모 미확정 비율 숫자 제거 — 기존 시안 검토 결과 유지).
- 데이터: 참석 수·리포트 대상 수는 있음(§5.A 2번). 측정 인원은 **지표별 eligible/측정/비교 가능 인원 신규 집계**(§5.E.2 ‘공통 신규’).

### S3. 수업 흐름 (시간축)

- 와이어: 제목 ‘수업이 흘러간 모습’. 상단에 지표 선택 탭(기본 ‘마음’ = 집중도·이완도·감정균형도 3선 한 그래프, ‘몸’ 탭 = 심박·호흡·HRV 각각 작은 3개). 아래 시간축 영역 그래프 1개(데스크톱 높이 240, 모바일 200).
- 그래프 명세:
  - 종류: 선(Recharts LineChart 재사용). X = 수업 경과 분(시작~종료), Y = 마음 3지표는 0–100 % 공통 축. 몸 지표는 지표마다 자체 축(단위가 달라 한 축에 겹치지 않는다). **그래프 높이를 지표 사이에서 비교하지 말라**는 회원 리포트의 안내문 유지.
  - 값: 지표별 **측정자 평균**을 5분 버킷 단위로 표시(버킷 내 측정 2명 미만이면 점 생략). 5분 단위 점+선으로 데스크톱·모바일 동일 데이터를 쓰되, 모바일은 툴팁 대신 그래프 아래에 선택 구간 값을 표시.
  - 배경: 전반/후반 경계를 점선 1개로 표시하고 ‘전반’ ‘후반’ 라벨(변화량 계산 기준과 일치시키기 위함). 3등분 라벨(처음·중간·마무리)은 X축 아래 보조 눈금으로만.
  - 이동평균: 회원 리포트와 동일하게 1초 윈도우 잡음을 평탄화(결측은 건너뛰고 잇지 않음).
  - 범위 표현: 선택 시 ‘개인 평균 범위’를 연한 음영 띠로. **측정 ≥2명인 구간만**, 1명 구간은 선·띠 모두 미표시.
  - 금지: 정상 범위 띠, 목표선, 좋음/나쁨 색, 개인 선 겹쳐 보기(개인 선은 S5에서).
  - 색: 지표 식별색(§5.E.1)만. 방향 색 금지.
- 문장(그래프 위 1줄, 서사형): `전반에는 {지표1}이 {값1}% 부근이었고, 후반에는 {값2}%로 {올랐어요/내려갔어요/비슷했어요}.` 예: ‘집중도는 전반 52%에서 후반 61%로 올랐어요.’ 가장 큰 변화 1개 지표만 문장화, 나머지는 S4에서. ‘가장 크게 변한’이라는 표현은 쓰되 순위 나열은 하지 않는다.
- 데이터: **신규 집계**. 현재 정규화 `timeline.*`은 개인별 리포트 content에만 있고(`report_task.py:303–363`), 다운샘플링되어 있어 클래스 시간 버킷 평균의 정본이 될 수 없다. 개인 `eeg_feature` 표본 → 정규화(진행 화면과 같은 기준) → 5분 버킷 개인 평균 → 참여자 동등 가중 평균(측정 ≥2명).

### S4. 몸과 마음의 변화 (회원 리포트 03·04 통합)

- 와이어: 소제목 2개 ‘몸의 리듬’(호흡·심박·HRV 3장) → ‘마음의 흐름’(집중·이완·감정균형 3장). 각 소제목 아래 서사 1~2줄 → 지표 카드 3장 세로. **지표 카드 1장 = 지표 1개, 데스크톱 1열 풀폭**(결정 6). 카드 기본 높이는 접힘 시 1줄 요약, 펼침 시 상세.
- 소제목 서사 템플릿:
  - 몸: `호흡수는 {a}→{b}회/분, 심박은 {c}→{d}bpm로 {방향문구}.` / 마음: `집중도는 {…}, 이완도는 {…}.`
  - 둘 이상 지표를 한 문장으로 연결할 때는 ‘~했고, ~했어요’ 형태로 잇고 **3개를 넘기지 않는다**. 결측 지표는 문장에서 빼고 카드에만 ‘—’ 표시.
- 지표 카드(상단→하단):
  1. 이름 · EEG/PPG 배지 · 단위 (§5.E.1 라벨 그대로: 집중도/이완도/감정균형도/BPM/호흡/HRV)
  2. **대표값 큰 숫자**(클래스 평균, 측정 ≥2명) + 단위. 1명이면 큰 숫자 자리에 ‘측정 1명’, 보조 ‘참여자별 결과에서 확인’.
  3. 변화 줄: `전반 {a} → 후반 {b}  {+/−Δ}{단위}` (EEG는 %p). 변화 방향 배지 증가/감소/유지(중립색).
  4. 서사 1문장 (§4.2 사전). 예: ‘집중이 후반으로 갈수록 깊어졌어요.’
  5. 통계 줄(데스크톱 1줄/모바일 2줄): `측정 {n}명 · 개인 평균 범위 {min}–{max}{단위} · 비교 {m}명 · 유효 {분} ({%})`
  6. 차트 2종: **전반 vs 후반 2막대**(회원 리포트 `DualBarChart` 재사용, 후반 막대=지표 식별색) + **작은 시간 추이 선**(S3와 같은 데이터의 지표별 스파크라인, 높이 80). 두 차트 모두 측정 ≥2명일 때만.
  7. 접힘 영역: 지표 설명 1줄(`METRIC_DEFINITIONS` 재사용), ‘읽는 법’(방향 안내 문구는 해석 아닌 설명으로 순화: ‘호흡수가 낮아지면 숨 쉬는 횟수가 줄었다는 뜻이에요’).
- 예시 카드 문구 (합성): `집중도 · EEG` / `57 %` / `전반 52 → 후반 61 (+9%p) · 증가` / ‘후반으로 갈수록 집중 신호가 높아졌어요.’ / `측정 4명 · 개인 평균 범위 44–68% · 비교 4명 · 유효 36분(80%)`
- ‘함께 움직인 사람 수’ 보조 줄(선택, 상담사 전용): `비교 4명 중 3명 증가 · 1명 유지`. 순위·개인 식별 없음. 비교 인원이 3명 미만이면 숨김(기존 `class_report_trend_service` 익명 분포 정책 준용).
- 데이터: 6지표 전후·평균·범위·유효 시간 **전부 신규 집계**(§5.E.2). 산식은 기존 `build_metrics_summary`의 세그먼트 동일 가중 전후 평균을 재사용하되 **정규화 후 개인 값 → 클래스 동등 가중 평균** 순서로 계산한다(정규화 후 평균과 평균 후 정규화는 다름, §5.E.2 [B]).

### S5. 참여자별로 이어보기

- 와이어: ‘함께한 사람들을 한 명씩 볼 수 있어요’ 소개 한 줄 → 참여자 행 목록(검색+상태 필터, 표/모바일 카드는 §5.B 그대로). 각 행에 **개인 한 줄 서사 미리보기** + 측정 상태 + 리포트 상태(생성/승인/전달) + [열기]. 참여 순서 고정, 정렬 없음, 점수 없음.
- 개인 한 줄 서사 템플릿(개인 6지표 시그니처 기반, 개인 리포트의 `journey` 앞부분 재사용 또는 규칙 폴백):
  - 측정 O: `{이름}님 · 호흡이 느려지고 집중이 후반에 높아졌어요.`
  - 측정 O + 일부 지표만: 있는 지표만 나열.
  - 미착용: `{이름}님 · 측정 없이 참여 — 기록과 코멘트로 리포트가 이어져요.`
  - 신호 불량: `{이름}님 · 신호가 고르지 않아 {지표}는 확인할 수 없어요.`
- 그래프: 행마다 **미니 스파크라인 2개**(집중도·호흡, 80×24) 선택. 개인 선을 한 그래프에 겹쳐 비교하지 않는다(순위 연상 방지). 펼침 표 ‘행=참여자, 열=6지표 평균·Δ+신호 품질’(§5.E.3) 유지.
- 범위(개인 서사 미리보기): 상담사 화면 전용이며 참여자에게 전달되는 내용이 아니다. 참여자에게는 승인된 개인 리포트만 간다.
- 데이터: 참여자 목록·측정/리포트 상태는 있음. 개인 한 줄 서사는 개인 리포트 `content.eeg.narrative`(서사 문자열로 저장됨, `report_task.py:360`)의 앞 한 문장 사용 가능 = **지금 있는 값**. 분석 중이면 ‘분석 중’. 개인 6지표 평균·Δ 구조화 값은 신규 집계.

### S6. 상담사가 할 일 (회원 리포트 ‘마무리’ 대응)

- 와이어: 제목 ‘이제 할 일’. 체크리스트형 3줄, 서로 독립. 각 줄 = 한 문장 상태 + 버튼 1개. 비차단. 기다리지 않아도 목록·홈으로 나갈 수 있음.
  1. **리포트 승인**: 상태 문장 + [참여자별 결과 보기] (자동 승인 C안 반영).
  2. **진행 기록**: §5.F 안내 카드(미작성·미안내 회차에 1회만). 이후엔 작은 ‘진행 기록 남기기’ 버튼.
  3. **다음 회차**: 다음 일정 요약 + [다음 회차 보기]. 없으면 ‘예정된 다음 회차가 없어요’ + [클래스 상세].
- 문장 템플릿:
  - 승인(유예 0분, 자동 승인 켬): `리포트는 생성되는 대로 자동으로 승인돼 참여자에게 이어져요. 생성 중 {k}명 · 승인됨 {j}명.`
  - 승인(유예 {x}분): `{HH:mm}에 자동 승인될 예정이에요. 생성 중 {k}명.` + [이번 회차 보류]
  - 승인(자동 승인 끔): `검토 대기 {r}명 — 공개 코멘트를 확인하고 승인해 주세요.`
  - 데이터 없는 리포트: `측정·기록이 없어 자동 승인에서 제외된 리포트 {z}건이 있어요.`
  - 진행 기록(§5.F 문구 그대로): ‘진행 기록을 남겨두면 다음 회차를 준비할 때 오늘의 진행 내용과 관찰을 다시 볼 수 있어요. 참여자에게 전할 코멘트를 작성할 때도 참고할 수 있어요.’ [지금 남기기] [비워두기]
- 그래프: 없음. 단, 승인 줄에 가는 **진행 막대(생성 중/검토 대기/승인됨 분할)** 1개 허용(숫자와 함께).
- 약속하지 않는 것: AI 자동 반영·자동 재생성·개선 판정. 비공개 메모는 자동 초안에서 제외(결정 4).

### 하단 고정

- 면책: `WELLNESS_DISCLAIMER` 재사용(진단/치료 목적 아님).
- 보조: ‘이 요약은 상담사에게만 보여요. 참여자에게는 승인된 개인 리포트만 전달돼요.’

## 4. 문장 생성 규칙 (명상 클래스용)

### 4.1 방향 판정

- 클래스 방향은 **개인 전·후반 값의 동등 가중 평균**으로 `early`, `late`, `Δ`를 구하고, 임계는 회원 리포트와 동일: 호흡수 1회/분, 심박 3bpm, HRV 5ms, 마음 3지표 변화율 5% 미만이면 ‘유지’.
- 지표별 비교 가능 인원이 2명 미만이면 방향을 내지 않는다(P2). 혼합 집계 방향 비산출은 **정규화된 개인 값을 먼저 계산한 뒤 평균**하므로 ‘여러 사람을 한 사람으로 해석’하지 않는다.
- 개인 전·후 계산에는 기존 `build_metrics_summary`의 세그먼트(pause/resume) 동일 가중 규칙을 재사용한다.

### 4.2 어휘 사전 (판정어 제거)

| 지표 | 상승(up) | 유지 | 하락(down) |
|---|---|---|---|
| 집중도 | 집중 신호가 높아졌어요 | 집중 신호가 비슷했어요 | 집중 신호가 낮아졌어요 |
| 이완도 | 이완 신호가 높아졌어요 | 이완 신호가 비슷했어요 | 이완 신호가 낮아졌어요 |
| 감정균형도 | 정서 안정 신호가 높아졌어요 | 비슷했어요 | 낮아졌어요 |
| BPM(심박) | 심박이 빨라졌어요 | 심박이 일정했어요 | 심박이 느려졌어요 |
| 호흡 | 호흡이 빨라졌어요 | 호흡이 고르게 유지됐어요 | 호흡이 느려졌어요 |
| HRV | 심박 간격의 변화가 커졌어요 | 비슷했어요 | 심박 간격의 변화가 작아졌어요 |

- 회원 리포트 문구와의 차이: ‘차분해졌어요’, ‘깊어졌어요’, ‘기복이 있었어요’, ‘자율신경 회복이 좋았어요’, ‘긴장이 남아 있었어요’ 같은 **해석·판정이 섞인 표현은 쓰지 않는다**. 위 사전은 방향만 말한다. 서사 연결(S1·S4 소제목)에서만 ‘차분해지는 쪽으로 움직였어요’처럼 약한 맥락어를 허용한다.
- 단위: EEG는 %p/%, 호흡 회/분, 심박 bpm, HRV ms. 사용자 화면에서는 ‘SDNN’ 대신 ‘HRV(심박 간격의 변화)’ 병기. ‘점수’ ‘스코어’ ‘정규화’ ‘PPG’ ‘원천’ 단어는 본문에서 금지(`FORBIDDEN_TERMS` 재사용; 라벨의 EEG/PPG 배지는 예외).
- 길이: 지표 문장 60자 이내(`MAX_METRIC_SENTENCE_LEN`).
- 서사 생성 경로(10/23 대표님 결정으로 변경): **AI(LLM) 사용 허용.** S1 한 줄·S4 소제목 서사·지표 문장은 AI가 쓰고, 검증(금지어·입력에 없는 수치·방향 모순·결측 지표 언급)을 통과한 필드만 채택한다. 실패·타임아웃·AI 꺼짐·검증 실패 시 위 문구 사전의 **규칙 문장이 결정론적 폴백**이다. S2·S3·S5·S6 문구와 모든 숫자는 AI가 쓰지 않는다. 입력은 이름 없는 클래스 집계·상태 코드뿐이며 비공개 메모는 보내지 않는다. 상세는 [counselor-class-report.md](counselor-class-report.md) §3.

### 4.3 금지 목록 (Astra·구현 공통)

종합 점수/지수, 클래스 ‘점수’, 참여자 순위·상위·하위, ‘우수/부족/양호/불량’, ‘좋아졌어요/주의가 필요해요’, ‘개선/악화/회복’, 빨강·초록 우열 색, 이전 회차와의 우열 비교(회차 간 비교는 이번 범위 밖), 개인 선 한 그래프 겹침, 측정 1명 상태의 평균·범위, 정상 범위 띠, 효과 단정 문구.

## 5. 데이터 매핑 요약

| 섹션 | 쓰는 값 | 지금 있는 값 | 신규 집계/응답 필요 |
|---|---|---|---|
| S0 | 클래스·회차·시각·진행 시간 | ✅ | — |
| S1 | 몸/마음 추세 문장, 칩 | 개인 단위 `narrative`(문자열 저장) 존재 | 클래스 6지표 early/late/Δ/방향 → 추세 문장. **서사 입력 구조화 응답** |
| S2 | 참석·측정·리포트 대상 수 | 참석·대상 ✅ | 지표별 eligible/측정/비교 가능 인원, 신호 불량·유실 인원 분류 |
| S3 | 시간 버킷별 클래스 평균(6지표), 전반/후반 경계 | 개인 `timeline`(다운샘플) 저장은 있으나 클래스 정본 아님 | **5분 버킷 클래스 평균 시계열**(정규화·동등 가중·측정 ≥2명 구간만), 지표별 신호 불량 구간 |
| S4 | 평균·전후·Δ·개인 범위·비교 인원·유효 시간/비율 | 기존 클래스 `change`는 집중·이완·스트레스 3지표 전후만 | **6지표 공통 클래스 통계**(§5.E.2 전부), `%p` 변환, 방향 분포 건수 |
| S5 | 참여자 목록, 상태, 개인 서사 한 줄, 스파크라인 | 목록·상태·`content.eeg.narrative` ✅ | 개인 6지표 평균·Δ 구조화 값, 개인 5분 스파크라인(2지표) |
| S6 | 승인 현황, 자동 승인 정책, 진행 기록 seen 상태, 다음 회차 | 승인 현황·다음 회차 ✅ | 진행 기록 안내 seen 상태(§5.F), 정책 설정값 응답(C안) — 기결정 |

**신규 집계 우선순위(구현 시 쪼개는 기준)**

1. (필수) 클래스·개인 6지표 `early/late/Δ`·평균·개인 범위·측정/비교 인원 — S1·S4·S5 공용. 한 응답 DTO로 설계.
2. (필수) 5분 버킷 클래스 평균 시계열 — S3·S4 스파크라인 공용.
3. (필수) 상태 분류 코드: `measured / partial / single / pending / poor_signal / lost / unworn / error` — S2·상태별 문구 분기 공용(§3).
4. (선택) 방향 분포 건수(‘비교 4명 중 3명 증가’), 개인 5분 스파크라인.

공통 제약(§5.E.2에서 이어짐): 현행 `coverage_ratio`를 측정 시간으로 환산하지 않는다. 유효 시간·분모 정의는 후속 기술 설계(plan/verify)에서 고정한다. 정규화 버전이 다르면 평균하지 않는다. 모든 수치는 상담사 전용 권한으로만 조회한다.

## 6. 디자인 가이드 (Astra 전달 사항)

- 톤: 회원 리포트의 편집형 레이아웃(eyebrow 번호, 큰 제목 2줄, 인용문 느낌의 한 줄 요약)을 업무 화면에 맞게 절제. 라이트 셸(#5F0080 / #F5EDFC / #F7F4F0), 16px 카드, 본문 16/26, 최소 13px, 조작 44px.
- 섹션 사이는 카드로 분리하되 S1→S4는 **하나의 이야기로 읽히는 세로 흐름**(eyebrow 번호 01~06, 스크롤 시 좌측 목차 ‘미니 내비’는 데스크톱만).
- 그래프는 S3 대형 1개 + S4 카드당 소형 2종. 지표 식별색만 사용, 방향색 금지, 축·단위 항상 표기, 결측은 끊김.
- 시안으로 반드시 확인할 화면 키(제안): `narr-normal`, `narr-partial`, `narr-single`, `narr-poor`, `narr-lost`, `narr-unworn`, `narr-pending`, `narr-error`, `narr-zero` (§3 행과 1:1). 모바일 390 / 데스크톱 1440.
- 상담(1:1) 화면은 이 시안에서 변경하지 않는다.
- 모든 값에 ‘합성 샘플’ 표기. 실제 서버 통계 계약이 이미 있다는 인상을 주지 않는다.

## 7. 열린 항목 (구현 전 verify에서 확정)

| 항목 | 현재 제안 | 비고 |
|---|---|---|
| 흐름 그래프 구간 단위 | 5분 버킷(30분 미만 수업은 2분) | 짧은 수업에서 점이 너무 적으면 단위 축소 |
| 몸/마음 카드 순서 | 몸→마음(회원 리포트와 동일). §5.E.1 표는 진행 화면 순서(마음→몸) | 기능 영향 없음, 디자인 판단 |
| 전반/후반 vs 초·중·후 | 변화량 계산은 **전반/후반**(기존 산식). 초·중·후 3등분은 X축 보조 라벨만 | 산식과 라벨 불일치 방지 |
| 비교 건수 줄(‘4명 중 3명 증가’) | 3명 이상일 때만 | 소규모 반 식별 위험 방지 |
