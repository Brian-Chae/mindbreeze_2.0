# SDD-044 — 리포트 서사 규칙 기반 자동화 (AI 없음) + 샘플 보기 개선

> 리포트 서사 문장을 LLM 호출 없이 규칙 기반 템플릿으로 자동 생성하고,
> 샘플 보기 기능(ReportSamplePage)을 SDD-043 디자인 + 규칙 기반 서사로 개선한다.

## 1. 배경·원칙

- 리폿 문장을 매번 LLM으로 생성하면 비용·지연 부담 → **규칙 기반 템플릿으로 자동화**
- 개별 지표의 변화량(전반-후반 비교) → 방향성(↑/↓/→) → 미리 정의된 문장 템플릿 매핑
- AI 개입 없이, 결정론적으로 동일 입력 → 동일 문장

## 2. 규칙 기반 서사 설계

### 방향성 판단
| 지표 유형 | 방향 판단 기준 |
|-----------|--------------|
| 정규화 지표(집중·이완·감정) | \|변화율\| ≥ 5% → ↑/↓, 미만 → →(안정) |
| 단위 지표(호흡·심박·HRV) | \|변화량\| ≥ 단위별 임계 → ↑/↓, 미만 → → |

### 문장 템플릿 (지표 × 방향)
| 지표 | ↓(감소) | →(안정) | ↑(증가) |
|------|---------|---------|---------|
| 호흡수 | 호흡이 깊고 느려졌어요 | 호흡이 고르게 유지됐어요 | 호흡이 빨라졌어요 |
| 심박수 | 심장이 차분해졌어요 | 심박이 일정했어요 | 심박이 빨라졌어요 |
| HRV | 자율신경이 긴장 상태였어요 | 자율신경이 유지됐어요 | 자율신경 회복이 좋았어요 |
| 집중도 | 집중이 흔들렸어요 | 집중이 유지됐어요 | 집중이 깊어졌어요 |
| 이완도 | 긴장이 남아 있었어요 | 이완이 유지됐어요 | 이완이 깊어졌어요 |
| 감정안정도 | 감정 기복이 있었어요 | 감정이 유지됐어요 | 감정이 평온해졌어요 |

### 종합 여정 (몸/마음 대표 방향 조합)
- 몸(호흡↓+심박↓+HRV↑) + 마음(집중↑+이완↑+감정↑) → "몸은 점차 이완으로, 마음은 차분한 안정으로 흘렀습니다."
- 그 외 조합도 템플릿으로 정의 (이완/각성/유지 × 안정/산만/유지)

## 3. 구현 범위

### T1. 서사 생성 유틸 (규칙 기반, 순수 TS)

- 변화량 → 방향성 판단 → 문장 매핑 + 종합 여정 조합
- LLM/API 호출 없음 (결정론적)

### T2. 샘플 페이지 개선

- 섹션: 종합 여정 → 몸의 변화 → 마음의 변화 → 마무리
