# SDD-208 — 클래스 진행 화면 리디자인 (회원·상담사 · 모바일/태블릿/데스크톱)

## 목적
클래스 진행 화면이 복잡하고 메인 화면과 통일감이 없다. **한 화면(스크롤 0)** 에 핵심만 보이고, 자연 배경이 최대한 노출되며, 카메라·음성·밴드·온/오프라인 모든 경우에서 무너지지 않는 화면으로 바꾼다.

## 확정 방향 (A안)
- 다크 + 풀블리드 자연 배경 + 반투명 소프트 시트(블러 없음), 하단 도크 → 모바일 바텀 시트 / 태블릿·데스크톱 우측 시트
- 평상시 화면 = "시간 + 핵심 지표 1개(정적 링)". 채팅·6지표·소리·기기·신호는 도크에서 시트로
- 아이콘은 메인 화면과 같은 2px 아웃라인, 퍼플 `#5F0080`, Pretendard, pill 버튼
- 근거 시안: `designs/class-player-redesign/` (기획.md, tokens.css, member.html, counselor.html, 케이스.md)

## 합의된 요구 (사용자 피드백 반영)
1. 앱은 **호흡 지시·호흡 애니메이션을 제공하지 않는다**(문구·그래픽 제거). "호흡" 지표(회/분)는 실측 지표로 유지
2. 상담사 화면: **지금 보는 지표 띠**(지표명 큰 글자·지표 고유색) + 모든 타일에 지표 약칭 라벨. 띠·타일 색 일치
3. 상담사 참가자 목록: **페이지 버튼 없음**, 타일 영역만 세로 스크롤(상단 바·지표 띠·도크 고정)
4. 상담사가 카메라를 켜면 **셀프뷰(내 화면)** 표시, 참가자 타일을 가리지 않는 전용 자리
5. 회원 화면: 그룹 평균·순위·±델타·종합점수 금지(상담사 화면만 그룹 평균 허용)
6. 밴드 미착용은 오류가 아닌 정상 상태(경고색 금지), 마이크 꺼짐 = AI 기록 제외 + EEG/PPG/ACC 유지 안내
7. 모든 경우 페이지 스크롤 0, 11px 이하 글자 0, 터치 ≥44px

## 확정 결정 (2026-10-16, Brian)
1. **회원 영상은 기본 비공개**. 회원이 원하면 켜서 상담사에게 보여줄 수 있다(회원 본인 선택, 상담사가 강제로 켤 수 없음). 상담사 1:1 화면의 회원 영상 자리는 회원이 켠 경우에만 나타난다.
2. 데스크톱 도크·미디어 줄 폭은 최대 640px 유지(가운데 정렬·균등 분배).
3. 상담사 상단 바 시간 숫자(15~18px)·그룹 평균(지표 띠 안) 위치 유지.
4. 좌우 대칭·비율 규칙은 `designs/class-player-redesign/균형.md`(S1~S10, CS1~CS5, MS1~MS3)를 구현 기준으로 삼는다.

5. plan.md §5 **D1~D13은 plan의 기본값으로 진행**한다(백엔드 변경 B1~B6 미적용·프론트 대체안, 오프라인 회원 상담사 영상 PiP 제거, 진행 중 BGM 행 제외, 마이크 꺼짐 문구는 사실에 맞게 회원/상담사 분리, 본인 5분 변화 문구 허용·그룹 대비 수치 금지 등). 사용자가 이의를 제기하면 해당 항목만 변경하고 verify 문구를 갱신한다.
