## 실기기 (Galaxy Note10 SM-N971N, Android 12, build N971NKSU2HWH5, One UI 4.1(ro.build.version.oneui=40100), USB 연결)
- `adb install -r`(dev 변형 `com.looxidlabs.mindbreeze2.dev`, 기존 앱 데이터 유지) 후 실행. 기존 패키지 삭제·초기화 없음.
- **합성 패킷 100ms 주기(EEG 25샘플)** 로 서비스 시험. RECORD_AUDIO `granted=false` 상태에서 정상 동작(마이크 불필요 확인).
- 시험은 USB 충전 상태 + `dumpsys battery unplug`로 비충전 상태 모사. 완료 후 `unforce`·`battery reset` 원복, deviceidle `ACTIVE` 확인.

## 한계·'대표 실기기 필요' 항목
- 합성 소스는 앱 프로세스 내 타이머라 **실제 BLE notify가 Doze에서 지속되는지는 미검증**. 밴드 실측(30분 화면 잠금·비충전·기본 배터리 설정) 필요.
- 합성 시험은 앱이 foreground 서비스 우선순위여서 Doze 중 CPU가 유지되는 것까지만 증명(wakelock이 유지된 상태). 네트워크(Socket.IO) 면제는 미검증 — T05 연결 후.
- 프레임 값은 간이 RMS/leadoff(SPIKE). 실제 지표는 T02 Rust 코어 연동 후.
- 상담사 화면 paint ACK, native Socket.IO·HTTP uploader, Rust JNI, Keystore secure store, 토큰 갱신, BLE 권한 요청 UX는 T02/T05 인터페이스 대기(계획만).
- WebView/프로세스 kill(`am kill`, 스와이프 종료) 후 서비스 재생성·journal 이어쓰기 실기기 시험 미실시. 현재 START_NOT_STICKY.
- 서비스 생존 시험은 Activity BACK(destroy 확인은 `dumpsys` 카운트 13이 task 기록이라 불명확) 수준. 최근앱 스와이프 시험 필요.
