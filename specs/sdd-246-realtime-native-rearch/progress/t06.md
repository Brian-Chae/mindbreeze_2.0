## 위험 / 한계

1. **화면 검증 부재**: 390/1440 Playwright, Chrome wire trace 미수행. `ClassPlayerPage` 연결은 tsc/기존 시험 통과 수준이며 v2 on 의 실제 화면은 미확인.
2. **1:1 상세 이관 미완**: 시간상 `SessionDetailPage`/`ClientSessionDetailPage`·`useWaitingRoomPresence`·`useEnterClass` 등 plan §9.1 의 나머지 경로는 reducer 로 옮기지 않았다. 계획서는 이 이관을 T06 범위로 명시하므로 **T06 은 미완료**다. 이어받을 때 `useLiveV2` + `toSessionLiveMetrics` 를 그대로 쓰면 된다.
3. 손 낙관 표시(intent)는 `LiveClient.setHand` 에 있으나 현행 `raiseEntryHand` REST 경로와 아직 교체 연결하지 않았다(회원 화면은 v2 on 에서도 기존 손들기 REST 사용).
4. `ClassPlayerPage` 는 v2 on 이어도 기존 v1 훅(`useSessionLiveSocket` 등)을 계속 구동한다(회귀 0 우선). v2 회차는 서버가 v1 이벤트를 안 내므로 무해하나 v1 폴링 REST 는 남는다 → "READY 에서 REST live poll=0" 은 `LiveClient` 안에서만 성립하고 페이지 전체로는 미달성.
5. 5분 막대는 `BarAggregator` 로직만 있고 화면 컴포넌트에 연결하지 않았다. 신선도 시계(1초)는 `useLiveV2.nowMs` 가 제공.
6. `live:rendered`/paint ACK 왕복 측정, `live:clock_probe`, `capture.*` 명령 흐름은 클라이언트에 미구현.
7. 오라클 필터 경로·실측 골든(G1) 미충족은 T01/T02 기록 그대로 유지.
