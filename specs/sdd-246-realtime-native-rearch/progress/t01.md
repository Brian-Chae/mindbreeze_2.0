## 결정·발견 (후속 Task 필독)

1. **oracle 차이(숨기지 않음)**: 기존 TS 파서는 `(len-4)%size != 0` 패킷을 floor 로 일부 샘플만 받아들인다(합성 3건: EEG 3샘플, PPG 1, ACC 1). v1 계약은 `invalid_remainder`+원문 보존. T02 는 strict 를 따른다. 감독이 profile 변경으로 확정해야 한다. 공식 SDK 도 나머지를 조용히 버린다.
2. **TS 중복 처리**: `isDuplicatePacket` 은 2초 이내 역행·동일 tick 을 0샘플로 거르지만 conflict(같은 tick 다른 payload) 원문 보존은 하지 않는다 → T02 가 추가(분석 출력은 동일).
3. **앵커**: 현 웹(헤더=마지막 샘플)과 SDK(헤더=첫 샘플) 차이를 µs 로 expected 에 둘 다 기록. 펌웨어 명세/실측으로 의미 확정은 미완(D09 후속).
4. **합성 PPG**: 최종 데이터에서 SDNN 은 ~50초부터, 호흡은 ~70초부터 값이 나오고 15 breaths/min 이 재현됨. 100~110초 저품질 구간 이후 TS 가 SDNN 252.7·hr 105 로 튀는 현상(저품질 구간 RR 오염)이 oracle expected 에 포함 — 알고리즘 결함 후보이며 이식 차이로 가리지 않는다. 개선은 별도 version·골든 승인 대상.
5. **GF05**: backend `sigmoid_score` ↔ TS `sigmoidScore` 112점 + half-up 5점 정수 완전 일치. `legacy_cohort`(backend 사다리꼴, 71점)는 TS 실시간 코호트(선형)와 정의가 달라 비교 대상 아님(mode 분리).
6. **GF04 부분**: RSA 0.25Hz 합성만 포함. RR boundary·누적 59/60/61초·최소박동 threshold·flat/noise/NaN 전용 벡터는 T02 의 dsp_parity RED 작성 시 T01 소유로 추가 필요.
7. 검증 중 발견·수정한 내 오류: 합성 PPG 박동 인덱스 근사 오류(bisect 로 수정), u64 검사가 키 이름에만 의존(길이≥20 일반화), `samples` 카운터 객체 오탐(배열일 때만 누출).
