## 3. 범위와 비범위

**출시 범위:** 1:1·그룹의 입장/대기실/join/시작/종료/손들기·내리기/발언권/조용한 신호/음원 제어·동기화/실시간 지표 및 접촉·SQI. 클래스 열기·취소·대기 알림·대기열 취소/승격·그룹 집계, 채팅 활성 상태와 입장 체크인 요약도 같은 계약/snapshot에 포함한다. Socket.IO 단일 양방향 계약, Redis live 상태, DB/outbox 영속 경계, 재접속 snapshot+event, 장애 시에만 REST 폴백, native 수집 전체, 웹 WASM, 실측 패리티, raw/feature/display 보관 완결성, 구버전 이행·관측·복구 도구를 포함한다.

**HTTP 유지:** 회원가입/로그인·인증 갱신·동의 원장·정적 카탈로그/정규화 모델·미디어 토큰·presign/PUT/검증 ACK·manifest. 동의 변경이 live 자격에 미치는 결과는 outbox를 통해 같은 live 계약으로 반영한다. LiveKit 음성·영상 바이트는 WebRTC를 유지한다. 녹음·녹화 HTTP 청크 경로도 유지하되 종료 저장 회귀는 검증한다. 독립 채팅 본문/읽음·사후 리포트 진행 네임스페이스의 전면 개편은 제외한다(클래스 live 상태를 독립 수정할 수는 없다).

**비범위:** 의료 진단/새 생리 지표, 임의 알고리즘 개선, UI 전면 재디자인, HARU 제품 코드 수정, 밴드 펌웨어·자체 저장소 추가, 이미 미수신된 raw 복원, 웹 백그라운드 수집 보장, 전 플랫폼 동영상/녹음의 native 재작성. 다른 SDD의 연구 반출·보관기간 정책을 확대하지 않는다.

**물리·OS 한계:** LINK BAND 2.0에 자체 저장소가 없다. 밴드 이탈·전원/배터리 소진·BLE 꺼짐·사용자 강제 종료 중 미수신 구간은 영구 유실이다. 네트워크 단절 동안 원격 실시간 표시는 불가능하지만 수신 raw는 로컬 보관 후 재전송한다. OS 강제 회수 등 복원 시점이 불확실한 경우도 정확한 gap/unknown interval을 남긴다. 다만 정상적인 앱 백그라운드·잠금이 생긴 것 자체를 예외로 처리해 B02를 통과시킬 수 없다. 지원 프로필에서 정상 잠금만으로 목표 미달이면 출시 차단이다.

## 6. 비기능 요구와 정확한 측정 정의

다음 수치는 **설계 목표**이며 현재 달성 결과가 아니다. 정상 네트워크 시험 프로필은 RTT≤100ms, 인위 손실 0%, 업링크≥5Mbps, 실제 링크 품질/RTT 기록. 출시 기준 부하는 20명/회차·총100명/5회차이며 초과 모집을 허용하기 전 같은 게이트로 재산정한다.

## 8. 일정·확정 상태

설계 추정은 **구현·독립 QA 합계 120~165인일, 구현자3명+독립 QA1명 병행 시 구현 착수 후12~16주**다. 1~2주차에 가장 위험한 native 잠금·실시간 송신과 패리티 기준을 먼저 검증한다. 14일 이중 운용을 포함하며 스토어 외부 심사·장비/실측 자료 대기·추가 기종 인증 기간은 제외한다. G1 실패 시 재산정하며 고정 납기 약속이 아니다. 상세 Task와 합계는 Plan §10.

**대표가 결정할 열린 질문은 남기지 않는다.** D01~D11로 감독이 선택·이유·되돌림 비용을 확정했다. G1 미달이면 B안/B02 유지·출시 보류 후 재설계하며, 저장만 가능한 제품으로 자동 축소하지 않는다. 대표는 최종 G4에서 Galaxy Note10·iOS TestFlight·상담사 Chrome 실제 경험을 확인한다.
