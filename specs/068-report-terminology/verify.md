# SDD-068 구현 전 검증 계획

작성 시점: 구현 코드 변경 전. 사용자의 SDD-068 구현 지시에 따라 진행한다.

- [ ] HRV는 심박변이(심장 박동 간격의 변화), ms/bpm은 밀리초/회·분 단위로 표시한다.
- [ ] 명상 시간, 몸·마음 신호, 명상 시작(전반)·마무리(후반)로 맥락을 설명한다.
- [ ] 여섯 카드에 정의 및 명상 중 참고할 변화 방향을 상시 표시한다.
- [ ] 호흡수·심박수 하락 및 심박변이·집중도·이완도·감정안정도 상승에 개선 참고 문구를 붙인다. 반대는 주의 문구, 유지 상태는 중립 문구로 구분한다.
- [ ] 생체 신호의 변화만으로 건강·회복·실제 감정을 확정하지 않는다.
- [ ] LLM 문구의 용어도 표시 단계에서 순화하되 원본과 수치 계산은 보존한다.
- [ ] 결측/텍스트 전용 리포트에서 변화 카드나 값을 만들어내지 않는다.
- [ ] 웹/PDF가 동일 NarrativeSections를 사용한다는 기존 경로를 확인한다.
- [ ] `cd frontend && node --test tests/*.test.cjs` 통과.
- [ ] `cd frontend && npm run build` 종료 코드 0.

브라우저 실측 및 PDF 파일 출력은 자동 테스트와 별도 검증이며 수행 여부를 결과에 명시한다.
