# SDD-068 구현 계획

전달받은 구현 브리프를 승인된 구현 범위로 삼는다. 기존 수치 계산, 결측 처리, 보라·그린·크림 팔레트와 웹/PDF 공통 컴포넌트를 유지한다.

1. 기존 Node 테스트에 여섯 신호의 상승·하락·유지 해석 및 LLM 문구 순화 회귀 시나리오를 추가하고 실패를 확인한다.
2. narrative.ts에 신호 정의·해석을 공통화하고 HRV/단위와 과도한 확정 문장을 순화한다.
3. resolve-narrative.ts의 표시 문구와 요약 칩, NarrativeSections의 카드·비교 구간·설명을 개선한다.
4. 웹 보조 EEG 카드에는 실제 점수의 의미에 맞는 정의를 추가한다. 집중 안정 점수와 서사 집중도, 정서 안정 점수와 스트레스 역방향 근사는 구별한다.
5. Node 전체 테스트 및 frontend 빌드를 실행하고 summary.md에 결과와 검증 경계를 기록한다.
