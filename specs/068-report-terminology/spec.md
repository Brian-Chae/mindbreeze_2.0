# SDD-068 — 리포트 용어 순화 + 지표 설명 추가

> 다른 개발자 피드백: "구성은 좋다. 어려운 용어를 바꾸고 추가 설명을 달아달라."
> 서사형 리포트의 어려운 용어를 평이하게 바꾸고, 지표별 한 줄 정의와 방향성 해석을 추가한다.

## 1. 현황 문제
- HRV, 전반/후반, 지표, 세션 등 비전문가에게 어려운 용어 사용
- 집중도/이완도/감정안정도/심박변이 등 지표에 "무엇을 뜻하는지" 설명 없음
- 화살표(↑↓)만으로 "좋은 변화인지" 오해 가능 (예: 감정안정 ↓는 부정적으로 읽힘)

## 2. 구현 범위 (codex gpt-6-astra)
### T1. 용어 순화
- HRV → 심박변이(심장 박동 간격의 변화)
- 세션 → 명상 시간, 지표 → 몸·마음 신호
- 전반/후반 → 명상 시작(전반) / 마무리(후반) 등 맥락 명시

### T2. 지표 정의 추가
- 집중도 / 이완도 / 감정안정도 / 심박변이 각각에 한 줄 정의(무엇을 뜻하는지)를 카드 하단 또는 설명으로 추가

### T3. 방향성 해석 병기
- 화살표(↑↓) 옆에 "좋아졌어요 / 주의가 필요해요" 서술 병기 (좋은 방향 명확화)

## 3. 적용 범위
- 웹 리포트(NarrativeSections) + PDF(동일 NarrativeSections 재사용) 동시 반영

## 4. 주의
- 생체 지표의 정확성 유지, 표현만 평이하게 (허위·과장 금지)
- 서사형 기조 유지 (점수·진단 아님)
- SDNN/RMSSD 등 세부 통계 지표는 노출 최소화(심박변이로 통합)

## 5. 완료 기준
- 어려운 용어 순화 + 지표별 정의 + 방향성 해석 추가
- FE build 0 error
