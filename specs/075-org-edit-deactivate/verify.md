# SDD-075 구현 전 검증 계획

작성 시점: 2026-09-17, 애플리케이션 코드 수정 전.

## API 검증

- PATCH: 플랫폼 관리자만 가능; 없는 기관 404; If-Match 누락 428/잘못된 형식 422/구버전 412.
- name 공백/빈/null, 초과 길이, 알 수 없는 필드, verified null 거절; phone/address null 삭제, 누락 유지.
- 인증 변경 사유 필수, false→true 시각 생성, true→false 시각 제거, 같은 값은 시각 유지.
- 성공 변경마다 버전 증가 및 같은 트랜잭션 감사(행위자/대상/행위/전후/사유/시각).
- 영향 조회는 개인정보 본문 없이 계정·활성 연결·예정/진행 세션 수 및 차단 이유 제공.
- 개인 기관·활성 연결·scheduled/in_progress/paused 세션 차단. 귀속 미확정 기존 세션은 확인 필요로 차단.
- 확인값/사유 검사, 실행 시 영향 재검사, 중복 비활성화는 감사 중복 없음.
- 상태 필터 기본 운영, 비활성화 조회 가능, 재활성화 감사, 기존 데이터/계정/코드/사업자번호 보존.
- 코드 조회·가입·가입 승인·초대 재발송/수락·신규 세션/재실행에서 비활성화 차단.

## UI 검증

- 정보 수정 필드와 읽기 전용 정보 구분, 인증 변경 사유, 실패 시 입력 유지.
- 버전 충돌 안내/재조회, 성공 후 상세·목록·상담사 갱신.
- 영향 조회 오류·차단 이유·대상 이름/코드 표시, 코드 입력·사유·보존 동의 후 실행.
- 취소 기본 포커스, 처리 중 중복 방지, 미저장 변경 닫기 보호.
- 재활성화 사유 및 목록 운영/비활성화 필터.
