# SDD-205 — E2E 루프 2단계 (역할별 여정 약 25개)
## 목적
1단계 스모크(로그인·페이지 로딩)를 넘어, 각 역할이 실제로 하는 흐름을 배포 때마다 자동 확인한다.
## 결정 승계 (SDD-204)
dev 전부 자동 반영 / E2E 전용 계정 허용 / 실제 메일 발송 시나리오 제외(초대 폼은 열기만, 제출 안 함).
## 범위
- 내담자 7, 상담사 11, 기관관리자 5, 접근 통제 4, 플랫폼관리자 API 2 = 약 29개
- 데이터 생성은 'E2E-' 접두어 한정, 시나리오가 직접 삭제(잔여 0)
- 배포 후 스모크와 함께 자동 실행, 리포트에 여정 결과 포함
## 비범위
실제 메일, 라이브 수업(영상/BLE), 버그 자동 수정(3단계), 야간 탐색(4단계)
