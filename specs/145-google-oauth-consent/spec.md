# SDD-145 — Google OAuth 약관·민감정보 동의 (컴플라이언스)

## 배경

코드 리뷰 `[SEC-04] Google OAuth sev=상` 이슈 중 "신규 Google 가입 시 약관·민감정보 동의를 사용자 확인 없이 `True`로 일괄 기록"하는 문제를 해결한다.
민감정보 처리 동의는 개인정보보호법상 명시적 동의 취득이 필요하다.

## 변경

| 층 | 변경 |
|---|---|
| 백엔드 | `GoogleAuthRequest.consents` 필드 추가(선택). 신규 계정 생성 경로에서 미동의/누락 시 422 거부. 동의 항목별 실제 값 기록 |
| 프론트 | Google 로그인에 동의 체크박스 추가. 미동의 시 로그인 차단 + 안내. 동의값을 서버에 전달 |

## 동작 규칙

- **신규 Google 가입**: `consents`의 tos/privacy/sensitive 모두 `true`여야만 가입. 아니면 422.
- **기존 사용자 로그인**: `consents` 불필요(이미 동의 기록 존재).
