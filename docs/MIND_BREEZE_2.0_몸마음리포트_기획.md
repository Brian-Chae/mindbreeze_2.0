# MIND BREEZE 2.0 — 몸·마음 서사형 리포트 기획

> mind-breeze-report(1.0)의 디자인 스킴을 따르되, 점수 환원을 배제하고
> "지난 명상의 여정"을 서사 + 개별 지표 변화량으로 설명하는 리포트.
> 정규화는 표준 모델(sigmoid, SDD-036~041)을 추세 판단의 신뢰 기반으로만 사용(점수 노출 없음).

## 1. 핵심 원칙

1. **점수(종합 0~100) 없음** — 명상을 성적처럼 환원하지 않는다.
2. **서사 중심**: 종합 → 몸 → 마음 순으로 명상 여정을 설명.
3. **개별 지표는 변화량**으로만 표현 (방향성 ↑/↓ + 변화율 % 또는 ±단위).
4. **정규화는 내부 근거**: 표준 모델 sigmoid는 "추세/상태 판단"의 신뢰 기반일 뿐, 점수로 노출하지 않음.

## 2. 지표 6개 (변화량 표현)

| 축 | 지표 | 원천 | 표현 방식 |
|----|------|------|----------|
| 마음 | 집중도 | focus_index | 상대 변화율 % |
| 마음 | 이완도 | relaxation_index | 상대 변화율 % |
| 마음 | 감정안정도 | emotional_stability | 상대 변화율 % |
| 몸 | 심박수(BPM) | heart_rate | 절대 변화 ±bpm |
| 몸 | HRV | sdnn | 절대 변화 ±ms |
| 몸 | 호흡수 | respiratory_rate | 절대 변화 ±회/분 |

## 3. 리포트 섹션 구조

| 순서 | 섹션 | 내용 |
|------|------|------|
| 1 | Cover | 표지 (로고 + 클래스/유저 정보 + 신뢰도) |
| 2 | **종합 여정** | 한 문단 서사 (몸·마음이 어떻게 흘렀는지) |
| 3 | **몸의 변화** | BPM·HRV·호흡 — 방향성 + 변화량 + 추이 그래프 |
| 4 | **마음의 변화** | 집중·이완·감정 — 방향성 + 변화량 + 추이 그래프 |
| 5 | **마무리** | 다음 명상 제안 |

## 4. 변화량 계산 (전반-후반 비교)

- 세션을 절반으로 나눠 `전반 평균` vs `후반 평균`
- 정규화 지표(집중/이완/감정): `변화율 = (후반 - 전반) / 전반 × 100` → "↑ 12%"
- 단위 지표(BPM/호흡/HRV): `변화량 = 후반 - 전반` → "↓ 2.4회/분"
- 방향성: 양수 ↑ / 음수 ↓ / |변화| < 임계값이면 "유지(안정)"

## 5. 기술적 시사점

- raw 1초 feature → 표준 모델 sigmoid(내부) → 전반/후반 평균 → 변화량/방향성 → 서사 문장
- 종합 점수·가중치 제거 → 기술 난이도 하락 (정확 점수 산출 불필요)
- 기존 SDD-036~041 자산은 "추세 판단 신뢰 기반"으로 재활용

## 6. 결정 사항 (확정)

- 종합 점수 제거, 서사 + 개별 변화량으로 표현
- 방향성(↑/↓) + 변화량 표시, 그래프 추세 유지
- 디자인 스킴: mind-breeze-report(1.0) 유지

## 7. 후속 (SDD)

- 리포트 content 계약: 서사 문단 + 6지표 변화량/방향성 + 추세 timeline
- 백엔드: 전반-후반 변화량 산출 + 상태 분류(상승/하강/안정) + 서사 문장 생성(규칙/LLM)
- 프론트: 1.0 섹션 컴포넌트 이식 + 변화량/방향성 표시
