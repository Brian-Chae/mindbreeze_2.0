## 3. 깨끗한 항목 (확인한 범위에서 문제 없음)

- 가입 시 이용약관·개인정보·민감정보 3종 **분리 동의**와 서버 강제 검증, 일반·Google 가입 경로 모두 동일 적용, 미동의 시 가입 거부(`auth.py:190-220, 306-315, 870-899`); 동의 기록 저장(`models/consent.py`: 유형·버전·동의 여부·일시).
- 연구 목적 활용은 **별도 선택 동의**(기본 미동의, 불참해도 입장 가능), 동의 이벤트에 고지 버전 기록(`models/research.py` `notice_version`), 이메일·전화·이름 원문·녹음 내용은 연구 제외(`privacy-policy.ts` 제5조).
- 파기 로직 구현 존재: 원본(EEG·음성·영상·STT 원문) 종료일 기준 삭제, 비회원 PII 스크럽, 이력 테이블, dry-run 안전장치(`retention_sweep_service.py`) — 활성화만 남음.
- 마이크 오프 처리: `consent_audio=false` → `manual` 전이, STT·요약 스킵(`audio_service.py:78-88`, `stt_task.py:501-503`).
- 리포트 면책 문구 존재(PDF 포함), 점수 환원 지양 문구("건강 상태 판정이 아님", `NarrativeSections.tsx:290,299`), 낮은 신뢰도 시 AI 요약 비노출·참고용 고지(`EegQualityBanner.tsx`).
- 처리방침 페이지 공개 라우트(`/privacy`, 로그인 불필요)와 가입·녹음 모달 링크(`PrivacyPolicyLink`), 보관일 상수 `RAW_RETENTION_DAYS` 공유로 ConsentModal 문구 불일치(이전 점검서의 30일 표기) **해소됨**(`ConsentModal.tsx:5,33`).

- 비밀번호 해시(argon2, passlib), 로그 마스킹 모듈(`core/log_redaction.py`) 존재(상세는 보안 감사 범위).

## 4. 상위 10개 요약

1. **[차단] 앱 내 계정 삭제 없음** — 관리자 전용 삭제만 존재(`admin.py:276`). Apple/Google 심사 거절 사유.
2. **[차단] 처리방침에 위탁·국외이전 누락** — 음성·전사가 Gemini/OpenAI(국외)로 전송되나 방침은 제3자 제공 없음 취지.
3. **[차단] 이용약관 본문·링크 없음** — 약관 동의 체크박스만 존재, `/terms` 라우트 없음.
4. **[차단] 삭제 스위프 prod 비활성** — 방침은 90일 삭제를 약속하나 `retention_sweep_enabled=False`.
5. **[차단] 참여자 녹음 동의가 고지에 그침** — 입장 단계에서 녹음 동의/거부 선택지 없음, 호스트만 동의 모달.
6. **[높음] 개인정보 보호책임자·만 14세 미만 처리 방침/코드 부재.**
7. **[높음] 동의 철회·버전 관리·재동의 기능 없음**, 민감정보 동의가 한 줄·일괄 필수(뇌파 미사용자도 필수).
8. **[높음] 의료기기·표시광고 리스크** — "두뇌건강 리포트", 스트레스 수치 표현(법무 확인 필요), 루시 위기 응대에 공식 상담전화 안내 설계 없음.
9. **[높음] 생성형 AI 고지 불완전** — 리포트·루시에 AI 생성 표시 부재, 방침에 AI 조항 없음.
10. **[중간] 라이선스/외부 호출** — 오픈소스 고지 화면 없음, venv에 AGPL `pymupdf`(requirements 미포함, 제거 확인 필요), 외부 폰트 CDN으로 IP 전송, Stable Audio BGM 라이선스 원문 확인 필요.
