# 즉시 클래스(지금 바로 시작) 기획

- 작성일: 2026-10-21 · 상태: Phase 1 기획 + Phase 2 시안 (구현 전, Brian 승인 대기)
- 시안: `designs/instant-class/index.html`
- 관련: SDD-216 `instant-class-followup.md`(바로 지금 1회차·즉시 초대), SDD-223(진행 중 회차 바로 초대·입장)

## 1. 문제

- 준비 없이 지금 수업을 열어야 하는 경우가 있다: 갑자기 요청받은 명상 수업, 예약을 깜빡한 수업, 현장에서 바로 진행하는 체험.
- 현재도 '바로 지금'은 있지만 **4단계 마법사의 2단계 안쪽**에 숨어 있다.
  - 시작 선택 → 기본 정보(이름·방식·정원) → 일정 형태에서 '바로 지금' → (관리자는 강사) → 초대·확인 → 완료 → 진행 화면.
  - 최소 클릭 7~8회, 이름 직접 입력 필수. 급할 때 쓰기 어렵다.
- 목표: **버튼 1~2번, 10초 안에 대기실이 열리고 회원에게 코드를 알려줄 수 있다.**

## 2. 해결 방향

| 구분 | 현재 | 변경 |
|---|---|---|
| 진입 | 클래스 만들기 → 2단계에서 '바로 지금' | 홈·클래스 목록·만들기 첫 화면에 **'지금 바로 시작'** 직접 버튼 |
| 입력 | 4단계 전부 | **한 화면**. 필수 입력 없음(모두 기본값) |
| 이름 | 직접 입력 필수 | 자동 이름 `즉석 명상 · 10월 21일 오후 3:20` (수정 가능) |
| 설정 | 매번 처음부터 | **지난 즉시 클래스 설정 기억**(시간·방식·정원·LINK BAND·녹음) |
| 초대 | 만들기 전에 결정 | 선택. 열린 뒤 **코드·QR·링크**로 공유, 진행 중에도 초대(SDD-223) |
| 완료 후 | 완료 화면 → 진행 화면 이동 버튼 | 상담사 본인이면 **바로 대기실(진행 화면)**, 코드 크게 표시 |

## 3. 사용자 흐름

### 3.1 상담사(지도사) — 기본 2클릭

1. 홈/클래스 목록의 **[지금 바로 시작]** 클릭
2. 즉시 클래스 화면(한 화면, 기본값 채워짐) → **[지금 열기]** 클릭
3. 대기실(진행 화면)로 이동. 화면 상단에 클래스 코드·QR·링크 복사, '회원 초대' 버튼
4. 회원이 코드/링크/앱 알림으로 입장 → 지도사가 '수업 시작'

### 3.2 센터 관리자

- 같은 화면에 **'진행 지도사'** 선택 1개 추가(필수). 열린 뒤 진행 화면이 아니라 '회차 확인' + 코드 공유 화면으로 이동.

### 3.3 회원

- 기존 경로 그대로: 앱 알림 '지금 입장할 수 있어요' / 메일 입장 링크 / 참여 코드 입력(`/join`).

## 4. 화면 구성 (시안 대응)

| ID | 화면 | 핵심 |
|---|---|---|
| IC-01 | 진입점 | 홈 히어로·클래스 목록 헤더에 '지금 바로 시작'(주) + '새 클래스 만들기'(보조) |
| IC-02 | 시작 선택 | 기존 2카드 위에 **'지금 바로 시작해요'** 카드 추가(가장 위, 강조) |
| IC-03 | 즉시 클래스 한 화면 | 이름(자동)·소요 시간 칩(20/30/45/60분·직접)·진행 방식·더보기(정원·LINK BAND·녹음·채팅)·회원 초대(선택). 하단 [지금 열기] |
| IC-04 | 열렸어요(공유) | 코드 크게·QR·코드/링크 복사·회원 초대. 상담사는 [대기실로 들어가기] 1클릭 |
| IC-06 | 회원 초대 시트 | 탭 2개: 회원(앱 알림)·이메일(입장 링크+코드 메일). 문자·카카오톡은 유료 발송이라 제외 |
| IC-05 | 모바일 | IC-03·IC-04 세로 배치, 하단 고정 CTA |

## 5. 기본값 규칙

| 항목 | 첫 사용 | 이후 |
|---|---|---|
| 이름 | `즉석 명상 · {월일} {오전/오후 시:분}` | 동일 규칙(매번 새 시각) |
| 소요 시간 | 30분 | 지난 즉시 클래스 값 |
| 진행 방식 | 온라인 | 지난 값 |
| 정원 | 10명 | 지난 값 |
| LINK BAND | 선택(opt-in) | 지난 값 |
| 녹음/채팅 | 녹음 켬 / 채팅 끔 (일반 기본과 동일) | 지난 값 |
| 진행 지도사 | 상담사=본인, 관리자=미선택 | 관리자=지난 지도사 |

- '지난 값' 저장은 1차는 브라우저 저장(localStorage, 사용자별 키). 기기 간 공유는 필요 시 2차.
- 오프라인 선택 시 장소 주소는 필수(기존 검증 유지), 지난 주소를 채워 둔다.

## 6. 정책

- 즉시 클래스는 기존 `start_now` 계약 그대로: 1회차, 서버 현재 시각, 생성 즉시 `open`(대기실). 수업 시작·녹음은 자동 시작 안 함.
- 겹치는 일정이 있으면 차단하지 않고 경고 시트 1번 → '그대로 열기'(기존 충돌 확인 계약 재사용).
- 목록에서 즉시 클래스는 **'즉석' 칩**으로 구분. 끝난 즉시 클래스는 '지난 클래스'에 남고, '다시 열기'(같은 설정으로 즉시 클래스 생성)를 제공한다.
- 일반 정기 클래스로 전환은 하지 않는다(필요하면 '지난 클래스 그대로 시작'으로 정기 편성).
- LINK BAND 없이도 동일하게 동작.
