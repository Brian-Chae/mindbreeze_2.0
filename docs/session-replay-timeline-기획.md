# 세션 라이브 UX + AI 기록/리플레이 타임라인 — 기획 (MVP1 우선)

> Mind Breeze 핵심 기능: AI 기반 상담 기록 자동 생성 + 세션 리플레이·인사이트 코멘트.
> 기존 코드 조사 완료(2026-09-18). LiveKit·음성녹음·STT·리포트 파이프라인은 이미 존재 → 갭만 신규 개발.

## 기존 코드에 이미 있는 것 (재사용)

- LiveKit 화상: `useLiveKit.ts`, `VideoConference.tsx` (livekit-client, 카메라/마이크)
- 음성 녹음: `useAudioRecorder.ts` (MediaRecorder, 5초 청크 업로드 → `audio_chunks`)
- 음성 동의: `ConsentModal.tsx`
- 세션 라이브 페이지: `SessionLivePage.tsx` (호스트 콘솔 + 녹음/마커/LiveKit + LINK BAND)
- 내담자 모니터링: `SessionMonitorTable.tsx` (**테이블** — EEG/밴드/배터리)
- LINK BAND EEG 실시간: `useBand.ts`, EEG feature WS
- STT: `stt_task.py` (Whisper + pyannote), `transcript` API
- 세션 기록 리플레이: `SessionRecordPage.tsx`, `RecordView.tsx` (전사문 탭)
- AI 리포트: `report_task.py` (AI 요약)

## MVP1 범위 (이번에 진행)

1. **세션 시작 전 카메라/마이크 프리뷰** — 시작 버튼 → 바로 시작 X, zoom처럼 카메라/마이크 열어 상태 확인 후 시작
2. **내담자 상태 "카드" 뷰** — 기존 테이블을 카드 그리드로 전환, 카드별 상태 표시
3. **카드 선택 → 상세 뷰** — 내담자 현재 상태 + 세션 동안 상태 변화(시계열) 데이터 확인
4. **영상 녹화·저장** — 현재 음성만 저장 → 상담사 영상(전면/후면) 녹화·저장 추가 (`video` 저장 테이블/API 신설)
5. **원격 내담자 화상/음성** — LiveKit으로 원격 참여 + 모니터링 (오프라인은 상담사 카메라·마이크만 저장)

### 녹화 정책 (확정)
- 오프라인: 상담사 카메라 + 마이크만 열고 저장
- 온라인 클래스: 내담자 영상·음성은 **저장하지 않음** (상담사가 저장하지 않는다)
- 세션 종료 후: 영상 + 음성 저장됨

## MVP2 핵심 요구사항 (★ 기록 — 가장 중요)

> **리포트에서 "시간에 따른 기록"을 영상·텍스트·음성의 타임라인 기준으로 재생하고, 시간 이동을 손쉽게 하는 UX/UI가 핵심.**

- 세션 기록을 **타임라인**으로 재생 (재생/일시정지/시간 드래그 이동)
- **영상 + 텍스트(전사문) + 음성**을 시간축에 동기화하여 동시 재생
- 특정 시점(예: "내담자 집중도가 떨어진 순간", "특정 발화")으로 즉시 이동
- EEG/생체신호 변화도 타임라인 위에 겹쳐 표시 → 기록 + 영상 + 텍스트 + 음성 + 생체신호를 한 흐름으로 재생
- AI 코멘트/인사이트도 타임라인 특정 시점에 앵커링

## 구현 순서
1. MVP1 (세션 라이브 UX + 카드 + 영상 녹화) → 기획 → SDD → 구현
2. MVP2 (타임라인 재생 UX/UI) → MVP1 완료 후 별도 기획
