## 상(상) 5건 — 본문 상세

### 1. EEG-RAW-02 — EEG 원시 데이터 ack 검증·완료 마커 부재 📊
- **현상**: `ack_upload()`가 클라이언트가 보낸 chunk_id 목록만으로 `upload_status='uploaded'`를 확정. S3 객체 존재(HEAD)·크기·체크섬·청크 연속성(누락) 중 어느 것도 검증하지 않음.
- **근거**: `eeg_raw_service.py:155-190`(checksum/size는 '값 있으면 갱신'만, uploaded 무조건 설정) · `record.py:159-160`(failed 상태 미사용).
- **영향**: 실제 업로드 실패해도 'uploaded'로 마킹 → EEG 데이터 조용히 유실.
- **해결**: ack 시 S3 HEAD 검증 + 크기/체크섬 대조, 실패 시 failed 마킹. 공수 1일.

### 2. EEG-RAW-01 — S3 presigned PUT 실패 시 스텁 URL 폴백 📊
- **현상**: `generate_presigned_put()`이 자격증명 미설정뿐 아니라 boto3 서명 실패(모든 예외) 시에도 정상 URL과 구분 불가능한 스텁 URL로 폴백. 클라이언트가 이를 실제 PUT URL로 받아 업로드해도 저장 안 됨.
- **근거**: `storage_service.py:34-56`(`except Exception → _stub_url`) · `:20-21`(_STUB_HOST).
- **영향**: prod에서 자격증명 오류 시 조용히 전체 EEG 업로드 유실.
- **해결**: 자격증명 미설정은 스텁 허용하되, 서명 실패는 예외 전파(500)로 클라이언트가 실패 인지. 공수 0.5일.

### 3. INFRA-01 — 데이터 export 큐 소비 워커 미설치 🚪
- **현상**: SDD-071 export 태스크가 라우팅되는 `exports` 큐를 소비하는 워커가 dev 배포에 설치되지 않아 export 요청이 소비자 없이 영구 pending.
- **근거**: `deploy-dev.yml:58-75`(tar에 mindbreeze-export-worker/beat.service 미포함) · `:143-155`(worker/email-worker만 설치) · `celery_app.py:26-29`(task_routes → 'exports') · `data-export-운영.md:15`(이미 문서화된 미해결 이슈).
- **영향**: 데이터 export 기능 dev에서 동작 안 함.
- **해결**: deploy-dev.yml에 export-worker(및 export-beat) 설치·재시작 추가. 공수 0.5일.

### 4. INFRA-06 — 시크릿 평문 커밋 🔐
- **현상**: `backend/.env`에 실제 시크릿(RESEND_API_KEY·SECRET_KEY·AWS_* 값)이 평문 커밋·추적됨.
- **근거**: `git ls-files` → backend/.env 추적됨 · 루트 `.gitignore:7` '.env'(이미 추적돼 무시 안 됨).
- **영향**: SECRET_KEY 노출 시 세션 토큰 위조 가능, Resend/AWS 키 유출.
- **해결**: `git rm --cached backend/.env` + .gitignore 재확인 + **시크릿 순환**(RESEND_API_KEY·SECRET_KEY 재발급). 시크릿 순환은 사용자 확인 필요. 공수 0.5일.

### 5. EEG-QRY-01 — EEG 조회 created_at 인덱스 부재 🐢
- **현상**: `latest_feature_window()`·`feature_windows_chronological()`이 ORDER BY created_at인데 인덱스는 (session_id,participant_id,window_index)만 존재 → 대용량 세션 전체 스캔.
- **근거**: `eeg_query.py:71-83,102-117` · `eeg_feature.py:34-37` · 마이그레이션 `c1d2e3f40288:40-49`.
- **영향**: 그룹 세션 실시간 집계·리포트 생성 지연.
- **해결**: (session_id, participant_id, created_at) 인덱스 추가 alembic 마이그레이션. 공수 0.5일.
