## 중(중) 27건 · 하(하) 17건 — 부록

> 상세는 `specs/` 조사 원본(mb2-functional-issues.json) 참조. 대표 항목:

**중(중) 대표:**
- 상담사 비공개 메모 `update_memo`가 저장 없이 성공 응답(no-op)
- 본인 비밀번호 재설정이 직전 3개 재사용 금지 미적용
- 내담자 step4 매칭이 ended 링크 재활성화 안 함
- 개인 상담사 반려 시 고아 계정/기관 잔존 → 재신청 영구 차단
- client 리포트 생성이 participant_id 미구분(그룹 세션 오귀속)
- 클래스 코드 참여 시 정원 검사·대기열 처리 없음
- 리포트 비동기 생성 시 완료 메일 자동 발송 누락
- WS 다중 세션 join 시 이전 룸 미이탈
- 채팅 멀티탭 시 먼저 탭 차단
- 리포트/내담자 목록 서버 페이지네이션 위 필터·검색·정렬 누락
- 내담자 상세 '입장하기' 버튼 access_code null 시 무동작
- 기관 관리자 판정·가입 신청이 membership 대신 org_id 미러 사용(다중 소속 오류)

**하(하) 대표:**
- birth_date 미래 날짜 허용
- 초대 조회가 만료·사용 토큰도 상담사 정보 노출
- 리마인더 이메일 HTML 본문 미사용(평문 발송)
- 영상 API session_id 형식 오류 시 500
- 졸음 플래그 산출 복붙 오류(가드가 잘못된 지표 검사)
- HRV 지표 정의 불일치(상담사 rmssd vs 회원 sdnn)
- 로그인 기존 사용자도 가입 동의 매번 강제
