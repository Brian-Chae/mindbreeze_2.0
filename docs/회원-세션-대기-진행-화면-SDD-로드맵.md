## 처리 규칙 (Brian 합의)

1. **한 번에 하나의 SDD만** — 완료(요약·테스트) 후 다음 SDD 착수.
2. 각 SDD는 7-Stage(①Spec→②Plan→③Verify→④Implement→⑤Test→⑥Summary→⑦Review)를 거친다.
3. Stage ③(Verify)는 구현 전 필수 게이트. 승인 후 Stage ④~⑥ 연속 진행.
4. `specs/NNN/` 에 spec/plan/verify/summary 4종 문서 완비.
5. 커밋 태그: `feat(sdd-NNN):` / `fix(sdd-NNN):`.
