# 실기기 검증 체크리스트

> 자동화 테스트(vitest/pytest)로 커버하지 못하는 영역. 출시 전 실기기로 수동 검증한다.
> 기준: dev.mindbreeze.looxidlabs.com (최신 develop 반영)

## 1. LINK BAND · EEG (가장 중요)

- [ ] Chrome/Edge에서 LINK BAND 2.0 페어링 → 대기실 "링크밴드" 탭에서 연결
- [ ] 250Hz Raw 스트리밍 시작, 6개 지표(집중도·이완도·정서·BPM·호흡·HRV) 값 표시
- [ ] 접촉불량(lead_off) 발생 시 → 복구 절차 3단계 안내 모달 표시
- [ ] 밴드 착용 중 BLE 끊김 → 복구 후 재연결(전역 singleton), 해당 구간 유실 확인
- [ ] 밴드 미착용 상태로도 입장·AI 기록·리포트 정상 동작(선택적 사용)
- [ ] Safari/Firefox 접속 시 "Web Bluetooth 미지원" 안내 + 밴드 없이 진행 가능

## 2. 오디오 · 비디오 (LiveKit)

- [ ] 온라인 1:1 — 상담사↔회원 카메라·마이크 양방향 송수신
- [ ] 온라인 그룹(≤20) — 기본 뮤트 + [손 들기] → 발언권 부여 시 카메라·마이크 켜짐
- [ ] 오프라인 — 상담사 영상 미표시(또는 수신 전용), 하울링 없음
- [ ] 상담사 화상 미시작 시 — 5회 재시도 후 수동 "영상 다시 시도" 버튼 노출
- [ ] 스피커 기본값 — 온라인=ON / 오프라인=OFF 계약 준수

## 3. 세션 라이프사이클

- [ ] 상담사 클래스 시작 → 회원 대기 화면이 자동으로 라이브 전환(WS, 폴링 지연 없음)
- [ ] 종료 → 회원 화면 종료 + 상담사·회원 리포트 자동 생성
- [ ] 종료 화면 — 리포트 이메일 OTP + 인증코드 재발송 + 3단계 스텝퍼
- [ ] 종료/이탈 버튼 → 확인 모달 후 이탈
- [ ] 중도 입장 시에도 3단계 준비(설문·밴드·기기) 강제 유지

## 4. 다중 참여자 부하

- [ ] 그룹 클래스 10명 동시 입장 — 대기실 인원 카운트 수렴(15초 heartbeat)
- [ ] 20명 이상 오프라인 그룹 — 상담사 영상 타일 자동 숨김
- [ ] 동시 EEG 스트리밍 5명 이상 — 지표/추이 그래프 갱신 지연 없음
- [ ] WS 재연결(네트워크 절단) — 복구 후 지표·화면 상태 재동기화

## 5. 리포트 · 데이터

- [ ] 세션 종료 → 리포트 PDF 다운로드·이메일 발송(Celery email worker 구동 확인)
- [ ] EEG 미측정 세션 — 상담사 코멘트 + AI 초안 자동 발송
- [ ] 뇌파 데이터 + 상담 내용 접근 제어(상담사/내담자 권한 분리)

## 6. 디바이스 · 반응형

- [ ] 노트북 1024~1124px 폭 — 진행 화면 3열 잘림 없음(단일 열 전환)
- [ ] 모바일 — 대기실 "이름 → 입장" 순서, 지표 현재값 표시
- [ ] 키보드만으로 조작 — 탭/방향키/Enter로 대기실·진행 화면·모달 전체 내비게이션
- [ ] 스크린리더 — 미터·디바이스 상태가 초당 낭독되지 않고 상태 전이만 안내
