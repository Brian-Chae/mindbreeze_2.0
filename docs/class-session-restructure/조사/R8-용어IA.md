2. 가장 큰 사용자 체감 불일치는 **같은 화면 흐름에서 `클래스`(탭·카드)와 `세션`(알림 센터 라벨 `notification-format.ts:11-31`, 푸시/인앱 제목 `세션이 취소되었습니다` 등, 리포트 이메일 제목 `세션 리포트가 도착했습니다`)이 섞이는 것**이다. 이번 개편에서 영역별 용어 사전 하나로 모으는 것이 가장 효과가 크다.
3. 사이드바·하단 탭·E2E·가드 테스트가 **라벨 문자열에 직접 의존**(`label === '클래스'` 3곳, `class-flow-shell-terms.test.ts`, `BANNED_COPY`)하므로 라벨 변경 전에 키 기반으로 바꾸는 선행 작업이 필요하다.

### 4.4 호칭(진행자) 문제 — 새로 드러난 항목
- 클래스·회원 화면의 진행자 호칭이 **전부 `상담사`**: 프론트 리터럴 205건/81파일, 그중 `components/class`·`components/client`·`pages/client`·`pages/sessions` 78건 (예: `상담사가 클래스를 시작했어요` `StartedSheet.tsx`, `상담사에게 클래스를 신청해 보세요` `ClientHomePage.tsx:390`, `상담사가 클래스를 만들면 알려드려요` `ClassHero.tsx`).
- 명상 지도사가 쓰는 제품에서 `상담사` 는 맞지 않는다. `지도사` 는 마케팅·시안 페이지(`pages/design/*` 20건)에서만 쓰이고, 앱 화면에는 0건, `강사` 는 0건(R9 의 데이터 용어 "강사"와 화면 용어가 다름).
- 기본값: **명상 영역 화면은 `지도사`**, 상담 영역은 `상담사`, 데이터·권한 문서는 `강사`. 한 계정이 두 영역을 쓰는 경우 호칭은 **그 화면의 영역**을 따른다(계정 칭호가 아니라 화면 영역 기준). `백엔드 상담사` 문구 707줄 중 사용자 노출분은 별도 집계 필요(`미확인`).
- 영향: 같은 컴포넌트(`ClassHero`, `EndView`, `StartedSheet`, `NoticeStepView` …)가 두 영역에 공유되므로 호칭도 용어 사전의 키가 된다.

### 4.6 영역별로 갈려야 하는 문구 / 공유 컴포넌트
- **영역에 따라 갈리는 것**: 진행 컨트롤·확인 시트·상태 안내·알림·메일·리포트 제목·마법사 전체·목록/상세 제목·호칭. 갈리지 않는 것: 입장 절차 문구(`입장하기`, 코드 확인, 개인정보 입력), 밴드·기기 점검, 오류 일반 문구, 법적 고지.
- **공유 컴포넌트** 후보(R3 §6.1·6.2 재사용 판정과 일치): `ClassHero`, `ClassActionSheet`, `MemberStateScreen`, `EndingScreen`, `LeaveCloseSheet`, `NoticeStepView`, `EndView`, `StartedSheet`, `WaitStartView`, `enter-action.ts`, `host-state-model.ts`, `host-start-model.ts`. → 컴포넌트에 `area` prop(또는 모델 함수 인자)을 추가하고 문구는 사전에서 읽는다(S 137건 중 상위 12파일이 80건=58%: `enter-action.ts` 12, `host-shell-data.ts` 10, `ClassPlayerPage.tsx` 9, `host-state-model.ts` 8, `HostClassListView.tsx` 6, `MemberStateScreen.tsx` 6, `LeaveGuardModal.tsx` 6, `ClientHomePage.tsx` 6, `SessionRecordPage.tsx` 5, `EndingScreen.tsx` 4, `shell-data.ts` 4, `ClassActionSheet.tsx` 4 — 공유 컴포넌트 후보 목록과 겹치는 파일을 먼저 사전화하면 절반 이상이 한 번에 정리됨).
- **가드 분리**: `BANNED_COPY`(`e2e/class-flow/lib.mjs:272`)를 `BANNED_COMMON` + 영역 정규식으로 분리: 명상 `세션|수업|오픈`, 상담 `클래스|수업|오픈|(?<!상담 )세션`. `class-flow-shell-terms.test.ts` 의 SWEPT 경로(10개)는 영역 화면까지 확장하고, 상담 화면에서는 `상담 세션`만 허용하도록 조건 추가. `selftest.mjs:122` 의 금지어 샘플 `세션` 은 명상 영역 기준으로 유지.
