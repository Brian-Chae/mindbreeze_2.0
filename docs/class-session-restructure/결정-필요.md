> 2026-10-17 · `기획.md` 와 짝. **비즈니스·정책 결정만** 담는다. 기술 선택(테이블 구조, 제약 방식, 롤링 윈도우, API 형태 등)은 모두 기본값으로 `기획.md` §5 에 반영했고 여기에 넣지 않았다.
> 이미 확정된 것은 넣지 않았다: 클래스=프로그램/세션=회차 · 결석·보강·중간 합류·이탈 · 고정형 + 정기형 · 기존 단회차 → 클래스 1 + 세션 1 · 명상 클래스/상담 분리 · 모든 사용자에게 두 메뉴 오픈(**기관 단위 노출 설정은 삭제**) · **비회원 내담자 상담 허용(확정, 항목에서 제외)** · **상담 종결 + 데이터 보관(확정 — 개념 여부는 제외, 보관 기간 숫자와 범위만 남김)**.
> 답하는 방법: 기본값대로 가도 되면 `D-nn 기본값`이라고만 하면 된다. 기본값이 근거 없는 임의값이 아닌 이유는 각 항목의 "영향"과 조사 문서(`조사/R*`)에 있다.

## 출시 순서 변경에 따른 적용 (2026-10-19)

- 클래스 우선 출시: Phase 0~5 + Phase 8-A. 상담 Phase 6·7 전용 결정은 후속 업데이트 착수 시 처리하며 클래스 출시를 차단하지 않는다. 최신 순서는 `기획.md`의 「출시 순서 조정」을 따른다.
- `D-64`의 Phase 2 상담 메뉴 노출은 기존 구현 이력이다. **클래스 첫 출시에서 상담 메뉴·직접 URL·생성 유형·알림 진입점을 공개할지는 별도 출시 결정**으로 남긴다. 이번 순서 변경만으로 기존 화면 제거·API 차단을 수행하지 않는다.
- `D-37` 상담 자동 승인 정책은 Phase 6에서 확정한다. 다만 공유 설정이 상담에도 영향을 주는 경우 클래스 출시 검증에서 공개 범위에 맞는 격리를 확인한다.
- `D-16` 비회원 클래스 장기 참여와 클래스 동의·출석·리포트 권한 결정은 Phase 4~5 범위에 유지한다. 비회원 상담 연기를 이유로 함께 미루지 않는다.
- 아래 원안의 Phase 0~2 결정 표는 당시 착수 이력이다. 완료된 SDD의 결정·검증 결과가 우선하며 기존 승인을 다시 요구하지 않는다.
