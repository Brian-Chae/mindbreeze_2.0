# [MB261024][FIX] 알림 세부 설정 항목별 켜기·끄기

## 문제
- 설정 > 알림에서 묶음 스위치를 누르면 뜨는 화면이 항목 목록만 보여 주고 항목별로 바꿀 수 없었다.
- 대화상자가 화면 전환 효과(transform) 안에 있어 하단 메뉴 밑에 깔렸다(실기기 캡처).

## 수정 (`frontend/src/components/settings/notification-groups.tsx`)
- 이메일·인앱 행에 `세부 설정 n/m` 버튼 추가 → 현재 선택으로 대화상자 열기.
- 대화상자: 항목마다 스위치 + 맨 위 '전체' 스위치(일부 상태 표시). 적용 전에는 저장하지 않음.
- 묶음 스위치로 열면 기존처럼 전 항목을 켜기/끄기로 채운 상태로 시작(항목별 조정 가능).
- 적용 시 그 묶음 항목만 전송(다른 묶음·채널·push 보존), 바뀐 것 없으면 저장 안 함.
- 대화상자를 `createPortal(document.body)`로 띄워 하단 메뉴 위에 표시.
