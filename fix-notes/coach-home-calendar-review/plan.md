# 코치 홈 월간 달력 리뷰
2026-11-19 · 구현 전 검토 · 기준: before-full/empty-{1440,1280,390}-{page,card}.png

1. **비율·밀도·레일 균형**: 현재 1440/1280 캡처 날짜 버튼은 64×64px. 전달받은 약 140px 높이는 현재 코드에서 재현되지 않는다. 5주 달력이 목록 위 공간을 많이 차지하므로 데스크톱 행 56px, 모바일 48px로 명시한다. 회차 목록 길이는 데이터에 따라 자연스럽게 늘어나게 두며 레일에 맞춰 강제 자르지 않는다.
2. **정렬**: before-full-1440-card.png에서 요일과 숫자의 중심이 어긋난다. aspect-ratio와 max-height가 버튼 너비까지 64px로 제한하여 가변 열 안 왼쪽에 붙는다. 정사각 비율을 없애고 열 전체 너비로 확장한다. 월 이동 가운데·오늘 오른쪽은 유지한다.
3. **상태 체계·주변 조화**: 같은 캡처의 19일에 보라 원+사각 선택 배경/테두리가 겹친다. 모든 날짜 숫자를 32px 원형 영역으로 통일하고 오늘=채운 원, 선택=원 테두리, hover=원 배경으로 구분한다. 동시 상태는 채운 원+바깥 링. 카드의 기존 라운드/여백은 유지한다.
4. **색 대비**: 일요일 헤더만 빨강이고 날짜는 동일 검정이다. 토·일 헤더와 날짜를 일관되게 구분하고, 회차 점은 보라/흐린 보라로 유지하되 지난 점은 조금 진하게 한다. 색에만 의존하지 않도록 날짜 접근성 이름의 회차 건수를 유지한다.
5. **모바일·접근성**: 월 화살표 너비 36px, 날짜 높이가 폭에 종속된다. 화살표 44px, 날짜 48px 높이와 균등 너비로 정리한다. role=grid 안에 row 없이 gridcell 버튼이 놓였고 aria-pressed가 gridcell 역할에 결합되어 있다. 복잡한 키보드 grid 계약을 추가하지 않고 이름 있는 group 안 네이티브 버튼을 사용해 Tab/Enter/Space와 눌림 상태를 보존한다.

## 구현 순서
1. CSS 달력 영역의 비율/정렬/상태 규칙 정리.
2. 네이티브 버튼 의미 유지. 데이터/API/목록 로직 불변.
3. 홈/달력 및 전체 테스트, 타입/린트, 6개 화면 캡처, 독립 리뷰.
