# 홈 레일 카드 수정 계획

요청에서 지정한 글자 크기·터치 영역·카드 형태를 승인된 수정 기준으로 사용한다.

## 원인
- home-card-parity.css의 패널 공통 min-height:200px.
- 회원 알림 카드 flex-1과 빈 상태 py-8.
- 두 홈 행의 12~13px 글자와 32px 대화 아바타.

## 순서
1. 합성 데이터 Chrome 전 화면·계산 스타일 기록.
2. 카드별 높이를 내용에 맞추고 두 홈 행 규격 수정.
3. 기존 이동·읽음·미읽음 개수·조건부 렌더링 회귀 검증.
4. 390/1440 Chrome 후 화면, 타입·eslint·빌드·vitest, 별도 리뷰.
5. 한글 커밋·브랜치 푸시·develop 대상 PR.
