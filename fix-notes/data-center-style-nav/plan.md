# 데이터 센터 스타일 수정 계획

사용자가 스타일 통일·검증·커밋·푸시·PR을 명시 승인한 Fix 작업이다.

1. 명상 클래스 목록·상세 및 Tailwind preset을 기준으로 버튼·탭·칩·카드·폼 스타일을 조사한다.
2. 원인: 데이터 센터 일반 hover 선택자가 primary hover보다 우선하여 밝은 배경과 흰 글자가 결합한다. 화면·측정·다운로드 CSS의 중복 버튼 규칙과 opacity 기반 disabled를 공통 controls.css로 대체한다.
3. 클래스와 같은 Tailwind 유틸리티(@apply), 실제 preset 보라 색, 12px 버튼/입력 모서리, 16px 카드, 밑줄 탭, 흰 목록/테이블 표면을 적용한다. disabled는 불투명 회색 바탕·진한 회색 글자, focus-visible은 보라 외곽선으로 표시한다.
4. 다운로드 대화상자·작업의 재인증 로직과 라벨은 수정하지 않는다. CSS만 적용한다.
5. 별도 검증자가 Chrome 1440/390 화면 및 hover를 캡처하고 실제 계산 스타일 대비를 검증한다. 집중/전체 vitest, 타입, 빌드, 변경 파일 lint를 수행한다.
