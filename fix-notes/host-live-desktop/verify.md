# 구현 전 검증 기준

- 첫 이벤트 0ms, 같은 토스트 갱신, 6초 기본/갱신 최소3초/최초10초 상한, following4초, 쿨다운 없음.
- 이름/현재 집계, 손취소/TTL/중복/재연결, 동시 주제, pause/dismiss 검증.
- 5개 영역 동일 경계, 신호 줄 도크 위, 도크4개, 체크인은 수업 상태 안.
- 셀프뷰 기존 높이 유지와 폭=높이*16/9, placeholder/영상 동일. 모바일 배너 최소폭/넘침 검증.
- Chrome 390/768/1280/1440에서 기본/손1/손여럿/quiet/status PNG+측정 JSON, JS 오류와 가로넘침0.
- 지정 회귀 tests, tsc, 변경 파일 eslint, build. 실제 서버/장치 통합 증거와 구별.

사용자가 요구와 검증을 명시적으로 승인하여 구현 요청한 기준이다.
