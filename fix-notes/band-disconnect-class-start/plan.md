# 수업 시작 밴드 연결 수정 계획

- 사용자 요청으로 원인 조사, 최소 수정, 검증, 커밋·push·PR까지 승인된 Fix 작업이다. 서버·DB·환경 파일 접근과 배포는 하지 않는다.
- #70 캐시는 정확한 네 가지 공통 목록만 허용한다. 실시간 GET은 기존 비캐시 동작을 회귀 테스트로 고정한다.
- 대기 중 소유자 없는 BLE 단절 후 수업 시작 인계: 캐시된 기존 기기만 자동 복구하고 신규 사용자·수동 해제는 연결하지 않는다. 정상 인계 시 물리 연결을 유지한다.
- 연결 중/재연결 중 session-live 소켓을 재생성하는 결함: 기존 객체와 구독자를 유지한다. 명시적 disconnect 함수는 계속 객체를 폐기한다.
- 테스트 먼저 RED → 최소 수정 → GREEN. 구현은 주 에이전트, 독립 검토는 읽기 전용 에이전트가 담당한다. 같은 워크트리에서 병렬 수정하지 않는다.
- 수정 소유: useBand.ts, lib/socket.ts, 관련 신규/기존 테스트, 이 fix-notes 폴더. PR #72의 보고서/요약 파일은 수정하지 않는다.
- 추가 재현 대상: 네이티브 복귀 시 선택적 배터리 read 실패만으로 정상 BLE를 강제 해제한다. OS 연결 목록으로 단절을 확인한 경우에만 정리하고, 검증 중 새 연결이 생기면 이전 검증을 폐기한다. 소유 파일에 capacitor-ble-adapter.ts와 해당 테스트 추가.
- 정상 연결 인계 때 connected→connecting으로 강등되어 회원 UI가 lost로 표시되는 결함도 재현한다. 이미 연결된 기기는 스트림 인계 동안 connected를 유지한다.
