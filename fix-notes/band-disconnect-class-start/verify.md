# 구현 전 검증 계획

작성 시점: 구현 전. 사용자 지시에 따라 아래 테스트를 연속 수행한다.

- [x] 준비 화면 연결→언마운트→수업 마운트에서 scan/connect/disconnect 추가 호출 없이 연결을 인계한다.
- [x] 대기 중 실제 단절 후 수업 마운트에서 기존 기기로 자동 복구한다. 실패하면 백오프를 유지한다.
- [x] 한 번도 연결하지 않았거나 수동 해제한 경우 자동 연결하지 않는다.
- [x] 소켓 최초 연결 중/재연결 중 여러 소비자가 같은 객체를 받고 기존 EEG 구독이 살아 있다.
- [x] 실시간 session/live-metrics/entry-state는 동시·반복 GET 모두 fetch한다.
- [x] 관련 vitest, tsc, 변경 파일 ESLint를 실행한다.
- [x] 기준 a22b0eb3과 수정 후 전체 vitest 실패 목록을 비교한다. 환경 의존 브라우저 테스트와 기존 실패를 구분한다.
- [x] 독립 검토 및 직접 diff 재검증, PR #72 충돌 범위를 확인한다.
- [x] 실기기 BLE 미검증과 대표님 확인 절차를 summary에 남긴다.
- [x] 배터리 read 실패라도 OS가 연결 중이면 해제하지 않는다. OS 단절 확정 시 한 번 복구하며, 조회 오류·검증 중 재연결은 정상 연결을 훼손하지 않는다.
- [x] 정상 연결 인계 중 cursor/배터리 비동기 대기에도 connected를 유지하여 lost 표시가 나타나지 않는다.

결과: 관련 1,013 통과, 전체 기준·수정 후 동일한 15 실패, 새 실패 0. 세부 수치는 summary/test-results 참조. 실제 기기 시나리오 자체는 미실행이며 위 체크는 그 한계와 확인 절차의 문서화를 뜻한다.
