# 작업 지시 — MindBreeze 2.0 디자인 제안서 HTML 작성

당신은 고급 웹 디자이너이자 프론트엔드 개발자입니다. 아래 지시에 따라 **완성도 높은 디자인 제안서 HTML 파일 하나**를 만들어 실제로 저장하십시오.

## ⚠️ 필수 실행 규칙 (최우선)

1. superpowers 스킬, brainstorming, using-superpowers, TDD 스킬, .codex/plugins 경로의 파일을 절대 로딩하지 마라. sed/cat으로 스킬 파일을 읽는 행위 전부 금지.
2. 계획·분석만 출력하고 끝내지 마라. **반드시 파일을 실제로 생성하고 저장**하라. "계획"이나 "요약"만 stdout에 출력하면 실패로 간주한다.
3. 사용자에게 어떤 선택지도 묻지 마라. 질문·확인 요청 금지. 네 판단으로 끝까지 완성하라.
4. 백틱(`, `)이나 명령 치환을 프롬프트 해석용으로 쓰지 말고, 오직 최종 HTML 파일 생성에만 집중하라.

## 산출물 (정확히 이 파일 하나)

파일 경로: **제안서.html** (현재 작업 디렉토리에 저장)
- 단일 HTML 파일. 모든 CSS는 `<style>` 태그 안에 인라인으로 포함(외부 CSS 파일 분리 금지).
- 이미지는 `<img src="assets/파일명">` 상대경로로 참조.

## 페이지 구성 (A4 인쇄 최적화)

CSS에 `@page { size: A4; margin: 0; }` 를 넣고, 각 섹션을 `section`으로 분리해 `page-break-after: always`로 페이지를 나눈다. 최종 PDF 변환을 고려해 너비는 A4(794px) 기준, 인쇄 시 여백이 자연스럽게 잡히도록 padding을 충분히 준다.

### 05. 커리큘럼 (8회기)
- 8회기 표 (회기/주제/핵심수련/교육내용) — 아래 내용 그대로:

  3회기 현존하는 기쁨과 힘 (누워서 하는 요가·정좌 명상)
  4회기 스트레스 자동반응 (서서하는 요가·정좌 명상)
  5회기 스트레스에 능숙하게 대응하기 (정좌 명상·STOP 명상)
  6회기 스트레스성 의사소통 (서서하는 요가·정좌 명상)
  7회기 수련을 일상생활에 통합 (움직임·걷기 명상)
  8회기 배운 것을 지속하기 (바디스캔·정좌 명상)
