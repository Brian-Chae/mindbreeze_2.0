## 1. 디자인 방향성 요약

상담사 화면이 18회 루프를 거쳐 "완성"에 도달한 이유는 화려함이 아니라 **층위(layering)와 지표 표현의 생명력**이다. 배경 `#12081C` 위에 `#1d1027`·`#21132b`·`radial(#382047→#1b1025)` 세 단계의 보라 틴트 서피스를 쌓고, 그 위에 `#ffffff1A` 보더와 `#ffffff06` 버튼 필을 얹어 "검정에 흰색 알파를 섞은 평면"이 아닌 **깊이 있는 다크 캔버스**를 만들었다. 지표는 숫자 카드가 아니라 SVG 아크 링(퍼플→라벤더 그라디언트, round cap) + 중앙 대형 숫자 + 하단 막대 추이 + 증감 라벨의 4요소 복합체로, 값이 바뀔 때 "살아 있다"는 감각을 준다. 회원 화면이 "썩 마음에 들지 않는" 이유는 이 두 가지가 모두 없기 때문이다 — 배경이 순수 검정 `#060507`이고, 6지표가 선택 1개만 퍼플인 평면 숫자 카드 3×2다.

따라서 **이식 대상은 (a) 보라 틴트 레이어드 토큰 체계, (b) 다이얼+추이+증감 지표 복합체, (c) MIND/BODY 섹션 구분, (d) 타이포 계층(값 `font-weight:500` + `tabular-nums` + `letter-spacing:-1px`), (e) 간격·반경 그리드(radius 12px, gap 8/10/12/16/20)** 다섯 가지다. 이식하지 않는 것은 **밀도**다. 상담사 화면의 `hcp-roster`·`hcp-people`·`hcp-table-wrap`·집계 헤더·발언권 토글은 관제용이고, 회원 화면은 명상 중인 당사자가 본다.

회원 맥락에 맞춘 조정의 핵이 세 가지다. 첫째, **다이얼은 상담사보다 크고 수는 적게 보인다**. 상담사는 68px 다이얼 6개를 한 화면에 눌러 담지만, 회원은 6개 중 **선택된 1개를 84px 히어로 다이얼**로, 나머지 5개는 **44px 서브 다이얼**로 두어 시선이 한 곳에 머문다(선택은 기존 `selectedKey` 상태 그대로 재사용). 둘째, **그룹 평균 틱·범위 밴드는 전부 제거**한다. 상담사 화면의 `hcp-tick`·`hcp-range-band`·`hcp-average-line`은 비교 장치이고, 회원 화면에는 개인 점수·순위 비노출 원칙상 비교 기준을 띄울 수 없다. 대신 **본인의 세션 시작 구간 평균(베이스라인)**을 점선으로 깔아 "나 대비"만 보여준다. 셋째, **증감 라벨은 상담사의 "3분대비"가 아니라 "5분간"** — 현재 `MetricBarChart.computeTrend`가 이미 12×25초 = 5분 구간의 첫–끝 델타를 계산하므로 문구만 통일한다(`+32 · 5분간`).

움직임도 차분함 쪽으로 조정한다. 상담사 화면의 아크/숫자 `transition:color 300ms`를 회원 화면에서는 **아크 `stroke-dasharray` 1200ms ease-out**, 숫자는 **값 자체가 25초 구간 평균으로 스로틀**된 상태를 유지한다(Brian 확정 선호 — 1초마다 튀는 값 금지). 즉 다이얼 중앙 숫자는 `snapshot`(1Hz)이 아니라 **차트와 동일한 25초 구간 평균의 최신 버킷**을 쓴다. 이것이 이 기획안에서 가장 중요한 단일 결정이다 — 다이얼을 1Hz로 돌리면 "살아있는 지표"가 아니라 "불안한 지표"가 되고, 명상 몰입을 깬다.

마지막으로 **1화면 수렴(1280×720 / 390×844 스크롤 없음)** 은 타협하지 않는다. 히어로 다이얼을 키우는 대신 서브 다이얼을 축소하고, 차트 높이를 84→72px로 줄이고, BGM 미니바와 밴드 상태 줄을 한 줄로 병합해 수직 예산을 확보한다(§4 수직 예산 표).

## 2. 색상·타이포·토큰 개선

### 2.1 토큰 재정의

`.member-class-player` 의 커스텀 프로퍼티를 상담사 화면과 **동일 이름·동일 값**으로 맞춘다. 이름까지 같게 두는 것이 중요하다 — 이후 두 화면 중 한쪽만 색이 바뀌는 드리프트를 막는다.

| 토큰 | 현재(회원) | 변경안 | 용도 |
|---|---|---|---|
| `--bg` | `#060507` | **`#12081C`** | 스크림 하단, 몰입 오버레이 바닥 |
| `--purple` | `#5F0080` | `#5F0080` (유지) | 다이얼 아크 시작, 선택 상태 |
| `--cream` | `#F7F4F0` | `#F7F4F0` (유지) | 본문 텍스트, 최신 막대 |
| `--muted` | 하드코딩 `#bfb3c6`/`#b9adbf`/`#b2a3bc`/`#c5baca` 난립 | **`#bcaec5` 단일화** | 보조 텍스트 10/11px |
| `--lavender` | 없음 | **`#dcb5ee`** | 섹션 라벨, 단위, 포커스 링 |
| `--mint` | `#01f0c8` (범용 액센트) | `#01f0c8` **(라이브/연결 의미로만 한정)** | 라이브 점, 밴드 연결 dot, BGM 재생중 |
| `--border-container` | `#ffffff14`/`#ffffff17`/`#ffffff12`/`#ffffff1a` 난립 | **`#ffffff1A` 단일화** | 카드·패널 보더 |
| `--border-divider` | 없음 | **`#ffffff0D`** | 섹션 구분선, 차트 baseline |
| `--surface-1` | — | **`#1d1027`** | 우측 지표 패널 |
| `--surface-2` | — | **`#21132b`** | 팝업(볼륨/밴드), 채팅 시트 |
| `--surface-fill` | `#ffffff12` | **`#ffffff06`** | 버튼/필 기본 (hover `#ffffff10`) |
| `--selected-bg` | `#5f0080a6` | **`#2b1637`** | 선택 지표 카드 배경 |
| `--selected-border` | `#bc80d2` | **`#b78cca`** | 선택 지표 카드 보더 |
| `--delta` | — | **`#c9aed7`** | 증감 라벨 |

> **난립 색상 9개를 4개 토큰으로 수렴**하는 것 자체가 개선의 절반이다. 현재 회원 CSS에는 회보라 계열 보조 텍스트 색이 `#bfb3c6 #b9adbf #b2a3bc #c5baca #d9cddd #a996b2 #b4a7be` 7종 있는데, 의미 차이가 없다.

### 2.2 배경 레이어 (3단 구성)

```
L0  FadingImageBackground (기존 유지 — 이미지 크로스페이드)
L1  .player-scrim   linear-gradient(#190822D9, #12081CF2)   ← 현재 #060507F0 → #12081C 로 교체
L2  .player-right   #1d1027 + 1px solid #ffffff1A            ← 현재 #060507CC 반투명 → 불투명 서피스
L3  카드/팝업        #21132b                                   ← 팝업만 사용
```

`.player-right` 를 **반투명 검정에서 불투명 `#1d1027` 서피스로 바꾸는 것**이 깊이감 회복의 핵이다. 현재는 배경 이미지가 비쳐 지표 영역의 대비가 프레임마다 흔들린다. 영상 타일(`.player-video`) 의 radial 그라디언트는 상담사 `hcp-host` 와 같은 톤(`#382047 → #1b1025`)으로 맞춘다.

### 2.3 타이포

| 역할 | 현재 | 변경안 |
|---|---|---|
| 폰트 | (상속) | **Pretendard 명시** (상담사와 동일) |
| 베이스 | 13px | 13px / `line-height:1.4` (유지) |
| 타이틀 h1 | 15px/600 | 15px/**500** |
| 섹션 라벨 (MIND/BODY) | 없음 | 11px/500 + `small` 9px `letter-spacing:1.5px` `color:--lavender` |
| 지표명 | 11px `#c5baca` | 10px `--muted` |
| 히어로 다이얼 값 | 26px/600 | **34px / `font-weight:500` / `tabular-nums` / `letter-spacing:-1px`** |
| 서브 다이얼 값 | 26px/600 | **15px/500 / `tabular-nums` / `letter-spacing:-.5px`** |
| 단위 | 10px/400 `#ffffff99` | 9px/400 `--lavender` (히어로는 11px) |
| 증감 라벨 | 없음(차트 head에만) | 10px `--delta` `tabular-nums` |
| 타이머 현재값 | 38px/600 | 38px/**500** `tabular-nums` `letter-spacing:-1px` |
| 빈 값 `—` | 26px/400 `#8a7d8f` | 동일 크기 / `--muted` / weight 400 |

**`font-weight:600` → `500` 전환**이 상담사 화면 "완성도"의 숨은 요인이다. 600은 다크 배경에서 숫자가 번져 보이고, 500 + `letter-spacing:-1px` 조합이 훨씬 정밀해 보인다. 회원 화면 전체에서 600을 500으로 내린다(단 `--cream` 대비는 유지되므로 가독성 손실 없음).

### 2.4 포커스 링

현재 `outline: 2px solid var(--player-mint)`. **`--lavender` 로 교체**(`outline-offset:3px`) — 상담사 화면과 동일. 민트는 "라이브/연결" 의미 전용으로 남겨 의미 충돌을 없앤다.

## 3. 6지표 표시 방식 재설계

### 3.1 구조: 히어로 1 + 서브 5 (MIND/BODY 묶음)

```
┌─ 마음 MIND ──────────────────────────────┐
│  ╭────────╮                              │
│  │ 집중도 │   이완도 ◌64    정서안정 ◌71  │   ← 히어로(선택) + 서브 2
│  │  ◍ 87% │                              │
│  │ +32·5분│                              │
│  ╰────────╯                              │
├─ 몸 BODY ────────────────────────────────┤
│   BPM ◌72      호흡 ◌14      HRV ◌42     │   ← 서브 3
└──────────────────────────────────────────┘
```

- **히어로 다이얼** = 현재 `selectedKey` 지표. 84px(데스크탑) / 72px(모바일). 선택 변경 시 히어로 위치가 MIND↔BODY 섹션 사이를 이동하지 않고, **항상 해당 섹션의 첫 칸**에 렌더 — 레이아웃 점프를 막기 위해 각 섹션의 1번 칸을 `grid-area` 로 고정하고 선택된 지표만 그 칸으로 스왑한다.
- **서브 다이얼** 44px, 중앙 숫자 15px, 지표명 상단 10px, 증감 라벨은 **서브에서 생략**(과밀 방지). 상담사 화면은 6개 전부에 델타를 붙이지만, 회원 화면에서는 히어로에만 붙인다.
- **MIND/BODY 구분은 적용한다.** 단 상담사처럼 `border-left` 2컬럼 분할이 아니라 **상하 2행 + `border-top:1px solid --border-divider`** — 회원 우측 컬럼이 세로로 길어 수평 분할이 맞지 않는다.

### 3.2 다이얼 스펙 (상담사 `HostMetricDisplay` 에서 이식)

| 요소 | 값 |
|---|---|
| viewBox | `0 0 120 120`, `r=51`, `stroke-width:6` |
| 트랙 | `#ffffff14` |
| 아크 | `linearGradient` `#5F0080 → (.45) #A16BBC → #D4B5E3`, `stroke-linecap:round`, `pathLength="100"` + `strokeDasharray="{gauge} 100"`, `transform="rotate(-90 60 60)"` |
| 글로우 | 히어로만 `filter: drop-shadow(0 0 6px #5f008066)` |
| 정규화 | `%` 지표(focus/relaxation/emotional) = 값 그대로 0–100. 비율 지표(bpm/respiration/hrv) = **`chartMax` 기준 0–100** (`METRICS[].chartMax`: 100/24/60 — 이미 정의됨). 상담사의 "최근 표본 범위 상대 위치" 방식은 쓰지 않는다 — 회원 화면은 절대 스케일이 해석하기 쉽고, 범위 정규화는 값이 평탄할 때 아크가 요동친다. |
| 중앙 | `<b>{값}</b><small>{단위}</small>` 세로 스택, `flex-direction:column`, `line-height:1` |
| 값 소스 | **25초 구간 평균의 최신 버킷** (`averageMetricBuckets(series)` 의 마지막 non-null). `snapshot` 1Hz 직결 금지. |
| 애니메이션 | `transition: stroke-dasharray 1200ms ease-out` / `prefers-reduced-motion` 시 0 |
| null | 아크 미렌더(트랙만) + 중앙 `—` `--muted` |

### 3.3 추이 막대: 현재 로직 유지, 표현만 교체

현재 `MetricBarChart` 의 12버킷 × 25초 평균 로직은 **그대로 유지**한다(Brian 확정 선호). 바꾸는 것은 표현뿐:

| 항목 | 현재 | 변경안 |
|---|---|---|
| 구현 | `div.player-bar` 12개 + `repeating-linear-gradient` 그리드 | **SVG `viewBox="0 0 240 64"`** (상담사 `hcp-bars` 와 동일 좌표계) |
| 막대 | `background:#cbbbd76b`, 최신만 민트→퍼플 | `fill: url(#bars)` 수직 그라디언트 `#5F0080(.55) → #A16BBC(.8) → #D4B5E3`, **최신 막대만 `fill:--cream` `fill-opacity:.9`** |
| 모양 | `border-radius:4px 4px 2px 2px` | `rx="3.75"`, `width:7.5` (상담사와 동일) |
| baseline | 없음 | `border-bottom:1px solid --border-divider` |
| 비교선 | 없음 | **본인 베이스라인 점선** — 세션 첫 3버킷 평균을 `path.player-baseline` (`stroke-dasharray:3 3`, `--lavender` `opacity:.4`)로 1본. 그룹 평균/범위 밴드는 **넣지 않는다**. |
| 증감 | charthead 우측 `▲ 5분간 +32` | 유지 + **히어로 다이얼 하단에도 복제**(`+32 · 5분간`, `--delta` 10px) |
| 높이 | 84px (모바일 100px) | **72px** (모바일 88px) — 수직 예산 확보 |
| 축 라벨 | `5분 전` / `지금`(민트) | 유지, `지금`을 `--lavender` 로 (민트 의미 한정) |
| 범례 | 없음 | 하단 1줄 `링: 현재 구간 평균 · 막대: 25초 구간 평균 · 점선: 시작 구간` 9px `--muted` |

### 3.4 선택 인터랙션

현재 `.player-metric[aria-pressed=true]` 가 `#5f0080a6` 로 **면 전체를 퍼플 칠**하는 것이 밋밋함의 원인이다(선택 1개만 눈에 띄고 나머지는 죽는다). 변경:

- 선택 카드: 배경 `--selected-bg(#2b1637)`, 보더 `--selected-border(#b78cca)`, `inset 0 0 0 1px #b78cca2e`. 우상단 점(`::after`) 제거 — 히어로 크기 자체가 선택 표식이다.
- 비선택 카드: 배경 **없음**(`transparent`), 보더 없음, 다이얼만 떠 있음. 카드 테두리 5개를 지우면 과밀감이 크게 줄고 히어로가 자연히 부각된다.
- hover: `background:#ffffff06`.
- 10초 자동 로테이션(상담사 `hcp-rotating`)은 **회원 화면에 넣지 않는다** — 명상 중 시선을 끌어당기는 자동 변화는 금지.

## 4. 레이아웃 개선

### 4.1 데스크탑 1280×720

```
grid-template-columns: minmax(0,1.55fr) 400px;   /* 현재 1.5fr/1fr → 우측 고정폭 */
gap: 20px;  padding: 0 20px 20px;
```

우측을 **고정 400px**로 바꾼다. 가변폭에서는 히어로 다이얼·서브 다이얼·막대 폭이 뷰포트마다 달라져 디자인 검수가 불가능했다. 영상이 남은 폭을 전부 먹는다(16:9에 가까워짐 — 현재보다 개선).

**우측 컬럼 수직 예산 (720 − topbar 64 − padding 20 = 636px)**

| 블록 | 현재 | 변경안 | 비고 |
|---|---|---|---|

## 7. 이식 시 함정·주의

1. **데이터 계약 불변.** `useBand` / `useSessionLiveSocket` / `seriesRef`(`MAX_POINTS=300` 링버퍼) / `scoreIndices` / `averageMetricBuckets` / `METRICS` 정의는 **건드리지 않는다**. 교체 범위는 `GuestMeditationPanel` 의 JSX 표현층 + `MetricBarChart` 내부 렌더 + `member-class-player.css`. SDD-024/026/040 회귀 금지.
2. **다이얼 값 소스를 `snapshot` 으로 연결하지 말 것.** `snapshot[key]` 는 1Hz다. 다이얼은 반드시 `averageMetricBuckets(seriesRef.current[key])` 의 최신 non-null 버킷을 쓴다. 이걸 틀리면 Brian 확정 선호("1초마다 튀는 값 금지")를 정면으로 위반한다. 현재 `chartTick = Math.max(1, floor(seriesTick/25)+1)` 스로틀 게이트를 **다이얼에도 공유**해야 하므로, 버킷 평균을 `useMemo`로 한 번 계산해 다이얼·차트가 같은 값을 쓰도록 리프트한다.
3. **SVG gradient id 충돌.** 다이얼 6개 + 막대 1개가 같은 DOM에 있고, 모달/몰입 오버레이로 재마운트된다. 상담사처럼 `useId()` 로 고유화할 것. 하드코딩 id 금지(두 번째 다이얼부터 아크가 사라진다).
4. **Tailwind 클래스 템플릿 리터럴 합성 금지.** 현재 몰입 오버레이가 ``className={`... ${screenOff ? ... : ...}`}`` 형태인데, 조건부로 **완전한 클래스 문자열을 선택**하는 방식(지금처럼 전체 클래스를 양쪽에 다 쓰는 형태)만 허용. `bg-[${token}]` 류의 동적 값 합성은 JIT가 못 잡는다. 신규 스타일은 전부 `member-class-player.css` 로 — 이 화면은 CSS 파일 기반이 정본이다.
5. **44px 터치타깃 유지.** 서브 다이얼이 44px로 작아지므로 **클릭 영역은 다이얼이 아니라 카드 전체**(`min-height:56px` 이상, 모바일에서도 44 이상)여야 한다. 다이얼 자체를 버튼으로 만들면 모바일 36px 축소 시 접근성 위반.
6. **`prefers-reduced-motion` 가드 확장.** 현재 `animation/transition: none !important` 전역 가드가 있으나, 신규 `stroke-dasharray` 트랜지션과 아바타 호흡, 시트 슬라이드가 모두 이 가드에 포함되는지 확인. 단 `!important` 전역 차단은 아크의 **초기 렌더 값**까지 막지 않는지(dasharray는 속성이므로 안전) 확인.
7. **접근성 라벨.** 다이얼은 `aria-hidden` SVG + 텍스트 노출(상담사 패턴). 막대 SVG는 `role="img"` + `aria-label` 에 12구간 값 나열(현재 구현 유지). `aria-pressed` 로 선택 상태 전달하는 현재 방식 유지 — `role="radiogroup"` 으로 바꾸지 말 것(스크린리더 포커스 이동 패턴이 바뀌어 회귀 위험).
8. **1화면 수렴 회귀 테스트.** 1280×720 / 390×844 두 해상도에서 `scrollHeight === clientHeight` 를 Playwright로 검증. 특히 `band.error` 표시 시(+1줄)와 미연결 시(연결 버튼 +1줄) **최악 케이스**를 포함. 현재 CSS가 `.player-right { overflow-y:auto }` 로 도피하고 있어 회귀가 눈에 안 띈다 — 예산을 §4.1대로 맞춘 뒤 **`overflow:hidden` 으로 바꿔 회귀를 드러낸다**.
9. **민트 의미 한정 누락 주의.** `--player-mint` 를 전역 액센트로 쓰는 지점이 현재 7곳(focus outline, video label dot, band dot, bar gradient, axis `지금`, bgm state, audio-resume). 이 중 **포커스 링 / bar gradient / axis** 3곳은 라벤더·퍼플로 바꿔야 한다. 전부 바꾸면 "연결됨"의 신호성이 사라지므로 **dot 계열 3곳만 민트 유지**.
10. **`.player-metric` 보더 제거의 역효과.** 비선택 카드에서 보더를 지우면 터치 영역이 보이지 않는다 → 모바일에서는 `#ffffff0D` 아주 약한 보더를 **남긴다**(데스크탑만 투명). 모바일은 호버가 없어 어포던스가 필요하다.
11. **오프라인 >20명 / 강당형 경로 확인.** `showCounselorVideo=false` 일 때 `.player-hall` 이 영상 칸을 채우는데, 새 radial 그라디언트가 적용되는지 확인. 이 경로는 테스트에서 자주 빠진다.
12. **디자인 정본 동시 갱신.** `design/member-class-player/index.html` 이 정본이므로, CSS/TSX만 바꾸고 정본을 방치하면 다음 루프에서 되돌아간다. **정본 → 구현 순서**로 진행.
