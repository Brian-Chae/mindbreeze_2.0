# 수정 요청 R2 — 사용자 피드백 3건 (member-b, host-b 만 해당)

`기획.md` §0-2 (R2-1~R2-3a) 를 읽고 수행. 규칙·측정·산출 경로는 `지시서-공통.md` 그대로. **담당 html·shots·fit·tools 만 수정**, 영향 받는 케이스만이 아니라 **전체를 4개 뷰포트로 다시 캡처·측정**(수정 전 위반 → 수정 후 0). 금지어 grep(R1 포함) 0 유지.

## R2-1 (member-b FM06c · host-b FH06/내 밴드 시트)
- 전극 LED 안의 체크·엑스 아이콘 **전부 삭제**. LED는 색(민트/빨강)만. 전극 아래 라벨 텍스트(`왼쪽 실패`·`오른쪽 양호`·`기준 …`)와 범례는 유지. 소형 LED(로비 행)도 동일. 측정 스크립트의 "LED 안 아이콘 존재" 검사는 "아이콘 없음" 검사로 뒤집는다.

## R2-2 (member-b FM06d · host-b FH05) — 카메라 켜짐 케이스만
- 영상 하단 **가로 막대 제거**. 기본안: 영상 **우측 가장자리 세로 레벨 미터**(너비 8~12px, 영상 높이의 50~60%, 하단부터 차오름, 마이크 토글 버튼 바로 위, 우측 여백 8의 배수) — 마이크 토글·카메라 토글은 우측 하단 세로로 쌓지 말고 기존 위치 규칙(균형.md S2·S6)에 맞게 대칭 유지(예: 우측 세로 미터 + 하단 가운데 토글 2개, 혹은 우측 열에 미터 위·토글 아래; 좌우 균형을 해치지 않는 쪽으로 정하고 이유를 보고).
- 대안안 케이스를 같은 화면에 `-iconmeter` 접미로 추가: 마이크 토글 아이콘 자체가 레벨을 표시(아이콘 밝기·바깥 링 채움 정도로 단계 표현, 색+채움 단계+라벨 `정상/조용해요`). 두 안을 갤러리에서 나란히 비교할 수 있게 케이스명으로 구분.
- **카메라 꺼짐 + 마이크만**은 기존 가로 레벨 막대 유지(변경 금지).
- 권한 거부·장치 없음·미지원 케이스는 기존대로.

## R2-3 / R2-3a (host-b FH06·FH07, member-b FM06·FM07)
- host-b FH06: 시작하기 버튼 활성 조건을 "대기실 1명 이상"으로. 준비 중 회원이 있으면 버튼 위 상태줄(`N명 준비 완료 · M명 준비 중` — 순위·점수 아님), 비활성 사유는 대기 0명일 때만 `회원이 입장하면 시작할 수 있어요`. 케이스: 대기 0(비활성) / 3명 중 일부 준비 중(활성) / 전원 완료 / 준비 완료 0명·대기 3명(전원 준비 중, 활성) × 온라인·오프라인 × 1:1·그룹.
- host-b FH07 시작 확인 시트: 준비 중 회원이 있을 때 `준비 중인 회원 M명` 목록(이름 + 미완 단계 칩: 설문/LINK BAND/기기 — 아이콘+라벨) + 안내 `준비 중인 회원은 시작 후에도 입장해서 이어서 준비할 수 있어요` + 버튼 `지금 시작하기`(주) / `조금 더 기다리기`(보조). 전원 준비 완료면 지금처럼 간단한 확인. 목록이 길면(≥6) 시트 내부 스크롤이 아니라 "외 N명" 접기.
- member-b: FM06(a~e 중 임의 단계에 얹는 공통 오버레이 또는 상단 배너 시트) 케이스 `started` — `상담사가 클래스를 시작했어요` / `지금 입장하기`(주) / `준비 이어서 하기`(보조) + 건너뛴 항목 한 줄 안내. 최소 FM06b(설문 중)·FM06d(기기 중) 2단계에 `started` 케이스 추가, 4개 뷰포트. FM07 은 자동 입장이라 변경 없음(인덱스에 설명만).
- 인덱스 가정 열에 A9 기재.
