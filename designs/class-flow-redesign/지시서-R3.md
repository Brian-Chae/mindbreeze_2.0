## R3-1 아이콘 미터 확정 (member-b FM06d, host-b FH05)
- 세로 레벨 미터 안(우측 가장자리 미터)을 **완전 삭제**: HTML·CSS·측정 검사·스크린샷·인덱스 행. 카메라 켜짐 케이스는 모두 **아이콘 미터**(마이크 토글 둘레 5단계 링 + 아이콘 밝기, 상태 칩 `정상`/`조용해요`)를 기본으로 하고, 케이스명에서 `-iconmeter` 접미를 없앤다(기존 `ok-iconmeter` → `ok`, `camon-iconmeter` → `camon` 등). 접미 없는 구(세로 미터) 케이스·`*-iconmeter` 중복 케이스는 정리해 케이스가 중복되지 않게 한다.
- 카메라 켜짐 케이스: 가로 막대 0·세로 미터 0·아이콘 링 1 을 측정으로 강제. 카메라 꺼짐+마이크만: 가로 막대 유지(변경 금지). 토글 쌍은 하단 가운데 유지.
- 아이콘 미터는 색에만 의존하지 않는다: 링 채움 단계(5단계) + 칩 라벨.

## R3-2 대기실이 비어 있어도 시작 (host-b FH06·FH07)
- FH06: `시작하기` 버튼 항상 활성. 대기실 0명일 때 버튼 위 상태줄 `대기실이 비어 있어요 · 초대한 회원은 시작 후에도 입장할 수 있어요`(비활성 사유 문구 삭제). 초대 0명(초대 현황 `초대 0명`)도 시작 가능 케이스를 포함. 대기 0 케이스는 1:1·그룹 × 온라인·오프라인 모두에서 버튼 활성을 측정으로 강제.
- FH07: 대기실 0명 변형(`empty-wait`): 준비 인원 카드에 `아직 아무도 입장하지 않았어요`, 안내 `시작하면 초대한 회원이 이후에 입장해요`, 버튼 `지금 시작하기`(주)/`조금 더 기다리기`(보조). 마이크·녹음 동의 요약은 기존 유지.
- 인덱스 가정 열: A9 에 "대기실이 비어도 시작 가능, 시작 후 입장" 추가.
