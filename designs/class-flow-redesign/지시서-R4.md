# 시안 워커 지시서 R4 (SDD-209 R0 — R4/R5 정책 정합화)

R1-1(코드·OTP 전면 제거, 회원 전용)을 **대체**한다. 정본: `specs/sdd-209-class-flow-redesign/` 의 plan.md(§R4·R5 요약, §1.2), verify.md(§3·§4 문구 원문, §6' 허용 차이 AD1~AD22), policy-revision-r4.md(개정 R5). 공통 규칙(`지시서-공통.md`)·측정 규칙은 그대로 적용한다.

## 정책 → 시안 반영
- **4자리 코드 입장**: FM04(코드 확인만) → FM04b(이름·성별·생년월일·이메일+이메일 확인, OTP 없음) → FM05(`{입력한 이름}님`). 참가자 화면에는 코드를 노출하지 않는다. 상담사 화면(FH03·FH04·FH06a)은 4자리 코드 표시·복사(QR 없음).
- **리포트 반영 선택·연구 동의**(FM06a): 고지(기록 원본 `{N}일` 후 삭제) / 반영 선택(기본 `반영하지 않아요`) / 연구 동의(별도 블록·기본 미동의) 분리. 계속하기는 항상 가능. 기간은 시안에서 `{N}일` 플레이스홀더 그대로.
- **밴드**: 필수여도 참가를 막지 않음(`LINK BAND 사용을 권장해요. 없어도 참가할 수 있어요`·`권장` 칩·`LINK BAND 없이 계속하기`).
- **대기**: `대기 취소`(확인 시트, 서버 제외, 재대기는 끝 순번).
- **상담사 만들기**: 그룹 정원 스텐퍼(기본 10 · 온라인 최대 50 · 오프라인 최대 100 · 1:1 은 1명 고정), 유형 `기타` 이름 입력, `AI 분석` 토글 제거, 비회원 이메일 초대(FH02d `email`), 초대 결과 `초대했어요`/`메일 발송을 요청했어요`(전달 단정 금지).
- **종료**: 비회원은 입력한 이메일(마스킹)로 자동 발송, 리포트 제외 참가자는 `보낼 리포트가 없어요`. 상담사 FH07 은 제외·연구 동의 인원 수(익명)를 표시하되 시작을 막지 않음. FH09 `excluded-common`.
- 수동 기록은 **상담사의 녹음 선택 해제·마이크 끔**에 한함.
