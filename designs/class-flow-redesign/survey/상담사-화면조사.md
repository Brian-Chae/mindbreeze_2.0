## 10. 조사 부산물·정리

- 테스트 세션: 제목 접두 `[호스트조사]`로만 생성. 총 **34개 생성 → 34개 모두 삭제(필요 시 end/cancel 후 DELETE)**, 최종 잔여 0 확인(스크립트 로그 합산 기준). 기존 데이터(`[조사] …`, `SDD-188 스모크`, `회원 입장 E2E 클래스` 등)는 건드리지 않음.
- **삭제 불가 잔여물**: 회원 계정(`client@test.com`)에 세션 초대·종료·취소 알림이 누적됨(최근 100건 중 87건이 `[호스트조사]` 관련 알림). 알림 삭제 API 없음(읽음 처리만 존재) — 별도 정리 필요.
- 토큰·비밀번호는 어떤 파일에도 저장하지 않음(스크립트는 `/tmp`, 환경변수로만 주입).
