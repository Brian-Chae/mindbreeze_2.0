## 산출 규칙
- **단일 자체포함 HTML**(인라인 SVG 아이콘, 외부 http 리소스 0). 이미지는 상대경로 `assets/bg/background{1,4,5,8,10}.webp`만. 다른 워커 파일·공통 파일·`../class-player-redesign/` 수정 금지.
- 화면 선택: `?screen=FM03&case=ready` 형태. 파라미터 없으면 해당 파일의 첫 화면. 파일 상단에 화면·케이스 인덱스(개발자용 `?index=1`)를 둔다.
- 아이콘: lucide 스타일 2px 아웃라인 SVG(`.ic`). **이모지·문자 글리프(✓ ✕ ← › ‹ • ○ ● × 🎤 등)를 아이콘으로 쓰지 않는다.** 영문 대문자 아이브로우 금지. 점수·%·순위·그룹 평균 금지(진행률 막대 제외).
- 호흡 지시 문구 금지. 모든 간격 8의 배수. 글자 12px 이상(11px 이하 0). 터치 ≥44px. 페이지 스크롤 0(`document.scrollingElement.scrollHeight <= innerHeight`) — 단 셸형의 목록 영역과 이용 가능한 리스트만 내부 스크롤.
- 오프라인(대면) 케이스는 영상·마이크·BGM 자리를 **자리째 제거하고 안내로 채운다**(빈칸 금지). LINK BAND 미사용은 정상 상태(경고색 금지).
- 데모 데이터는 고정 시연값. 시작 예정 시각은 `오늘 오후 3:00` 식 상대 표기.
- 가정(기획 §9 A1~A6)을 쓰는 화면은 화면 우상단 개발자용 배지가 아니라 `?index=1` 인덱스 표의 "가정" 열에 기재.
