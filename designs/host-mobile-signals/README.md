# SDD-235 상담사 모바일 신호 시안

- `index.html`을 브라우저에서 열면 현재 / A / B 및 7가지 상태를 선택할 수 있다.
- A 추천: 기존 5개 도크 위에 손들기·조용한 신호 고정 줄. B: 도크를 신호 중심으로 재편하고 지표·체크인·도구를 더보기로 이동.
- 현재 화면은 코드와 사용자 설명을 기반으로 한 **구조 재현**이며 dev 화면 스크린샷이 아니다. 개인정보 없는 가상 회원 A–F 6명, 밴드 미착용, 녹음 중 상태를 사용한다. 현재 +N은 이 고정 샘플에서 녹음·체크인 외 숨는 칩 그룹 수를 표시한다. 실제품의 폭 계산 알고리즘을 복제하지 않았다.
- 390px 중심이며 1440px에서는 현행 상단 칩 줄·5개 도크·우측 시트 배치를 유지한다. 데스크톱의 아이콘·장식·타일 크기까지 복제한 화면은 아니다.
- 자산: `frontend/public/images/background3.webp`를 `assets/background.webp`로 복사. CSS/JS/이미지는 모두 상대경로. 네트워크·외부 폰트·제품 API에 연결하지 않는다. 아이콘은 시안 내 SVG, 한글은 OS 폰트 폴백.

## 상태와 조작

| 상태 키 | 화면 |
|---|---|
| none | 손들기 0, 신호 0 |
| hand | 손든 회원 1명 |
| signals | 잘 따라가요 1 / 조금 어려워요 2 / 잠시 쉴게요 1 |
| toast | 손들기 1 + 조용한 신호 4 + 신호 토스트 (현재 화면에는 토스트 없음) |
| sheet | 손들기 시트 열림 |
| quiet | 조용한 신호 시트 열림 (현재 화면은 체크인 하단) |
| speaking | 발언권 있음 1명 |

손들기 → 발언권 주기 / 손 내리기, 부여 후 회수, 토스트 → 신호 시트, 신호 → 체크인, B 더보기 → 기존 메뉴, 닫기/Escape를 체험할 수 있다. 손 내리기는 제안 기능이며 서버 권한 확장이 필요하다. 그 외 기존 메뉴는 연결 위치를 설명하는 자리표시다.

**시안 한계:** 상태 선택용 고정 샘플이다. 자동 토스트 시간·묶음·TTL·새 이벤트 수신·서버 처리·LiveKit 마이크 전환은 실행하지 않는다. 정책은 Spec에 명시했으며 후속 구현 검증 대상이다. 시트 밖 배경은 시각적으로 차단하고 키보드 Tab을 시트에 제한한다. 실제 제품 접근성 통합 검증을 대체하지 않는다.

## 캡처·검증

`capture.cjs`는 사용자가 지정한 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`을 headless로 실행하고 `file://` 로컬 HTML만 연다. HTTP(S) 요청은 차단한다.

```bash
# 사용자 지정 공유 의존성이 연결되어 있을 때 실행
node designs/host-mobile-signals/capture.cjs
```

결과: `validation.json`, `screenshots/{current|a|b}-{상태}-{390|1440}.png` 총 42장. 모바일 390×844, 데스크톱 1440×1000.

- 42개 렌더: 가로 넘침 없음, 시안 버튼 최소 44×44, 최소 글자 13px, backdrop-filter 없음, JS 오류 없음.
- 샘플 조작: 발언권 부여→회수, 손 내리기, 토스트→이름 없는 종류별 집계, B 더보기→체크인.
- 키보드: Escape 닫기 및 조치/시트 전환 후 원래 진입 버튼으로 포커스 복귀.
- 1440px: B에서도 기존 지표 기준 도크 유지, 추가 신호 줄 없이 상단 한 줄로 통합.
- 대표 이미지 육안 확인: A 토스트·손들기 시트, B 여러 신호, 1440px 신호 시트. 실제 iPhone/Safari/Capacitor·백엔드·DB·소켓·BLE 검증은 수행하지 않았다.
- 독립 검토: 데스크톱 구성·+N/발언권 경로·포커스 복귀 지적을 수정 후 재캡처.
