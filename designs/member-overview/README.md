# SDD-230 회원 목록·상세 디자인 시안

이번 결과는 **Stage ① Spec과 정적 시안**이다. 제품 구현·Plan·Verify·마이그레이션·서버/DB 확인은 수행하지 않았다.

## 열어 보기

- [시안](index.html): `#table` 표 / `#cards` 카드 / `#detail` 윤가온 상세.
- [Spec](../../specs/sdd-230-member-overview/spec.md): 원천 데이터 표, 개인정보·기관 경계, 범위·단계·결정 항목.
- 모든 이름·전화번호·기관·기록·변화량은 가상이다. 회원용/상담사용 리포트의 생성·발송 작업은 없다.
- 시안은 서비스 API를 호출하지 않는다. 폰트만 기존과 같은 Pretendard CDN을 사용한다. 오프라인에서는 시스템 폰트로 대체될 수 있다.

## 화면 증거

Chrome headless 전체 페이지 캡처, deviceScaleFactor=1. 데스크톱/태블릿 높이는 1000px, 모바일은 844px이며 전체 페이지 PNG는 그보다 길 수 있다.

- 표: [1440](table-1440.png) · [1194](table-1194.png) · [390](table-390.png)
- 카드: [1440](cards-1440.png) · [1194](cards-1194.png) · [390](cards-390.png)
- 상세: [1440](detail-1440.png) · [1194](detail-1194.png) · [390](detail-390.png)

1440은 표 전열을 보여 주며, 1194/390은 표 영역만 수평 스크롤한다. 이름 열은 고정된다. 모바일 카드와 상세는 한 열로 흐른다. 표 안에서 가려진 열은 의도된 수평 스크롤 대상이며 페이지 넘침과 구분한다.

## 검증 결과

- [layout-audit.json](layout-audit.json): 최종 Chrome 버전·뷰포트·요소 위치·텍스트 넘침·페이지 너비·상호작용 결과.
- 9개 화면: 페이지 가로 넘침 0, 검사 대상 텍스트 넘침 0, JavaScript 오류 0, Pretendard 로드 확인.
- 9개 PNG 직접 육안 확인: 주요 패널·텍스트·버튼 겹침과 의도하지 않은 잘림 없음. 모바일 상세 헤더 줄바꿈을 보정한 뒤 재캡처했다.
- 11개 상호작용 확인: 검색, 카드 전환 시 검색 유지, 초기화, 온라인 필터, 클래스 그룹핑, 상세 진입, 상담 유형 필터, 기간→유형 교집합, 유형→기간 교집합, 목록 복귀 필터 유지, 빈 결과.
- 독립 읽기 전용 검토에서 기간/유형 필터 교집합 결함을 발견해 공통 계산으로 수정했고 재검토·브라우저 검증을 통과했다.
- 데이터 현황 핵심 주장도 독립 검토자가 소스와 대조했다. 검증자의 검토가 실제 API/권한/DB 적용 증거를 대신하지 않는다.

## 재현

로컬에 설치된 Playwright 모듈과 Chrome을 사용한다. 의존성 설치나 제품 빌드는 필요하지 않다.

```bash
node designs/member-overview/capture.cjs
```

이 워크트리에 node_modules가 없으면 기존 Playwright 모듈 경로를 명시한다. 이번 실행은 같은 저장소 메인 체크아웃의 설치된 모듈을 사용했다.

```bash
MB_PLAYWRIGHT_PATH='/Volumes/Looxid SSD/looxid/repository/mindbreeze_2.0/frontend/node_modules/playwright' node designs/member-overview/capture.cjs
```

## 시안의 한계

- 실시간 접속과 개인정보 열람은 예시다. 원본 링크·열람 버튼은 안내만 표시한다. 실제 권한/동의는 API에서 구현해야 한다.
- 윤가온의 상세만 활동 이력 예시를 제공한다. 다른 회원은 해당 회원 헤더와 '예시 미준비' 안내를 표시한다.
- 헤더 집계는 가상 30일 전체 값이고 타임라인은 주요 활동을 발췌한 예시다. 활동 필터는 타임라인에만 적용한다.
- 그룹핑 예시는 회원당 클래스 1개다. 복수 클래스 중복 그룹/unique count는 Spec의 향후 수락 기준이다.
- 보기·검색·필터는 같은 탭 세션에서 유지한다. 스크롤 복원·영구 보기 설정·서버 페이지네이션·실제 로딩/장애 재시도는 제품 구현의 수락 기준이며 이번 시안에서 재현하지 않았다.
- 390px는 데스크톱 Chrome의 뷰포트 검증이다. 실물 태블릿/모바일 기기 검증은 수행하지 않았다.
