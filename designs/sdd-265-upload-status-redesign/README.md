# SDD-265 — 데이터 현황 HTML 시안 3안

가상 데이터로 만든 디자인 비교물이다. 제품 구현·API 연동·SDD 구현 승인을 의미하지 않는다. 각 HTML은 CSS·JS를 내장하며 파일을 직접 열 수 있다.

- 회차는 20건 탐색 fixture 중 최근 10건씩 교체한다. 첫 페이지가 브리프의 10회차(진행 중 1·확인 필요 2·그 외 7)이며 다음 페이지는 동작 확인용 추가 예시다.
- 참여자는 40명 중 10명씩 4페이지. 모두 수신 36·확인 필요 2·기대량 미확인 1·수집 제외 1. 회원은 본인 회차 10건씩 선택하고 첫 회차에 서버 등록 3건 대기.
- 디자인 토큰: 기존 `designs/sdd-261-upload-status/build-mockups.py`의 보라 `#5F0080`, 배경 `#F7F4F0`, 카드 20px, 표 헤더 `#F2F3F8`, 테두리 `#E8E2ED`.

### 현행 대비 측정 범위

실제 서비스는 실행하지 않았다. 아래 기준은 저장소의 기존 SDD-261 정적 HTML 시안을 동일 브라우저로 다시 캡처한 값이며 **현행 제품 화면 실측이 아니다**. 기존 시안에는 코치 회차 목록·회원 화면의 동일 fixture가 없어 그 두 화면의 현행 대비 감소율은 미확인이다.

| 비교 대상 | 1440 | 390 |
|---|---:|---:|
| 기존 `02-class-participants.html` | 3721px | 4107px |
| 기존 `03-mobile.html` | 6727px | 7150px |

| 새 상세 (40명 → 한 페이지 10명) | 기존 참여자 표 1440 대비 | 기존 참여자 표 390 대비 |
|---|---:|---:|
| 안 1 | 1517px / 59.2% 감소 | 1547px / 62.3% 감소 |
| 안 2 | 1504px / 59.6% 감소 | 1533px / 62.7% 감소 |
| 안 3 | 1504px / 59.6% 감소 | 1533px / 62.7% 감소 |

전체 인원을 한 번에 보이는 기존 시안과 10명 페이지를 비교한 결과다. 같은 의미의 데이터와 행 밀도만 비교한 수치는 아니며 페이지 전환 비용이 생긴다. 안2는 표를 접으면 더 짧지만 위 표는 펼침 기준으로 보수적으로 측정했다. 첫 목록 행의 390px 상단 위치는 안1 442px·안2 402.5px·안3 520px로 첫 뷰포트 안에 있다.

## 서사 문구와 근거

| 상태 | 코치 | 회원 | 기관관리자 |
|---|---|---|---|
| 일부 확인 필요 | 2명의 수신 근거 확인이 필요해요. 해당 참여자에게 앱 재접속을 안내해 주세요. | 앱을 켜 둔 채 와이파이에 연결해 주세요. | 담당 김서연 코치에게 확인해 주세요. |
| 서버 등록 3건 대기 | 이어올림을 기다려 주세요. | 서버에 등록된 3건의 수신을 기다리고 있어요. 앱을 켠 채 와이파이 연결을 유지해 주세요. | 담당 코치가 수신 상태를 확인할 수 있어요. |
| 모두 수신 | 확인된 기대 범위는 모두 수신됐어요. 추가 조치는 없어요. | 확인된 기대 범위는 모두 수신됐어요. 추가 조치는 없어요. | 확인한 범위를 담당 코치와 볼 수 있어요. |
| 기대량 미확인 | 수신 기록은 있지만 전체 기대량이 미확인이에요. 최신 기록을 확인해 주세요. | 현재 받은 기록을 확인할 수 있어요. | 담당 코치에게 대조 근거를 확인해 주세요. |
| 측정 진행 중 | 현재 받은 기록을 확인했어요. 수신을 기다려 주세요. | 앱을 켠 채 측정을 이어가 주세요. | 담당 코치에게 현재 수신 상황을 확인해 주세요. |
| 오프라인·조회 실패 | 최신 현황을 확인하지 못했어요. 연결 확인 후 새로고침해 주세요. | 연결 후 다시 확인해 주세요. | 최신 조회 후 담당 코치를 확인해 주세요. |
| 수집 제외 | 재접속 안내 대상이 아니에요. | 추가 조치는 없어요. | 수집 대상 설정을 담당 코치와 확인할 수 있어요. |

- 서버 수신 기준이다. 폰 대기량·지연 원인은 미확인. 리포트 반영 여부와 별개다.
- 미착용은 밴드 데이터, 마이크 OFF는 음성 데이터의 수집 제외다. 음성 OFF로 EEG 미수신을 설명하지 않는다.
- 혼합 예시에서 대상 확인 38명, 대상 범위 미확인 1명, 제외 1명. 참여자 38/38은 수신 기록 유무이며 모두 수신 판정 인원 36명과 다르다.
- 확정 범위의 feature는 `36×185 + 2×120 = 6,900`, 기대량 `36×185 + 2×270 = 7,200`창. 원시는 신호별 `36×3 + 3 + 4 = 115`, 기대량 `36×3 + 6 + 6 = 120`건이다. 미확인 1명의 180창·9건은 이 합계에서 제외한다.
- 일부 대상의 기대 범위가 미확인이므로 전체 진행 막대는 빗금으로 표시한다. 확인된 비율을 전체 진행률로 바꾸지 않는다. 모든 기대 범위가 확인된 상태에서만 채워진 막대를 보인다. 진행 중은 잠정 범위로 명시한다.
- 안1의 상태 변주와 모든 안의 비혼합 시트는 독립된 예시다. 혼합 상태 이외에는 혼합 참여자 표를 숨겨 상단과의 모순을 방지한다.
- 복사는 안내문만 클립보드에 저장한다. 새로고침은 예시 조회 시각만 변경한다. 실제 업로드·발송 요청은 없다.
