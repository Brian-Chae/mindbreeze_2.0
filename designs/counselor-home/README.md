# SDD-232 상담사 홈 디자인 검토

Stage ①의 정적 시안이다. 제품 코드는 구현하지 않았다. Brian의 방향·공통 카드 빈 값 범위 결정 후 중단 상태를 해제한다.

## 보기

`index.html`을 Chrome으로 직접 연다. 별도 서버가 필요 없다. 파일을 저장소에서 이동하면 상대 경로의 토큰·폰트·배경 참조가 끊기므로 현재 위치에서 연다.

- 상단 '현재 구성' / '제안 A' 전환. 현재 구성은 소스 기반 재구성이고 실제 서비스 캡처가 아니다.
- '표시 상태'에서 일정 있음 / 첫 방문 / 클래스 조회 실패 / 카드 빈 값 / 진행 중 회차 / 긴 제목을 선택한다.
- 기본 화면은 제안 A. `index.html?view=current`는 현재 구성, `index.html?view=proposed&case=live`는 진행 중 상태다.
- 크기는 실제 브라우저 너비에 반응한다. 캐러셀·코드 펼침·부분 실패 재시도는 로컬 동작한다.
- 링크/개설/복사/입장/기록 버튼은 목적지만 dialog로 안내한다. API·실제 클립보드·발송·서비스 이동은 수행하지 않는다.

## 재현 명령

저장소 루트에서 실행:

```sh
node designs/counselor-home/capture.mjs
```

Playwright는 현재 워크트리 `frontend` 설치를 먼저 사용하고, 없으면 이미 설치된 메인 체크아웃 `mindbreeze_2.0/frontend` 패키지를 읽기 전용으로 사용한다. 설치·lockfile 변경 없음. Chrome `channel: chrome`, headless, DPR 1, file:// 로딩, reduced motion 환경이다. 외부 HTTP 요청은 자동 차단하며 발생 자체를 오류로 판정한다.

## 확인 항목과 근거

`fit-results.json`이 실행 결과의 원본이다. 최종 Chrome 155.0.8059.85 실행: 28조합 모두 통과, 28동작 모두 통과. 가로 넘침·검사 대상 겹침·작은 조작 대상·작은 글자·패널 이탈·요청/스크립트 오류 0건.

- 문서 scrollWidth와 뷰포트 비교: 페이지 가로 넘침.
- 명시적 레이아웃 컨테이너의 보이는 형제 요소 bounding box 교차: 섹션·타일·헤더·조작·일정 행의 겹침. 캐러셀에서 의도한 일부 카드 가림은 허용한다.
- 주요 패널의 뷰포트 가로 이탈, 조작 대상 44×44px, 직접 텍스트가 있는 요소의 12px 하한.
- 로컬 Noto Sans KR 로딩, JS pageerror, 실패 요청, 외부 HTTP 요청.
- 진행 중 사례의 첫 일정 상태가 히어로와 같은 '진행 중'인지 확인.
- 크기별 동작 7개: 캐러셀 다음/이전, 상담사 코드 펼침, 새 클래스 목적지 안내, 부분 실패 재시도, 현재 전환, 제안 복귀. 전체 28건.

자동 교차 검사는 모든 글자/아이콘의 픽셀 겹침을 증명하지 않는다. 저장된 1440·1194·390 화면을 별도 검토자가 직접 확인해 주요 가림·섹션 간격을 점검했다. 현재 비교 화면은 제품 셸·상태를 단순화했으므로 제품의 기존 오류·접근성을 판정하는 증거가 아니다.

## 점검 중 수정한 사항

- 짧은 '전체' 링크의 터치 폭 44px 확보.
- 상태/화면 전환 시 기존 ResizeObserver를 해제해 이전 캐러셀 콜백의 null 참조 제거.
- 스크롤 이동 폭을 실제 카드 폭+gap 기준으로 계산하고 시작점 padding 오차 2px를 허용.
- `mb-tokens.css`의 원격 font import 대신 원격 참조 없는 실제 디자인 토큰 합본 CSS 사용. 폰트는 저장소 Noto Sans KR로 고정해 반복 캡처 안정화.
- 팀 강사에게 홈 요약만으로 진행 권한을 추정하지 않도록 히어로·진행 타일 모두 회차 상세를 경유하는 설계로 수정.
- 회차 코드·참여/게스트 수를 일정 영역의 보조 작업으로 표현, 검토 배너의 목적지를 기존 pending 필터와 일치.
- 진행 중 시안의 같은 회차가 일정에서는 '예정'으로 보이던 가상 상태를 일치시킴.

## 보존할 제품 기능

검토 대기, 일정, 대화, 알림, 상담사 코드 마스킹/복사, 회차별 코드/기록/진행·참관, 지금 바로 시작, 새 클래스, 기존 플래그와 조건부 안내. 시안의 브리핑·프로필 위치는 조건부 영역의 배치 설명이며 무조건 노출로 바꾸는 제안이 아니다.

## 한계

이 검증은 HTML의 고정 데이터·반응형 표현과 로컬 조작만 확인한다. API 응답·인증·권한 실행·회원 실제 경로·DB·메일·EEG·실제 앱 동작은 검증하지 않았다. backend 필요성은 현재 소스 계약의 판단이며 라이브 확인이 아니다. 이번 작업에서 Stage ③ Verify나 구현 완료를 작성하지 않는다.
