# B안 — "Daylight Window" (라이트 · 분할형)

> A안(다크 · 풀블리드 자연 + 도크/시트)과 **다른 방향**의 대안. 같은 기능·같은 제약(스크롤 0, 호흡 지시 없음, 회원 비경쟁)을 지키되 형태와 톤을 바꾼다.

## 1. 방향 한 줄
메인 화면(라이트 크림퍼플 · 흰 카드 · 퍼플 포인트)을 **그대로 이어서**, 자연은 "창(Window)" 하나로 또렷하게 보여주고 정보는 라이트 패널에 정돈한다.

## 2. A안과의 차이

| 항목 | A안 | B안 |
|---|---|---|
| 톤 | 다크 + 반투명 소프트 시트 | **라이트**(`#F5EDFC`/흰 카드) — 메인 앱과 동일 |
| 자연 배경 | 풀블리드 배경 위에 UI가 얹힘 | **둥근 "자연 창"** 으로 분리(사진을 가리는 UI 없음, 사진 선명) |
| 레이아웃 | 중앙 링 + 하단 도크 + 시트 | **분할**: 모바일은 위 자연 창 / 아래 라이트 패널, 태블릿·데스크톱은 좌 자연 창 / 우 라이트 패널 |
| 상호작용 | 도크 → 시트 호출 | 하단 **탭바(메인 앱과 동일 스타일)** 로 패널 내용을 전환(시트 없음, 패널 안에서 교체) |
| 사진 가독성 | 스크림 필요 | 사진은 창 안에서만 쓰고 글자는 라이트 패널에만 — 대비 문제 없음 |

## 3. 공통 디자인 규칙
| 항목 | 값 |
|---|---|
| 배경 | 페이지 `#F5EDFC`(크림퍼플). 카드·패널 `#FFFFFF`, 보더 `#EADCF6`, 그림자 `0 6px 24px rgba(95,0,128,.08)` |
| 포인트 | `#5F0080`(Primary), `#B373EF`(보조), `#D2AEFC`(배지) |
| 텍스트 | 제목 `#1F1F1F`, 본문 `#4A4150`, 보조 `#7A6F85` |
| 자연 창 | 반경 28px, 사진은 `assets/bg/background*.webp`. 창 위에는 글자를 최소화하고, 올리는 경우 24px 이상 큰 글자 + 하단 그라데이션 스크림 |
| 폰트/스케일 | Pretendard, 12/13/15/18/24/36/56만 사용, 11px 이하 금지 |
| 아이콘 | 2px 아웃라인, round (A안·메인과 동일 `.ic`) |
| 버튼 | pill, 터치 ≥44px |
| 지표 색 | 라이트 배경 대비를 위해 아래 `--b-m-*` 사용(`tokens-b.css`) |
| 모션 | 호흡 지시·호흡 애니메이션 **없음**. 링 호 전환 1.2초만 허용 |

## 4. 화면 구성

### 4.1 회원용 (`member-b.html`)
- **자연 창**: 모바일 상단 약 42% / 태블릿·데스크톱 좌측 약 56%. 창 좌상단에 `나가기`, 우상단에 `연결 상태`, 창 하단에 진행 시간 `12:34 / 30:00`(36px)과 제목(15px)을 스크림 위에 표시. 상담사 영상 PiP는 창 우하단(카메라 꺼짐이면 숨김).
- **라이트 패널**: 핵심 지표 1개(이완도) 링 + 지표명·값·단위, 상태 설명 한 줄, 5분 추이 스파크라인 + "5분간 +8".
- **탭바(5개)**: `내 상태` · `채팅` · `조용한 신호` · `소리` · `기기`. 선택한 탭이 패널 영역을 교체(`내 상태`=6지표 2×3 링 + 히어로 선택, `채팅`=메시지 목록 + 입력, 등).
- 밴드 미착용: "밴드 없이 참여 중이에요 / 측정 없이도 수업은 그대로 진행돼요".
- 금지: 그룹 평균·순위·±델타·종합점수·호흡 지시.

### 4.2 상담사용 (`counselor-b.html`)
- **자연 창**은 좁게(모바일 상단 약 22% 띠 / 태블릿·데스크톱 좌측 약 28% 세로 창)로 두고, 그 안에 **상담사 셀프뷰**(카메라 켜졌을 때 내 영상, 거울 반전, 라벨 "내 화면")를 함께 보여준다. 카메라 꺼짐이면 자연 사진만 남음.
- **라이트 패널**: 상단 정보(제목·시간·접속 7/8·그룹 평균 이완도) → **지금 보는 지표 띠**(지표명 18px+ · 지표 고유색) → **참가자 타일 그리드(세로 스크롤)**. 타일에 지표 약칭 라벨 + 지표 색 링.
- **탭바(5개)**: `지표 기준` · `채팅` · `미디어` · `체크인` · `도구`. 선택 시 패널 영역 교체(그리드는 `내 목록` 탭으로 복귀).
- 페이지 전환 버튼 없음. 12명 이상은 그리드 내부 스크롤(`?n=12`, `?n=24`).

## 5. 공통 제약 (A안과 동일)
- 4개 뷰포트(390×844 · 834×1194 · 1194×834 · 1280×720)에서 `html,body` 스크롤 0. 내부 스크롤은 채팅·참가자 그리드만.
- 11px 이하 글자 0, 겹침·이탈·잘림 0, 터치 ≥44px.
- 이모지 금지, 외부 http 리소스 0, `frontend/`·`backend/`·git 건드리지 않음.
