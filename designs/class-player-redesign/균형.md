# 좌우 대칭·비율 균형 규칙 (A안 · 모든 케이스 공통)

> 피드백: 일부 화면(특히 태블릿 세로 834×1194)에서 영상 PiP는 왼쪽 위에 쌓이고, 시트는 오른쪽에 붙고, 링은 중심에서 벗어나고, 마이크·카메라 줄과 도크는 폭의 60%만 쓰며 왼쪽에 쏠려 있다. **좌우 대칭과 비율이 균형 있게 보이도록 레이아웃 규칙을 세우고 모든 케이스에 적용한다.**

## 1. 기준축
- **메인 영역** = 열린 사이드 시트를 뺀 가용 가로 영역. 시트가 없으면 뷰포트 전체.
- **중심축** = 메인 영역의 가로 중심. 모든 "단독 요소"는 이 축에 정렬한다. 사이드 시트가 열리면 메인 영역이 줄어들고 **축도 함께 이동**한다(요소가 시트 쪽으로 쏠리거나 시트 밑에 깔리지 않는다).

## 2. 규칙 (S1~S10)
| ID | 규칙 | 측정 기준(px) |
|---|---|---|
| S1 | 단독 요소(링, 링 아래 안내/칩, 도크, 미디어 줄, 배너, 시간 필)의 가로 중심 = 중심축 | \|중심 − 축\| ≤ 2 |
| S2 | 가장자리까지 가는 요소(상단 바, 도크, 미디어 줄, 배너, 바텀 시트)는 **좌우 여백이 같다** | \|left − (영역폭 − right)\| ≤ 2 |
| S3 | 상단 바: 좌(나가기)와 우(연결 상태/종료)는 **같은 높이·같은 바깥 여백**, 제목/시간은 중앙. 한쪽만 비는 구성 금지(우측 요소가 없으면 좌측과 같은 크기의 자리를 비워 대칭 유지) | 좌 여백 = 우 여백, 좌우 요소 높이 차 ≤ 2 |
| S4 | **영상 PiP(상담사·내 화면)는 짝으로 가운데 정렬**: 2개면 같은 크기를 가로로 나란히 중앙에, 1개면 중앙에. 한쪽 구석에 세로로 쌓지 않는다 | PiP 묶음 중심 = 축 ± 2, 2개 PiP 크기 동일 |
| S5 | **태블릿 세로(폭 < 높이)는 사이드 시트 금지** — 바텀 시트(폭 = 메인 영역 폭 − 동일 마진, 중앙 정렬, max-width 640)로 연다. 사이드 시트는 가로형(1194×834 이상)에서만 | 시트 좌우 여백 동일 |
| S6 | 도크·미디어 줄은 **전체 폭을 쓰고 항목을 균등 분배**(space-evenly). 항목 폭 동일. 폭 60%만 쓰고 한쪽에 붙는 구성 금지 | 항목 간격 편차 ≤ 2, 좌우 여백 동일 |
| S7 | 링은 **가용 세로 영역(상단 바 아래 ~ 미디어 줄/도크 위)의 세로 중앙**에 둔다. 링 위쪽 여백 : 아래쪽 여백 = 1 : 1 (±8%) | \|위 − 아래\| ≤ 영역높이×0.08 |
| S8 | 배너·칩·안내 박스는 **같은 최대폭**(min(92%, 480px))으로 가운데 정렬. 서로 다른 폭의 박스를 왼쪽 정렬로 쌓지 않는다 | 폭 편차 ≤ 2 또는 폭 동일 규칙 준수 |
| S9 | 태블릿·데스크톱에서 본문 컬럼이 너무 넓어지면 **중앙 컬럼 max-width(560~640px)** 로 제한하고 바깥은 자연 배경을 노출 | 컬럼 좌우 바깥 여백 동일 |
| S10 | 수직 리듬: 요소 간 간격은 8의 배수 스케일(8/16/24/32)만 사용하고, 같은 종류 간격은 같은 값 | 간격 집합 ⊂ {8,16,24,32,40,48} |

## 3. 상담사 화면 추가 규칙 (CS1~CS5)
| ID | 규칙 |
|---|---|
| CS1 | **참가자 그리드는 중앙 정렬**: 첫 타일 왼쪽 여백 = 마지막 타일 오른쪽 여백(행 기준). |
| CS2 | **마지막 행도 중앙 정렬**(`justify-content:center`): 8명=3열이면 3/3/2의 2를 가운데로. 열 수는 가능하면 인원을 균등히 나누는 값(8명: 2·4열, 6명: 3열, 12명: 3·4열)으로 고른다 |
| CS3 | 헤드 행(지표 띠 + 셀프뷰): 좌우 **같은 높이**, 구석에 떠 있는 작은 박스 금지. 셀프뷰가 있으면 `띠 : 셀프뷰` 비율을 고정(모바일 약 62:38, 태블릿·데스크톱 약 66:34)하고 둘 다 같은 바깥 여백을 쓴다. 셀프뷰가 없는 오프라인(C04·C06)은 띠와 요약 패널이 **같은 비율 구조**로 채운다 |
| CS4 | 칩 줄(손든 회원·필요 조치·대기)은 가운데 정렬, 넘치면 "+N" |
| CS5 | 1:1 카드: 회원 카드는 가운데, 6지표 링은 **3×2 균등 격자**, 5분 추이와 체크인은 같은 폭 |

## 4. 회원 화면 추가 규칙 (MS1~MS3)
| ID | 규칙 |
|---|---|
| MS1 | 오프라인(M05·M06)에서 영상·마이크가 빠져도 중앙 컬럼 구조는 동일(링 + 카드 3장이 같은 폭, 세로 균등) |
| MS2 | 6지표 2×3 시트의 카드는 동일 크기·균등 간격 |
| MS3 | 전체 화면 상태(M19 네트워크 끊김·M20 대기열·M21 종료)는 **화면 정중앙**(가로·세로)에 한 덩어리로 |

## 5. 검증 방식 (모든 케이스 × 4개 뷰포트)
- 뷰포트: `390x844`, `834x1194`, `1194x834`, `1280x720` **전부** (이전엔 일부만 측정)
- 측정 스크립트가 `getBoundingClientRect`로 위 표의 기준을 자동 검사하고 결과를 `shots/cases/{member|counselor}-symmetry.txt`에 케이스·뷰포트·규칙 ID별로 기록. 위반은 0건이어야 한다.
- 스크린샷도 **전체 케이스 × 4개 뷰포트**로 재생성(`shots/cases/`).
- 기존 검사(스크롤 0, 11px 이하 0, 겹침·이탈·잘림 0, 터치 ≥44, 빈 영역 0, 호흡 문구 grep 0)도 모두 유지.
