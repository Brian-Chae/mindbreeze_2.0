# 클래스 진행 화면 리디자인 기획 — "자연 창(Nature Window)"

> 대상: 회원용 클래스 진행 화면(`GuestMeditationPanel`) · 상담사용 클래스 진행 화면(`ClassPlayerPage` 호스트 워크스페이스)
> 단계: Phase 1(기획) + Phase 2(디자인 시안). 구현 전. 승인 후 SDD 진행.
> 작성: 2026-10-16

---

## 1. 문제 정의

| 구분 | 현황 | 사용자 영향 |
|---|---|---|
| 정보 밀도 | 회원: 클래스정보·프로필·6지표 다이얼·추이 그래프·신호 버튼·상담사 영상·오디오·채팅·원시 데이터·밴드 연결이 3컬럼에 동시 노출. 상담사: 참가자 로스터·정렬/표 전환·타이머·셀프뷰·미디어·체크인·도구가 한 화면에 노출 | 모바일에서 세로 스택 → 스크롤 필요, 명상 중 시선 분산 |
| 일관성 | 메인 화면(라이트 `#F5EDFC`/퍼플 `#5F0080`, 아웃라인 아이콘, 둥근 카드)과 클래스 화면(검정 계열 다크, 이질적 아이콘·타이포)이 다른 제품처럼 보임 | 브랜드 통일감 약함 |
| 분위기 | 배경이 단색 다크 + 카드 레이어. 자연 이미지는 대기실 일부에만 | 힐링 맥락과 불일치 |
| 반응형 | 모바일/태블릿/데스크톱별로 스크롤·패널 폭 조절(리사이즈 핸들) 방식이 달라 정합 약함 | 기기 간 사용 경험 편차 |

## 2. 목표 · 원칙

| # | 원칙 | 기준 |
|---|---|---|
| P1 | **한 화면(스크롤 없음)** | 390×844 · 834×1194(태블릿 세로) · 1194×834(태블릿 가로) · 1280×720(데스크톱) 에서 페이지 스크롤 0. 리스트(채팅·참가자)만 내부 스크롤 허용 |
| P2 | **자연이 주인공** | 화면 면적의 55% 이상은 자연 배경이 비어 보이게. 정보는 가장자리·하단 도크에 배치 |

| P5 | **회원 지표 비경쟁** | 회원 화면은 절대값 + 본인 5분 추이만. 그룹 평균·순위·±델타 노출 금지. 종합점수 환원 금지, 서사·변화량 중심 |
| P6 | **LINK BAND 선택** | 밴드 미착용 시에도 같은 구조. 지표 영역은 "밴드 없이 참여 중" 상태로 대체(빈 칸 금지) |

## 3. 디자인 언어 (회원·상담사 공통)

### 3.1 배경 — 자연 창
- 풀블리드 자연 사진(저장소 `frontend/public/images/background*.webp` 사용) + 그라데이션 스크림(상단 `rgba(18,8,28,.35)` → 하단 `rgba(18,8,28,.72)`)
- 슬로우 크로스페이드(시안에서는 정지 이미지, 구현 시 기존 `FadingImageBackground` 재사용)
- 시트/카드는 **소프트 시트**: 반투명 퍼플틴트 `rgba(24,12,36,.58)` + 1px `rgba(255,255,255,.14)` 보더 + **블러 없음**(glassmorphism 금지 정책·저사양 보호). 배경이 비쳐 보이는 정도만 허용
- 가독성: 본문 텍스트는 소프트 시트 위에서만 사용. 배경 위 직접 텍스트는 타이머·제목 등 큰 글자(≥24px)에 한함

### 3.2 색 · 타이포 · 형태
| 항목 | 값 |
|---|---|
| 브랜드 | `#5F0080`(Primary), `#B373EF`(라벤더 액센트), `#D2AEFC`(배지), `#F5EDFC`(크림 퍼플) |
| 텍스트 | 시트 위 `#F7F4F0`(hi) / `#CFC6D6`(mid) / `#9A90A6`(lo) |
| 상태 | 연결됨 민트 `#01F0C8`(데이터 하이라이트 전용), 경고 `#E8B4A0`(dawn coral). 순수 red 금지 |
| 폰트 | Pretendard Variable (숫자는 `tabular-nums`) |
| 타이포 스케일 | 12 / 13 / 15 / 18 / 24 / 36(타이머·히어로 숫자 56) — 11px 이하 금지 |
| 반경 | 시트 24px · 카드 16px · 버튼 pill · 아이콘 버튼 원형 44px(터치 타깃 ≥44px) |
| 아이콘 | 아웃라인 2px stroke, round cap/join, 24px 그리드 (메인 `SidebarNav` 아이콘과 동일 계열). 이모지 금지 |
| 모션 | 앱은 호흡 지시·호흡 애니메이션을 제공하지 않는다(정적 링). 값 변화 시 링 호 전환 1.2초 ease-out만 허용. `prefers-reduced-motion` 시 정지 |

### 3.3 시트 패턴 (한 화면의 핵심)
- **하단 도크**: 아이콘 버튼 4~5개(원형, 라벨 12px). 탭하면 시트가 아래에서 올라옴
  - 모바일: 바텀 시트(높이 60% / 전체 85%), 태블릿·데스크톱: 우측 사이드 시트(폭 360~420px)로 표시하며 자연 배경은 좌측에 그대로 노출
- 시트는 동시에 1개만. 닫기: 바깥 영역·스와이프 다운·닫기 버튼

## 4. 화면 구성 (시안 범위)

### 4.1 회원용 — 진행 중 화면 (기본 뷰 + 시트 3종)
| 존 | 내용 | 비고 |
|---|---|---|
| 상단 바 | 나가기 · 클래스 제목 · 진행 시간(`12:34 / 30:00`) · 연결 상태 점 | 높이 56px |
| 중앙 | **지표 링**(정적 게이지) 중앙에 핵심 지표 1개(선택 지표, 기본 이완도) + 지표명·값·단위. 앱이 호흡을 지시하는 문구·애니메이션은 두지 않음 | 링 지름 min(60vw, 46vh). 밴드 미착용 시 "밴드 없이 참여 중이에요" + "측정 없이도 수업은 그대로 진행돼요" |
| 중앙 하단 | 5분 추이 한 줄(스파크라인) + 변화 문구("5분간 +8") | 회원용 비교 장치 없음 |
| 상담사 영상 | 상담사 카메라가 켜진 경우 우상단 PiP(모바일 96×128, 태블릿·데스크톱 200×120)로 표시, 꺼진 경우 숨김 | 탭하면 확대/축소 |
| 하단 도크 | `내 상태`(6지표 시트) · `채팅`(시트, 미읽음 배지) · `조용한 신호`(시트 3버튼) · `소리`(BGM·음량) · `기기`(LINK BAND 연결·원시 데이터) | |
| 내 상태 시트 | MIND(집중·이완·감정균형) / BODY(BPM·호흡·HRV) 6개를 2×3 링으로, 선택 시 중앙 히어로 지표가 바뀜 | 태블릿·데스크톱은 우측 시트 |

### 4.2 상담사용 — 진행 중 화면 (기본 뷰 + 시트 4종)
| 존 | 내용 | 비고 |
|---|---|---|
| 상단 바 | 클래스 닫기 · 제목 · **함께한 시간 / 계획 시간** · 참가자 수(접속/전체) · 종료 버튼(경고 확인 모달) | |
| 지표 표시 띠 | 그리드 바로 위에 **"지금 보는 지표: 이완도"** 띠를 항상 표시(지표별 고정 색 + 이름 + 단위). 지표 순환(10초) 중에는 띠와 모든 타일 라벨이 동시에 바뀜 | 한눈에 "이완인지 집중인지" 식별 |
| 중앙 | **참가자 타일 그리드(세로 스크롤)**: 이름 + 선택 지표 링(숫자 + **지표명 라벨**) + 밴드 상태점. 타일은 고정 최소 크기이고 참가자가 많으면 그리드 영역 안에서 손가락으로 스크롤. 상담사가 수업을 지도하는 중이라 버튼 조작을 요구하지 않음 | 모바일 2열, 태블릿 세로 3열·가로 4열, 데스크톱 5~6열 |
| 하단 도크 | `지표 기준`(집중·이완·감정·BPM·호흡·HRV 선택 + 10초 순환 토글) · `채팅` · `미디어`(내 카메라·마이크·BGM) · `체크인`(자가 체크인 요약) · `도구`(정렬·표 보기·코드 복사) | |
| 타일 탭 | 참가자 상세 시트(6지표 + 5분 추이 + 체크인 응답) | |
| 상담사 전용 | 비교·정렬·평균은 상담사에게만 노출(회원 노출 금지) | |

### 4.3 반응형 레이아웃 요약
| 뷰포트 | 회원 | 상담사 |
|---|---|---|
| 390×844 | 세로 1열, 도크+바텀 시트 | 타일 2열, 도크+바텀 시트 |
| 834×1194 (태블릿 세로) | 세로 1열(링 확대), 우측 사이드 시트 | 타일 3열, 우측 사이드 시트 |
| 1194×834 (태블릿 가로) | 링 중앙 + 우측 사이드 시트 | 타일 4열 + 우측 사이드 시트 |
| 1280×720 (데스크톱) | 링 중앙 + 우측 사이드 시트, PiP 확대 | 타일 5~6열 + 우측 사이드 시트 |

## 5. 비범위
- 대기실·종료 화면 리디자인(별도). 이번 시안은 진행 중 화면만
- 데이터 계약·소켓·권한 변경(표현층만 교체)
- 영상 송출(LiveKit) 로직 변경

## 6. 승인 요청 사항 (결정만)
1. 방향: 평상시 "시간 + 핵심 지표 1개 + 지표 링"만 노출하고 나머지는 도크의 시트로 이동(P3)
2. 상담사 화면: 참가자 타일 중심 + 도크/시트 구조
3. 자연 배경 사진 선택(시안에 5종 적용 — 배경 변경은 구현 시 클래스별 설정 유지)
