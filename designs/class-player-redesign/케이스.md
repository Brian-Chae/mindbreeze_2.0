# 클래스 진행 화면 — 케이스 매트릭스 (A안 확정 기준)

> A안(다크 · 풀블리드 자연 + 도크/시트)을 확정 방향으로 하고, 카메라·음성·밴드·온/오프라인의 **모든 경우의 수**에서 화면이 무너지지 않는지 시안으로 검증한다.
> 코드 근거: `Session.location_type`(online/offline), `SessionParticipant.raise_hand/speaking/consent_audio/is_waitlisted/band_*`, `useLiveKit`, `useBand`, `device_status(lead_off)`, `mediaPrefs{cameraOn,micOn}`.

## 0. 공통 원칙 (모든 케이스)
| # | 원칙 |
|---|---|
| R1 | 어떤 케이스든 **페이지 스크롤 0**, 레이아웃 **자리 고정**(상태가 바뀌어도 요소가 튀지 않음) |
| R2 | **빈 칸 금지**: 없는 것은 이유 + 다음 행동 한 줄(예: "밴드 없이 참여 중이에요 / 측정 없이도 수업은 그대로 진행돼요") |
| R3 | **앱은 호흡을 지시하지 않는다**(문구·애니메이션 없음). "호흡" 지표는 실측 지표로 유지 |
| R4 | 밴드는 선택: 모든 EEG 요소는 `밴드 연결됨`에서만. 미착용은 오류가 아니라 **정상 상태**(회색·점선, 경고색 금지) |
| R5 | 경고색(코랄)은 **조치가 필요한 것**에만: 끊김, 접촉 불량(리드오프), 마이크/카메라 권한 거부, 네트워크 끊김 |
| R6 | 회원 화면은 그룹 평균·순위·±델타·종합점수 금지. 상담사 화면만 그룹 평균 허용 |
| R7 | 마이크 꺼짐 = **AI 기록에서 제외**(EEG/PPG/ACC는 유지)임을 상담사·회원 모두에게 한 줄로 알림 |
| R8 | 상태는 색만으로 전달하지 않는다: 점선/실선 + 아이콘 + 짧은 라벨 병행 |

## 1. 축(Axis) 정의
| 축 | 값 |
|---|---|
| 장소 | **온라인**(LiveKit 영상·음성) / **오프라인**(대면·같은 공간: 영상·음성 송수신 없음, 지표·소리·체크인 중심) |
| 인원 | **1:1 상담**(참가자 1명) / **그룹**(온라인 ≤20, 오프라인 다수) |
| 역할 | 회원 / 상담사 |
| 카메라 | 켜짐 / 꺼짐(사용자 선택) / 권한 거부 / 기기 없음 |
| 마이크 | 켜짐 / 꺼짐(AI 기록 제외) / 권한 거부 / **발언권 대기**(온라인 그룹 회원 기본 뮤트: 손들기→상담사 부여) |
| 밴드 | 미착용(선택) / 연결 대기 / 연결됨 / 신호 약함 / 리드오프(접촉 불량) / 끊김(재연결 중) / 배터리 부족 / 미지원 브라우저 |
| 네트워크 | 정상 / 재연결 중 / 끊김(수동 재시도) |
| 단계 | 진행 중 / 종료 확인 / 종료 후 리포트 생성 중 |

## 4. 레이아웃 분기 요약 (장소 × 역할)
| | 온라인 | 오프라인 |
|---|---|---|
| 회원 | 상담사 영상 PiP · 내 PiP(1:1) · 마이크/손들기 도크 · 밴드 도크 | **영상·마이크 UI 없음.** 도크 = 상태·채팅·소리·기기만. 중앙은 지표(밴드 연결 시) 또는 현장 안내(무밴드) |
| 상담사 | 셀프뷰 + 카메라/마이크 토글 + 발언권 관리 | **셀프뷰·카메라 토글 없음.** 녹음 마이크 상태만. 헤드 행은 지표 띠 + 요약 칩 |

## 5. 산출물 규격 (워커 공통)
- 4개 뷰포트 중 필수: `390x844`, `1280x720`. 핵심 케이스(M01·M05·M06·M10·C01·C04·C05·C09)는 `834x1194`, `1194x834`도 추가.
- 스크린샷 경로: `shots/cases/{member|counselor}-{ID}-{viewport}.png`.
- 측정: 각 케이스×뷰포트에서 `scrollHeight<=innerHeight`, 11px 이하 0, 겹침/이탈/잘림 0, 터치 ≥44px, **빈 영역(콘텐츠 없는 큰 박스) 0**, 호흡 지시 문구 `grep` 0.
- 결과표 `shots/cases/{member|counselor}-cases-fit.txt`, 전체 갤러리 `cases.html`(어시스턴트 작성).
