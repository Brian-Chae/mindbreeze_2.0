IC-06 · 회원 초대 — IC-04에서 [회원 초대]를 눌렀을 때

데스크톱은 오른쪽 사이드 시트(코드 화면이 그대로 보이게), 모바일은 아래에서 올라오는 시트. 탭 2개: 회원(센터 회원 검색·선택 → 앱 알림 '지금 입장할 수 있어요'), 이메일(비회원 포함 → 입장 링크+코드 메일). 문자·카카오톡 공유는 유료 발송이라 이번 범위에서 제외(코드·링크 복사로 대체). 회원 탭은 '최근 함께한 회원'을 맨 위에 둬 검색 없이 바로 체크. 이미 들어온 회원은 '입장함'으로 비활성. 정원 넘으면 선택 막힘. 보내고 나면 시트가 닫히고 IC-04에 초대 상태(입장함/초대 보냄/실패·다시 보내기)가 붙는다.
