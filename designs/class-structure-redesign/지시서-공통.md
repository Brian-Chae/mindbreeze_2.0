## 용어 (이전 시안과 달라진 점)
- **클래스 = 프로그램(상위)**, **세션 = 회차(하위)**. 화면 문구에서 회차는 `3회차`, `3/8`, 정식 명사로 필요할 때 `세션`(예: `이번 세션`, `세션 편집`)을 쓴다. `클래스` 를 단회차 의미로 쓰지 않는다.
- 명상 진행자 = **지도사**, 상담 = `상담`/`상담 N회차`(정식 `상담 세션`), 센터 관리자 메뉴 `구성원`. 회원 쪽 `내 클래스` / `내 상담`.
- 한 세션의 진행 강사는 **정확히 1명**(0·2명 이상 표현 금지). 클래스 강사는 1명 이상. 미배정은 편성 초안에서만 표시.
- 금지: `수업`, `오픈`, `참여하기`, `1:N`, 이모지, 문자 글리프 아이콘, 점수·%·순위·종합점수·강사 평가/순위(진행률 막대와 `3/8` 같은 횟수 표기는 허용), 호흡 지시, 영문 대문자 아이브로우, 외부 http 리소스. 상담 영역에는 정원/대기열/비회원 4자리 코드 입장 같은 명상 전용 UI를 넣지 않는다(관계 코드 입장은 비회원 상담 시안에만).
- 명상/웰니스 리포트는 서사 + 변화량만. 점수 환원 금지. 그룹 평균·순위 금지.
