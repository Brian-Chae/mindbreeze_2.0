# SDD-261 데이터 저장·업로드 현황 — 보강 시안

모든 이름·수치·시각은 가상 예시다. HTML을 직접 열 수 있으며 서버 연동은 없다.

## 변경 파일

- `build-mockups.py`, HTML 4개: 시안 생성 원본과 결과.
- `verify-mockups.cjs`: 화면·상호작용 확인.
- `screens/`: 기본 8장(1440×900, 390×844), 모바일 전체 2장, 참여자 펼침 1장, 정지 상태 2장, `qa.json`.

## 스타일 근거

기존 `frontend/src/components/layout/floating-bottom-nav.css`의 높이 66px, 좌우 16px, 어두운 배경·활성 보라색·둥근 메뉴를 반영했다. 메뉴 구성은 `frontend/src/lib/mobile-menu-swipe.ts`의 상담사 메뉴를 따른다. 메뉴 링크는 시안 이동용이다. 기존 공통 보라색·카드·배경 스타일을 유지한다.

40명 = 확인 필요 4명 + 수신 확인 35명 + 수집 제외 1명. 서버 수신과 전체 생성 범위 대조는 분리한다. 수신만으로 리포트 생성 가능을 선언하지 않는다. 폰 대기량 미확인은 0건이 아니며 서버 등록 대기와 다르다.

## 확인 결과와 한계

헤드리스 Chrome에서 4개 HTML × 두 화면 크기 가로 넘침 없음. 40명 표, 검색, 수신 확인 필터 35명, 그룹핑, 검색 빈 상태, 상세 펼침, 실시간 정지/재개, 모바일 마지막 참여자 스크롤·펼침, 오프라인 카드 재조회 안내를 확인했다. 대표 데스크톱·모바일 캡처를 시각 확인했다.

실시간 문구·시각과 정지/재개는 시안 상호작용이며 실제 폴링이나 경과 시간 계산은 없다. 기관 선택은 드롭다운 예시이며 연쇄 API 조회·권한 검증은 없다. 오프라인 재조회도 서버 요청이 아닌 화면 상태 예시다. 실제 API·실기기 앱·네트워크 복구·저장 대조·권한은 미검증이다. 폰 보류 상태는 독립 상태 예시이며 실제 서버가 아는 값으로 해석하면 안 된다.
