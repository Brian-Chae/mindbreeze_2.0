# 대시보드 재설계 기획 — 회원 · 상담사

> **대상**: 회원(내담자) 홈 · 상담사 대시보드
> **단계**: Phase 2 디자인 (리뷰 완료 → 기획 → 목업 → Brian 승인 → Phase 3 구현)
> **리뷰**: 회원/상담사 각 1개 UX 리뷰 에이전트 병렬 오케스트레이션 완료

---

## 1. 핵심 진단 (두 리뷰 공통 결론)

현재 두 대시보드 모두 **"행동"이 아니라 "정보 나열"** 로 시작한다. 사용자가 화면을 여는 실제 목적(다음 세션 입장 · 리포트 확인 · 오늘 할 일)이 스크롤 하단이나 테이블 안에 묻혀 있다.

| 화면 | 현재 최상단 | 문제 |
|------|------------|------|
| 회원 홈 | 상담사 필터 pill → 초대/다가오는/즉시 클래스 (조건부) | 다음 세션 히어로 없음, 세션 카드 3종 중복, "최근 활동 피드"는 순수 중복 노이즈, 리포트에 "상담사용"까지 노출(버그), 담당 상담사 표시 없음 |
| 상담사 대시보드 | 코드 배너 → 프로필 배너 → 통계 4개 | 진행중 클래스 즉시 입장 CTA 없음, "오늘 일정" 섹션 자체가 없음(최대 공백), 리포트 승인 워크플로 미노출, 통계 카드 dead-end, 테이블 8컬럼 가로스크롤 |

**공통 원칙**: "지금 해야 할 일 → 곧 해야 할 일 → 둘러보기" 3단 위계로 재구성. 행동(입장·승인·확인)을 최상단 0스크롤에 고정한다.

## 2. 회원(내담자) 홈 재설계

**방문 목적 2가지로 수렴**: ① 다음 세션 언제·어떻게 입장(참여코드) ② 지난 세션 리포트 확인.

### 레이아웃 (위 → 아래)

1. **헤더** — 인사 + 담당 상담사 연결 칩(아바타·이름·"연결됨") + 알림. → 연결 상태 상시 노출(현재 홈에 없음)
2. **[히어로] 다음 세션** — 퍼플 브랜드 배경, 화면 유일 최강조.
   - 라이브 카운트다운 · 요일/시간 · 담당 상담사 · 참여코드(복사 버튼) · **입장하기** CTA
   - 상태 ready/in_progress면 "지금 입장 가능" 전환
   - LINK BAND는 "선택 착용" 한 줄로 축소(강제 느낌 금지)
3. **[조치 필요] 초대된 클래스** — 초대 있을 때만. 수락/확인 CTA
4. **[세션 후] 미확인 리포트** — 내담자용(type=client)만, NEW 배지 + 확인 CTA + 생성중 배지
5. **[둘러보기] 이번 주 일정** — 컴팩트 리스트 3~5건(캘린더는 "달력 보기" 토글로 보조화)
6. **[아카이브] 지난 리포트 전체 보기** — 링크 1줄

### 제거/수정
- ❌ "최근 활동 피드" 삭제 (세션·리포트 중복 나열, 행동 없음)
- ❌ 세션 카드 3종 통합 → 단일 세션 섹션 (시간·참여코드 위치 고정)
- ❌ 상담사 1명일 때 필터 pill 숨김 (죽은 UI)
- ✅ 리포트 카드 onClick → 상세 연결
- ✅ 카운트다운 라이브화, 참여코드 라벨·복사 일원화, 로딩 스켈레톤

## 3. 상담사 대시보드 재설계

**방문 목적**: 업무 시작점 — 지금 뭘 해야 하는지 0스크롤에서 결정.

### 레이아웃 (위 → 아래)

1. **헤더** — 인사 + 소속 + **[+ 새 클래스]**(primary) [세션 목록](보조)
2. **[1] 지금 할 일 (Action Queue)** — 최상단 행동 큐
   - 진행중/오픈 클래스 카드(제목·참여자·경과) + **[입장]** 버튼 + 코드 복사
   - 승인 대기 리포트 N건 배너 → [리포트 검토]
   - 생성 실패 리포트 경고(있을 때만, 레드)
3. **[2] 오늘 · 다가오는 일정** — scheduled_at 기반 타임라인 (현재 완전 누락)
   - 시간순, 30분 임박 강조(퍼플 액센트 바) + [입장]/[준비]
4. **[3] 요약 타일** — 클릭 드릴다운형(dead-end 제거): 진행중 / 승인 대기 / 오늘 예정 / 총 참여자
5. **[4] 내 클래스** — 그룹 헤더(진행중·오픈 / 예정 / 지난 세션) + 우선순위 정렬 + 5컬럼 축소
6. **[5] 접이식 상담사 코드** — 최하단 한 줄 요약 (상단 공간 회수)

### 제거/수정
- ❌ 통계 4카드 dead-end → 드릴다운 타일로 전환
- ❌ 상시 코드 배너 → 접이식
- ❌ 8컬럼 테이블 → 5컬럼(제목/유형/상태/참여자/액션)
- ✅ 리포트 상태 4축 노출(생성중/검토필요/승인됨/실패) — 백엔드 필드 재사용
- ✅ 세션 목록(SessionListPage)과 역할 분리: 대시보드=지금 할 일+오늘, 세션목록=전체 편집

## 4. 공통 디자인 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| 배경 | `#F7F4F0` (크림) | 페이지 배경 |
| 카드 | white + `#E8E3EC` 보더 | 기본 카드 |
| 퍼플 | `#5F0080` | 주 액센트·히어로·CTA |
| 퍼플 연 | `#F5EDFC` | 보조 강조 배경 |
| 민트 | `#01f0c8` | 진행중/라이브 상태만 제한 사용 |
| 텍스트 | `#1F1F1F` / `#6F6F6F` | 주 / 보조 |
| 폰트 | Pretendard | 전체 |

**위계 규칙**: 최강조(퍼플 채움)는 "다음 세션 히어로(회원) / 지금 할 일(상담사)" 단 하나에만. 나머지는 white/연보라로 낮춘다.
