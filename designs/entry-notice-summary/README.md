요약은 새로 작성한 UI 문구이며, 법적 고지 원문은 상세에서 그대로 제공한다. 기본 시연 조건에 해당하는 원문은 아래와 같이 모두 남긴다.

| 영역 | 화면에 남는 핵심 | 상세에 보존하는 원문 |
|---|---|---|
| 기록 | 녹음·뇌파·영상 / 뇌파는 LINK BAND를 쓸 때만 / 영상은 카메라를 켤 때만 | “녹음과 AI 기록”, “음성을 녹음하고 AI가 기록지를 만들어요”, “뇌파 측정(LINK BAND를 쓸 때만)”, “영상(카메라를 켤 때만)” |
| 열람 | 지도사·관리자 / 관리자는 명상 리포트만 열람해요 | 진행 지도사·등록된 다른 지도사의 기록지·리포트 열람, 비진행 지도사에 대한 원문·원본·실시간 개인 뇌파 제한, 참관 지도사 조작 제한, 관리자 수정·승인 불가 및 상담 본문 비공개: 원문 2개 단락 전체 |

| 하단 | “확인하고 계속하기”, “리포트 반영은 클래스가 끝나기 전까지 바꿀 수 있어요.”, “개인정보 처리방침 보기” | 변경 가능 시점은 리포트 시트에도 중복 표시 |

연구 시트의 원문 5개 단락:

1. 동의하면 비식별 처리한 뇌파·맥박·움직임 데이터와 지표, 암호화한 이름 ID·성별·생년·월이 삭제 기한 없이 계속 보관돼요
2. 이메일·전화번호·이름·녹음 내용은 보관하지 않아요
3. 동의하지 않아도 클래스에 참여할 수 있어요
4. 철회하려면 운영팀에 요청해 주세요
5. 비식별 처리해도 다른 정보와 결합하면 본인을 알아볼 가능성이 완전히 없지는 않아요

원본 사본에는 모든 조건 분기까지 보존되어 있다. 시안은 온라인·AI 켜짐·명상·밴드 선택·90일·리포트 제외 기본 fixture만 재현한다. 실제 구현 때 아래 조건을 기존대로 유지해야 한다:

- `retentionDays === null`: “기록 원본(뇌파·음성·영상)은 정해진 기간이 지나면 삭제돼요”. 타일도 숫자를 추정하지 않고 “정해진 기간 후 삭제”로 표시.
- `aiEnabled=false`: “녹음”, “음성을 녹음해 클래스 기록으로 보관해요” / 오프라인이면 “현장 대화를 녹음해 클래스 기록으로 보관해요”. AI 켜진 오프라인은 “현장 대화를 녹음하고 AI가 기록지를 만들어요”.
- `bandMode=none`: 뇌파 항목 제외. 오프라인: 영상 항목 제외. 명상 외: 명상 강사팀 열람 고지 조건 유지.
- `reportChoice=null`: 기본 미선택 상태와 “고르지 않으면 반영하지 않는 것으로 진행돼요”를 실제 화면에서 유지. 이번 시연은 기존 fixture처럼 excluded이며 제품 기본값을 바꾸는 제안이 아니다.
- 저장 실패: “연구 동의를 저장하지 못했어요. 미동의로 진행해요.”를 화면에 그대로 표시. 어떤 선택·저장 실패도 입장을 차단하지 않는다.

## 구현 예상 범위

- `NoticeStepView.tsx`: 고지 요약 UI + 기존 props에 따른 상세 내용 분기 + 현재 세 카드에 상세 진입 버튼.
- 전용 요약/상세 컴포넌트 분리 가능. 원문 문자열은 하나의 출처를 공유해 요약 시트와 고지가 갈라지지 않게 한다.
- `member-flow.css`: 해당 화면에 한정한 15/24 본문·13/20 보조·44px 터치와 반응형 배치. 공용 CSS 전역 수정은 피한다.
- `FlowSheet`/`PlayerSheet` 재사용 우선. 기존 데스크톱은 사이드 시트 판단 로직이 있으므로 이 화면에 한해 하단 시트를 쓰는 옵션 필요 여부 검토. 시안은 두 너비 모두 하단 중앙 시트다.
- 리포트 상태/연구 동의 저장 API·서버·DB 변경 없음. 시트 확인 버튼은 읽기 닫기만 수행하며 동의를 대신하지 않는다.
- 원문의 조건부 분기, 저장 실패, 기본 미선택, 동의하지 않고 계속하기, 긴 이름/제목, 폰트 확대와 작은 화면, 포커스·Escape·스크린리더를 회귀 검증한다.
- 제품에서는 기존 개인정보 처리방침 링크 유지. 시안의 정책 링크/이전/나가기/계속하기는 설명만 표시하고 실제 이동·입장·저장은 하지 않는다.
