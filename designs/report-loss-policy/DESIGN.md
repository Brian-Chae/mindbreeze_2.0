# 리포트 데이터 유실 표시 — 디자인 스펙 (Phase 2)

> MIND BREEZE 2.0 · 세션 리포트의 EEG/전사 데이터 유실을 "표시"하는 UI 설계.
> 기존 리포트(서사 구조 · 7지표 · `not_measured` 숨김) 위에 유실 표시 레이어를 **얹는** 설계. 재설계가 아니다.
> 목업: [`mockup.html`](./mockup.html) — 뷰(Counselor/Client) × 상태(①~⑥) 전 조합 리뷰 가능.

### 1.2 신규 · 유실 전용 토큰

> 유실(loss)은 **중립 그레이 + 빗금(hatch)**을 기본 언어로 쓰고, 고지(배너)에는 **웜 로즈 warning 톤**을 쓴다. 브랜드 퍼플/민트는 "유효 데이터"에만 사용해 유실과 색으로 분리한다.

| 역할 | 토큰 | 값 | 용도 |
|---|---|---|---|
| 유실 그레이 | `--loss-gray` | `#A2A3AD` | 유실 지표 값/라벨 텍스트 |
| 유실 저채도 배경 | `--loss-gray-soft` | `#E8E8EA` | 커버리지/바 트랙 바탕 |
| 빗금 스트로크 | `--loss-hatch` | `#C4C4CC` | 45° repeating-linear-gradient 빗금 |
| 배너 배경 | `--loss-banner-bg` | `#FFF4EC` | 유실 고지 배너 바탕 (웜 로즈) |
| 배너 보더 | `--loss-banner-border` | `#F7C9A8` | 배너 외곽선 |
| 배너 텍스트 | `--loss-banner-fg` | `#A5472A` | 배너 제목/강조 (가독 로즈) |
| 배너 아이콘 | `--loss-banner-icon` | `#E6593D` | 좌측 4px 바 + 경고 아이콘 |
| 참고용 배경/보더/텍스트 | `--ref-bg` / `--ref-border` / `--ref-fg` | `#FBF6E6` / `#ECD98A` / `#8A6A14` | "참고용" 라벨·고지 (웜 옐로우 틴트) |

**빗금 패턴 정의 (유실의 시각적 시그니처):**
```css

background-image: repeating-linear-gradient(45deg, transparent 0 5px, var(--loss-hatch) 5px 7px);
```

## 2. 컴포넌트 스펙

### 2.1 신뢰도 뱃지 (Confidence Badge)

- **구조**: `pill` · [컬러 dot 8px] + 라벨 텍스트(caption/600).
- **변형(variant)**: `high`(민트 dot·그린 톤) / `medium`(옐로우) / `low`(로즈). `none`은 뱃지 미표시(배너가 대체).
- **상태**: 정적. 전 구간 유실(③)에서는 신뢰도 뱃지 대신 유실 배너로 대체(`none`).
- **노출**: Counselor·Client 공통. 라벨 문구는 "신뢰도 높음/보통/낮음"으로 뷰 동일.

### 2.2 사유 칩 (Reason Chip)

- **구조**: `pill` · [12px 아이콘] + 사유 텍스트(11/500). 외곽선형.
- **변형**: 기본(중립 보더) / `warn`(로즈 틴트 — 유실 사유일 때). 아이콘: `연결 끊김`=link, `측정 구간 짧음`=clock, `저품질 신호`=wave.
- **상태**: 복수 칩 가로 나열("사유" 라벨 + 칩들).
- **노출**: **Counselor 전용**. Client에는 사유 코드·칩을 노출하지 않는다(차분한 문장으로 대체).

### 2.3 측정 커버리지 바 (Coverage Bar)

- **구조**: 헤드(라벨 + 수치) → 16px 높이 `pill` 트랙(측정/유실 세그먼트 가로 분할) → 레전드.
- **세그먼트**: 유효=퍼플 그라디언트(`lavender→primary`), 유실=그레이+45° 빗금.
- **변형**: `counselor`(수치 "4.3분 중 2.0분 측정 · 47%" 노출 + 측정/유실 레전드) / `client`(수치 비노출, 막대 + "측정됨/측정 안 됨" 레전드 + 차분한 캡션).
- **상태**: 정상(①)·전 구간 유실(③ 100% 빗금)에서는 `metricsMode`에 따라 노출/비노출. 부분·저신뢰·복구에서 노출.

### 2.4 유실 고지 배너 (Loss Banner)

- **구조**: 좌측 4px 아이콘 바 + 경고 아이콘(22px) + [제목(14/700) + 본문(13)]. `md` radius.
- **톤**: warning/rose (`--loss-banner-*`).
- **변형**: `eeg-loss`(시나리오 ③: 전 구간 유실) / `stt-fail`(시나리오 ⑥: 요약 실패). 뷰별 문구 분기(아래 §4).
- **상태**: 해당 시나리오에서만 렌더. 그 외 DOM 미삽입.
- **원칙**: "측정 시도했으나 연결 끊김으로 유실" — **숨기지 않고 명시**.

### 2.5 "참고용" 라벨 + 매우 낮음 고지 (Reference Label & Notice)

- **구조**: `pill` 라벨 "참고용"(옐로우 틴트, 700) + 점선 테두리 고지 박스("데이터 유실로 신뢰도 매우 낮음 …").
- **변형**: 라벨은 Counselor·Client 공통 노출 가능하나, **고지 박스 상세 문구(커버리지·검토 권고)는 Counselor 전용**. Client는 "측정된 구간이 적어 참고용으로만 안내" 수준의 문장.
- **상태**: 시나리오 ④(커버리지 <50%). 사유 칩과 **병행 노출**(연결 끊김 + 측정 구간 짧음).

### 2.6 복구 대기 배지 (Recovery Pending Badge)

- **구조**: `pill` · [회전 스피너 12px] + "복구 대기 중 · 남은 시간 {remain}". info 블루 틴트.
- **변형**: `counselor`(남은 시간·재처리 예정 명시) / `client`("뇌파 분석을 마무리하는 중이에요" — 시간/기술어 비노출).
- **상태**: 시나리오 ⑤(provisional). 이 상태의 지표는 **잠정값**이며 커버리지·지표를 함께 노출하되 "잠정" 맥락을 유지.

### 2.7 EEG 7지표 카드 (참고 — 기존 컴포넌트에 유실 상태 추가)

- **기본**: [지표명 + 값] + 퍼플 그라디언트 바. 7지표: 집중도·이완도·스트레스·몰입도·안정도·좌우뇌 균형·정신적 피로.
- **추가 상태**:
  - `partial`: 측정 구간 기준 저채도 퍼플 바 + "측정 구간 기준" 주석. 일부 지표는 `구간 부족`으로 산출 제외.
  - `lost`: 점선 테두리 + 빗금 바 + "측정 안 됨" + "유효 구간 없음" 주석. **숨기지 않음**.

### 2.8 타임라인 (참고 — 기존 컴포넌트에 유실 구간 추가)

- 세션 길이 대비 가로 트랙. 유효=퍼플 라인, 유실=빗금. 캡션으로 빗금 의미 설명(뷰별 문구 분기).

## 3. Counselor / Client 노출 차등 표

> 확정 결정 A1(Client 명시+차분+이유 설명) / B2(매우 낮음 명확 고지) / C2(Counselor 관리 정보 노출) 반영.

| 요소 | Counselor | Client |
|---|---|---|
| 신뢰도 뱃지 | ✅ 노출 | ✅ 노출(동일 라벨) |
| 사유 칩(연결 끊김/구간 짧음/저품질) | ✅ **노출** (리뷰·발행 판단 근거) | ❌ 비노출 |
| 커버리지 수치("47%", "4.3분 중 2.0분") | ✅ **노출** | ❌ 비노출(막대만) |
| 커버리지 막대 | ✅ 노출 | ✅ 노출(측정됨/측정 안 됨 레전드) |
| 유실 고지 배너 | ✅ (관리 톤 문구) | ✅ (차분·이유 설명 문구) |
| "매우 낮음" 상세 고지(검토 권고) | ✅ **노출** | ❌ 비노출 ("참고용으로만 안내" 수준) |
| 복구 대기 — 남은 시간/재처리 | ✅ **노출** | △ "마무리하는 중" (시간·기술어 비노출) |
| 기술 용어(사유 코드·윈도우·provisional) | ✅ 가능 | ❌ 금지 |
| 종합점수 단일 숫자 | ❌ 금지 | ❌ 금지 (서사·변화량 위주) |

**Client 문구 원칙(A1)**: 유실을 명시하되 차분하게, 이유를 최대한 설명. 예) "중간에 연결이 끊겨 뇌파 일부 구간은 측정되지 않았어요. 측정된 구간으로 안내드려요."

## 4. 상태별(①~⑥) 표시 규칙 매핑 표

| 상태 | 조건 | 신뢰도 뱃지 | 사유 칩 | 커버리지 바 | 유실 배너 | 참고용/매우낮음 | 복구 배지 | 7지표 | 타임라인 | AI 요약 |
|---|---|---|---|---|---|---|---|---|---|---|
| **① 정상** | 전 구간 수집 | high | — | —(숨김) | — | — | full | 전 구간 유효 | 노출 |
| **② 부분측정** | ≥50%, 끊김(예 47%*) | medium | 연결 끊김 | ✅ 측정/유실 | — | — | partial(+일부 제외) | 유실 구간 빗금 | 노출 |
| **③ 유실** | 0 윈도우(전 구간 끊김) | none | 연결 끊김 | ✅ 100% 빗금 | ✅ "측정 시도했으나 연결 끊김으로 유실" | — | **lost(숨김 아님)** | 전 구간 빗금 | 노출 |
| **④ 매우 낮음(B2)** | <50%(예 31%) | low | 연결 끊김 + 측정 구간 짧음 | ✅ 측정/유실 | — | ✅ "참고용" + "유실로 신뢰도 매우 낮음" | partial | 유실 구간 빗금 | 노출 |
| **⑤ 복구 대기** | 시스템 오류·복구 가능(provisional) | medium(잠정) | 저품질 신호 | ✅ 측정/유실 | — | — | ✅ "복구 대기 중(남은 시간)" | partial(잠정) | 유실 구간 빗금 | 노출 |
| **⑥ STT 실패** | 전사/요약 없음 | high(EEG 영향 없음) | — | — | ✅ **상담 본문**에 "요약 실패" 배너 | — | — | full | full | **숨김 + 원본 전사 유지** |

\* 브리프 예시는 "50% 이상"이 부분측정이나, 목업에서는 커버리지 바의 유실 표현을 명확히 보여주기 위해 47%를 샘플 수치로 사용. 실제 임계값(≥50%=부분/medium, <50%=매우 낮음/low)은 표의 "조건" 열을 따른다.

### 4.1 정상 vs 비정상 구분 (최상위 원칙)

| 구분 | 경로 | 처리 |
|---|---|---|
| **밴드 미착용** (`not_measured`, opt-out) | 정상 | EEG 보조 섹션 **전체 DOM 미노출(숨김 유지)** |
| **유실** (②~⑤) | 비정상 | 숨기지 않고 **유실 명시** (배너/뱃지/커버리지/빗금) |

> 두 경우를 **절대 동일하게 처리하지 않는다.** `not_measured`는 "측정 안 함(정상)"이고, 유실은 "측정하려다 실패(비정상)"다. ⑥ STT 실패는 EEG가 아닌 상담 본문 AI 요약에만 영향을 준다(EEG는 정상 표시).

## 5. 배치 규칙 (기존 리포트 구조 위 삽입 지점)

```
Cover ───────────── 밴드 상태 요약 태그(상태별 치환, 점수 환원 없음)
Narrative ───────── 종합→몸→마음→마무리 (서사·변화량; 유실 UI 없음)
Session 본문 ────── ⑥일 때 AI 요약 숨김 배너 + 원본 전사 유지
EEG 보조 ───────── [우상단] 신뢰도 뱃지 / 참고용 / 복구 배지
                    [상단] 유실 고지 배너(③)
                    [사유] 사유 칩 행 + 매우낮음 고지(④, counselor)
                    커버리지 바 → 7지표 → 타임라인
```

- EEG 유실 UI는 **EEG 섹션 내부 상단**에 집중. 서사/변화량 섹션은 유실 표시로 오염시키지 않는다(서사는 자기보고 종합이므로).
- 점수 환원 금지: 커버·EEG 어디에도 종합점수 단일 숫자를 노출하지 않는다.
- 다크 테마 아님: 화이트/크림 리포트 톤 유지.
