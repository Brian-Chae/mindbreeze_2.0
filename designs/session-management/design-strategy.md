## 1. 컨셉: "Clinical Calm, Engineered Precision"

심리상담·명상·뇌파측정이 한 화면에 공존하는 제품이다. 두 감각을 동시에 만족해야 한다.

- **차분함(Calm)** — 내담자와 상담사가 머무는 공간. 다크 캔버스 + 절제된 모션 + 호흡하는(breathe) 빈 상태.
- **정밀함(Precision)** — EEG는 의료 인접 데이터. 모노스페이스 수치, 단색 바, 정렬된 그리드로 "측정 도구"의 신뢰감.

이 둘을 잇는 장치가 **타이포 위계**다. 우아한 명조(Gowun Batang)가 "사람의 영역"(제목·서사)을, 기술적 산세리프/모노(IBM Plex)가 "데이터의 영역"을 맡는다. 컬러는 위계를 만들지 않는다 — *구조와 의미*에만 쓴다.

### 왜 다크인가
브랜드 원색은 라이트 표면(#FAFAFA·#F5EDFC)이지만, 기획의 명시 방향이 **Dark/elegant/minimal**이고 Live 화면은 화상·뇌파 시각화가 오래 응시되는 환경이다. 다크 캔버스는 (1) 화상/파형의 명암 대비를 살리고 (2) 장시간 응시 피로를 줄이며 (3) `#5F0080`을 *빛나는 액센트*로 격상시킨다. Anti-Slop 규칙(퍼플 그라디언트 on 화이트 금지)과도 정합한다.

## 2. Anti-Slop 적용 결정 기록

| 규칙 | 어떻게 지켰나 |
|---|---|
| no glassmorphism | 모달 백드롭은 `rgba(8,5,11,.72)` **단색 디밍**. backdrop-blur·bg-white/10 전무. 패널은 불투명 `--bg-elev`. |
| no rainbow gradients | 면 그라디언트는 브랜드 글리프·아바타의 *동일 색상 명도 그라디언트(purple→purple)* 뿐. EEG는 무지개 대신 **3 의미축(focus/calm/stress) + 톤스케일**. |
| no fake dashboards/charts | EEG는 실제 제품 기능 → 제거 불가. 대신 ① `샘플 데이터` 배지 명시, ② 장식용 가짜 차트 금지(파이·도넛·면적 차트 없음), ③ 정직한 스파크라인 파형 + 단색 진행 바만. |
| no stock-photo hero | 히어로 섹션 없음. 비디오 타일은 `{{COMFYUI_BG}}` 플레이스홀더로 표기(실제 화상 자리). |
| 타이포 우선 | 모든 화면의 위계가 폰트 크기·굵기·패밀리로 성립. 컬러를 흑백 처리해도 위계가 무너지지 않음. |
| dark + purple accent | 화면당 액센트 1~2개. 나머지는 무채색 + 퍼플 톤 그레이. |

> **판단**: "fake charts 금지"의 본의는 *신뢰를 가장하는 장식*의 배제다. EEG 대시보드는 기획의 핵심 기능이므로 *정직하게* 구현하되 예시성을 명시했다 — 규칙의 자구가 아니라 의도를 따랐다.

## 3. 화면별 의도

### ① 세션 관리 대시보드
- **이중 시야**: 좌측 주간 캘린더(공간적 일정 파악) + 우측 오늘 아젠다(행동 큐). 캘린더의 `now-line`과 진행중 블록의 라이브 글로우로 "지금"을 즉시 인지.
- **필터는 도구열로**: 유형/온오프라인/상태 셀렉트 + 뷰 세그먼트(주간/일간/목록)를 헤더 한 줄에 정렬. 색 도트로 유형을 *병기*(색만으로 전달 금지).
- **세션 카드**: 좌측 3px 유형 액센트 바 + 상태 배지 + 진행방식 태그(온/오프·인원·LINK BAND). 매트릭스 정보를 카드 한 장에 압축.

### ② 세션 생성/수정 폼
- **좌 입력 / 우 실시간 요약**의 분할. 선택을 바꾸면 우측 프리뷰 카드가 "이 세션은…"으로 결과를 서술 → 매트릭스 조합의 결과를 *문장*으로 확인.
- **유형 4종 + 커스텀**: 4 카드 + 하단 커스텀 입력칸(기타 선택 시 활성). 단계 번호(1·2·3·4)로 폼의 리듬을 잡음.
- **매트릭스 노트**: 온/오프 × 인원 × LINK BAND 조합이 Live 화면을 어떻게 바꾸는지 퍼플 틴트 박스로 명시 → 설정의 *결과*를 미리 학습.

### ③ Live (온라인)
- **좌 화상(1.55) / 우 패널(1)**. 우측은 탭(EEG/메모/참여자)으로 전환, 하단 고정 녹음 바.
- **EEG 대시보드**: Fp1·Fp2 파형 → 핵심 3 KPI(집중/이완/스트레스) → 10종 지표 리스트. 정보 밀도를 위→아래 굵기 순으로 배치.
- **라이브 신호**: REC 타이머(모노) + 펄스 도트 + 이퀄라이저 바. "녹화 중"을 과하지 않게, 그러나 분명하게.

### ④ Live (오프라인 Solo)
- **③과 동일 골격**, 비디오 영역만 *비활성 플레이스홀더*로 교체("Solo 방 · 화상 없음" + breathe 링 + 녹음 파형). 우측 패널·녹음 바·EEG는 완전히 동일.
- **의도**: 온/오프라인 전환이 *레이아웃 학습 비용 0*이 되도록. 다른 건 "화상의 유무"뿐임을 시각적으로 증명.

### ⑤ 참여자 초대 모달
- **3 탭(이메일/링크/코드)**. 링크 탭은 복사 필드 + 권한 토글(링크 참여/대기실 승인/만료) + 초대된 참여자 목록.
- **단색 디밍** 뒤 대시보드. blur 없이도 위계가 성립하도록 백드롭 농도로 분리.

## 4. LINK BAND 매트릭스의 UI 표현

기획의 핵심 복잡도는 **온/오프 × 1:1/1:N × LINK BAND(미사용·필수·선택)** 조합이다. 디자인은 이를 *상태 머신*으로 다룬다.

- **공통 골격 1개**(Live shell) + **상태별 슬롯 교체**: 비디오 슬롯(온라인 타일 ↔ Solo 플레이스홀더), EEG 슬롯(대시보드 ↔ 미사용 빈 상태), 인원 슬롯(단일 ↔ 그리드).
- **LINK BAND 미사용**: EEG 패널 자리에 "측정 안 함" 빈 상태(코드: `if(bandConnected)` 가드 — 기능은 차단하지 않음).
- **필수/선택 차이**: 필수=미착용 시 시작 차단 경고 / 선택=착용 토글 + 미착용 시 회색.

→ 한 벌의 컴포넌트로 8+ 조합을 커버. 유지보수·학습 비용 모두 최소화.

## 5. 토큰·구현 핸드오프

- **컬러/타이포/스페이싱**: `DESIGN.md` §2~5의 CSS 변수가 `decks/index.html` `:root`에 그대로 구현됨 → 프론트엔드 토큰화 시 1:1 이식 가능.
- **폰트**: Google Fonts(Gowun Batang / IBM Plex Sans KR / IBM Plex Mono). 프로덕션은 self-host 권장.
- **컴포넌트 매핑(shadcn/ui)**: Button/Badge/Tabs/Dialog/Select/Toggle/Card에 본 토큰 적용. 세그먼티드·EEG 셀·캘린더 블록은 커스텀.
- **상태색 토큰**은 의미 기반(`--st-*`, `--type-*`, `--eeg-*`) → 다크/라이트 테마 전환 시 캔버스 변수만 교체.
- **ComfyUI 자산**: `{{COMFYUI_BG}}` 표기 위치 = 화상 타일 배경. 분위기 배경이 필요하면 동일 토큰으로 추가 생성.

## 6. 데모 사용법
`decks/index.html`을 브라우저로 연다. `←`/`→`(또는 Space/PageUp·Down, Home/End)로 5화면 이동, 하단 도트 클릭으로 점프. 1920×1080 스테이지가 창 크기에 맞춰 자동 스케일된다.

## 7. 후속 제안 (이번 범위 밖)
- 1:N(그룹) Live의 SFU 그리드 + 참여자별 EEG 탭 상세.
- LINK BAND *미사용* Live 화면의 EEG 빈 상태 풀 디자인(현재는 규칙만 정의).
- 라이트 테마 토큰셋(브랜드 라이트 표면 활용) 병행 산출.
- 세션 종료 → 리포트 생성 트랜지션 플로우.
