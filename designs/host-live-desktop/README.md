2026-10-22 · 디자인 검토용 · 제품 코드 변경 없음.

## 작업 기준

- 모바일 SDD-235 동작을 기준으로 신호 줄을 모든 화면의 도크 바로 위에 유지한다.
- A: 최대 1000px 동일 컬럼, 기존 헤드 비율 유지, 도크 4개(지표 기준·채팅·미디어·도구). 수업 상태는 참가자 영역 머리글에서 연다.
- B: 최대 1200px 동일 컬럼, 데스크톱 셀프뷰를 참가자 그리드로 이동, 도크 4개(수업 상태·채팅·미디어·도구). 지표는 상단 카드에서 연다. 모바일 헤드 구조는 유지한다.
- 체크인 집계·상세는 수업 상태 안에 포함. 독립 상시 체크인 칩과 도크 항목 제거.
- 현재 화면은 SDD-235의 실제 컴포넌트 하니스 캡처를 그대로 비교 자료로 사용한다. 운영 실사용 캡처가 아니며 가상 데이터다.
- 기존 player-tokens.css 및 host-player.css 색·형태를 사용. 제안의 본문 15px 이상, 보조 13px 이상, 터치 44px 이상, 블러 없음.
