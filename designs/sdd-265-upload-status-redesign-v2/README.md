# SDD-265 — 숫자 중심 상황판 2차 시안

가상 데이터만 사용하는 자체 완결 HTML이다. 제품 코드·API 동작을 의미하지 않는다. 1차 안 3의 조치 대상 우선 그룹, 보라 #5F0080, 배경 #F7F4F0, 20px 카드, 테두리 #E8E2ED를 계승했다.

| 파일 | 내용 |
|---|---|

## 피드백 반영

| 요청 | 반영 |
|---|---|
| 숫자 우선 | 상세 4칸 + 전송 막대, 조치 문장 1줄 |
| 확인할 곳 먼저 | 확인 2회차 → 측정 중 1회차 → 정상 회차 접힘 |
| 최근 10건 | 목록 5건씩 2페이지, 회원 10회차 선택 |
| 조치 대상 우선 | 40명 중 2명 먼저, 모두 도착 36명은 접힘 + 10명 페이지, 대기·제외 별도 접힘 |
| 측정 길이 | 회차 52분 + 전체 40명 합계 34.7시간 구분 |
| 집계 미확인 | 전체를 단정하지 않고 확인된 38명 기준 94% 표시, 미확인 1명·제외 1명 별도 |
| 정상 | 모두 도착, 추가 조치 없음이라는 사실 라벨 |
| 상태 변주 | 상세·회원의 상태 예시 선택: 모두 도착/일부 확인/집계 대기/측정 중/오프라인 |

## 용어 치환표

이 표의 왼쪽 열은 검증 대상 화면에 노출하지 않는 기존 용어다.

| 기존 | 화면 표현 |
|---|---|
| feature | 분석 데이터 |
| 원시 / raw | 측정 기록 파일 |
| EEG / PPG / ACC | 뇌파·맥박·움직임 (참여자 접힘 내부만) |
| 업로드 / 수신 | 전송 현황 / 서버에 도착 |
| 확인 필요 | 코치: 확인할 사람 2명 / 회원: 확인 필요 |

HTML 2개에 아래 명령 실행 결과 **0건**, 종료 코드 1(매칭 없음) 확인.

```sh
rg -ni 'feature|원시|raw|EEG|PPG|ACC|업로드|수신|종합점수|좋음|나쁨|보증' designs/sdd-265-upload-status-redesign-v2/*.html
```

## 높이 비교 — Chrome headless 실측

뷰포트 1440×900 / 390×844, full-page PNG 및 documentElement.scrollHeight 기준. 가로 넘침은 모두 0px.

| 화면 | A 1440 | A 390 | B 1440 | B 390 |
|---|---:|---:|---:|---:|
| 코치 목록 | 1015 | 1049 | 917 | 903 |
| 회차 상세 | 938 | 1035 | 924 | 1049 |
| 회원 | 900 | 844 | 900 | 844 |

1차 README의 안 3 모바일 목록 실측은 1149px(브리프의 1131px와 차이 있음). 같은 README 기준 A 100px, B 246px 감소. 정상 그룹 기본 접힘·5건 페이지 기준이며 전체 펼침 높이 제한을 의미하지 않는다. 상세의 상단 숫자·전송·조치 대상은 데스크톱 첫 화면 안에 배치했다.
