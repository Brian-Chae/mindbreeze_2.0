# 확정안 구현 전 검증

제품 수정 전 작성. 이전 A안 구현은 현재 dirty 상태로 존재하며 최종 승인 시안으로 대체한다.

1. 제목 원문(날짜·시각 포함) 보존, 긴 제목만 ellipsis. 코드가 밀리지 않는다.
2. 원문 4자리 0482 유지, 잘못된/없는 코드는 생략. stats=null은 접속만 생략.
3. 코드 탭 native modal, 복사 기존 콜백·성공 피드백, Esc/닫기/포커스 복귀.
4. 상단 X 없음. 도구 시트 화면 나가기와 클래스 종료 별도 액션 유지.
5. 320/390/1194/1440 짧은/긴 제목에서 overflow·제목/코드 겹침·박스 밖 액션 없음.
6. 동일 바의 두 행과 종료 전용면/라운드 실제 CSS 확인. 모바일 종료44px 이상, 코드 터치44px.
7. 집중/기존 호스트/shared 테스트·프로덕션 빌드. 실서버/DB/LiveKit 배포는 제외.
